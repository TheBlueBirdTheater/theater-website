# Ludus Docs

This skill bundles an unofficial, community-maintained Markdown mirror of the
public Ludus support documentation (https://support.ludus.com/, 811
articles), so questions about Ludus can be answered from the real docs
instead of guessed at.

This skill is intentionally generic to the Ludus platform — it contains no
information about any specific venue's own integration or configuration.

## How to use this

1. Grep `reference/` for the relevant keyword, or open the matching
   category folder below directly — don't read the whole corpus.
2. For the full list of articles with links, see
   [reference/INDEX.md](reference/INDEX.md).
3. Each reference file keeps its original `source_url` in its frontmatter;
   cite that URL when you use it, and prefer it over guessing when the
   local file might be stale.
4. If nothing here answers the question, say so rather than inventing Ludus
   behavior — this corpus can lag behind the live docs.
