# Set availability dates on Add-Ons

When adding or editing an Add-On, you can set availability dates. This allows you to control when the Add-On will become available and when sales will end. This is especially useful if you want sales for Add-Ons to end before the sales are done for the overall event/class.

### To set the availability dates:

1.  Navigate to the event, collection, or class where you have the Add-Ons attached. Then, next to the title, click **Pricing** --> **Add-Ons.**
    
2.  Either create a new Add-On by clicking **+Add-On** or edit an existing Add-On by clicking **Edit**.
    
3.  Scroll to the bottom of the page and click **Advanced Options**.
    
4.  Next to the section titled **Availability**, choose a time for **Sale Starts** and **Sale Ends**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/LtrLPFaZb-XiEXfDDiTVO_screen-shot-2023-09-06-at-91540-am.png?format=webp "Document image")
    
5.  Click **Save Changes** at the bottom of the page.
