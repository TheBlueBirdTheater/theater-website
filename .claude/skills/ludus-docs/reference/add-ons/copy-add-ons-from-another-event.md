# Copy Add-Ons from another event

When setting up Add-Ons for a new event/collection, you might have ones that are similar to those of a previous event (i.e., you sell the same type of flowers for every event). Within Ludus, you can copy over the general settings of an earlier event's Add-Ons.

1.  Go to the event/collection for which you'd like to set up Add-Ons.
    
2.  Next to the title, click **Pricing** --> **Add-Ons**.
    
3.  Click **+Add-On** \--> and then **Copy from Another Event**
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-QehJa8F5yZG4YDXSU1bal-20250328-182511.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-lDoZgkqjIDm7Ga7_BndeO-20250328-182527.png?format=webp "Document image")
    
4.  Choose the event that housed the Add-Ons you'd like to copy over.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-mSEs77mQiWjWnJUCeCqTa-20250328-182638.png?format=webp "Document image")
    
5.  Check the box for each Add-On you'd like to copy over and click **Copy**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-hhs90jSm6Hd562DpWMvpR-20250328-182658.png?format=webp "Document image")
    
6.  Use the **Edit** button next to the Add-On to make any adjustments needed.
    

Inventories are tracked separately for Add-Ons. If you copy an Add-On, it will start fresh with whatever inventory you set.
