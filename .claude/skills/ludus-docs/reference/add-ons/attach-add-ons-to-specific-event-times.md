# Attach Add-Ons to specific event time(s)

You may wish to attach Add-Ons to one or a select few nights instead of every single event time. In this case, you will want to adjust the "Assignment" on the Add-On.

1.  Locate the event/collection the Add-Ons are attached to.
    
2.  Next to the title, click **Pricing** --> **Add-Ons**.
    
3.  Click **Edit** next to the desired Add-On.
    
4.  Under the section titled **Assignment** click the option for **Specific event times**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_t-nA_OH7szg7bI0xitp0_screen-shot-2023-08-31-at-82448-pm.png?format=webp "Document image")
    
5.  Check the box for each performance where the Add-On is available.
    
6.  Click **Save Changes**.
