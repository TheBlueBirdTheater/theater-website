# Attach Add-Ons to a specific ticket price

You may wish to attach Add-Ons to a specific ticket price. Then, once someone chooses that ticket price, they will be asked to select an Add-On. This is particularly useful for things like dinner theatre, where patrons need to choose their dinner selection. See how to do this below!

1.  Locate the event/collection to which the Add-Ons are attached.
    
2.  Next to the title, click **Pricing** --> **Add-Ons**.
    
3.  Click **Edit** next to the desired Add-On.
    
4.  Scroll to the bottom of the page and click **Advanced Options**.
    
5.  For the section titled **Attach to Ticket Price**, check the box for each ticket price the Add-On should be attached to.
    
6.  Click **Save Changes**.
    

This Add-On will only be available if that ticket price is selected by the patron. By default, patrons will be required to select an option should they select this ticket price. You can make it optional by selecting the **Optional Add-On box**.
