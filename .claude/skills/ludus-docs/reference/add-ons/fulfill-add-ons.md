# Fulfill Add-Ons

When you sell an Add-On, your patron receives a voucher to claim the item, which has a QR code and/or barcode. When you fulfill the Add-On it is marked as picked up in Ludus so that you can easily track if items have been received.

You have a few options to mark the add-on as fulfilled in Ludus.

### The Check-in List or Add-On List

You can mark add-ons as fulfilled via the **Check-in List.** This can be accessed by going to **Options-> Check-In** **List** or **Options-> Add-On List** (by switching to the Add-Ons tab).

Locate the add-on by the patron's name, select the add-ons by checking the boxes, and then select Mark as Fulfilled from the drop-down and click **Submit**.

### The Box Office App (IOS and Android)

When using the **Ludus Box Office App**, you can scan the QR code / Barcode for the add-ons while on the same scan page for the event that you are checking in.

There is an Add-on section in the Scanning window that allows you to see the add-ons sold and mark them as fulfilled. If you open that tab, you can see all the add-ons that have been marked as fulfilled (Green Checkmark) or Unfulfilled (No check mark).

If an item was mistakenly marked as fulfilled and you need to reverse that, you can simply click on the item to mark it unfulfille,d and the green checkmark will go away.
