# Edit Add-Ons

Once you have created an Add-On, you may need to make slight adjustments. Perhaps the inventory has changed, or you would like to update the image. Either way, it is simple to accomplish.

1.  Find the event/collection that your Add-Ons are attached to.
    
2.  Next to the title, click **Pricing** --> **Add-Ons**.
    
3.  Next to the desired Add-On, click **Edit**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-fN9F2I9znu89wMhoBZAwP-20250328-182304.png?format=webp "Document image")
    
4.  Click **Save Changes** at the bottom of the page to finish.
