# Add a Trigger to a Pass

Similar to events, you can add a Trigger to a Pass for when you would like it to be turned on or off for sales. This can be particularly helpful if you find yourself in the midst of the busy season and won't have time to handle this manually.

To do this, go to **More** (at the top of your admin panel) -> **Passes** -> **Options** (next to the pass) -> **Triggers**. Once Triggers is selected, you will be prompted with the options to:

-   Set a Sales Start Date

-   Set a Sales End Date

-   Select a Timezone

-   Save the Triggers

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8LwYuP38Nwuk4gpDaSolw_screen-shot-2023-08-28-at-41046-pm.png?format=webp "Document image")

## Sales Start Date Trigger

When toggled on, you will be able to select when you wish for your pass to go on sale to the public. You can still sell these passes on the admin panel prior to this time.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1K_J1vNk5nubOE6l9tpkB_screen-shot-2023-08-28-at-41233-pm.png?format=webp "Document image")

## Sales End Date Trigger

When toggled on, you will be able to select when you wish for your pass sales to end on your patrons' or public-facing site. You can still sell these passes on the admin panel after this time if desired.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9n4Gk_MA52xPLZDJn_HbJ_screen-shot-2023-08-28-at-41301-pm.png?format=webp "Document image")

## Select Timezone

Prior to saving your Triggers, ensure that the correct timezone is reflected. This will ensure that your pass sales begin and end at the correct time for your location.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WrUPcrTBnDlY8SwTqBYnQ_screen-shot-2023-08-28-at-41459-pm.png?format=webp "Document image")

Be sure to _**Save**_ Triggers prior to exiting this screen!
