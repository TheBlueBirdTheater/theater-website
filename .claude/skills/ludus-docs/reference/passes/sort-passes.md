# Sort Passes

If you have multiple passes available to your patrons, you might want to sort the order in which they are listed or how they are displayed for your patrons. With the **Sort** function for passes, you can easily adjust and move how your passes appear for patrons.

To set this up, go to **More** (at the top of your admin panel) -> **Passes**. From here, you will select **Sort** and be able to adjust and move Passes as needed.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zNuyN_G1Jqg-_2I1IVzOM-20251215-211531.png?format=webp "Document image")

Once sorted, be sure to select Save Sort for these changes to be reflected on the patron site!
