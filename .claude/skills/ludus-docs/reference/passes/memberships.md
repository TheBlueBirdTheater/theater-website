# Memberships

## Overview

Memberships are a type of pass that does not come with any tickets. Memberships are used exclusively for giving patrons perks. Depending on how you set up the membership, they can use their passholder code to gain early access to purchase tickets, unlock special ticket prices, auto-apply discount codes, and more.

Memberships are unique in that they can be set for a one-time payment or a recurring membership (monthly, quarterly, biannually, or annually) based on the date the patron initially purchases the membership.

### How do Memberships work?

Each member receives a unique member code they can use to log in when they visit your Ludus page. Once logged in, they'll be greeted with a unique member experience you create that can entail unlocking special things like ticket prices and discounts.

### Membership Perks Available

Here are some of the perks you can automatically offer with a Membership on Ludus (all optionally enabled by you):

-   Allow early purchase access to eligible events

-   Allow access to "Admin Only" event times

-   No fees on all individual tickets (absorbed by group)

-   Exempt Order-level Custom Fees

-   Issue comp tickets that reset each membership year
