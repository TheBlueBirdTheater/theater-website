# Set up a Membership

## Steps to Create a Membership

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Click **Create Pass** and select **Membership**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YzCqxJW915MjIFyARllQS_screenshot-2026-07-13-at-81717-am.png?format=webp "Document image")
    
3.  Fill out each section in accordance with how you'd like the pass to function. For more information about each section, view the "Options & Terms" below.
    
4.  Click **Add Pass** to save.
    

## Options & Terms

-   **Type**: The kind of pass you are setting up. This will be automatically chosen based on your selection on the previous page.

-   **Name**: The name of the pass. This is what patrons will see when purchasing the pass.

-   **Pricing**: The price patrons will pay to purchase the pass. For memberships, you can choose both the price and the frequency (if you want a recurring membership fee).

-   **Tax Exempt** _(only if you are collecting Sales Tax)_: Select if you wish for the pass to be exempt from any Sales Tax

-   _Suggested Article:_ [Collect Sales Tax](https://support.ludus.com/collect-sales-tax)

-   **Expiration**: When the passcode stops working for each patron.

-   **Description**: A customized _description_ that is displayed when patrons are choosing their pass. Great for explaining the benefits of the pass to the purchaser.

-   **Perks**: Manage perks given to pass holders when they sign in using their pass.

-   _Suggested Article_: [Perks available for Flex Passes and Memberships](https://support.ludus.com/perks-available-for-flex-passes-and-memberships)

-   **Form**: Attach a form to the pass purchase process. _Suggested Article_: [Attach a Form to a Pass](https://support.ludus.com/attach-a-form-to-a-pass)

-   **Coming Soon**: Display the pass as an option that will soon be for purchase while still restricting public sales.

-   _Suggested Article_: [Enable Coming Soon mode for a Pass](https://support.ludus.com/enable-coming-soon-mode-for-a-pass)

-   **Special Passcode**: Requires a special passcode to unlock this pass. Leave blank for no passcode.

-   _Suggested Article_: [Passcode protect a Pass](https://support.ludus.com/passcode-protect-a-pass)

-   **Fees**: Choose whether you'd like to pass on or absorb the Ludus ticketing fee. \*Note the fee for flex passes only when the pass is purchased, not when tickets are redeemed on the pass.

-   _Suggested article_: [Ludus Pricing Table](https://support.ludus.com/ludus-pricing-table)

-   **Color**: The color that will appear on the pass selection page and pass reporting. This is only a visual change and does not limit or change any functionality.
