# Discounts and Memberships

When utilizing Memberships, you can also set up those tied to discounts for your events, as well as global discounts. These discounts can be automatically applied when a patron is signed in with their pass or Membership.

### Create an Event Level Discount:

1.  Go to **Pricing** (next to the event) -> **Select Discounts**.
    
2.  Click on **\+ Discount** to set up your discount.
    
3.  While you will need to set a code for the discount, it is not required, as it will auto-apply when they are signed in as Members.
    
4.  Scroll to the bottom of the discount creation, and here you will want to select "**Auto-Apply based on Pass Holder**". Once selected, be sure to choose the Membership you wish to use it on.
    
5.  Save once finished, and the discount will be live for the event!
    

### Create a Global Discount:

1.  Go to **More** (at the top of your account) -> and select **Global Discounts**.
    
2.  While you will need to set a code for the discount, it is not necessary, as it will automatically apply when they are signed in as Members.
    
3.  Check out more on [Global Discounts](https://support.ludus.com/global-discounts) to see how they function and for clarity on how the setup works.
    
4.  Scroll to the bottom of the discount creation, and here you will want to select "**Auto-Apply based on Pass Holder**". Once selected, be sure to choose the Membership you wish to use it on.
    
5.  Save once finished, and the discount will be live for the event!
