# Perks available for Flex Passes and Memberships

Memberships and Flex Passes come with a pass holder code that pass holders can use at checkout to unlock special perks and benefits. Check out each section below to learn more about the perks you can choose to enable.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3OWwkOXicLVGM7WzArDRM_screenshot-2026-06-22-at-123930-pm.png?format=webp "Document image")

## Perks Defined

### **Allow early purchase for eligible events**

Allow patrons to bypass the fact that an event is turned off and purchase tickets before you turn it on to the general public. If this box is checked, any event you have selected under the "Event" settings for the pass will be available for purchase immediately.

If you wish to grant early access to events but are not yet ready to do so for a specific event, you can leave it unchecked under the "Event" setting on the pass and check that event when you are ready for them to access it.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Ee5PiCVsbdxHYoYK-sNrq_screen-shot-2023-09-12-at-44833-pm.png?format=webp "Document image")

### Allow access to "Admin Only" event times

You might have specific event times marked as "Admin Only". This means that only you, as a box office admin, have access to sales for this date. By checking this box, you are granting access to these "Admin Only" event times if you are a pass holder. This is a great way to unlock special event times for members or flex pass holders.

### No fees on all individual tickets (absorbed by your group)

Perhaps, as a default setting for your events, you want to pass the Ludus ticketing fee on to patrons. By checking this box, any tickets a patron purchases when logged in as a pass holder will have the fees absorbed instead of being passed on. If a patron buys a $10 ticket, the Ludus ticketing fee will be absorbed by your organization rather than paid for by the patron. The patron will pay the flat amount of $10, and your proceeds will reflect $10 minus the ticketing fee.

### Exempt Order-level Custom Fees

If you have set up [Custom Fees](https://support.ludus.com/custom-fees) at the Order level and wish to exempt pass-holders from this, select this option; it will apply to all Flex and Membership holders when they make a purchase and have signed in with their Pass-Code.
