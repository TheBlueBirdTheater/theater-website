# Add Notices to Passes

# Notices and Passes

Sometimes you need to add additional information either to the pass tab for patrons or the confirmation of their pass order. This is easily accomplished through the Notices available on Ludus!

## Global Pass Notice

To access the Global Notice for Passes, go to **More** (at the top of the admin panel) -> **Global** **Notices** -> **Passes**. This is to share any additional information with patrons on the Passes tab. If you are creating and offering passes for your season or events, this would be a great place to share additional information with your patrons about those passes or memberships.

## Pass Confirmation Notice

To access the Confirmation Notice for Passes, you will want to go to **More** (at the top of the admin panel) -> **Passes** -> **Options** (next to the pass) -> **Notices**. From her,e you can add any additional information you would like to include in the Confirmation email that comes with the purchase of a pass.
