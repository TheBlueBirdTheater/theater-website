# Requirements for Renewals

**To begin with, for Pass renewals, you need the following items:**

-   Prior season's Passes (cannot be archived, but should be turned off). Once your Renewals are generated, you can archive the preceding season's Passes.

-   Passes are set up for the new season.

Any events for the pass renewal cannot have any sales. If tickets for those events have already been sold, the pass renewal will not work.

**Additional considerations:**

For same-seat season passes, both old and new passes must be for the same number of events and event times for the renewal to work. Flex Passes and Memberships can have a varying number of events and tickets available from season to season without causing issues with renewals.

They also must be in the same Seating Chart. Any updates must be reflected on the original pass so the renewals can find the matching seat.

At a minimum, both the old and new passes must have price terms for each event selected for the renewal to work.
