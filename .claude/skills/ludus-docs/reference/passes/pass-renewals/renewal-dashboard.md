# Renewal Dashboard

The Renewal Dashboard is where you will create and manage all renewals of your passes.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/BtppMdmjMYB_Yb05ETwbr_screenshot-2026-07-10-at-40046-pm.png?format=webp "Document image")

Each pass that is being renewed is displayed here, as well as the options for those passes.

### View

The View Button can be used to see ALL pass renewals and their status. Additionally, it is possible to send a reminder to all or specific patrons from this screen as well as view the details of the renewal, including processing the sale of the pass to the patron.

Additional functions on this panel include:

-   Printing Mailers

-   Triggers

-   Settings

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3zrtjxZasm_-upKPwdsrl_ludus-manual-admin-2024-04-02t113214326.png?format=webp "Document image")

### Settings

The Settings button allows you to adjust the Default Pass renewal settings.

This is where you can set up payment methods for the Mailers if you will be mailing out renewals.

Additionally, you can set the ability for patrons to make changes to their renewal as a default. This can also be selected on the specific pass renewal settings.

You can create the Notification email here as well.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pNxuI0g3cZ-2xBXw3NCbU_ludus-manual-admin-2024-04-02t115537169.png?format=webp "Document image")

### Options

The Options button offers items exclusive to the specific pass renewal.

The Options here include:

-   **Set Triggers** including**:**

-   Renewal Start Date and Time

-   Renewal End Date and Time

-   Renewal Reminders: Sends a reminder to all pending renewals on a set number of days before the renewal closes.

-   Timezone

-   **Send Notification Email:** send to all pass holders for renewal

-   A prompt will appear to ensure you wish to take this action

-   **Print Mailers:** Print out mailers to send by mail.

-   **Settings:** Adjust the settings for the specific pass, which differs from the Default pass renewal settings.
