# Pass Renewal FAQ's

Below you will find some of our Frequently Asked Questions and how to handle them:

### Do my events need to be turned on to send out Pass Renewals?

The event does _not_ need to be turned on in order for pass renewals to be sent out. This is similar to a Season Ticket.

### How do pass renewals save seats for patrons?

Pass renewals reserve seats, so other patrons cannot purchase them once the pass renewal has been applied to that seat.

### How is the admin notified that an attempt was made on a patron's credit card?

Admins aren’t notified if an attempt was made because Ludus will handle it all. Pass renewals reserve the seats so other patrons cannot purchase the seats under the pass renewal.

### How many attempts to charge the card are required to cancel a pass?

The card will be attempted to be charged 3 times; the patron is notified each time to update their card info, and then it auto-cancels. This will all show on the Pass's order screen inthe admin panel.
