# Void a Renewal

When you click the View Details button on a pass reservation, you will see an option to void the renewal reservation. But when should you use that option?

### Void a renewal reservation

_**Here are some times when using Void is the right choice:**_

-   When the patron has told you they will not be renewing.

-   If you find that the reservation is a duplicate.
