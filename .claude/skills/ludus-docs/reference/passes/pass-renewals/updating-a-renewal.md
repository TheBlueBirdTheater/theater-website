# Updating a Renewal

It is not uncommon to need to make changes to a patron's renewal. This can easily be done within the Pass renewal itself.

**Here is how to update an existing Renewal:**

1.  From the **Passes** screen click **Pass Renewals** to enter the renewal dashboard.
    
2.  Select the name of the renewal for the order you need to edit.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/NVabYGoy27PHlScKG8TiV_t-curtis-performing-arts-centre-admin-4.png?format=webp "Document image")
    
3.  Select **View Details** next to the patron's order you want to edit.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4jfVrDLtWVWz-V-ghkW_H_t-curtis-performing-arts-centre-admin-5.png?format=webp "Document image")
    
    This will open the patron's record for the renewal.
    
4.  Click Renew to open the renewal and allow making changes Or taking payment
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/xSzQX7xrCPYQzLSNoyTti_t-curtis-performing-arts-centre-admin-6.png?format=webp "Document image")
    
5.  You are now on the renewal itself, here you can see the Seats for each show, and if need be you can edit the seats or performance selected by removing the tickets from the reservation and making new selections.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/PGnbdvE4_AbtRUX-UXObH_t-curtis-performing-arts-centre-admin-7.png?format=webp "Document image")
    
6.  If you make changes to the reservation they are automatically saved when you click **Go Back** at the top of the page.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ypmYbQNotzG5F4mO85Hor_t-curtis-performing-arts-centre-admin-8.png?format=webp "Document image")
