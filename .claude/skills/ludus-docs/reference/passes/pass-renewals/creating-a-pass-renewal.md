# Creating a Pass Renewal

To begin with, for pass renewals, you will want to first ensure that you have created your new passes.

If the pass is for assigned seating events, the seat charts must match between this season and last season, as well as the number of performances offered on each pass.

### Create your first renewal:

1.  Contact Support via chat or email to have pass renewals activated. Once activated, you will receive a link to get started with your pass renewals.
    
2.  This link will be take you to the Renewal Dashboard, where you will be able to set up your pass renewals.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WIRiZJjJ2qJP7Owl02z3F_screenshot-2026-07-10-at-35203-pm.png?format=webp "Document image")
    
    You will be prompted to enter a name for the renewal.
    
    If you are renewing more than one pass, then you will want to give this a specific name to help identify exactly what pass this is for. IE - Adult First Friday Season Ticket.
    
    If you are renewing just one pass then this can be given a general name.
    
3.  Select the Current Pass and New Pass from the drop-down and click **Continue**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6KLadv96EhEQmEEmXc7MD_ludus-manual-admin-94.png?format=webp "Document image")
    
4.  Match performance days from the old pass to the new pass and click **Continue**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/V8lisn6MMJRZCWDsaoURm_ludus-manual-admin-98.png?format=webp "Document image")
    
5.  Match the pricing for the passes and click **Continue**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/t93NIMDU1-hpOpJ-YOAZR_ludus-manual-admin-99.png?format=webp "Document image")
    
6.  Select the options you wish to use for this particular pass renewal. (Note if you are renewing several different passes, you can have different settings for each)
    
    **Options here include:**
    
    -   Allowing changes to be made to the pass.
    
    -   Self-Service (Patrons can change the reserved pass)
    
    -   Box Office only
    
    -   Renewal Start Date
    
    -   Renewal End Date
    
    -   Renewal Timezone
    
    -   Email Notification Content. (specific to this pass renewal)
    
    Click **Finish** when you have made these selections.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/K7rdhzt4bd4Tivje7y53P_ludus-manual-admin-100.png?format=webp "Document image")
    

Your pass renewal will be generated (This may take some time), and you will be returned to the renewal dashboard where you can see the prepared renewal.

If you have additional passes to renew, repeat the steps above until all your passes are set up for renewal.

If you are renewing **Flex Passes**, you will not need to match up pricing or event dates as part of the setup of the renewal.
