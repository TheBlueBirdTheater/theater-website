# Renewal Communications

The key to a successful renewal is communication. With pass renewals, you can send both Email notifications and postal mailers to each patron with an open renewal.

If there is no contact email under Settings (⚙️) -> General for your organization, the reply-to-email address will be whichever user sends the renewal email.

If no contact email is set and John Doe (johndoe@ludus.com) sends the renewals, those will come from their email.

### Email Renewals

To send out the email notifications for renewals, navigate to the Renewal Dashboard and click **Options** next to the renewal you want to send, select Send Notification Email, and then confirm you are ready to send the renewals by clicking **Send Notification Email**.

### Print Mailers for Renewal

You can download and print the mailers for renewals. To do so, navigate to the Renewal Dashboard and click **Options**, next to the renewal you want to print the mailers for, and select Print Mailers. This will open a PDF that you can either print now or save to print later.

The mailer will include the renewal options you selected in the Default Pass Settings.

Mailers use the Logo and colors that are set up in the **Design Tool**.

_Suggested article:_ [Design Tool](https://support.ludus.com/design-tool "Design Tool")

### Email Reminders

**Triggers** can be set up to automatically send reminders via email to any pass holder who has not taken action to renew. Triggers can be set up by selecting Options next to the renewal and selecting Triggers. Under Triggers, you define the start and end date for renewals. When an end date is set, you can also set renewals to be sent based on the number of days before the renewal end date.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/d5Lo0pPljApdtcUkjWjdS_t-curtis-performing-arts-centre-admin-13.png?format=webp "Document image")

_Additionally, you can manually send those out:_

1) Send a mass reminder to all renewals that are still pending by clicking Options next to the pass on the renewal dashboard and selecting Send Notification Emails.

2) Click View on the renewal dashboard, and select individually who to send renewals to.

After sending the first renewal notice, you can edit the notification email to add content such as "A friendly reminder to renew your season tickets by..." or other call-to-action information.

This can be done by selecting **Settings**, under **Options,** next to the pass.
