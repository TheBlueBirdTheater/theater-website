# Processing Renewal Sales as an Admin

Processing a sale or renewal as an administrator can be done either through the Renewals dashboard or via the patron record.

### Selling via the Patron record

1.  Search for and open the patron record via the global search bar at the top of your admin panel.
    
2.  On the patron record, scroll down to the Renewals section as seen here:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/JtWCnZgPrTojZVd_P9PIl_ludus-manual-admin-2024-04-03t120036594.png?format=webp "Document image")
    
3.  Click on the renewal that they wish to purchase. The renewal will open, and here you can click the **Renew** button to renew or make changes.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/G9Al5s3IUPhVq_KalnxB4_ludus-manual-admin-2024-04-03t120208277.png?format=webp "Document image")
    
4.  Once the order is correct, click **Renew Pass** to proceed to take payment.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KLwGMcCiuT19PvzmpEFOG_processing-renewal-sales-as-an-admin-archbee-document.png?format=webp "Document image")
    

### Selling via the Renewal Dashboard

1.  Click View on the Renewal Dashboard. This will open a list of all renewals.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/z9hOZjoMSNKIrlYVTNV2D_ludus-manual-admin-2024-04-03t133917146.png?format=webp "Document image")
    
2.  Use the search bar to look up the patron's name.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RcJ8c-iPR3HzVT1Aa9qOI_ludus-manual-admin-2024-04-03t134052566.png?format=webp "Document image")
    
3.  Click **View Details** next to the pass to open the renewal.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/vS_wDp_SWDd6OZrViQl0A_ludus-manual-admin-2024-04-03t134249829.png?format=webp "Document image")
    
4.  Click **Renew** to be taken to review the pass and to edit the order if needed.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zUVQ46-5Vbef3Erjnzkuq_ludus-manual-admin-2024-04-03t134440811.png?format=webp "Document image")
    
5.  If the order is correct, click Renew Pass at the top of the page to process payment.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CXQMdFBdK3sN7VTckrSz3_processing-renewal-sales-as-an-admin-archbee-document-1.png?format=webp "Document image")
    

Please note that if you are renewing an existing season ticket, the sale should be made via the patron record or the renewal dashboard.
