# View Renewals

The Renewal Dashboard allows you to view and sell your current renewals.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/BtppMdmjMYB_Yb05ETwbr_screenshot-2026-07-10-at-40046-pm.png?format=webp "Document image")

The **View** button will open a page of ALL your ongoing renewals, including all passes that are in renewal. Including the numbers completed, Pending, and voided.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WIHaiwDqJLLv404NVq_DI_ludus-manual-admin-2024-04-11t120810017.png?format=webp "Document image")

You can also send reminders to individuals from here or view the details of the renewal.

If you would like to only see one of the renewals, you can click on the name of the pass renewal to open all the reservations for that particular pass.

### View Details

When you select View Details for a patron's reservation, the reservation opens, and the number of passes will be shown, as well as the seats selected for each event time.

In this example, it's 2 Same Seat Season tickets.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/tj4mF-97T9hDxmrSXGAC0_ludus-manual-admin-2024-04-11t122710945.png?format=webp "Document image")

With the reservation open, you have the following options:

-   **Print a Mailer** - For this specific order

-   **Send a Reminder** - Sends a single email reminder

-   **Renew** \- Take payments or edit the order

-   **Void** \- Releases the reservations
