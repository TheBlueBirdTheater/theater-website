# Attach a Form to a Pass

Forms are found throughout Ludus and are used to collect additional information from purchasers beyond their name, email, phone number, and address. To learn more about Forms and the various fields you can set up, check out this article.

_Suggested Article_: [Forms](https://support.ludus.com/forms)

Before attaching it, make sure you have built your Form. To learn how to do this, check out our article.

_Suggested Article_: [Create a Form](https://support.ludus.com/create-a-form)

### Attach to a Pass

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the desired Pass, click **Edit**.
    
3.  Scroll down to the section titled "Form."
    
4.  From the drop-down menu, select the form you'd like to attach.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pRt_QHVAH3oIj7v1kRBZV_screen-shot-2023-08-30-at-82140-pm.png?format=webp "Document image")
    
5.  Click **Save Changes**.
