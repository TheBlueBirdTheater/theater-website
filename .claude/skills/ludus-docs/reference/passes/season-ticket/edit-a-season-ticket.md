# Edit a Season Ticket

Up until your first sale of the specific pass at hand, you can edit any details you'd like. Once sales have begun on the pass, the "Type" and "Pricing" of the pass cannot be changed. All other settings can be edited.

To change the settings on a Season Ticket:

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the pass you'd like to edit, click **Edit**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pptHn_zRpAuFSysv-XClf_screen-shot-2023-09-14-at-84959-am.png?format=webp "Document image")
    
3.  Change the applicable settings. \*See "Options & Terms" below for more information.
    
4.  Click **Save Changes** to save.
    

## Options & Terms

-   **Type**: The kind of pass you are setting up. This will automatically be chosen based on your choice on the previous page.

-   **Name**: The name of the pass. This is what patrons will see when purchasing the pass.

-   **Pricing**: The price patrons will pay to purchase the pass.

-   **Flat Price** - The Patron will pay a single, flat rate for all the tickets within the pass.

-   **Discount Percentage** - The final price of the pass is calculated by taking a percentage off of the total value of all the tickets the patron added to the season pass (i.e. If you set a discount percentage pricing of 10%, a patron who chooses $100 worth of tickets will end up paying $90 while a patron who chooses $140 worth of tickets will pay $126.)

-   **Description**: A customized _description_ that is displayed when patrons are choosing their pass. Great for explaining the benefits of the pass to the purchaser.

-   **Events**: Distinguish which _event(s)_ are available for selection in this pass (must include at least one event, and up to all of them).

-   **Event Times**: Select which _event times_ are available for selection in this pass. \*Click **Select All** to quickly choose all event times.

-   **Ticket Types**: The different prices/ticket types that patrons will be able to select with the pass.

-   **Rules**: Set rules that the patron must follow before being able to check out

-   **Require tickets to be selected for each eligible event** - If you have four events available with the pass, the user must purchase at least one ticket to each event before completing their purchase

-   **Require tickets to be selected for each eligible event time** - If you have 3 event times available with the pass, the user must purchase at least one ticket for each of the three times before completing their purchase

-   **Require patron to meet the total number of tickets for pass** - If you have a total ticket limit set on the pass, the patron will have to select that number of tickets before being able to check out. Any fewer will return an error.

-   **Limits**: Limits to the amount of overall tickets they will receive with each pass and the number of tickets they can use per event, event time, etc.

-   _Suggested Article_: [Breakdown of Limits on Season Ticket](https://support.ludus.com/breakdown-of-limits-on-season-ticket)

-   **Form**: Attach a form to the pass purchase process.

-   _Suggested Article_: [Attach a Form to a Pass](https://support.ludus.com/attach-a-form-to-a-pass)

-   **Coming Soon**: Display the pass as an option that will soon be for purchase while still restricting public sales.

-   _Suggested Article_: [Enable Coming Soon mode for a Pass](https://support.ludus.com/enable-coming-soon-mode-for-a-pass)

-   **Special Passcode**: Require a special passcode to unlock this pass. Leave blank for no passcode.

-   _Suggested Article_: [Passcode protect a Pass](https://support.ludus.com/passcode-protect-a-pass)

-   **Fees**: Choose whether you'd like to pass on or absorb the Ludus ticketing fee. \*Note the fee for flex passes only when the pass is purchased, not when tickets are redeemed on the pass.

-   _Suggested article_: [Ludus Pricing Table](https://support.ludus.com/ludus-pricing-table)

-   **Color**: The color that will appear on the pass selection page and pass reporting. This is only a visual change and does not limit or change any functionality.
