# Breakdown of Limits on Season Ticket

Just as you can set limits on how patrons can redeem their Flex Pass, you can set limits on the events, event times, and ticket prices available for selection when a patron buys a Season Ticket.

Check out the sections below to learn about the different ways you can set limits on your Flex Passes.

## Limit the number of tickets a patron can select

When setting up a Season Ticket, there is an entire section for Limits. Within this section, you can control how many tickets a patron can select per pass overall and limit how many can be used per event, per event time, etc.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nYxczsYD4br7wJynsdSvu_screen-shot-2023-09-12-at-40124-pm.png?format=webp "Document image")

To set a limit for each line, navigate to the pass settings page. (This is where you will be when you are first setting up the pass or if you click **Edit** next to the pass on your admin panel.)

Under the "Limits" section, insert a number for each thing you wish to limit. If you don't have a limit for a specific line, you can leave it blank. To see examples of what each limit means, check the list below

### Examples of Limits

-   **Limit purchaser to "x" total tickets**: The total number of tickets the patron will have on the pass. If the pass is limited to 8 total tickets, regardless of which events they are for, insert 8 here.

-   **Limit purchaser to "x" events**: The number of different events the pass can be used on. Maybe you have 5 different events eligible with the pass but want to limit them to only using their 8 tickets on 4 out of the five events. (This is a less common limit)

-   **Limit purchaser to "x" tickets per event**: The number of tickets from the total that can be used on each event. If they have eight tickets total, you might set a limit of 2 tickets per event so that they can't select all eight tickets for one event.

-   **Limit purchaser to "x" tickets per event time**: The number of tickets a patron can spend on a particular event time. Maybe you're okay with them spending all 8 tickets on one event but want them to have to spread them out to different event times. (2 on Thursday, 2 on Friday, 2 on Saturday, 2 on Sunday)

-   **Limit purchaser to "x" event times per event**: Limit how many different showings they can attend with the pass. For instance, you have four different event times for an event, but you only want them to be able to select tickets to two event times of their choosing.

The above limits only control the number of events or event times they have access to. To be specific about which events/event times they have access to, check out the "Limit Events, Event Times, and Ticket Prices" below.

## Limit Events, Event Times, and Ticket Prices

When setting up a pass, you can select the events, event times, and ticket prices the pass will apply to.

To choose which one to apply, navigate to the pass settings page. (This is where you will be when you are first setting up the pass or if you click **Edit** next to the pass on your admin panel.)

1.  Choose which Events the flex pass applies to. You can choose all or a select few.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/M3tEfbQ9mtdkvsgvE8MpX_screen-shot-2023-09-12-at-42020-pm.png?format=webp "Document image")
    
2.  Below the Events, you will see all the event times for the events you checked above. Choose which event times they have access to. (IE - if this is a "Weekend Only" pass, you can check the Saturday and Sunday times while leaving the Friday ones unchecked. \*Click **Select All** to easily choose all event times.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/t2WAPwMx1HTIx07C1HsWd_screen-shot-2023-09-12-at-42224-pm.png?format=webp "Document image")
    
3.  Choose which ticket types they have access to. This is particularly useful if you have tiered seating and wish to restrict the flex pass to a specific area on your seating chart. Click **Select All** to easily choose all available ticket types.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/e904RJ-FkWribdCI9RMYZ_screen-shot-2023-09-12-at-43528-pm.png?format=webp "Document image")
    
4.  Click **Save Changes** to save.
