# Season Tickets (Passes) and Absorbing Fees

If you choose to set up a Season Ticket (pass) and wish to have fees absorbed, there are a few key items to know.

### Flat Price Season Ticket:

When setting up a Flat Price Season Ticket/Passes, you can choose to have those fees absorbed directly on the pass. This will absorb all fees associated with the pass/ticket, and the patron will not have to pay those.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-Mn6wncZ_NdliXukqG_64J-20250414-130612.png?format=webp "Document image")

### Discount Percentage Season Ticket:

When setting up a Discount Percentage off a Season Ticket/Pass, you can not elect to absorb fees directly on the pass.

Since this pass type is essentially a discount, those fees would need to be absorbed in the event itself. That would be under **More** (next to the event) -> **Settings** -> **Additional** Options. From here, you can select to absorb fees on the event if desired.

If you absorb fees on the event, that setup will absorb the fees for all patrons who purchase tickets to the event, not just those with the discount percentage season ticket.
