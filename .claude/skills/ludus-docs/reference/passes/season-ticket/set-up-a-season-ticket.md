# Set up a Season Ticket

## To add a Season Ticket:

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Click **Create Pass** and select **Season Ticket**.
    
3.  Fill out the applicable settings for your pass. \*Learn more about each setting below under "Options & Terms."
    
4.  Click **Add Pass** to save.
    

If you are interested in setting up a **Same Seats Season Ticket,** reach out to [Live Chat Support](https://support.ludus.com/live-chat-support) for assistance. Same Seats passes allow patrons to select their seats for the first event, and the remaining events will automatically assign the same seats.

Check out [What are Same-Seat Season Tickets (Passes)?](https://support.ludus.com/what-are-same-seat-season-tickets-passes) for more information.

## Options & Terms

-   **Type**: The kind of pass you are setting up. This will automatically be chosen based on your choice on the previous page.

-   **Name**: The name of the pass. This is what patrons will see when purchasing the pass.

-   **Pricing**: The price patrons will pay to purchase the pass.

-   **Flat Price** - The Patron will pay a single, flat rate for all the tickets within the pass.

-   **Discount Percentage** - The final price of the pass is calculated by taking a percentage off of the total value of all the tickets the patron added to the season pass (i.e. If you set a discount percentage pricing of 10%, a patron who chooses $100 worth of tickets will end up paying $90 while a patron who chooses $140 worth of tickets will pay $126.)

-   **Tax Exempt** _(only if you are collecting Sales Tax)_**:** Select if you wish for the pass to be exempt from any Sales Tax

-   _Suggested Article:_ [Collect Sales Tax](https://support.ludus.com/collect-sales-tax)

-   **Description**: A customized _description_ that is displayed when patrons are choosing their pass. Great for explaining the benefits of the pass to the purchaser.

-   **Events**: Distinguish which _event(s)_ are available for selection in this pass (must include at least one event, and up to all of them).

-   **Event Times**: Select which _event times_ are available for selection in this pass. \*Click **Select All** to quickly choose all event times.

-   **Ticket Types**: The different prices/ticket types that patrons will be able to select with the pass. If no ticket types are selected, then patrons can choose from any public ticket price available.

-   _**For Flat Price Season Tickets ONLY:**_ If you need to have **Recognized Revenue** available in your event report, ensure that you select this advanced feature in this location as well.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-mVdyCeSvZD59hVQgGjOw5-20250707-151608.png?format=webp "Document image")

-   **Allow Access to selected "Admin Only" types on the patron side.** Using this setting would allow you to set up special pricing on events for the exclusive purpose of selling season tickets. It can also be used to offer bonus events on the season ticket at a special discounted price.

-   **Rules**: Set rules that the patron must follow before being able to check out

-   **Require tickets to be selected for each eligible event** - If you have four events available with the pass, the user must purchase at least one ticket to each event before completing their purchase.

-   **Require tickets to be selected for each eligible event time** - If you have 3 event times available with the pass, the user must purchase at least one ticket for all three times before completing their purchase

-   **Require the patron to meet the total number of tickets for the pass** - Any fewer will return an error. If you have a total ticket limit set on the pass, the patron will have to select that number of tickets before being able to check out.

-   **Limits**: Limit to the number of overall tickets they will receive with each pass and the number of tickets they can use per event, event time, etc.

-   _Suggested Article_: [Breakdown of Limits on Season Ticket](https://support.ludus.com/breakdown-of-limits-on-season-ticket).

-   **Form**: Attach a form to the pass purchase process. _Suggested Article_: [Attach a Form to a Pass](https://support.ludus.com/attach-a-form-to-a-pass)

-   **Coming Soon**: Display the pass as an option that will soon be for purchase while still restricting public sales.

-   _Suggested Article_: [Enable Coming Soon mode for a Pass](https://support.ludus.com/enable-coming-soon-mode-for-a-pass)

-   **Special Passcode**: Requires a special passcode to unlock this pass. Leave blank for no passcode.

-   _Suggested Article_: [Passcode protect a Pass](https://support.ludus.com/passcode-protect-a-pass)

-   **Fees**: Choose whether you'd like to pass on or absorb the Ludus ticketing fee. \*Note the fee for flex passes only when the pass is purchased, not when tickets are redeemed on the pass.

-   _Suggested article_: [Ludus Pricing Table](https://support.ludus.com/ludus-pricing-table)

-   **Color**: The color that will appear on the pass selection page and pass reporting. This is only a visual change and does not limit or change any functionality.

## Season Tickets and Early Access

Early access with Season Tickets can be easily achieved in Ludus.

1.  First, set up all the events on the **Event** tabs. Leave all of these events turned off.
    
2.  Once your events are set, you can go to set up the Pass under **More** -> **Passes**. This is outlined above as well.
    
3.  Once created, and when you are ready to sell this pass, toggle the pass to "ON."
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-iuMcRbx_aHyOCaxf5CkLC-20250527-194750.png?format=webp "Document image")
    
4.  Once this is turned on, and all of your events are still off, patrons will be able to access the Passes tab on the patron site.
    
    From here, they can purchase tickets to any event linked to the pass.
    

This differs from the **Flex Passes** and the "_allow early access_" rule. As soon as your **Season Ticket** is activated, any event tied to it becomes accessible (regardless of whether the event is turned **on** or **off**). Please note that if events are in _**View Only mode**_, passholders will not be able to access tickets.
