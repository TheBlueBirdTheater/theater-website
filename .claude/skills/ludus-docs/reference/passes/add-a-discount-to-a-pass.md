# Add a Discount to a Pass

In the same way that you can add discounts to individual events, classes, etc., you can add discounts to the pass purchase process. This allows you to have discount codes that patrons can use to purchase a pass at a lower price.

### To add a code discount to a pass:

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the desired pass, click **Options** --> **Discounts**.
    
3.  Click **+Discount**.
    
4.  Fill in the appropriate details according to how you'd like the discount code to function. \*See below for more details on each section.
    
5.  Click **+Add Discount** at the bottom to save
    

### Terms & Options

-   **Code** - The actual code that patrons will have to insert to receive the discount.

-   **Amount** - The percentage or flat amount that will be taken off per pass or on the overall order.

-   **Usage per Patron** - Limit the amount of times that a single patron can use this particular code. A "1" here will mean that each patron (tracked by email) will only be able to use the code one time.

-   **Inventory** - The total number of times the code can be used across all patrons. Setting "10" here means that the code can be used on ten orders before becoming obsolete.
