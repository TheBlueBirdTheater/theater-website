# Enable Coming Soon mode for a Pass

If you need Passes to be visible, but you don't want to start selling them yet, this is easily accomplished through **Coming Soon Mode**. This can be enabled and disabled for any pass at any time.

To accomplish setting this up, go to **More** (at the top of your admin panel) -> **Passes** -> **Edit** (next to the Pass you would like this enabled on). Once there, scroll down to the bottom of the page where you will see "**Coming Soon**" available. Simply click "**On**" and it will enable the feature!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/QeFev4shwVcMDnLaac76Q_screen-shot-2023-08-28-at-33523-pm.png?format=webp "Document image")

When this feature is turned on for your Pass, the patrons will be able to see that the Pass will be available soon, and you can continue to sell the pass on the admin panel if desired!
