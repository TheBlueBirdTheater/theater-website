# Passcode protect a Pass

If this is a Pass that maybe has a special price attached, or perhaps you only want to have it available to a select group of patrons (like donors or VIPs) you can have that pass available only through passcode. By enabling the Passcode for a specific pass, only those with the code will be able to access that pass (whether it's a season ticket, flex pass, or membership).

To accomplish setting this up, go to **More** (at the top of your admin panel) -> **Passes** -> **Edit** (next to the Pass you would like this enabled the passcode on). Once there, scroll down to the bottom of the pass where you will see "**Special Passcode**". At this point, you can enter your passcode and select "**Save Changes**" for it to be saved.

Once saved, the passcode will be required by any patron wishing to purchase that pass type, as seen below. This will not require a passcode on the admin site.
