# Using a Flex Pass as a perpetual pass

You may have a desire to create a perpetual pass, meaning a pass that's valid until it's used up, regardless of Seasons or time frames. The Flex Pass is the best fit for this, as a Flex Pass purchase can be set to include a specific number of tickets.

### Setting up a perpetual flex pass

1.  Navigate to **More** on the top navigation bar and select **Passes**.
    
2.  Click **Create Pass**.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-UtslrMWBB2vFmFlFx5hvX-20240827-142002.png?format=webp "Document image")
    
3.  Select **Flex Pass** from the options listed.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YzCqxJW915MjIFyARllQS_screenshot-2026-07-13-at-81717-am.png?format=webp "Document image")
    
4.  Fill out the pass fields, including the pass description and the events the pass is valid for (Currently, you can go back at any time and add more.) As well as the ticket types that the pass can be used on. Be sure to define the total number of tickets they can get per pass, as well as any Rules or Perks.
    
    If you do not select any of the ticket types for an event, the pass will work for **all** available public ticket types.
    
    Here is an example of a Pass setup that allows 4 total tickets that can be redeemed on any allowed event in any quantity (1 ticket per event or all 4 can be used if desired), and event time (note: Opening night event times are not selected).
    
    This is the initial setup. As you add more events the pass can be used for, you will want to edit the pass to add the event, along with the times & Ticket Types.
    
    
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-ioZ8LSZwflCLiyM0A-m2N-20240827-150925.png?format=webp "Document image")
    

### Adding additional events to your perpetual flex pass

As you create new events that can be redeemed with the perpetual flex pass it is necessary to add them to the pass. To do so follow these steps.

1.  Navigate to the flex pass to edit. (**More**, on the top navigation, then select **Passes**.)
    
2.  Locate your pass, and click the **Edit** button located next to the Sell button.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-G4mWX_B57zIsPatsTEZns-20240827-151755.png?format=webp "Document image")
    
3.  The pass will open for editing. Scroll down to the Events section and select the event(s) to add to the pass.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-fkXmHLE0J_Y9gCGO0e97K-20240827-153706.png?format=webp "Document image")
    
4.  Select the event Date(s) that are available to the pass.
    
    Note: Thursday is an opening night gala, so it is not selected for the pass in this example.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-QY5N3X6TbNKy3846Nf0fX-20240827-153928.png?format=webp "Document image")
    
5.  Select the Ticket type that is valid for this event.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-BtHT7mNB9cRrpOI_KRzTw-20240827-154045.png?format=webp "Document image")
    
    If a new event has a single ticket type such as "General Admission" or "All Tickets" you can select this type for the pass it doesn't have to be Adult if that is not what offerederd for the event.
    
    
    
6.  Save your pass.
    

### FAQ's about using a flex pass as a perpetual pass:

**How can I update the price of the pass if necessary?** Once a pass is sold, it is not possible to change the price. Turn the pass off so it's not sold online any longer. Then create a New Pass with the updated pricing.

**Will turning off the pass stop the pass from being able to be redeemed by current pass holders?** No, turning it off just prevents it from being sold online. Current pass holders can still redeem the pass as long as there are events it is good for.

**All the sold passes have been fully redeemed. Can I now archive them?** Yes, archiving the pass will remove it from the dashboard. It will also prevent any existing passes from being redeemed, so you only want to do this once you know that all pass holders have redeemed their passes completely.

**Do I need to add all our events to the pass?** No, it's your pass; you can define how it works, but it's recommended that you list the general exceptions in the pass description to not upset your patrons. IE: Not valid for Opening night performances, Galas, or Rentals.

**Can I schedule when the sale of my pass begins and ends? Can it be a limited-time offer?** Yes, you can use Triggers to set both an on-sale date and/or a sales end date/. Triggers are located under the Options button next to each pass.
