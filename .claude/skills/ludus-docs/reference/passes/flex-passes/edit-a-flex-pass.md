# Edit a Flex Pass

Up until your first sale of the specific pass at hand, you can edit any details you'd like. Once sales have begun on the pass, the "Type" of the pass and the Until your first sale of the specific pass Pricing of the pass cannot be changed. All other settings can be edited.

To change the settings on a Flex Pass:

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the pass you'd like to edit, click **Edit**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/D-7jLdLRcI1s7FVoGlmiZ_screen-shot-2023-09-12-at-25214-pm.png?format=webp "Document image")
    
3.  Change the applicable settings. \*See "Options & Terms" below for more information.
    
4.  Click **Save Changes** to save.
    

If you change settings/events available on a pass, the changes will automatically apply to all active passes of this type. However, this will not change previous sales. (IE - If you originally made "In the Heights" tickets available for redemption with a pass and a patron has already done so, their original ticket will remain, but they, and any other patrons, will not be able to redeem for that event moving forward.)

## Options & Terms

-   **Type**: The kind of pass you are setting up. This will automatically be chosen based on your choice on the previous page.

-   **Name**: The name of the pass. This is what patrons will see when purchasing the pass.

-   **Pricing**: The price patrons will pay to purchase the pass.

-   **Description**: A customized _description_ that is displayed when patrons are choosing their pass. Great for explaining the benefits of the pass to the purchaser.

-   **Events**: Distinguish which _event(s)_ are available for reservation in this pass (must include at least one event, and up to all of them).

-   **Event Times**: Select which _event times_ are available for reservation in this pass. \*Click **Select All** to quickly choose all event times.

-   **Ticket Types**: The different prices/ticket types that patrons will be able to select with the pass.

-   **Perks**: manage perks given to pass holders when they sign in using their pass. _Suggested Article_: [🔹 Special Perks for Flex Pass and Memberships](0ZNSi2PwIruBFjkNjUt3R)

-   **Limits** _Suggested Article_: [Breakdown of Limits on Season Ticket](https://support.ludus.com/breakdown-of-limits-on-season-ticket)

-   : Limits to the number of overall tickets they will receive with each pass and the number of tickets they can use per event, event time, etc.

-   **Form**: Attach a form to the pass purchase process. _Suggested Article_: [Attach a Form to a Pass](https://support.ludus.com/attach-a-form-to-a-pass)

-   **Coming Soon**: Display the pass as an option that will soon be for purchase while still restricting public sales.

-   _Suggested Article_: [Enable Coming Soon mode for a Pass](https://support.ludus.com/enable-coming-soon-mode-for-a-pass)

-   **Special Passcode**: Requires a special passcode to unlock this pass. Leave blank for no passcode.

-   _Suggested Article_: [Passcode protect a Pass](https://support.ludus.com/passcode-protect-a-pass)

-   **Fees**: Choose whether you'd like to pass on or absorb the Ludus ticketing fee. \*Note the fee for flex passes only when the pass is purchased not when tickets are redeemed on the pass.

-   _Suggested article_: [Ludus Pricing Table](https://support.ludus.com/ludus-pricing-table)

-   **Color**: The color that will appear on the pass selection page and pass reporting. This is only a visual change and does not limit or change any functionality.
