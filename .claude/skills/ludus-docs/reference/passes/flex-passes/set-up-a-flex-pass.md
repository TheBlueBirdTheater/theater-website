# Set up a Flex Pass

## Steps to Create a Flex Pass

1.  From the top navigation bar, click the **More** --> **Passes.**
    
2.  Click **Create Pass** and select **Flex Pass**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YzCqxJW915MjIFyARllQS_screenshot-2026-07-13-at-81717-am.png?format=webp "Document image")
    
3.  Fill out each section in accordance with how you'd like the pass to function. For more information about each section, view the "Options & Terms" below.
    
4.  Click **Add Pass** to save.
    

## Options & Terms

-   **Type**: The kind of pass you are setting up. This will automatically be chosen based on your choice on the previous page.

-   **Name**: The name of the pass. This is what patrons will see when purchasing the pass.

-   **Pricing**: The price patrons will pay to purchase the pass.

-   **Tax Exempt** _(only if you are collecting Sales Tax)_**:** Select if you wish for the pass to be exempt from any Sales Tax

-   _Suggested Article:_ [Collect Sales Tax](https://support.ludus.com/collect-sales-tax)

-   **Expiration**: When the passcode stops working for each patron.

-   **Description**: A customized _description_ that is displayed when patrons are choosing their pass. Great for explaining the pass's benefits to the purchaser.

-   **Perks**: manage perks given to passholders when they sign in using their pass.

-   _Suggested Article_: [Perks available for Flex Passes and Memberships](https://support.ludus.com/perks-available-for-flex-passes-and-memberships)

-   **Limits**: Limits on the number of tickets they will receive with each pass and the number of tickets they can use per event, per event time, etc.

-   _Suggested Article_: [Breakdown of Limits on Season Ticket](https://support.ludus.com/breakdown-of-limits-on-season-ticket)

-   **Events and/or Classes**: Distinguish which _event(s) or class(es)_ are available for reservation in this pass (must include at least one event, and up to all of them).

-   **Event Times**: Select the _event time_ available for reservation on this pass.

-   Click **Select All** to quickly choose all event times.

-   **Ticket Types**: The different prices/ticket types that patrons will be able to select with the pass. If no ticket types are set, then the pass can be used on all publicly available ticket prices.

-   We recommend assigning the pass to tickets that are not $0. When assigned to a $0 ticket, the ticket will appear as free rather than being removed from the pass total.

-   Select _**(Advanced) - Enable recognized revenue values for event-level reporting**_ if using that.

-   _Suggested Article:_ [Recognized Revenue and Cash Basis Reporting](https://support.ludus.com/recognized-revenue-and-cash-basis-reporting) for more information.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-mVdyCeSvZD59hVQgGjOw5-20250707-151608.png?format=webp "Document image")

-   **Form**: Attach a form to the pass purchase process.

-   _Suggested Article_: [Attach a Form to a Pass](https://support.ludus.com/attach-a-form-to-a-pass)

-   **Coming Soon**: Display the pass as an option that will soon be for purchase while still restricting public sales.

-   _Suggested Article_: [Enable Coming Soon mode for a Pass](https://support.ludus.com/enable-coming-soon-mode-for-a-pass)

-   **Special Passcode**: Requires a special passcode to unlock this pass. Leave blank for no passcode.

-   _Suggested Article_: [Passcode protect a Pass](https://support.ludus.com/passcode-protect-a-pass)

-   **Fees**: Choose whether you'd like to pass on or absorb the Ludus ticketing fee. \*Note the fee for flex passes only when the pass is purchased, not when tickets are redeemed on the pass.

-   _Suggested article_: [Ludus Pricing Table](https://support.ludus.com/ludus-pricing-table)

-   **Color**: The color that will appear on the pass selection page and pass reporting. This is only a visual change and does not limit or change any functionality.

**Flex Passes** do not require that you have all events created prior to selling them. You can add events eligible to use on the pass at any time by editing the pass. You can set the pass rules to specify the total number of tickets the pass is valid for.
