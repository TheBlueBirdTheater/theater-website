# Offer Special Pricing for Flex Pass Holders to Events Not Included in the Pass

It is possible to provide a discounted price to flex pass holders for tickets to events that are not covered by the flex pass. _**Usage Example:**_ You have a special event that is not covered by the flex pass, and you wish to extend a special price to those pass holders to promote sales.

Here is how to create the special price.

1.  Create a new price term. Provide a unique name for it, such as Pass Holder Special Offer. And enter the price that you wish to offer.
    
2.  Under Access, select Pass Holders and select the Pass(s) that this price should be offered to, and save.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-htlozwBYuK8aBVxcqrsm_ludus-manual-admin-2024-04-29t125306657.png?format=webp "Document image")
    

This price will not be limited by the number of passes a patron owns and will not count toward the number of tickets allowed by the pass itself. You can limit the number of tickets that a pass holder can redeem at this special price by using the Limit per patron setting in the pricing setup.

Patrons who log in with the appropriate Flex Pass code will be offered this price as well as any limits you may have set on that price term.
