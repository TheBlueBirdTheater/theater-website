# Breakdown of Limits on Flex Pass

Passes and other season subscriptions are not one-size-fits-all. Therefore, there are multiple ways to set limits for your flex passes. This allows you to create a pass that fits your needs. Not you adjusting your needs to fit a pass.

Check out the sections below to learn about the different ways you can set limits on your flex passes.

## Limit the number of tickets a patron can redeem

When setting up a flex pass, there is an entire section for Limits. Within this section, you can control how many tickets a patron receives overall and limit how many can be used per event, per event time, etc.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nYxczsYD4br7wJynsdSvu_screen-shot-2023-09-12-at-40124-pm.png?format=webp "Document image")

To set a limit for each line, navigate to the pass settings page. (This is where you will be when you are first setting up the pass or if you click **Edit** next to the pass on your admin panel.)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/r2SLPhrpqftFhYKLr3qC0_screen-shot-2023-09-12-at-25214-pm.png?format=webp "Document image")

Under the "Limits" section, insert a number for each thing you wish to limit. We recommend at least setting a limit on the total tickets (otherwise, they can use this code to reserve every single seat you have on sale). If you don't have a limit for a specific line, you can leave it blank. To see examples of what each limit means, check the list below

### Examples of Limits

-   **Limit purchaser to** **"x"** **total tickets**: The total number of tickets the patron will have on the pass. If the pass comes with 8 tickets, regardless of how they can be used, insert 8 here.

-   **Limit purchaser to** **"x"** **events**: The number of different events the pass can be used on. Maybe you have 5 different events eligible with the pass, but want to limit them to only using their 8 tickets on 4 out of the five events. (This is a less common limit)

-   **Limit purchaser to** **"x"** **tickets per event**: The number of tickets from the total that can be used on each event. If they have eight tickets in total, you might set a limit of two tickets per event, so they can't use all eight tickets on one event.

-   **Limit purchaser to** **"x"** **tickets per event time**: The number of tickets a patron can purchase on a particular event time. Maybe you're okay with them spending all 8 tickets on one event, but want them to have to spread them out to different event times. (2 on Thursday, 2 on Friday, 2 on Saturday, 2 on Sunday)

-   **Limit purchasers to "x"** **event times per event,** and different showings they can attend with the pass. For instance, you have four different event times for an event, but you only want them to be able to redeem tickets to two event times of their choosing.

The above limits only control the number of events or event times they have access to. To be specific about which events/event times they have access to, check out the "Limit Events, Event Times, and Ticket Prices" below.

## Limit Events, Event Times, and Ticket Prices

When setting up a pass, you can select the events, event times, and ticket prices the pass will apply to.

To choose which ones to apply, navigate to the pass settings page. (This is where you will be when you are first setting up the pass or if you click **Edit** next to the pass on your admin panel.)

1.  Choose which Events the flex pass applies to. You can choose all or a select few.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/M3tEfbQ9mtdkvsgvE8MpX_screen-shot-2023-09-12-at-42020-pm.png?format=webp "Document image")
    
2.  Below Events, you will see all the event times for the events you checked above. Choose which event times they have access to. (e.g. if this is a "Weekend Only" pass, you can check the Saturday and Sunday times while leaving the Friday ones unchecked. \*Click **Select All** to easily choose all event times.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/t2WAPwMx1HTIx07C1HsWd_screen-shot-2023-09-12-at-42224-pm.png?format=webp "Document image")
    
3.  Choose which ticket types they have access to. This is particularly useful if you have tiered seating and wish to restrict the flex pass to a specific area on your seating chart. Click **Select All** to easily choose all available ticket types.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/e904RJ-FkWribdCI9RMYZ_screen-shot-2023-09-12-at-43528-pm.png?format=webp "Document image")
    
4.  Click **Save Changes** to save.
