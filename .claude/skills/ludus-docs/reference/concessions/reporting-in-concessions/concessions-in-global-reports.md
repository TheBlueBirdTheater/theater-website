# Concessions in Global Reports

### Summary, Revenue, and Sellers Reports

Within the **Summary, Revenue,** and **Sellers Reports,** you can select **Type** (at the top) -> and select **Concessions** in the dropdown.

Once selected, you can click **Generate** to view that report.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/v-Bus74jjOeJDQA1x7Ils_screenshot-2026-08-06-at-30310-pm.png?format=webp "Document image")

When **Concessions** is selected (in the above image), you can see a breakdown of that **Type**.
