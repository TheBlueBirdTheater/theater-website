# Concessions Settings

You can access Retail Settings under **Concessions** (at the top of the account) -> **Settings**. Additionally, these can be reached through the [Concessions Dashboard](https://support.ludus.com/concessions-dashboard) as well!

# Settings Options

### General Settings

1.  Enable tipping at checkout for credit card sales

2.  Enable donations at checkout.

3.  Hide the tip screen if there is a donation in the cart.

4.  Set the Concessions Fees to be absorbed or passed on to the patron.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/wXcLOYVZf1Ai-yT8-xHuI_screenshot-2026-08-06-at-30523-pm.png?format=webp "Document image")

### Tag Manager

1.  Create Tags (to manage and track different products, like clothing vs. food).

2.  Delete unneeded or unused tags.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/hLU48mWjND6pIOhFX_ejR_screenshot-2026-08-06-at-30613-pm.png?format=webp "Document image")

### Tax Manager

**Note** - Tax Manager can only be used on accounts with direct deposit.

1.  Opt to charge or not to charge sales tax.

2.  Create new tax codes for items in Concessions.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/abW6RjEahSkBoiFpfQSzy_screenshot-2026-08-06-at-34333-pm.png?format=webp "Document image")

_**It's your responsibility to verify that your product's tax categories are correct. Applying inaccurate tax categories can result in collecting too much or too little tax when those categories are used to calculate taxes. If you're not sure that your tax categories are correct, then contact a tax expert.**_

### Group Manager

1.  Create separate groups within your organization.

2.  These can also be removed if not needed.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/uh_w_J9Jj-kJ9ZS62aZkW_screenshot-2026-08-06-at-34447-pm.png?format=webp "Document image")

This is a great feature if you have several groups within your organization that use the same Ludus account (IE - orchestra, band, choir, etc...).
