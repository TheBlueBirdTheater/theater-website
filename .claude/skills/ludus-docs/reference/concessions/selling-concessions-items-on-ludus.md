# Selling Concessions Items on Ludus

If you wish to sell Concessions Items on the Ludus Platform, there are 2 ways to accomplish this.

First, you can sell these items as Add-Ons through Collections, Classes, and Events: [Global Add-Ons](https://support.ludus.com/global-add-ons)

The second way to accomplish this is to sell the items directly from the Ludus Retail tab in your Ludus admin panel.

To do this:

1.  Go to **Concessions** (at the top of your account) -> Select **Dashboard**.
    
2.  From here, you will select **Sell Items** (at the top right of the page).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/OpwUZ1zBHvJ6WL9lOHqcT_screenshot-2026-08-06-at-34623-pm.png?format=webp "Document image")
    
3.  This will bring up all of your available Retail Items.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/vQrl5dI3UbplLnz6RtV06-20260109-160903.png?format=webp "Document image")
    
4.  Before adding items to the cart, if you have **Groups** set up, you can select the group you are selling as in the top-right corner.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/5ZALPtv1HRNDAhGeqZY-l-20260109-162634.png?format=webp "Document image")
    
    See [Concessions Settings](https://support.ludus.com/concessions-settings) for more information on **Groups**.
    
5.  From here, you can select the item(s) you wish to add to the cart by selecting that item, and then choosing how many and, if needed, what variants.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/U3GqKYqSOK5vdylS6qy2w-20260109-161040.png?format=webp "Document image")
    
6.  Once items are added to the cart, you can select to link an existing patron to the order or add a new patron.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1km2ZoB1_jKnus1_KYalO-20260109-161230.png?format=webp "Document image")
    
    If linking a patron, you can search for and select them, or select "Create New Patron" if they are not yet in your system.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/QIaAkcCg2FbjsYMOE_k7E-20260109-161655.png?format=webp "Document image")
    
    Additionally, if you wish to bypass that, you can simply select Process Payment at the bottom of the order.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zdKMCeA1qGaAepiVmA4Us-20260109-161341.png?format=webp "Document image")
    
    Before processing the payment, you can also select to add a discount code or a donation if requested by the patron.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KoGw0ZfFx8VLia6gyajaQ-20260109-161543.png?format=webp "Document image")
    
7.  Finally, when you select Process Payment, you will be taken to the Point of Sale page, where you can process the sale and items.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/NEeskvP0X3US0gqe-fhwP-20260109-162141.png?format=webp "Document image")
    
    You can still switch the group you are selling to before the sale goes through.
    
    For example, if you are selling as the choir but meant to select the band, simply select the dropdown (top right) and click the correct group.
