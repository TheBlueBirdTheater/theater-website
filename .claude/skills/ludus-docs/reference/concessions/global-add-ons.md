# Global Add-Ons

While [Add-Ons](https://support.ludus.com/add-ons) can be created for a specific event, you also can create Global Add-Ons and use those through Retail.

When you go to Events and select **Pricing** (next to the event) -> **Add-Ons,** you can set these up.

### Create a Global Add-On

1.  Select **Pricing** (next to the event) -> **Add-Ons**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-aOnZfvjW0fLNjfc24g8ff-20250226-180011.png?format=webp "Document image")
    
2.  Once there, select **\+ Add-On**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-BKx7yK545sw5riKoduphQ-20250226-180226.png?format=webp "Document image")
    
3.  On this screen, you will be able to pick to set up **From Retail Inventory**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-6zKE9RNYUjKpioZaON02N-20250226-180316.png?format=webp "Document image")
    
4.  You can select which retail items you wish to use for this event/globally and then select add item.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-K0i_CFQAnk0hjFxVQhAbK-20250226-180358.png?format=webp "Document image")
    
5.  _Finally_, you will be brought to a screen to approve:
    
    1.  Basic Info
    
    2.  Variants
    
    3.  Advanced Options
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-uMnIXdaz6UPYqEdgp3wHe-20250226-180431.png?format=webp "Document image")
    
6.  Once finished, be sure to select "**Add to Event**".
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-wc9BeRV_pAGyuTLq2eCWY-20250226-180520.png?format=webp "Document image")
