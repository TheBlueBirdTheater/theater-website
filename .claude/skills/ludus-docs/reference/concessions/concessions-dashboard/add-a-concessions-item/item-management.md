# Item Management

Once an Item has been created it will show in the Item Library. From here you can:

1.  Edit the Item

2.  Archive the Item

3.  Delete the Item

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/bOHaxiJwOB_HUcSEEqFN1_screenshot-2026-08-05-at-124322-pm.png?format=webp "Document image")

### Manage Items on the Dashboard

1.  Go to **Concessions** (at the top of your account) -> **Dashboard**.
    
2.  Click the **3 dots** to the far right of your item.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/PZntM1va90Ar-3BFOfWTI_screenshot-2026-08-05-at-124424-pm.png?format=webp "Document image")
    
3.  From this dropdown, you can **Edit**, **Archive**, or **Delete**.
    

You can also Sort Columns, as needed:
