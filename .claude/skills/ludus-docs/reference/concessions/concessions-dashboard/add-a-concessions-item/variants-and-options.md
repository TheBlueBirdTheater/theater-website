# Variants and Options

When setting up your Concessions Items, you will see the **Options** and **Variations** under the item's setup.

While these are both available when setting up an item, they are not required and can be skipped.

### **What are the Options and Variants for Items?**

-   **Options -** If you have multiple types of your item (IE, color, size, etc).

-   **Variants** - If you need to adjust the amount available or price of each item (IE - you have fewer blue mugs and they cost more money to make, you might adjust that price and quantity).

### Use Options and Variants

If you wish to use the Options and Variants, follow the guide, as it will walk you through them in detail.

### Not Using Options (Variants)

If you do not wish to use Options and create multiple variants, and instead wish to make separate Items, you can definitely do that!

**To create your Item:**

When adding a retail item, Ludus will walk you through the setup.

1.  Once you select **Add Concessions Item**, you will then be prompted to fill out the **Basic Info**:
    
    -   Item name (required)
    
    -   Tags (optional)
    
    -   Description (optional)
    
    -   Image (optional)
    
2.  Once **Basic Info** is filled in, you can then add the **Tax Category**:
    
    -   If tax-exempt, select that.
    
    -   If a tax code is needed, select that, OR create a new one.
    
    -   When creating a code, give it a **Name** and **a percentage** (**%**).
    
3.  After the **Tax Category** is finished, you will be able to fill out the **Inventory**.
    
    -   You can choose to **Track Inventory**.
    
    -   Additionally, you can set a **Low Stock** number to be notified when stock reaches a specific level.
    
    -   While you might not use Stock tracking for something like popcorn, it can be used for sweaters, mugs, etc.
    
    If you choose NOT to track Inventory, there will be no Stock option under Variants.
    
4.  At this point, you can SKIP over **Options**.
    
5.  Under **Variants**, you can add the quantity available and the price of that item.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-kEQ5rF1HpWmjZ6OyXWntg-20250226-172712.png?format=webp "Document image")
    
6.  Finally, you can adjust the **Settings** for that item. Under this final section, you will be able to adjust:
    
    -   **Sales Channels** - Where this item can be sold.
    
    -   **Order Limits** - Limit the number of these items that can be sold per order.
    
    -   **Refundable** - The admin can issue a refund to the patron after purchase.
    
7.  Once finished with all of the above, be sure to **save** (at the top right of the form).
