# Active and Inactive Items

Once an Item is created, it can be made active or inactive at any point.

**To change the status of your Item, there are 2 ways:**

### Item Setup

When setting up the Item initially ([Add a Concessions Item](https://support.ludus.com/add-a-concessions-item) ), you can select Active or Inactive in the top right corner. As soon as the setup is finished that will be saved.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/PZntM1va90Ar-3BFOfWTI_screenshot-2026-08-05-at-124424-pm.png?format=webp "Document image")

### From the Dashboard

1.  Go to **Concessions** (at the top of your screen) -> **Dashboard**.
    
2.  Scroll down to your list of Items.
    
3.  Go to the **Status** column next to the item.
    
    Then select either **Active** or **Inactive** for your item.
    
4.  As soon as you select it, it will take effect immediately.
