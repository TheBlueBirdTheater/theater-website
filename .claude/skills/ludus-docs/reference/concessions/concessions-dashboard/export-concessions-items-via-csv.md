# Export Concessions Items via CSV

One of the many items that can be exported from Ludus (via CSV) is the Retail Inventory list. Additionally, you can export this while keeping the set sort and filters.

To access this, simply go to **Concessions** (at the top of your account) -> **Dashboard**.

From here, scroll down to your Concessions Inventory. You can add any needed sorting in **All Inventory**, **Tags**, or **Filter by Status**.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-Zldqz1grJE8y8-Zk8S9HZ-20250805-154322.png?format=webp "Document image")

Once you have selected those items (or if you don't need any of those items), you can click the "**\->CSV**" button to export your Inventory!
