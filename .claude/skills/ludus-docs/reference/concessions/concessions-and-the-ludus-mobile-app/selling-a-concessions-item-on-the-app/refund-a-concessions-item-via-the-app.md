# Refund a Concessions Item (via the app)

If you are in the app and need to refund an item, you can easily do that through the retail tab.

### Refund in the App:

1.  Go to **Concessions** (along the bottom menu bar) -> and select **Transactions**.
    
2.  Once selected, you will see a list of transactions.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/7BYqM36d78d72Flyn-TJr_img-1057.jpg?format=webp "Document image")
    
    Select the one you wish to refund.
    
3.  Once selected, you will see the ability to refund that item via the **Issue a Refund** button.
    
    You must have the item listed as "Refundable" via the Item setup on the admin panel. See more of this under [Add a Concessions Item](https://support.ludus.com/add-a-concessions-item) .
