# Refund a Concessions Item (via the admin panel)

To refund an item via the admin panel, go to **Concessions** (at the top of your account) -> **Reports**.

### Refund on the Admin Panel:

1.  Go to **Concessions** (at the top of your account) -> **Reports**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-UReq6S2flr4_k-5WJedjz-20250306-190356.png?format=webp "Document image")
    
    Scroll down to Transactions, and select the item you wish to refund.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-KAfLGyfApcpfQIiygt0aX-20250306-190509.png?format=webp "Document image")
    
2.  Once selected, you will be brought to the item order page.
    
    From here, select **Issue Refund** at the top.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-VmU-tcUFv5hWR86OKeWb4-20250306-190537.png?format=webp "Document image")
    
3.  Once selected, you will be prompted to select a reason to refund the items, as well as which items need to be refunded.
    
    Once each of those are selected, you can proceed with **Complete Refund**.
    
    If the refund is for a cash sale, you will issue it in cash on your end.
    
    Credit Card orders will automatically be returned to the patron's card.
    
    
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-JmbpaYxdO4lOK9HNXJv_H-20250306-190700.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-ZW6Rc1MvgwnyZj7K-966K-20250306-190722.png?format=webp "Document image")
    
4.  Once completed, you will be taken back to the order page, with the refund success shown at the top and under the **Status** of the order.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-9f9AFJ31_83Hs-FczsOfk-20250306-190937.png?format=webp "Document image")
