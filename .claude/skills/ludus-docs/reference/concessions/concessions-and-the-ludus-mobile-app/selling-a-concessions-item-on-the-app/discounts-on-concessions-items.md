# Discounts on Concessions Items

If you wish to set up a discount on a Retail Item, this can easily be accomplished via Global Discounts.

To set up this discount navigate to:

1.  **More** (at the top of your account) -> **Global Discounts**.

2.  From here, select **+Global Discount**.

3.  Once selected, you will want to have it either apply to **Everything** (which will include Retail) OR you can select to have it apply to specific **Events, Collections/Classes, or Retail Items**.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-iCNlx35HNHEzXJ3_8rmyS-20250317-180549.png?format=webp "Document image")

**Note** - For more information on Global Discounts, be sure to read through the Ludus resource called: [Global Discounts](https://support.ludus.com/global-discounts)

Once your discount is set up, you will be able to apply that via the app.

1.  Log into your Ludus Box Office App

2.  Select Retail (at the bottom of the screen).

3.  Once there, you can [Selling a Concessions Item on the App](https://support.ludus.com/selling-a-concessions-item-on-the-app) .

4.  After you go through the process of adding the item (and before checkout), you can select to add the discount you created under Global Discounts.

1.  See below to **Select Discount** -> **Add Applicable Code** -> and **view that discount on the order**.
