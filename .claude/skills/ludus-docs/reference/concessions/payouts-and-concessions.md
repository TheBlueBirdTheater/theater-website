# Payouts and Concessions

Depending on your Concessions setup and whether you have the Group Feature being used (found under [Concessions Settings](https://support.ludus.com/concessions-settings) ) payout will look a little different between Direct Deposits and paper checks.

### How will I receive my payout?

-   **Direct Deposits** — the payout will run the same as everything else on the account: daily, weekly, or monthly

-   The deposit report will be broken down into a Concessions category. If you are using the Group feature under **Concessions** \-> **Settings** \-> **Group Management,** the report will break this down by group.

-   **Paper Checks** — proceeds will be sent on the 1st of every month (similar to donations and Passes)

-   If you are using the Group feature under **Concessions** -> **Settings -> Group Management**, a separate check will be sent to each group based on the check payout method attached to that group. This is similar to Add-Ons, where a separate Add-Ons check is sent apart from event ticket sales.

Currently, Tax can ONLY be turned on and used for Concessions if you are on Direct Deposits.
