# Concessions Dashboard

The Dashboard is the main hub for Concessions, where you can view and manage a variety of items.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3DPLOULQz6jMW6brL_h9K_screenshot-2026-08-05-at-124037-pm.png?format=webp "Document image")

**From this section of Retail, you will be able to:**

-   Add retail items

-   View weekly items sold

-   View weekly sales

-   See top-selling items

-   View monthly sales

-   Access all reports

-   View, tag, and monitor items in inventory

[Add a Concessions Item](https://support.ludus.com/add-a-concessions-item)
