# Initial Setup of Concessions

When you first go to **Concessions** (at the top of your account) -> **Dashboard**, you will be brought through the initial setup process for Retail.

1.  First, you will be brought to the Get Started page. If you **select Get Started** here, you will go through the following setup steps.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pEKknj9evNAUIn4ziW4PT_screenshot-2026-08-05-at-123609-pm.png?format=webp "Document image")
    
2.  Once selected, you will be brought through the Tax Setup screen.
    
    If you select **YES**, you will be accepting Taxes. Depending on your payout method, a pop-up will appear below.
    
    Currently, tax can ONLY be turned on and used with Concessions if you are on Direct Deposits.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV--shN-04cwM2w0uzndKOvy-20250227-162522.png?format=webp "Document image")
    
    If you select **NO** for Tax, you will see the following screen:
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-9BlF0hB4WZ0qZFsFVm-UN-20250227-162720.png?format=webp "Document image")
    
    Once you select the Tax option, you will click **Next**.
    
3.  From this page, you can select **Get Started.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ULhn3iz8oUBup2dgAMp_b_screenshot-2026-08-05-at-123805-pm.png?format=webp "Document image")
