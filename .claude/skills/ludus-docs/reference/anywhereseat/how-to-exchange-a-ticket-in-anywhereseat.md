# How to Exchange a Ticket in AnywhereSeat

Let's learn how to move someone's ticket from one event to another!

If a patron would like to view a different event than they originally purchased a ticket for, you can issue an exchange.

## To Exchange a Ticket:

1.  Look up the patron's order via the magnifying glass in your top navigation.

2.  At the top of their order's details page, click the **Exchange** button.

3.  Select the new event and **Confirm Exchange**. If you leave the "Resend Confirmation" option checked, they will receive an exchange confirmation and an updated calendar invite.
