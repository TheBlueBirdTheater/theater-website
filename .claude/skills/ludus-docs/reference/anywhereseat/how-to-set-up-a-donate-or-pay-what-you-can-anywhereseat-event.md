# How to Set Up a Donate or "Pay What You Can" AnywhereSeat Event

If you want to set up an event in AnywhereSeat that is donation-based or up to the patron, it's easy!

When setting up your event, check off "Name your own pricing." This allows your patrons to enter an amount of their choosing for their tickets instead of paying a set price.

You can set a **Minimum** amount starting at $0. So, if you wanted to allow patrons to watch for free, you could set it to $0. Those who want to pay can, and those who can't pay can watch for free.
