# How to Share Live Streams and Pre-recorded Videos through YouTube

If you wish to use YouTube to share either a live stream or a pre-recorded event, you can easily do this by setting the event up as Other (instead of a Live Stream or a Video).

When adding a link to a YouTube event, AnywhereSeat will act as a paywall to your event and one central location for patrons to find the event.

### **Set up a YouTube Event:**

1.  Go to your **Events** page on AnywhereSeat -> select **+Add Event**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-y4ioyyUHOiXsFb5ZP98a4-20250409-152239.png?format=webp "Document image")
    
2.  Once selected, you will see the option to set up a **Live Stream**, **Video**, or **Other**. When setting up a YouTube event, you will want to select **Other**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-emxV8HLArt9uoHZEGdAJi-20250409-152342.png?format=webp "Document image")
    
3.  Once selected, you will see the option to select Zoom, Google Meet, or Other. You will again select **Other**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-0jsOt6Lo3T0XMIsK42YQs-20250409-152559.png?format=webp "Document image")
    
4.  From here, you will add the **Direct Share Link** from your YouTube event. You will not want to use the YouTube embed link; that will not work here. The direct share link can be copied and input here.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-8ox5vzOpcl0voy0NOMrSs-20250409-152700.png?format=webp "Document image")
    
5.  Once the remaining details are input and the event is saved, you can preview the event through the "_Eye Icon_" next to the event time.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-AJWJtX3Zn70AkzTprnVdR-20250409-152931.png?format=webp "Document image")
    
    You will then see a pop-up to view the stream or video on a 3rd party platform.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-HILuV0PXYugSDHSlIEh9l-20250409-152948.png?format=webp "Document image")
    
6.  Finally, if you are doing a Live Stream, nothing will show until you go live. With a pre-recorded event, you will see that video show on YouTube.
