# Publishing Companies not Limited to a Specific Streaming Platform

**Note: this article only pertains to streaming. If you'd like to use us for live in-person ticket sales, please check out our** [**Ludus Tickets**](https://ludus.com/ "Ludus Tickets") **product.**

Some publishing companies have exclusive streaming partnerships for virtual shows, while others allow you to use the streaming platform of your choosing (such as AnywhereSeat).

Below is our running list of publishing companies that _**do not**_ limit you to one specific platform and/or do not have exclusive use partnerships. This list isn't exhaustive, so if you don't see your publishing company on the list, reach out, and we can help you determine whether AnywhereSeat is a good solution for you!
