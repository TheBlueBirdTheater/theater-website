# How to Reset a Ticket Code in AnywhereSeat

You might want or need to reset a patron's Ticket Code. We make it easy!

**To Reset a Ticket Code:**

1.  Look up the patron's order via the magnifying glass in your top navigation.

2.  Under "Order Details" next to the "Ticket Code" line item, click the **Reset Code** link and confirm. If you do not see the Reset Code link, it has not been used and will display as "Not Used."

Now, your patrons can use the same Ticket Code to enter your event. If you'd like to resend their order info, click the **Resend Confirmation** button at the top of their order page.
