# Embed AnywhereSeat

If you have enabled the [Embed Widget](https://support.ludus.com/embed-widget) on your Ludus account and also use AnywhereSeat, there is an embed code available for AnywhereSeat.

To gain access to this code, simply write into Ludus [Support](https://support.ludus.com/support) and the team will be happy to share that Embed Code with you!
