# How to Add Your Live Stream to AnywhereSeat

Let's walk through the steps of adding your Live Stream event to AnywhereSeat.

## To Add Your Live Stream:

**1**. Click the **Add Event** button

**2**. Choose your type of event: _Live Stream_

**3**. Enter your _Event Name_, _Description_ (optional), and _Cover Photo_ (optional)

**4**. Select how you want to live stream. All live streams are viewable via AnywhereSeat (no need to send patrons to an external page), but we need to know how you plan on live-streaming so we can correctly display your stream:

-   **Vimeo:** This option lets you embed your Vimeo live stream in AnywhereSeat. Once your live stream is set up in Vimeo -> select the ID number on your live stream's page under Event -> Link (see the screenshot below). Paste this number into your AnywhereSeat event, and you'll be good to go.

-   **Other:** This option allows you to embed a live stream in AnywhereSeat if you prefer to go this route (for example, if you have YouTube Live embedding capabilities). If you're having trouble finding the embed code for your live stream provider, reach out to AnywhereSeat support, and we'll help you find it!

_**Note:**_ You can set up your live stream and pre-sell tickets before going live, even if that's weeks in advance.

**5**. Under _Times_, select the _date(s)_ and _time(s)_ of your live stream

**6**. Enter the price for access to your live stream ($0 if you'd like it to be free)

7\. If you'd like to enable Real-Time Donations, Live Chat, or a Special Access Code for your event, do so here.

**8.** Finally, click **Add Event**

That's it! You're ready to share access to your live stream.

We recommend setting up your Live Stream at least 1-2 weeks in advance.
