# How to Use AnywhereSeat to Sell Tickets for a Zoom Call

If you'd like to sell tickets to a Zoom call, you can do that with AnywhereSeat!

When setting up your event in AnywhereSeat, select **Other** as your event type. You'll be able to enter your Zoom meeting ID. When patrons purchase a ticket, they'll be given access to your Zoom meeting 15 minutes prior to start (so there isn't a need to send out the meeting link yourself).

For more information on setting up Zoom events, check out [How to Use a Zoom Meeting for a Virtual Event in AnywhereSeat](https://support.ludus.com/how-to-use-a-zoom-meeting-for-a-virtual-event-in-anywhereseat)
