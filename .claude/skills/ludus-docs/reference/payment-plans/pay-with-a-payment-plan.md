# Pay with a Payment Plan

Once a class with a payment plan is live, the patron will see this option during checkout.

Payment Plans are currently available only as a payment method on the patron site and cannot be selected on the admin site.

1.  The customer will simply go to **Classes** and select the class with the plan they wish to register for.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Vi38aPCAlwmJtW86LRHfT-20260507-155443.png?format=webp "Document image")
    
2.  When they select Register, they will see fees, with **Payment Plan Available** as a payment option.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/GceSuqI-7abQ6DCVv-PbH-20260507-155611.png?format=webp "Document image")
    
3.  When a patron reaches the Cart page, they can select "additional payment options".
    
    This will give them the option for the Payment Plan.
    
    If you have "Invoice Me" as an option for your patrons, it will appear as an option.
    
    Patrons can select only one of these options at checkout, so if they select Payment Plans, they cannot also select Invoice Me.
    
    
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/14DQCkJzeQBmICyI2VLAt-20260507-155834.png?format=webp "Document image")
    
4.  When the patron selects Additional Payment Options, they will see the plan listed there and be able to apply that to their order.
    
    Simply select the Payment Plan option, and it will be applied.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/UonBAO6WyEvPn8mw49FBK_screenshot-2026-08-03-at-33209-pm.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/VOeYrMcGZ8dqhLxPO1w2l_screenshot-2026-08-03-at-33502-pm.png?format=webp "Document image")
    
    This plan will break down what is due and when each payment will be due.
    
    If the patron pays the first payment on 7/3 and the second payment is due on 7/4, the second payment will be processed the next day.
    
5.  Once the purchase is processed, the patron will be taken to the following confirmation screen, which breaks down the payments and the processed charge.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Oz1jdd9_wSOGJ6b6Z_iln-20260507-160809.png?format=webp "Document image")
