# Adjust a Specific Payment Plan

When you [View a Specific Payment Plan](https://support.ludus.com/view-a-specific-payment-plan) , you might need to edit or adjust that plan.

**There are several options available:**

### Collect Payment

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/XltPZGC75YBx1wbN892L1-20260507-170631.png?format=webp "Document image")

From here, you can collect payment in **credit**, **cash**, or **other** forms for the plan.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/HKCtNAjCZ3cy8eAGNdB35-20260507-170758.png?format=webp "Document image")

### Void the Payment Plan

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/J6Vawtwb-Boy5oc_a2NOU-20260507-171156.png?format=webp "Document image")

Once **Void** is selected, you can then choose to refund or waive (not refund) the payments.

Once you void this payment plan, no future payments can be collected for this class. **Please remove the attendee from the class if needed.**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9cSv0eGGy2Fds6xKSIUpz-20260507-171323.png?format=webp "Document image")

### Change Payment Method

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/QYYCCHAP8bcPM7zKgKuGD-20260507-171441.png?format=webp "Document image")

If a patron wishes to change their payment method and requests assistance, you can easily update it by clicking **\+ Add Payment Method** and saving the new credit card payment.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9SvRcDm0vaHyMszpDGi61-20260507-171827.png?format=webp "Document image")

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/BLjE327eqfyWQJU3q5SDQ-20260507-171848.png?format=webp "Document image")

### Process a Refund

If you need to refund all or part of a payment, you can do so in the Payments section by selecting Refund.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2EPkxJ-CRDYa-91XIZXxy-20260507-172045.png?format=webp "Document image")

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9geClYGlKN7Vja_SqSios-20260507-172119.png?format=webp "Document image")

### Edit the Payment Date

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-Gm7JcHl6MjDp_dXaZfxM-20260507-172409.png?format=webp "Document image")

If you need to edit the payment date for any or all patrons, select **Edit Date**.

This will affect only this patron's plan, not any other plans.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/n-0NdZBqzF_Ie7DvepTLp-20260507-172500.png?format=webp "Document image")

### Modify a Payment

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2YCGpcY1scT09KIxzMhdK-20260507-172708.png?format=webp "Document image")

_If you select Modify for a specific payment, you will be able to:_

1.  Waive that specific amount.

2.  Distribute that amount equally among the remaining payments.

3.  Pay that amount now, with the card on file.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CC1wrPugjIc89PyfdgbI0-20260507-172833.png?format=webp "Document image")

### Remove Items from the Plan

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZVY1ZRJR1L5646pt7-Lt8-20260507-173030.png?format=webp "Document image")

If you wish to remove items from the patron's plan, simply scroll down to the Items section and select **Remove Items**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Q3mUNcI_2GRZuxRJ-K3Hi-20260507-173114.png?format=webp "Document image")

**Previous payments will not be automatically refunded.** The remaining balance will be recalculated only across upcoming payments. You can manually refund previous payments.
