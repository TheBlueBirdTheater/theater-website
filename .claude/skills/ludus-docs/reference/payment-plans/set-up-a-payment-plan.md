# Set Up a Payment Plan

Payment Plans can currently only be set up under Classes. This can be set up when you are creating a Class.

Check out [Add a Class](https://support.ludus.com/add-a-class) for how to create a Class in Ludus.

**To set up a Payment Plan in a class:**

1.  Go to Collections (at the top of your account) -> Classes.
    
2.  From here, you will want to [Add a Class](https://support.ludus.com/add-a-class) .
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/LtFyAdu0DAeZsfPR0ZDwX-20260507-152454.png?format=webp "Document image")
    
3.  Fill in all required Class information, and when you reach the **Payment Options** section, select to turn Payment Plans **ON**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/LUAEQEn937jANZhIsxg2a-20260507-152611.png?format=webp "Document image")
    
4.  Once this is enabled, you will be able to set up your payment plan with however many payments you wish.
    
    The Payment Plan can have as many payments as needed, but they must equal 100%.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/V64DQmEKJZxnmkGRGp8k2-20260507-152835.png?format=webp "Document image")
    
    If you edit a payment plan after the Class is live and patrons are already on the plan, this will only affect future patrons.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/JFgLJsGXYH7xgih_1Fnt7-20260507-153014.png?format=webp "Document image")
    
5.  Once finished, be sure to select **Save** on the Class set-up, and you will be brought to set up the Class Fees and Dates.
    

Each class with Payment Plans enabled will have its own payment plan.

For example, if one is set up for your Improv Class, that will not automatically apply to any other class.
