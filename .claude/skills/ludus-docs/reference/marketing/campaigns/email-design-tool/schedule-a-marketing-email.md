# Schedule a marketing email

When setting up an email campaign, you can choose whether you'd like to send out the campaign immediately or schedule it for a custom date in the future. To set or edit the date and time the email is sent, follow the steps below.

1.  Navigate to **Marketing** --> **Campaigns**.
    
2.  Click **Edit** next to the campaign for which you'd like to set a send time.
    
3.  Scroll to the section titled "Scheduling" and insert the desired date and time.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2FKkoXV4iwU0hqM-YVS4H_screen-shot-2023-07-28-at-23757-pm.png?format=webp "Document image")
    
4.  If you are ready to place the email in the queue, click **Set Live**. If you'd like to keep editing, select **Save as Draft**.
