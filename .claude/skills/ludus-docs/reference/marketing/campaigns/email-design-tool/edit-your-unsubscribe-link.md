# Edit your Unsubscribe Link

To comply with spam regulations, all marketing emails must contain an Unsubscribe link. While one is automatically placed in your marketing email before sending, you can create one with the color and font you prefer.

### How to create a custom Unsubscribe link:

1.  Within the Email Designer, select a new column to add to your design in the location where you wish to add the Link.

2.  Now add a text block and enter the text you wish to have. Including the word Unsubscribe in that text.

1.  You can set the size, color, and font. Just like any other text box.

2.  The word Unsubscribe must appear in the box

3\. **Highlight** the word **Unsubscribe** and then **select the link icon** from the editor.

4\. Select **Special Link** and then **Unsubscribe** from the drop-down.
