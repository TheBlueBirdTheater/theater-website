# Set preheader text for email

When an email appears in an inbox, the recipient will see the sender, title, and preheader text. This preheader text acts as a preview before the user opens the email.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1niLwA8HZfVeygOAt5qwP_screenshot-2023-11-09-at-14346-pm.png?format=webp "Document image")

To set your preheader text:

1.  From the top navigation bar, click **Marketing** -> **Campaigns**.
    
2.  Next to the campaign you'd like to edit, click **Edit**.
    
3.  Scroll down to the "Content" section and click **Open Email Designer**.
    
4.  Along the right-hand side, click **Body**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/cw-Rul7eiQfHV5xVBgrVI_screenshot-2023-11-09-at-14822-pm.png?format=webp "Document image")
    
5.  Set your preheader text using the text box provided under "Email Settings".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/E0wI3mTGZourP2BOIj1ql_screenshot-2023-11-09-at-15123-pm.png?format=webp "Document image")
    
6.  Continue editing as needed _or_, to save, click **Continue** in the upper right-hand corner and then **Update** at the bottom of the campaign settings page.
