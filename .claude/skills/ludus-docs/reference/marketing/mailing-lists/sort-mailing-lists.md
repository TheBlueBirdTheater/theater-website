# Sort Mailing Lists

To sort the order in which your Mailing Lists appear, navigate to **Marketing** --> **Mailing Lists.**

1.  Click **Sort Mailing Lists**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gogka8ixoMXi6ipzDz44W-20250929-160226.png?format=webp "Document image")
    
2.  Drag the lists into the desired order.
    
3.  Click **Save Sort**.
