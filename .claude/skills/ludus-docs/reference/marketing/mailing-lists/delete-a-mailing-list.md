# Delete a Mailing List

To delete a Mailing List, navigate to **Marketing** --> **Mailing Lists**. Then, next to the Mailing List you'd like to delete, select **Delete**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/XyvubUnwjUjLWcGAJD8Sj-20250929-160644.png?format=webp "Document image")

_**This action cannot be undone.**_
