# Signup Patrons for a Mailing List Using Imports

You can add patrons in bulk to a mailing list by utilizing the Patron Import feature in Marketing.

### How to add patrons to a Mailing list via import

1.  Create or verify that your Mailing list exists in **Marketing** -> **Mailing Lists**.
    
2.  Gather and format the list of people to be imported to a mailing list on a CSV using the Sample file below.
    
    [patron\_example.csv](#)
    
    Only Email addresses are required, but you can add as much information as you wish. Remove any columns that you are not using from the form.
    
3.  Navigate to **Patrons** and select **Database**
    
4.  Click **Import.**
    
5.  Click or drag the CSV file into the Grey box labeled "Choose a File," then click "Continue."
    
6.  Once your file uploads, you will match the import columns to your file by selecting the appropriate items from the drop-down menu.
    
7.  Select the radio button under the Import Options box to **Subscribe patrons to mailing** lists. Then, check the boxes next to each list you wish to add patrons to.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/5HC1iQQYRIASqq8f94NJs_ludus-manual-admin-2024-05-29t092832227.png?format=webp "Document image")
    
8.  Click **Import** to complete the import and sign up
    

Like any patron import, importing duplicate or existing records will update information on existing patron records with the data included in this import.
