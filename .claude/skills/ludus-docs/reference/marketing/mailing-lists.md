# Mailing Lists

By default, all patrons are added to your marketing database. Unless they unsubscribe, you can send campaigns at your organization's discretion.

Mailing Lists allow your patrons to subscribe to specific, _additional_ mailings that interest them. Mailing Lists are self-subscribed by the patron and are different from the filtered lists of patrons you can create in audiences.

If you want to email all patrons in your database about upcoming ticket sales, you should use Audiences.

If you have a newsletter you want patrons to sign up for, you'd want to set up a Mailing List.
