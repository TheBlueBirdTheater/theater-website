# Resolving an "Email Size Too Large" Error Message

The "Email Size Too Large" error message appears when images and content exceed the maximum size for our email provider. This is generally caused by images being added to the email campaign via dragging and dropping directly into the image box rather than using the uploader provided within the Email design tool.

To ensure that your images are not too large, you will want to select the image block and upload via the provided upload tool. This will automatically resize and adjust the image so the file size is not too large.

## Uploading images in the email designer

Once you have added the image block to your email design, you will want to drag the file name into the Image file box shown below and click **Upload Image** to place it in your email.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/vkgwXT52PnVTKFQy8rZi0_download.png?format=webp "Document image")

Once you have uploaded the images with this method, the "Email Size too Large" message should be resolved. Please reach out to the Support team if you need additional assistance.
