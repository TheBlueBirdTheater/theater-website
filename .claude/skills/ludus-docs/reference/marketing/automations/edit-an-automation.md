# Edit an Automation

To edit an Automation, navigate to **Marketing** --> **Automations**. Then, click **Manage** next to the desired Automation.

Alter the fields and content design as needed. To review each area, check out this article.

_Suggested Article_: [Create an Email Automation](https://support.ludus.com/create-an-email-automation)

Be sure to click **Save** when done.

Any changes made will not affect Automations that have already been sent.
