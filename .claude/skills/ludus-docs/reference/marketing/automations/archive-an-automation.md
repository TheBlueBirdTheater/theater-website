# Archive an Automation

To **Archive** an Automation, navigate to **Marketing** --> **Automations**. Then, click the **View** button next to the automation you wish to archive.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CQZ7v1jo84weT9NV27p8z-20260610-144842.png?format=webp "Document image")

From here you can select to **Archive** the Automation.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/bc2S5QqsiZO2PxRQf_jgl-20260610-144907.png?format=webp "Document image")
