# Send a Test Automation

Once your automation is created, you will be able to send a test of that automation before it goes live and is sent to your patrons.

Go to **Marketing** (at the top of your account) -> **Automations**.

From here, select **Options** (next to the Automation you wish to test) -> and then select **Send Test**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/etgRxO7rPlqbt94ac5Cl8-20260608-161355.png?format=webp "Document image")

At this point, you can enter up to 15 emails (using a comma to separate them) that you wish to send the test to.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4VtZm815gFSZ66t8WtMJi-20260608-161432.png?format=webp "Document image")

Once that is sent, you will receive the Automation as the patron will receive it (so you are able to test and make sure that the automation looks how you want it to).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nwSL5HQlaF5eyE710MdXG-20260608-161828.png?format=webp "Document image")
