# Set your Automation triggers

When you first create your Automation, you will choose triggers for the email. This is a set amount of time (hours or days), before or after an event, at which the email will send.

When you are creating your Automation, there will be a section labeled "Trigger". You will see two boxes in that area.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/0oAgfoosPq8noJ--gcKkU_screen-shot-2023-08-11-at-111056-am.png?format=webp "Document image")

In the first box, select which option best fits your needs.

-   X Days After Event Starts

-   X Hours After Event Starts

-   X Days Before Event Starts

-   X Hours Before Event Starts

-   Custom Date

-   When selecting custom date (unlike selecting days/hours before or after the event) you can select the exact date and time you want your Automation to be sent (see below).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/W_pAhIuO2s35v_rka_JHE_screenshot-2026-06-30-at-34031-pm.png?format=webp "Document image")

In the second box (for X days/hours), fill out what number should go in place of X. For instance, if you want to send it out 9 hours before the event, choose "X Hours Before Event Starts" and insert "9" in the second box.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CHZQGjO9y8wWdv1A5oBkA_screenshot-2026-06-30-at-34246-pm.png?format=webp "Document image")
