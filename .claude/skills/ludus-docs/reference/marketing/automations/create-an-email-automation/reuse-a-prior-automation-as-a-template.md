# Reuse a prior Automation as a template

When creating your Automation, you can reuse the email design from a previous Automation as a template.

To do so, start creating an Automation.

_Suggested Article_: [Create an Email Automation](https://support.ludus.com/create-an-email-automation)

Then, under the section labeled "Template," navigate to the tab named **My Automations**. There, you will see a listing of your previous designs. Click on the design you'd like to utilize.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/DVhHIgPOnF4l0hggcIn4U_screenshot-2026-06-23-at-103327-am.png?format=webp "Document image")

You can delete templates that were created by accident or are no longer needed as originally intended. If you wish to delete a template, you can do so when you create an Automation under "My Automations".

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/xYyAEOSfhc1FYUWedeiKw_screenshot-2026-06-23-at-102740-am.png?format=webp "Document image")

You **cannot** delete a template that is attached to a live or draft automation.
