# Merge Tags & Automations

If you wish to customize your Automations (such as addressing each patron or including event details), you can do so easily with Merge Tags.

### Add Merge Tags to Automations

1.  To add Merge Tags to your Automation, go to **Marketing** (at the top of your account) -> **Automations** -> **New Automation**.
    
    This can also be updated or added to an Automation that has not yet been sent out. Once an Automation is sent, you can no longer add this.
    
2.  When you go to create your new campaign, select a **Starter** template or one of the templates you created under **My Templates**.
    
    The [Support](https://support.ludus.com/support) team is always available if you need additional help navigating Automations as required.
    
3.  Once you have a text box added to your Automation, you can customize the message so it is directly addressed to your patron.
    
4.  Begin by clicking the text box, where you will see Merge Tags along the top.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-36VuINncVlsGInAx02fla-20250428-163028.png?format=webp "Document image")
    
    **Merge Tags for Patron:**
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-nDQGTjKUsLvtyIQUSVMWy-20250428-165007.png?format=webp "Document image")
    
    **Merge Tags for the Event:**
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-A2Hb93LVJLdfgEh9bCQhl-20250428-165041.png?format=webp "Document image")
    
5.  From here, place the cursor where you would like the patron's name to go. If after "Dear", add a space and leave the cursor there.
    
    Additionally, with automations, you can include the following Merge Tags:
    
    1.  Event Date
    
    2.  Event Time
    
    3.  Event Title
    
    4.  Event Venue (Address)
    
    5.  Event Venue (Name of Venue)
    
    In the image above, it says, "Prom is 7 days away, on..." After that, I can add the **Venue Date** or **Venue Time**.
    
6.  Next, click **Merge Tags**. At this point, you can select a first name or both first and last names.
    
    Additionally, you can also add that event information.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-4Xei_3uWZc-_uFfGcARLr-20250428-163524.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-xmrzjzB1MvFvX9QBCRYx5-20250428-163546.png?format=webp "Document image")
    
    If using both first and last names, you will want to add a space between those.
    
    The event information is customized to that patron's purchase date. So if your event spans multiple days, it will only show the purchase date in the Merge Tag!
    
7.  Once your Automation Design is done, be sure to save it. Once you close out your design, you can preview it and schedule when you wish to send it out.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-Ls4vWaSc0FiNhrLrl3Xgj-20250428-163618.png?format=webp "Document image")
    
8.  Once that email is sent, it will then be customized to the patron and any other event information you added.
    

By using the Merge Tags feature, you can now directly address your automations, making them feel more personal.
