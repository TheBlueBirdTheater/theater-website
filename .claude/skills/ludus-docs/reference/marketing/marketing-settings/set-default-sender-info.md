# Set default sender info

Instead of doing so on a Campaign by Campaign basis, you are able to set Default sender info in your Marketing Settings.

To do so, navigate the **Marketing** --> **Settings**. Within the section labeled **Basic Info,** set your default Friendly-From Name a

1.  Navigate to **Marketing** --> **Settings**.
    
2.  Next to the section titled **Basic Info**, type in the Friendly Form Name and the Reply-to Email that will receive responses to any marketing emails.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/0eMpmTBwNz4Q_QiN2iDJG_screen-shot-2023-09-06-at-102102-am.png?format=webp "Document image")
    
3.  Click **Save Changes**.
    

This will simply be the default to save you a bit of time when setting up each campaign. You can still change the From Name and Reply-to Email for individual campaigns.
