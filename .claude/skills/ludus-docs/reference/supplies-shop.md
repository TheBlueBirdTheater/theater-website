# Supplies Shop

# Supplies Shop Overview

While no additional hardware is required to use Ludus, a few items can enhance your experience with the software and help speed up your box office line!

If your organization is tax-exempt, please contact Ludus Customer Support before making a purchase.

Items purchased from the Ludus Supplies Shop are non-returnable.
