# Enable Student Credit

To enable **Student Credit**, you will want to go through the following steps:

1.  Select **More** (at the top of the admin panel) -> then select **Students**.

2.  Once in the Students Feature, you will want to select **Settings**.

3.  When in the **Students Settings** you will want to turn **Student Credit** on by selecting **Yes**. This will enable tracking student sales.
