# Student Credit

If you are looking to track student sales through Ludus this can easily be done through our Student Sales Feature! This could be useful if you would like to see how many tickets each student has sold, or if you need to keep track of the percentage for a trip or some other event you might track credit for!

These sales can be tracked via the student's name in the Ludus system and make it easy for patrons to attach a sale to a student upon checkout!

Ludus does not pay the students this money. This is purely for tracking purposes on your end.
