# Merge Student Profiles

If you run into the issue where a student is added multiple times under Students, you can merge those students into one profile.

### Merge Student Profiles

1.  Start by clicking **More** (at the top of your admin account) -> **Students**.
    
2.  From here, **locate** the student's name you wish to merge on your list.
    
    This is similar to [Merge patron profiles](https://support.ludus.com/merge-patron-profiles)
    
3.  **Select** **View Ledger** for the Student you wish to Merge.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/I3cYkVqFVLz59zGm4ZywG_merge-student-profiles-archbee-document.png?format=webp "Document image")
    
4.  Once in the **Student's Ledger**, you can select **Merge** -> **Select** the profile you wish to **Merge** with.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zCk21clk1p1hwVuCGQuxk_merge-student-profiles-archbee-document-1.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/uHV27hxFf_VocB46NHEeT_screenshot-2024-05-15-at-102115-am.png?format=webp "Document image")
    
5.  Once you select to Merge the student profiles, you will get a pop-up message. This will ask you to verify that you want to merge and allow you to integrate the students into one profile.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/t5PDps8RUyVhrLNmc9-6n_screenshot-2024-05-15-at-102811-am.png?format=webp "Document image")
    
6.  Once finished, you will get a message that the merge was successful and you will be all set with just 1 student profile!
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZM1gqAAKHgltPs3yn8lYI_screenshot-2024-05-15-at-102820-am.png?format=webp "Document image")
