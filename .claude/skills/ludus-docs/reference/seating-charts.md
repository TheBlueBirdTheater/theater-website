# Seating Charts

Within Ludus, you can create seating charts and customize them for each event as needed! These charts can include tables, row seats, or both. To complete your chart, you can add shapes, text, and color-based sections. The following sections will bring you through each of those items and more when you set up your seating charts and events!

## What can this feature help with?

The Seating Chart feature in Ludus is required for reserved-seating events. The maker can create standard reserved seating and table seating, and can adjust it to create a black-box seating arrangement as well.

## Why use this feature?

If you are planning to host reserved or even hybrid events, the seating chart maker will be crucial for creating your seating arrangement.

## What makes this feature so special?

Ludus was built for the performing arts by people who care about them, and we want to make your life easier. The Seating Chart maker in Ludus lets you create and customize your seating arrangement as needed. This includes the ability to:

-   Assign color coding to your seats

-   Customize seat and section names

-   Move and rotate sections/rows as needed

-   Showing ADA seating and other seats that might need to be marked for one reason or another

## So how does this feature work?

Essentially, once you access the seating chart maker, you will be able to start creating your chart right away. We recommend having a diagram or image to work from, but you can move and mold the maker to suit your seating and events.

## How do I start creating Seating Charts?

**Steps to create a chart:**

Select **More** (at the top) → **Seating Charts** → click **Create Seating Chart** to get started.

Once you name your chart, start adding your sections, tables, labels, and shapes by hovering over the **green plus button** and clicking the element you would like to create.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CCzpz3D2x0hHMk6ESalpj_ludus-manual-admin-2024-06-07t140340436.png?format=webp "Document image")

As you add new elements, enter the necessary information and click **Save** when done.

It is recommended that you save your chart often while creating or editing. This creates a backup that can be recovered if needed.
