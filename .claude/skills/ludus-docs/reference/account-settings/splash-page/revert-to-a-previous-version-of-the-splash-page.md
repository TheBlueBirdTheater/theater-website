# Revert to a previous version of the Splash Page

Once a Splash Page is saved, it is logged in the Version History. To revert to a previous version of the Splash Page, click the **Settings Wheel Icon** (⚙️) and choose the **Splash Page** tab. Then click **Version History** at the bottom of the page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/S85n-cSyJvnOSBP-rdGNt-20260609-202900.png?format=webp "Document image")

Choose the version that you'd like to revert to and click **Revert.**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mT_iVkbfu48VVj5pGbNfC-20260609-202923.png?format=webp "Document image")

If you have many versions saved, you can click **Preview** to view what each version looks like before choosing to which you'd like to revert.
