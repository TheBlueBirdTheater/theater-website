# Basics of the Splash Page design tool

The drag-and-drop designer allows you to customize your Splash Page with different elements such as text, images, videos, links, and more! If you are familiar with our email design tool, you are already a pro, as the Splash Page maker utilizes the same technology. Check out the sections below to get more familiar with how the tool works.

## Background Editing

Customize the background color, width, alignment, and more by selecting **Body** from the panel on the right-hand side.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/L3qBWt0wMzrhr1Ba6GuGg_screen-shot-2023-08-03-at-101514-am.png?format=webp "Document image")

If you have a pattern or image you would like to use instead of a solid color, you can insert it by clicking the **Body** section and choosing **Upload Image**.

## Content Editing

### Blocks:

Decide how many elements are side by side by inserting different Blocks. Click **Blocks** from the panel on the right-hand side and drag the desired layout to the desired spot in the email body.

### Content:

Fill any of the blocks with the type of content listed below. Simply drag the element to the desired area.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/5sfEjOSZYAR6v9VgBLa63_screen-shot-2023-08-03-at-102437-am.png?format=webp "Document image")

-   **Columns:** This feature allows users to add columns to their design, enabling a more organized layout.

-   **Button:** Add any type of button in your email. You can change colors and styles.

-   **Divider:** This provides appropriate spacing at any point desired in the design.

-   **Heading:** Add headings (from levels 1-6) to the design.

-   **HTML**: This tool provides room to add custom HTML to the design.

-   **Image:** To make your emails attractive, you can add images using this tool. (JPG and PNG files recommended)

-   **Menu:** Menu is a built-in tool used to create navigation menus.

-   **Social:** Add social media icons/links to your design.

-   **Text:** Add custom text to your design. This includes merge tags and AI-powered Smart Text.

-   **Video:** Add YouTube or Vimeo videos to the design. This tool automatically generates thumbnails for videos in emails, ensuring they render correctly on all platforms.
