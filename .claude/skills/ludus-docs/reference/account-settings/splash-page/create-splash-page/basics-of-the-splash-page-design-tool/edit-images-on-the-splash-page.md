# Edit images on the Splash Page

The Splash Page Editor includes the ability to edit your images. This can come in handy if you want to size all your pictures so they all display the same.

The editor allows you to do the following:

-   Add Filters

-   Resize your image

-   Crop images

-   Draw on the image

-   Add Text

-   Add Shapes

-   Add Stickers

-   Add Frames

-   Adjust the corners of the image

To edit your images, click on the image on the page layout within the editor and from the right side panel, click **Edit Image.** This will open a pop-up to work with your pictures, where you can select the actions to apply to the image.
