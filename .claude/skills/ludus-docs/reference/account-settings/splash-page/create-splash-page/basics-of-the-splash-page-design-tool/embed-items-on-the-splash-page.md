# Embed items on the Splash Page

The Splash Page editor offers an HTML code block that allows you to add items from around the web to your splash page, such as Google Maps, Countdown Widgets, Instagram Feeds, and others.

### Use the HTML block to embed an item

1.  Click the **Settings** icon on the top navigation bar, and select **"Splash Page.**" Then click **Edit Splash Page**
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-0g88U2vApz2lJRhWwM1fY-20241030-152435.png?format=webp "Document image")
    
2.  Locate the location you wish to add the item to your splash page.
    
    If you haven't already, add a Block where you will place the HTML content to the page.
    
    _**(You can add it to an existing block if desired.)**_
    
3.  Drag the HTML content item into the block you created.
    
4.  Click the content box to open the side panel and paste in your embed code. Adjust any width and height parameters in the embed code to fit as you would like it to appear. (Splash pages generally are set to 1100px wide by default)
    
5.  Save the page when done.
