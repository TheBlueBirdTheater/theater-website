# Enable Collapsed View

Collapsed View provides a streamlined way to display events with multiple event times. Check below for how to enable this option.

1.  From the top navigation bar, click the **Settings wheel icon** (⚙️)
    
2.  Navigate to the **Design Tool** tab.
    
3.  Click the **Events** section on the **Design Tool** and then choose the circle for **"**Collapsed View".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2i984pRrVZ0OkmoiUOTA5_screenshot-2026-08-21-at-111226-am.png?format=webp "Document image")
    

Now, when your patrons go to buy tickets, they can click **Order Now** and the available event times will expand.
