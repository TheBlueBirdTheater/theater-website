# Change the colors on your Ludus page

Within the Design Tool, you have the ability to customize the colors of your Ludus ticketing page. Follow the instructions below to edit each color setting.

1.  Click the **Settings Wheel Icon** (⚙️) in the upper right-hand corner.
    
2.  Click the **Design Tool** tab.
    
3.  Choose which area (**Main, Header, Notices** along the top) you want to edit.
    
4.  Click the dropdown arrow next to the desired area in that section.
    
5.  From the options box, either select a new color or insert the color code in the text box.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yT72D7ebfYPU9OPoPL3VZ_screenshot-2026-08-21-at-111411-am.png?format=webp "Document image")
    
6.  Click **Choose**
    
7.  Click **Save Design**
    

**Check out the guide below to see exactly where each color appears on your page.**

## Where does each color appear?

### Main:

-   Background (1)

-   Links (2)

-   Titles (3)

-   Buttons (4)

-   Buttons Font (5)

### Header:

-   Header (6)

-   Header Font (7)

### Notices:

-   Background (8)

-   Links (9)

-   Titles (10)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/jeqUi23uHvZXpSKE66YZe_ludus-design-tool-guide.png?format=webp "Document image")

When using the Embed Widget, some color changes do not carry over into the widget, including the Main Background Color and Header Background Color
