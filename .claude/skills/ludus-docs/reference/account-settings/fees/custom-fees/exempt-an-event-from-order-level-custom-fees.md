# Exempt an event from Order-level Custom Fees

When you create an Order-level Custom Fee, it is automatically applied to all events on your account. However, there may be times when you wish to exclude an event from these Order-level Custom Fees.

Custom Fees are separate from the Ludus fee on card transactions. To learn more about Custom Fees, check out this article!

_Suggested Article_: [Custom Fees](https://support.ludus.com/custom-fees)

### To exempt an event from Order Custom Fees:

1.  On the main **Events** tab, click **More** next to the desired event and click **Settings**.
    
2.  Scroll to the bottom and click **Additional Options**.
    
3.  Check the box for "Exempt event from order custom fees".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/l_ljkK6FBmR1oypj3Pig6_screen-shot-2023-09-06-at-104221-pm.png?format=webp "Document image")
    
4.  Click **Save Settings**.
