# Ludus Partners

The Ludus Partnership Program is a dynamic collaboration aimed at strengthening the performing arts community, beginning with state and national organizations that already make significant contributions to the arts. By joining this program, these organizations can reap financial benefits such as increased sponsorships, revenue-sharing opportunities, and access to a powerful ticketing and event management platform. If you would like more information on the Ludus Partners or are curious if your group or organization is a partner, check out our [**Partners Page**](https://hello.ludus.com/partners "Partners Page") for more information!
