# Enable Thermal Printing

This setting, when enabled, activates the ability to utilize basic printing with your thermal printers rather than having to set up the printer as a raw printer.

More information on Basic Printing to Boca and Lemur Printers can be located in the article Basic Printing - [Thermal (5.5 x 2)](https://support.ludus.com/basic-printing-thermal-55-x-2 " Thermal (5.5 x 2)")
