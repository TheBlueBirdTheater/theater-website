# Enable DYMO printing

To enable DYMO printing functionality on your account:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner.
    
2.  Click the **Advanced** tab.
    
3.  For the section titled **DYMO Printing**, click **On**.
    

To learn more about the setup for DYMO printing, check out the following article.

_Suggested Article_: [DYMO Printer](https://support.ludus.com/dymo-printer)
