# Add a User

To add a new user to your Ludus account:

1.  From the top navigation bar, click the **Settings wheel icon** (⚙️) and navigate to the **Users** tab.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-5oUgmX9kYz7JgAquaKoRR-20250620-193404.png?format=webp "Document image")
    
2.  Click **+Add New User**
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-ESmrdvCk2_1L7ploc8IF2-20250620-193453.png?format=webp "Document image")
    
3.  Insert the user's name, email, desired username, password, admin level, and Access Level.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-Tpjk8ETIo2dYJookReH9z-20241111-194737.png?format=webp "Document image")
    
    If you check the box for "Require password change on the first login", the user will be prompted to set their own password in the confirmation email.
    
4.  Click **Save**. The user will receive an email with login details.
    

It is recommended that EACH user have their own user profile. If you have multiple volunteers scanning tickets, you can set them up as _**Scanner1**_, _**Scanner2**_, and so on. The same should go for sellers and other user levels.
