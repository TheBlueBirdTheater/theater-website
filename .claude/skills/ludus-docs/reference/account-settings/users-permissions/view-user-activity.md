# View User Activity

## Overview

When an admin takes an action, such as processing a sale or making an exchange, a note is added to your activity log. You can view this log account-wide or narrow down what one specific user has done

### To view user activity:

1.  From the top navigation bar, click the **Settings wheel icon** (⚙️) and navigate to the **Users** tab.
    
2.  **To view all activity**: Click **Activity** from the top.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ArU78mFbeJAG1UgGEpBzC_screenshot-2026-07-14-at-102344-am.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ixNyMLsinuewiXEUqfGPP_screenshot-2026-07-14-at-102301-am.png?format=webp "Document image")
    
    **To view activity for one specific user**: Click the 3 dots to the left of the user and select **User Activity**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RwcW4Mlw_sg34uqofBxJH_screenshot-2026-07-14-at-102407-am.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Dg3HpU8s3_-qCsCAimEgq_screenshot-2026-07-14-at-102728-am.png?format=webp "Document image")
    

In User Activity, you are able to filter by:

-   **Date Range**

-   **Admin Type**

-   **Admin (admin name)**
