# User Types - Breakdown

Each type of User can be broken down further, with different restrictions and access. Those include access to everything, limited (accessibility), and guest (accessibility).

### Super Admin

This user has full privileges to all features and account settings. There are no restrictions on this type of user.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-wUPnsWPCwVpzDWuk-DU5R-20250114-201051.png?format=webp "Document image")

### Admin

This user has full account management privileges, except for account settings.

1.  **Everything Admin User**
    
    This user type has the same access as the Super Admin, except for access to the Account Settings.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-w4ngUfrlM97FCMFLvez8r-20250114-201326.png?format=webp "Document image")
    
2.  **Limited Admin User**
    
    An Admin User can be created with full access to a limited number of features.
    
    **For example**, they could have full access, but only in Collections.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-dnQ1DM6NjtixTrwmCYKb4-20250114-202002.png?format=webp "Document image")
    
3.  ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-8fk2cARTmR30_oL58OJfB-20250114-202017.png?format=webp "Document image")
    
    **Guest Admin User**
    
    A Guest Admin will have full privileges, but only for specific events, classes, or collections. When creating the user type, those items can be assigned to it.
    
    **For example**, they could only have full access to Graduation.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-BbCEDa86jomBlHknhcv60-20250114-202319.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-T9w6tppd2lpNy6-eIrxBr-20250114-202336.png?format=webp "Document image")
    

### Seller

This user has sales capabilities on the admin panel.

1.  **Everything Seller User**
    
    This user has sales capabilities (including refunding and releasing purchases) on the admin panel.
    
    These users will not have access to items like "Marketing," even though they can view them.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-OlAEznf1o6XflOSnfCwtd-20250114-203123.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-SvPG4zTracCoHX_pnKog4-20250114-203135.png?format=webp "Document image")
    
2.  **Limited Seller User**
    
    This user has sales capabilities (including refunding and releasing purchases) on the admin panel, but with a limited number of features.
    
    **For example**, the user may ONLY have access to the Events.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-6-cBlAmQZ6CUQaH_y-1lT-20250114-203733.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-tCo7ZlSuR6EEZfdbpz52o-20250114-203805.png?format=webp "Document image")
    
3.  **Guest Seller User**
    
    This user has sales capabilities (including refunding and releasing purchases) on the admin panel, but only for specific events, classes, or collections.
    
    **For example**, the user may only have access to one class (Cello Lessons)
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-zwbsISJd6xUNijX_I_3U9-20250114-204043.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-RCSRxA1eBTWbZEp45Aumw-20250114-204032.png?format=webp "Document image")
    
4.  **Additional Permissions**
    
    Choose whether this user can issue refunds. If disabled, all refund options are hidden. Limited users can only refund within their assigned core features.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/C4gIsmC7_iNkPaEUHxH4X_screenshot-2026-07-14-at-112825-am.png?format=webp "Document image")
    
    _For refunds_ - Sellers with access to refunds cannot process fundraiser/donation refunds, gift card refunds, or payment plan refunds/voids. Those remain restricted to Admins and Super Admins.
    
    Additionally, for mixed-item orders, sellers can only refund item types they have access to.
    

### Viewer

This user can view sales and info but cannot make any changes.

1.  **Everything Viewer User**
    
    This user can view everything on the Ludus Admin panel, but they cannot make changes to the account.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-i2V0Pb_CVm0e6NxmWAx8a-20250114-204755.png?format=webp "Document image")
    
2.  **Limited Viewer User**
    
    This user can view only specified parts of the Ludus Admin panel, but they cannot make changes to the account.
    
    **For example**, the user may only have access to volunteer management (viewing only).
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-TBYyA-K9eDOAL9Sz_Odt4-20250114-205003.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-QP650KHdmRgZc65DgzuH4-20250114-205047.png?format=webp "Document image")
    
3.  **Guest Viewer User**
    
    This user can view only events, collections, or classes of the Ludus Admin panel, but they cannot make changes to the account.
    
    **For example**, the user may only have access to a Raffle Collection (viewing only).
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-u_1CORYV8ajbWpdksR1qf-20250114-205244.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-SGl9-ifz6S-g_znPkpeQC-20250114-205322.png?format=webp "Document image")
