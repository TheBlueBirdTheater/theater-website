# Recover a User

If a user is deleted and later needs to be recovered (for any reason), this can be easily accomplished on the **Users** tab.

You will want to go to **Settings** (represented by the gear at the top) -> **Users** -> **Deleted Users**. From here, you can view all deleted users and recover any of them from the list.

Click the "three dots" next to that user to either **View the User Activity** or, in this case, **Recover** that user.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-vM4K4FzESLygYtQ5jMikh-20250721-125746.png?format=webp "Document image")

Once the user is recovered, they will regain access to your Ludus account. Read through [Edit a User](https://support.ludus.com/edit-a-user) for more information if you need to edit any user details!
