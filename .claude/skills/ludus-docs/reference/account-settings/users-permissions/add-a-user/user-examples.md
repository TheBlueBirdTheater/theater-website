# User Examples

When setting up a Seller or Viewer User Profile, you might need examples of what they should look like or ideas for setting them up. The following will walk you through a few of the "basic" profile setups and how those function.

## Sellers

### Seller (Everything)

When setting up a Seller, if you wish for them to have access to everything, select that in the User setup.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/TceE3bpNR0_0vhdSAPqSF_screenshot-2026-07-14-at-114105-am.png?format=webp "Document image")

As the title says, this user will have typical seller permissions (selling, exchanging, and releasing tickets), but they will also be able to add patrons and view other areas of your account.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-VxGxZ3K_KXmUmW7qqLryr-20241031-143234.png?format=webp "Document image")

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-DCigzeisFrMIkcVg6Dfai-20241031-143234.png?format=webp "Document image")

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-Epso5vakPOpAjF0vRhy8h-20241031-143234.png?format=webp "Document image")

### Seller (Limited)

When setting up a Seller, you may not wish them to have access to everything on your account (even if that means they can only view certain items). In this case, you can set Limited access. When setting this up, you can select access to only items that would be sold on your account.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-nDjEmDecI-N3D3nQCpqix-20241111-200306.png?format=webp "Document image")

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-kcuXclAhg7d7zT5ALmyHg-20241031-143233.png?format=webp "Document image")

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-JIlFWmYORGxTfBRhwqCA8-20241031-143233.png?format=webp "Document image")

When setting up a Seller User with access to only these specific items, you will see that they can access them only as a seller. In this case, they can only sell from Events, Collections, Classes, Fundraising, Gift Cards, Passes, and Invoices. Additionally, they can exchange or refund/release a purchase.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-2h3KYbts5KeHUSXAPUoYm-20241031-143233.png?format=webp "Document image")

### Seller (Additional Permissions)

When setting up a seller profile, choose whether this user can issue refunds. If disabled, all refund options are hidden. Limited users can only refund within their assigned core features.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/C4gIsmC7_iNkPaEUHxH4X_screenshot-2026-07-14-at-112825-am.png?format=webp "Document image")

## Viewers

### Viewer (Everything)

When setting up a Viewer, if you wish for them to have access to everything, select that in the User setup. When this user is created, they can view everything in your account but cannot make any changes.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-fAnpNxmyBkWJizhQjc82z-20241031-143233.png?format=webp "Document image")

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-UOmmyC9xrKBFRlFbsw6gT-20241031-143233.png?format=webp "Document image")

### Viewer (Limited)

When setting up users, there may be a need to create a user for finance or an accounting department so they can follow along with the reporting. If this is the case, you can create a Viewer with Limited access for reporting only.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-YRkuG98k0tZpxZslfSfiF-20241031-143233.png?format=webp "Document image")

When set up and saved, those users will only see reporting as an option when signed in.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-SFRALn-0Dmy6RPenxuEgY-20241031-143233.png?format=webp "Document image")
