# Edit a User

### To edit an existing user:

1.  From the top navigation bar, click the **Settings wheel icon** (⚙️) and navigate to the **Users** tab.
    
2.  Click the three dots located to the right of the user and select **Edit.**
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-6eZN07yA5pvy5lw-KpU0N-20250620-193647.png?format=webp "Document image")
    
3.  This will allow you to update the name, username, email address, admin level, and access level.To change the password, click **Password**.
    
    To change the password, click **Password**.
    
    _Suggested Article_: [Reset User Password](https://support.ludus.com/reset-user-password)
    
4.  Click **Save** to finish.
