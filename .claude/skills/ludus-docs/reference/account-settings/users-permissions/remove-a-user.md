# Remove a User

### To entirely remove an existing user:

1.  From the top navigation bar, click the **Settings wheel icon** (⚙️) and navigate to the **Users** tab.
    
2.  Click the three dots to the right of the desired user record and select **Delete User**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-0hrPxRIGfuSXhWe-sMDrg-20241111-195248.png?format=webp "Document image")
    
    You must have at least one Super Admin user on your account at all times.
    
3.  Verify that you'd like the user removed.
