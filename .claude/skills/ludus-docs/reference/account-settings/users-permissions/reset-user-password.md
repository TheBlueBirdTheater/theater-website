# Reset User Password

To reset a user's password, go to **Settings** (⚙️ at the top of your admin panel) -> **Users**. Once there, click the three dots to the right of the user's record and select **Change Password**.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-wPirrk9k_ABxMWJ1neS5m-20241111-195923.png?format=webp "Document image")

You can also select **Forgot password** at login to get a password reset sent to your email!
