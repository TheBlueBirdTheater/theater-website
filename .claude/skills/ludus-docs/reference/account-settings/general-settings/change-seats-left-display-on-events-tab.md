# Change "Seats Left" display on events tab

On the Events tab from your admin panel, there is a gray display bar that shows real-time ticket availability. There are two different ways this can be displayed:

-   **Seats Left** - the total number of tickets for the event time minus tickets that have been sold and tickets that are held as a reservation.

-   **Seats Sold** - only the total number of tickets that have been sold, not reservations.

By default, this real-time counter will appear as "Seats Left."

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YEXCdWJjd_xHmZRCNVPhp_screenshot-2023-12-04-at-24254-pm.png?format=webp "Document image")

## Change the view to Seats Sold

Your organization may prefer to see this overview as seats sold instead of seats left. This will only show the number of tickets that have been sold and will ignore any reservations that have been made.

To make this change:

1.  Click the **Settings wheel icon** in the upper right-hand corner.
    
2.  From the "General" tab, scroll to the section titled "Seats Display".
    
3.  Click the button for "Seats Sold".
    
4.  Click **Save Settings** to finalize.
    

The events tab will now display the availability bar as "Seats Sold"

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pnK7jZPw2xLeXudM4Qy3q_screenshot-2023-12-04-at-32248-pm.png?format=webp "Document image")

Hover over the box that shows the seats left/sold to view the opposite statistic.
