# View the Deposit Status of a Check

To verify if a check has been cashed/deposited, navigate to **Reports** (at the top of your admin panel) -> **Proceeds**. You will see an icon next to the check number letting you know the check has been cashed or deposited.

If you have any questions about your proceeds, reach out to Ludus [Support](https://support.ludus.com/support) for more assistance!
