# Choose a primary check option

### Set a primary check option

If you have multiple check payout options, you will have a starred primary method. This will be the default option that is selected automatically when you create a new event, collection, donation category, etc. By default, this will be the first payout option that you set up.

To set/alter your primary check option:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner of your screen.
    
2.  Navigate to the **Payments** tab.
    
3.  Next to the desired payment option, click the **Star icon**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/wcyyP8o_shBV6BNb7zFKl_screen-shot-2023-09-06-at-63013-pm.png?format=webp "Document image")
    
    If the start is green, that is your primary check option. You are unable to delete your primary check option.
