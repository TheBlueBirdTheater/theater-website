# Add paper check payout option

With paper checks, you can set one or multiple payment options. If you have multiple different check options, you can set where a check is sent depending on the event, collection, donation category, etc.

_Suggested Article_: [Set alternative check methods per event/donation/etc.](https://support.ludus.com/set-alternative-check-methods-per-eventdonationetc)

### Information needed

-   The "**Pay to Account**" name

-   A Mailing Address

-   An EIN/Tax ID

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/DOKNkwP80NMcRaaeMydLS_screen-shot-2024-01-30-at-111128-am.png?format=webp "Document image")

With that information, you will be able to set up checks as your payout method.

### Add a new paper check payment option

To add a paper check option:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner of your screen.
    
2.  Navigate to the **Payments** tab.
    
3.  Click **+Add Payment Method**.
    
4.  Fill out the appropriate details and click **+Add Method**.
    
    If you have multiple check payout methods, repeat steps 4 and 5 as needed.
