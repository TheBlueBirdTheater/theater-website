# Set alternative check methods per event/donation/etc.

One of the perks of paper check payouts is that you can assign different recipients for each event, collection, class, donation category, pass, etc. Check out the drop-down menus below to learn where to find the check option setting for each item within Ludus.

These menus will only appear once you have multiple check methods set up. To learn more about setting up a check payout method, check out this article.

_Suggested Article_: [Add paper check payout option](https://support.ludus.com/add-paper-check-payout-option)

### For Events

1.  On the main **Events** tab, locate the desired event.
    
2.  Click **More** --> **Settings**.
    
3.  Scroll to the bottom and click **Additional Options**.
    
4.  Next to **Payout Method**, use the drop-down menu to select the desired option.

### For Collections

1.  From the top navigation bar, click **Collections** --> **Standard**.
    
2.  Next to the desired Collection title, click **Options** --> **Settings**.

3.  Next to **Payout Method**, use the drop-down menu to select the desired option.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-buY5lPPZp_uekwq-Tqy_l-20250428-184814.png?format=webp "Document image")
    

### For Classes

### For Donation Categories

By default, general donations will be sent to the primary payment option on the account.

_Suggested Article_: [Choose a primary check option](https://support.ludus.com/choose-a-primary-check-option)

If you have different Donation Categories, you can route checks to different recipients based on the donation category (e.g., if you have a category for choir, one for band, and one for orchestra, you can set corresponding recipients for donation checks).

To set up Donation Categories, be sure to read through this resource - [Donation Categories](https://support.ludus.com/donation-categories)

To set the payout method on a donation category:

1.  From the top navigation bar, click **Fundraising** --> **Categories**.
    
2.  Next to the desired category, click **Edit**.
    
3.  Next to **Payout Method**, use the drop-down menu to select the desired option.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-buY5lPPZp_uekwq-Tqy_l-20250428-184814.png?format=webp "Document image")
    

### For Passes

Proceeds will be sent to the primary method on the account.

_Suggested Article_: [Choose a primary check option](https://support.ludus.com/choose-a-primary-check-option)

### For Gift Cards

Proceeds will be sent to the primary method on the account.

_Suggested Article_: [Choose a primary check option](https://support.ludus.com/choose-a-primary-check-option)
