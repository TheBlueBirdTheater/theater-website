# Enable Dark Mode

Dark mode for the admin side can be enabled from the Labs page. Allow admins to switch to a dark color scheme for better readability and reduced eye strain.

To navigate to this, go to **Settings** (⚙️) -> **Labs** -> Scroll down to "**Dark Mode**".

Dark mode can be turned on or off as desired.

Dark mode only changes the admin view. Your patrons will see the colors you selected using the Design Tool.

You will want to turn dark mode off temporarily if you are using the Design Tool so that you can see the colors selected.
