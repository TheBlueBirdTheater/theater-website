# Public Ticket Counter

When you sell tickets from your admin panel, you will see how many tickets remain for each event time. On your ticketing page for patrons, they will simply see a button to buy tickets. If an event is sold out, they will see a message for that event time and will not be able to purchase tickets. However, you might want to display the remaining number of tickets to incentivize patrons to purchase now before tickets sell out.

### To display the remaining tickets to patrons:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner of your admin panel.
    
2.  Click the tab titled **Labs**.
    
3.  For the section titled **Public Ticket Counter**, click **On**.
    
4.  Click **Save** at the bottom of the page.
    

Now, when patrons go to purchase tickets, they will see the number of tickets remaining for each event time.
