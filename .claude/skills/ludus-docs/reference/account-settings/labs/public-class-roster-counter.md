# Public Class Roster Counter

When you have Classes available on your admin panel, you will see how many class spots remain on the Roster for each class time. On the class page for patrons, they will see a button to register. If the class is sold out, they will see a message for that class time and will not be able to purchase tickets. However, you might want to display the remaining number of class spots to incentivize patrons to enroll now before spots fill up.

### To display the remaining class spots to patrons:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner of your admin panel.
    
2.  Click the tab titled **Labs**.
    
3.  For the section titled **Public Class Roster Counter**, click **On**.
    
4.  Click **Save** at the bottom of the page.
    

Now, when patrons go to enroll in a class, they will see the number of spots remaining for each class time.
