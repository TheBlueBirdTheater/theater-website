# Rename a Seating Chart

If, for any reason, you need to rename a seating chart at any point, it is easy to adjust and manage via your Ludus admin panel. This could be useful if you first named a new chart after a performance your group did, but now wish to use something more generic, such as "PAC" or "Auditorium Seating".

## Change the name on your Seating Chart

1.  Select the **More** dropdown in the upper right-hand corner and click **Seating Charts**.

2.  Click the **Options** dropdown to the right of the seating chart you would like to edit the name of, and select **Settings**.

3.  Once in **Settings**, you can select the **Chart Name** → enter the new name → **Save** that information. Once saved, your chart name will now be updated!
