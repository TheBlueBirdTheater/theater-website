# Set up Seating Chart Levels

You will want to reach out to [Live Chat Support](https://support.ludus.com/live-chat-support) to have this feature added to your account.

Once you have enabled **Levels**, you can then progress to setting up your **Levels** for an event.

Before setting up Levels, you will want to have the Seating Charts ready to go under **More** -> **Seating Charts**.

For example, if you are using a Balcony and the Main Floor for your Levels, you will want to copy that main chart 2 times, removing the balcony from one copy and the Main Floor from the other.

See the main chart below and how that was broken up into the Main Floor and the Balcony.

## Set up Levels

1.  Go to **Pricing** (next to the event) -> **Levels**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/eRmu5AKRTLNiDUXFLt-Mx_screenshot-2024-06-14-at-12059-pm.png?format=webp "Document image")
    
2.  Once there, you can set up your **Level Name** (IE - Balcony), **Prices**, and **Seating Chart**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9bzQjd5yQSbqIBAirjwWZ_screenshot-2024-06-14-at-12259-pm.png?format=webp "Document image")
    
3.  Once added, be sure to save it. You can then add as many Levels as needed. Those will be listed under **Pricing** -> **Levels** once finished.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dYc0zjHPJ1g0uzj1U9X3X_screenshot-2024-06-14-at-13425-pm.png?format=webp "Document image")
    
    Each Level will show the prices that are associated with that Level.
    
4.  Once finished and saved, patrons can select which Level they wish to purchase from.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/lUPtoaXBfgPQ7jhanc9XC_screenshot-2024-06-14-at-13609-pm.png?format=webp "Document image")
    
    Patrons will then be able to select the Level and then the seat they wish to select/purchase.
