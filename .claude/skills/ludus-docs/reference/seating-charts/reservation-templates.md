# Reservation Templates

Reservation Templates are the result of many groups needing a way to reserve the same section for each event time. Instead of having to go through and create each reservation for each event time, you can simply create a template for that seating chart. This can be applied to all or just a few of your event times. Groups will use the Reservation Template when saving a section for ASL seating, administrators, or perhaps VIPS for an event. They can be applied at any time and can even be used in addition to single seats you have already reserved for an event.
