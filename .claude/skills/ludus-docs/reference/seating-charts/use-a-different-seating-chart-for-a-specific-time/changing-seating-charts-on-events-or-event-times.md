# Changing Seating Charts on Events or Event times

It is not possible to change to a different seating chart if sales are present at the event or at event time unless the chart you will be changing to has the same seat rows and numbers.

You will still be able to switch charts on your own if the chart you are switching to has matching Rows and Seats for all tickets sold.

### What happens if the Chart I want to change doesn't have matching seats?

If you attempt to change a seating chart with sales present, you will be prompted with a warning letting you know that there are seats missing from the chart you are changing to.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/OplHeotyTL6GizFmWx7BS_beta-data-tim-admin-5.png?format=webp "Document image")

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/wj-7C6uh9LZ1-K1f8NoRh_beta-data-tim-admin-4.png?format=webp "Document image")

If you click the link in either warning, you will be shown a list of sold seats that do not have a match on the chart you are attempting to switch to.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/UAjQYDtH_IbQ_0gzk5jRU_beta-data-tim-admin-7.png?format=webp "Document image")

You can use this screen to obtain the information you would need if you do want to still switch charts. With this information in mind, you can either have those seats added to the chart you are changing to, or you can contact support to have the chart switched, and then you can exchange those patrons' orders. (Note: this information will not be available _**after**_ the switch, so you will want to make notes of which orders need to be exchanged.
