# Attach a Reservation Template to an Event

Once you have created your Reservation Template(s), it's a simple process to get them attached to your event. The following will guide you through the process for either the overall event or specific event times.

## Attach a Reservation Template to an entire Event

To attach a Reservation Template to an event, go to **More** (next to the event) -> **Settings** -> make sure you are set up for **Reserved Seating** and select the desired template below that selection. Be sure to **Save** Settings!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FpIv9AuASnrcJZ4jqAepG_screen-shot-2023-09-01-at-41051-pm.png?format=webp "Document image")

## Attach a Reservation Template to a specific Event Time

To attach a Reservation Template to an event, go to **Options** (next to the event time) -> **Reservations** -> and select the **+Apply Template** on the edit time pop-up.
