# Create a Reservation Template

To create a Reservation Template, you will work with a seating chart already created in your Ludus account. If you have not yet created a seating chart, you will want to start that process.

_Suggested Article_: [Build a Seating Chart](KRqC81fUhna_vBqe8EbJv)

## Steps to Create a Reservation Template

1.  Go to **More** **→** **Seating Charts** to start creating your **Reservation Template.**

2.  Select **Options** next to the Seating Chart for which you wish to add a Reservation Template.

3.  Click on **Reservation Templates** → Click on **\+ Create** your first reservation template!

4.  **Enter** your Template's name (IE - Teacher Seats) → click **Create Reservation Template.**

5.  **Select** the seats you wish to have reserved in the chart. Click on **Save Changes** to save the Template and Chart.

6.  Navigate back to the **Events** tab → click **Options** next to the desired event time and click on **Reservations**.

7.  Select **Apply Template and** choose the **Reservations Template** you wish to use and click **Assign**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CuyWE-0rrk1PQ0kCYqRHq_screen-shot-2023-08-09-at-111706-am.png?format=webp "Document image")

This function can be used for multiple events and charts. Once saved to your Reservations, it can be changed by going to the reservations list and un-reserving or editing that list of reservations.
