# Recover a Seating Chart

At some point in the chart creation process, you might need to recover an older version of your chart. Perhaps you added seats, but you want to go back to when those seats were not there, or seat names were changed, and you want to go back to what they were before. No problem - this is simple with the seating chart recovery feature!

## Steps to recover an old Seating Chart

1.  Select the **More** dropdown in the upper right-hand corner and click **Seating Charts**.

2.  Click the **Options** dropdown to the right of the seating chart you would like to recover the name of, and select **Recovery**.

3.  Once **Recovery** is opened, you will be able to view all previously saved edits of your chart.

1.  From here, you will be able to either **Preview** and then select **Rollback to This Seating Chart**.

We currently do not allow admins to recover charts for active shows. Please contact Ludus Support if you need further help.
