# Use a different seating chart for a specific time

When setting up an event, you may need to assign a different seating chart to one of your event times. This can be particularly helpful if you have different seating arrangements available for specific nights, or if the event is split between different venues.

Before assigning an alternative seating chart for a specific event time, you will want to make sure that the seating chart is built into your account. To learn more about how to do this, click the following article.

_Suggested Article_: [Build a Seating Chart](KRqC81fUhna_vBqe8EbJv)

## Attach a separate Seating Chart to an Event Time

1.  First, navigate to your **Events** page.

2.  On your already created event, you will want to select **Options** (next to the event time that requires a different seating chart) → **Edit Time**.

3.  In the **Edit Time** box, you will want to select the ⚙️ or settings icon. This will direct you to a drop-down menu where you can choose a different seating chart.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/neqturtN8AF1gRGOOqJXv_screen-shot-2023-08-09-at-95505-am.png?format=webp "Document image")

Once an event has started selling tickets, you will not be able to change the chart on the admin panel. Please reach out to customer support for more assistance with this.
