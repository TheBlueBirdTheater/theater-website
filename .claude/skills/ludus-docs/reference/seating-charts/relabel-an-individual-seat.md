# Relabel an individual seat

# Relabel Seats on Ludus

Through the editing function of Seating Charts, you can change and relabel seat names. This can be useful if you are looking to change the name of a seat for either a wheelchair-accessible seat or a companion seat.

Rows and seat numbers should _**NOT**_ be changed on a chart used for an active event. This will result in any previously purchased seats not displaying under that patron.

Please reach out to [Live Chat Support](https://support.ludus.com/live-chat-support) for assistance with this.

## Relabel Seats

1.  Navigate to your seating chart by selecting **More** _**→**_ **Seating Charts** _**→**_ click **Edit** for the chart you wish to relabel seats on.

2.  **Select** the "cursor button" (located on the top left portion of the edit screen).

3.  Next, click on the seat you wish to relabel. Now, you can select that seat and add the new label!

1.  Be sure to select "**OK**" to save the seat label!
