# Build a Seating Chart

# Creating **Seating Charts**

Within the Seating Chart maker, you can create your own custom seating chart featuring sections, rows, tables, and shapes.

There are two ways to make a seating chart. You can either build it for yourself using the instructions below, or you can send us (Ludus Support) a labeled diagram, and we can build the chart for you at no additional cost.

If you wish to have Ludus build your seating chart for you, be sure that your chart/diagram has labeled row names and seat numbers. Each seat needs to have a unique name within the system. You can send the diagram via chat or in an email to support@ludus.com.

### Steps to create charts:

First, select **More** (at the top) → **Seating Charts** → click **Create Seating Chart** to get started.

Once you name your chart, start adding your sections, tables, labels, and shapes by hovering over the **green plus button** and clicking the element you would like to create.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CCzpz3D2x0hHMk6ESalpj_ludus-manual-admin-2024-06-07t140340436.png?format=webp "Document image")

As you add new elements, enter the necessary information, and click **Save** when done.

It is recommended that you save your chart often while creating or editing. This creates a backup that can be recovered if needed.

### The Seat Chart Tool Bar

The Tool Bar for the Seat Chart has several functions.

From left to right, these are the functions:

-   \+ button - for creating Sections for your seats, Tables, Labels, and Shapes.

-   Seat button - for marking a seat as Wheelchair, or changing the Tier (color of a seat)

-   Text button - used to rename/edit a single seat in a row.

-   Pop-up button - Used to add a pop-up message to the seat. ie: Companion Seat

-   Print - To print your chart including row/seat information

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/bAwNocOJAR4p_-flpRJq7_ludus-manual-admin-64.png?format=webp "Document image")

If you have clicked on an already created section on your chart, the toolbar changes to add more options. These additions are as follows:

-   Pencil - allows editing the settings for the section

-   Trash - Deletes the entire section

### Create a Standard Seat Chart

Follow these steps to create a seating chart for assigned seating.

1.  Click the Plus sign to create and define your first Section. For the sake of these instructions, we will call it Orchestra Center.
    
    -   **Name**: The name of the section. Which can be displayed on the Ticket
    
    -   **Name Alignment:** Hidden, Left, Right, or Center
    
    -   **Start Seats From:** Left or Right for the lowest number.
    
    Click Save after entering this information.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9nMitetlVakv-RpLR7Ggz_ludus-manual-admin-68.png?format=webp "Document image")
    
2.  Now that your first Section is created, you can drag it to the approximate location that you will want it to be. You can adjust this later.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/88fnweWo29kN-oxng-dHi_ludus-manual-admin-69.png?format=webp "Document image")
    
3.  Click **Add New Row** to begin defining your first row of seats.
    
    You will be prompted for the following for each row that you create:
    
    -   **Row Alignment** Left, Right, Center
    
    -   **Label** Row Letter / Number
    
    -   **Number of seats in the row**
    
    -   **Increment By**
    
    -   **Label Alignment** Left or Right of the row
    
    -   **Display Row Label** Checked to display by default
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/rMq3qyhG6oB-08Gql6TSl_ludus-manual-admin-71.png?format=webp "Document image")
    
    When you click Save, it will add the row to the section as seen below.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/OiY_QIQ1JFMsuHv6tyKT8_ludus-manual-admin-72.png?format=webp "Document image")
    
    Repeat this for each row in the section.
    
    If you have space between seats within a row, you can define the row with the number of seats that would be present if the row were full, then click twice on the seats to turn them off to create the space. Then you may need to use the Text button to correct the seat numbers.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Zn0QexXq4yJFoeMsRsSad_ludus-manual-admin-72.png?format=webp "Document image")
    
4.  Once your first section is built, you can then create a new section and repeat the process to build that section. Try not to overlap sections, and use the sections to create an aisle by leaving enough space between sections to show a break in the seating.
    

Be sure to **save** your work as you go.

Adjust the _spacing_ of your elements by dragging them to a new location and rotating if needed.

Change the seat label (**Text Cursor Icon**, or 3rd button in the toolbar), and add a seat message (**Message bubble icon**, or 4th button in the toolbar) that appears once a patron clicks that seat.

You can also _print_ (utilizing the **printer** icon), _zoom in / out_ (using the **+** and **\-** buttons), and _re-center_ (with the **crosshairs** icon) your chart.

### Create a Table Seating Chart

To make a chart of tables, you will click on the + Button on the chart toolbar.

Select Table. You will be presented with a window to select a Round or Square table. Fill in the information needed and then click Save to add it to the chart. (Note: This doesn't save the chart)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dRqg9QtBpnTCcE2TNZIrK_untitled-design-1.png?format=webp "Document image")

Once the table is created, you can drag it into position on the chart where you need it.

When creating a Square table, you must put seats on both the top/bottom and left and Right of the shape to create the shape of the table. You can turn those seats off after creating the table if you don't need them.
