# ASL Seating

If you have a reserved event, please note that ASL seating is available for your patrons, which can be easily accommodated in Ludus. The following steps will guide you through setting this up for a specific event time.

### Copy your Seating Chart

1.  Navigate to **More** (at the top) -> **Seating Charts**.
    
2.  Once there, select **Copy** next to the chart you use for your event.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Up7AJ4rpNG_vuZIQGGQmP_screen-shot-2024-02-06-at-111733-am.png?format=webp "Document image")
    
3.  Once copied, **create a title** for your new (copied) chart.
    
    Add something to the title to let you know the type of copy it is. So if it's an ASL-specific chart, add something like "ASL Edit The Main Auditorium."
    
4.  Next, select the color in the dropdown to fill in your ASL seating.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Q5b9wF0F9ZCOEUcFcZRpz_screen-shot-2024-02-06-at-112300-am.png?format=webp "Document image")
    
    Once selected, you can fill in the seats that you would like to notate as ASL seating.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/oKKlWskKhuQeI2GymS8u5_screen-shot-2024-02-06-at-112445-am.png?format=webp "Document image")
    
5.  Once adjusted, you can add a note to each seat and the legend, informing patrons that this seating is specifically for ASL users.
    
    To add a note, select the **Speech Bubble** (at the top) and then select the seats to add a note to each seat. This note will appear when patrons attempt to purchase that seat.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/LLR8RP0KzFiXsFYTQLkUM_screen-shot-2024-02-06-at-112555-am.png?format=webp "Document image")
    
    Additionally, you can note on the chart Legend that this is ASL seating by going to the **Pencil Icon** (top left).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/92hXwlnMw07ekaA0tg7Jv_screen-shot-2024-02-06-at-112637-am.png?format=webp "Document image")
    
6.  Once finished with all changes, **save** the chart and **set it as Live**.
    

### Attach the chart to your Event

1.  Navigate to **Options** (next to the event time; this chart needs to be attached) -> **Edit Time**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/91vp66wmXZ8VKXwZ6X_0s_screen-shot-2024-02-06-at-113253-am.png?format=webp "Document image")
    
2.  Once selected, click on the **⚙️ (settings)** -> your newly copied chart in the dropdown.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/sF4NlHm5k9r_OqpCHhCZb_screen-shot-2024-02-06-at-113428-am.png?format=webp "Document image")
    
3.  Be sure to **save** this change, and your chart will be available for that event time!
    

If you need assistance or your event is already live, reach out to the customer support team via your chat icon for help.
