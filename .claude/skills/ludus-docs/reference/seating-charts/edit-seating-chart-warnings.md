# Seating Chart Edit Warnings

If you need to make changes to a chart, you may come across edit warnings. These warnings are intended to prevent any modifications that could impact customers who currently hold tickets to an ongoing event. If you are using a chart for an active event and wish to edit it, you will be prompted to either accept certain statements or reach out to our customer support for assistance.
