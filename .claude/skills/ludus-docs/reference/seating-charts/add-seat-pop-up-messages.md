# Add seat pop-up messages

# Pop Up Messages

It is possible to add messages to your seats on your seating chart so that they will display when the seat is selected. These pop-up messages can be very helpful in communicating additional information to patrons selecting those seats.

Some examples of messages you might want to add are:

-   This seat has a partially obscured view.

-   This is a Transfer Seat

-   This is a Companion Seat

-   This location does not have a seat. It is for persons in a wheelchair only.

### Add a message to the seats

1.  Navigate to your seating chart by selecting **More** _**→**_ **Seating Charts** _**→**_ click **Edit** for the chart you wish to add messages to.

2.  Next, select the **Messages** icon as shown below.

3.  **Click** _**→**_ add a message, and a modal window will appear for you to enter the message.

4.  **Click OK** when you are done with that seat.

5.  Repeat the above for any seat you wish to have a message on.

6.  Be sure to **Save** the Chart before navigating away from it.
