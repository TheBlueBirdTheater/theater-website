# Authentication

If you are interested in using Authentication, please contact Ludus support.

_Suggested Article_: [How to Contact Ludus](https://support.ludus.com/how-to-contact-ludus)

## What can this feature help with?

Authentication is an optional feature within Ludus that allows you to import unique ID numbers and restrict ticket access to only those with a valid ID number.

## Why use this feature?

Most commonly, these are used for events such as prom, graduation, and other school activities. However, you aren't limited to just those events. There are several use cases for this feature.

## What makes this feature so special?

Ludus was built for the performing arts by people who care about them, and we want to make your life easier. The Authentication feature was created specifically with schools and limiting who can attend events in mind. Some of the great features of Authentication are:

-   **Set how many tickets each ID is allowed** — this is perfect for events like prom, where each student only gets 1 ticket.

-   **Allow guest purchases** — a student can buy their guest/date's ticket by entering their guest's student ID. If you have ticket limits in place, then that guest cannot go on later and buy their own since their ticket was already purchased.

-   **Allow outside guests** — if your event allows people without an existing student ID (such as a guest from another school), you can set up an "Outside Guest" ticket price that triggers the following manually entered fields: First Name, Last Name, Email, and School's Name.

-   **Restrict by grade** — you determine which ticket prices can be purchased by which grade levels. For example, for prom, you may allow only 11th- and 12th-graders to purchase tickets.

-   **Deny access to specific individuals** — if there are people in your system who should not be allowed to purchase tickets, you can block their IDs.

## So how does this feature work?

Once the support team has enabled the Authentication feature for you, you will be able to [Add/Import Authentication records](https://support.ludus.com/addimport-authentication-records) to the feature. Once this information has been added, the event can be set up to allow only the specified students to have access.

## How do I enable Authentication?

Once you have uploaded your Authentication records, you will want to set up an event with Authentication enabled. To do so:

1.  Begin adding your event as you would normally. _Suggested Article_: [Add an Event](https://support.ludus.com/add-an-event)
    
2.  On the Event settings page, click **Additional Options** at the bottom.
    
3.  For "Authentication," check the "Require Authentication for this event" box.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/cmujuRcwJtaIMSAdy85N1_screenshot-2023-11-20-at-54117-pm.png?format=webp "Document image")
    
4.  _Optional_: Restrict which grades can access this event by checking the "Limit Authentication to specific grades" box and entering the grade number(s) that have access.
    
    Grade numbers must be added as a comma-separated list without any spaces.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zTYrWJd_qTwQNM00L03RW_screenshot-2023-11-20-at-54336-pm.png?format=webp "Document image")
    
5.  Click **Continue** to continue with the event setup.
