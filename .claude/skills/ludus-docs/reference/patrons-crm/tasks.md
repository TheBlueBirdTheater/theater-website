# Tasks

Tasks is a CRM tool that allows you to create and assign interactions with your patrons. Perhaps you are conducting a donations drive and need to make a personal, one-on-one contact with a patron. You can create a task for that and assign it to the appropriate admin with a priority and due date.

Within Tasks, you can create and assign the following to your admins:

-   To-Do

-   Call

-   Email

-   Meeting

-   Gift

-   Letter

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-jI8g6i6EZAk0U3dOyf45q-20240814-154342.png?format=webp "Document image")

## Create a Scheduled Task

There are two methods for creating a task to be scheduled for the future.

### Method 1 - Tasks Panel

1.  Navigate to **Patrons,** then select **Tasks** from the menu to open the Tasks panel.
    
2.  Click Add Task to create and assign a new task.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-xmX8Wvx87rq8ufRQHhvZY-20240814-160214.png?format=webp "Document image")
    
3.  A pop-up will appear in which you can create the new task. You have the option to assign it to a specific admin or leave it open to all admins to complete. You can also set the date and time the task is due to be completed, and a reminder.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-DVt-WnFNPv6_VSY6Z2g8n-20240814-161135.png?format=webp "Document image")
    
4.  Click Create to save the task and assignment.
    
    The task will now appear on the tasks screen, as well as the patron's profile on the **Activity** tab.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-vBg-hsptkA-Jkmxsv5TMR-20240814-165926.png?format=webp "Document image")
    

### Method 2 - The Patron Profile

To create a task that is scheduled for the future, you can navigate to the patron's profile from

**Patrons-> Database** and select the **Create Task** button.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-fkCIa9Rnuq6uGp0pJLEl_-20240816-170300.png?format=webp "Document image")

### Log a Current Activity

If you need to log an Activity such as a phone call, email, or gift that is happening in real time, you can do so on the patron's profile on the Activities tab.

Suggested Article: [**Patron Profiles**](https://support.ludus.com/patron-profiles "Patron Profiles") in the Notes section.

### Viewing Tasks

You can see all tasks by navigating to **Patrons**, then selecting **Tasks**.

All non-completed tasks for all users will appear on the Upcoming tasks board. You can also view Overdue or completed tasks by selecting the appropriate tabs.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-tBN5EA6EZ7y4Q9-G0CS35-20240814-171907.png?format=webp "Document image")

The search field allows searching for tasks by Task name, Patron Name, or Assignee.

There are also filters present that allow filtering the results by Admin or Type of task for each page.

Clicking Details next to a task opens the task itself for review and editing. You can additionally mark the task as completed here.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-IIyHjRX8Z7vIHt9VgyJcV-20240814-172730.png?format=webp "Document image")

## Editing Tasks

Tasks can be edited from either the Tasks Screen or from the Patrons, Activity screen directly.

### To edit via the Tasks screen:

1.  Click **Details** next to the task you would like to edit.
    
2.  Hover your mouse over the top right of the pop-up window to have the edit icon appear.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-IIyHjRX8Z7vIHt9VgyJcV-20240814-172730.png?format=webp "Document image")
    
3.  Click the Edit icon and make any changes needed.
    
    Be sure to click **Save Changes** when done.
    

## Deleting a Task

Occasionally, you may need to delete a task, either because it was created in error or because you no longer need it and don't wish to have it completed.

Tasks can be deleted simply by clicking the task and opening it for editing. Once open, you will see a Delete button. This can be done via the Tasks page or from a patron's profile.

## Marking a Task as Completed

Tasks can be marked as completed from either the patron profile or via the tasks screen.

On the Tasks screen, you can click the checkmark next to the task name.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-OLOtnOBwPSZCwuwo5gKz6-20240814-194638.png?format=webp "Document image")

From the patron profile, you can also click the checkbox next to the Task.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Bx1a1-XYH1E1XELQVG5Ge-20240814-194850.png?format=webp "Document image")

Alternatively, you can click the **Details** button or **View Details** button for the task and there will be a button to mark as complete as well.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-hHyaXc2kIwe1yRIorIBJn-20240814-195056.png?format=webp "Document image")

## Mark a Completed Task as not Complete

Should you need to change the status of a task from Complete to Not Complete, you can do this simply by clicking on the green checkmark that appears when a task is completed. This can be done from both the Tasks page and the patron's profile in Activity.

## Task Notifications & Reminders

When a task is created and assigned to an admin, an email is sent to that admin letting them know about the assignment and allowing them to view the task.
