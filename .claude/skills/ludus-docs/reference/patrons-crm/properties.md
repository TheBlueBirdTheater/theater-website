# Properties

**Properties** allow adding information fields to patron records. These items are added to a patron's profile by an admin and are not accessible or filled out by the patron.

Adding a patron property adds that field to every patron record in the database. You can add as many custom properties as you wish to your patron records.

The following types of properties can be added.

-   Text Box

-   Short Answer Text Box

-   Number

-   Checkboxes

-   Single Checkbox

-   Dropdown

-   Date

-   Ludus Admin

-   File Upload (including):

-   jpeg

-   png

-   gif

-   pdf

-   CSV

-   xls / xlsx

When using the "File Upload" property, the maximum upload size is 10 MB.
