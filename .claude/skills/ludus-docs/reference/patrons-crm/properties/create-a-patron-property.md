# Create a Patron Property

Properties can be easily created from two different locations. A property can be created directly on the patron record or from the Properties page.

### Create a Property from the Properties page.

Creating and managing Patron Properties can be done from the Properties page.

1.  Navigate to **Patrons** and select **Properties.**
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Gw4KWKfTJ1ZxcwKPrdpKX-20241015-132018.png?format=webp "Document image")
    
2.  Click the Add Property button.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-_T2iD36jF6PoOTNRdF_EB-20241015-132213.png?format=webp "Document image")
    
3.  Select the type of property you would like to add. For this example, we will choose the number field.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-SMr6s_o7CtEvWTrELyt3A-20241015-132710.png?format=webp "Document image")
    
4.  Give the property a name and click Create to save the property.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Li5LeBecASCmh8P8JTILN-20241015-132502.png?format=webp "Document image")
    
5.  Success! Your new property has been added to all patron profiles.
    

### Create a Property directly on a Patron's profile

Properties can also be added to a patron's profile. To add a new Patron Property to all patron profiles, follow the steps below.

1.  Navigate to a patron profile. This can be done by searching for a patron via the global search bar and clicking their record, or via the **Patrons** menu under **Database** by selecting a patron**.**
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-FE4UQ1XAF9veX91GQXBxL-20241015-133340.png?format=webp "Document image")
    
2.  On the patron record, locate the Add Patron Property link on the lower left of the screen and click to open the Create Property window.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Y6mPbdCOoSxXFBLyYUfRh-20241015-133704.png?format=webp "Document image")
    
3.  Select the type of property to add and provide a name for the property. Then click **Create** to add the field.
    
    **Reminder** - this property will be added to ALL patron records.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-xQjDlfPfdh6wsUjRfxuK2-20241015-135329.png?format=webp "Document image")
    

### Create a Property directly on a Patron's profile

Your new property will appear now on the patron record, and information can be added.
