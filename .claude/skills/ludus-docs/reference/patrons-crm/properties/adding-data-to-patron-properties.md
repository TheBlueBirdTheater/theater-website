# Adding Data to Patron Properties

Once you have added Properties to your database, you will want to add data to the fields. Let's get started

1.  Open a patron record to which you wish to add data.
    
2.  Locate the property you wish to fill out and click the edit (pencil icon) that appears next to it.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-ISeuGELNeog2NllkjF-v3-20241015-142510.png?format=webp "Document image")
    
3.  Enter your data for the field selected. In this example, we have selected the Birthdate field which allows either typing the date or using the calendar view to select it.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-BKfmNN9X-TT_tUOWyt_ZL-20241015-142710.png?format=webp "Document image")
    
4.  After entering the birthdate a banner will appear showing how many changes you have made to properties on this record. Click **Save** to save the information.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-eDl-N3cjYl3KWBmpeAGek-20241015-143020.png?format=webp "Document image")
    

You can edit multiple properties on the same patron record before saving if desired.

### Edit data already entered in a Property

To edit data in any property simply open the patron record and click the edit button next to the property to update or remove data from the field selected. Remember to save your changes before navigating away.
