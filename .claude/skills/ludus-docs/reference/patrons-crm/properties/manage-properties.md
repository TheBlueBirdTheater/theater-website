# Manage Properties

The Patron Properties screen allows you to quickly add, sort, and delete any properties you add to your patron profiles.

### Sort the order in which your Properties appear

1.  Open the Properties screen from the Patrons menu.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Gw4KWKfTJ1ZxcwKPrdpKX-20241015-132018.png?format=webp "Document image")
    
2.  Click the 6-dot icon, then drag the property up or down in the list to adjust it. The order will save automatically.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-BHnp-1DjgbpVd2AKz7If5-20241015-150828.png?format=webp "Document image")
    

### Edit a Property already in use.

A property can be edited by navigating to Patrons and selecting Properties.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-Gw4KWKfTJ1ZxcwKPrdpKX-20241015-132018.png?format=webp "Document image")

Click **the Edit** button next to the property to open it and make changes.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-4D0yXe8nHyjWf-FBmLfNe-20241015-202055.png?format=webp "Document image")

A new window will open to allow you to update the property title and fields if applicable. Click **Save** when done to update.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-jp9gpNAifdDyqamTBDU4Y-20241015-202305.png?format=webp "Document image")

### Remove a Property from patron records.

Properties can be archived from patron records. This is done via the Patrons page under Properties.

To remove a property, click the Cabinet Icon next to the property you wish to remove.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-8iu47ktVpYzl5OBMKAtAc-20241015-200917.png?format=webp "Document image")

Once you select a property to archive, you will be presented with a message that must be accepted.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-NXYXy4UD-KHj5V2jCWQBw-20241015-201214.png?format=webp "Document image")

### Recover an Archived Property

Properties can be recovered from patron records. This is done via the Patrons page under Properties.

On the Properties page, select Archived to view all the archived properties.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-KTjUQpW4eftIBdu56KIj5-20241015-204415.png?format=webp "Document image")

Click the recover button next to the property to put it back on the patron profiles.

Any saved information for that property will be added to the patron's profile during recovery.
