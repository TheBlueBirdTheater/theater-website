# Patron Tag Manager (CRM)

The Patron Tag dashboard is used to view, manage, and create tags used on your account. To access your Patron Tags, go to **Patrons** (at the top of your admin account) -> **Patron Tags**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/iEXCyahS6BYMiBkzNmuWw_screenshot-2024-06-05-at-124339-pm.png?format=webp "Document image")

### My Tags

"My Tags" are created by you and are specific to your group. These can be edited and deleted.

### Donor Tags

When someone donates to your program, they will automatically be tagged as a "donor" in Ludus. You do not need to manually tag them when they donate; the system will handle it.

### Ludus Tags

Ludus Tags are default tags that are present in all accounts. These tags cannot be edited or deleted. However, you can add or remove patrons to these tags if desired.

### Creating a New Tag

To create a new tag, click the **New Tag** button, enter a name for the tag, and save.

You can also import and assign tags to patrons via a patron import. As long as your imports include the patron's email address, it will update any information, including adding tags to the patron's record.

### Options in the Patron Tag Dashboard

On the Tags dashboard, you can perform the following actions:

-   **View:** Shows patrons with the selected tag.

-   **Assign to Patron**: You can add patrons to a tag chosen from a list.

-   **Edit**: Easily update the name of the tag (My Tags only)

-   **Delete**: Remove the tag from all patron records. (My Tags only)

Patron Tags should only be used for tagging multiple patrons with the same tag. Examples of this include VIPs, Donors, Volunteers, and Performers.

Tags _should not be used_ for single-purpose items that will not be used on other patron records. Examples of what not to use it for include: additional phone numbers, nicknames, or personal data. Private notes are suited to that type of information.
