# Exporting Audiences

Audiences can be exported to a CSV for use in physical mailings.

1.  To do so, navigate to **Patrons** and select **Audiences**.
    
2.  Locate the Audience you wish to export and click on **Edit**.
    
3.  Select **Export to CSV** to export the audience with full patron data.
