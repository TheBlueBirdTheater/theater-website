# Search Criteria for Identifying Duplicate Records

The Manage Duplicates feature searches your database for duplicates using the following criteria. If two or more records meet the following conditions, the records are returned as possible duplicates.

-   Email Username (anything before the @ ) + Last Name

-   First Name + Last Name + Company

-   First Name + Last Name + City

-   Phone + Street Address + City + State + ZipCode

-   Phone + Street Address + City + State

-   Phone + City + State + Zip

-   Phone + City + State

-   Phone + First Name

If you choose to ignore a duplicate, that record will no longer come up as a possible duplicate on subsequent searches.
