# Manage Duplicates

The Manage Duplicate feature scans your database and returns a list of any duplicated records. You can then elect to combine the accounts or set them as ignored so they don't appear again when you run the function again.

### Check for duplicate records in your database.

1.  Select **Database** from the **Patrons** section on the top navigation bar, then click **Manage Duplicates**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8FxXiyW1D-SwMzHp1uQ3x_ludus-manual-admin-2024-07-22t091039923.png?format=webp "Document image")
    
2.  Click on **Run Check** to start the process.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/sCcho61NtLY2VtP2B3QnH_ludus-manual-admin-2024-07-22t092613526.png?format=webp "Document image")
    
3.  A list of any duplicated patrons will appear. You can then click **Review** next to a result to see what information matches.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/rxBcfFFOlbpOutocE18Eq_ludus-manual-admin-2024-07-22t092743337.png?format=webp "Document image")
    
    Upon clicking **Review**, you can see that in this case, the phone number and Address are the same.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/UaCjM4rV3D7N8d41VXZyc_ludus-manual-admin-2024-07-22t093041889.png?format=webp "Document image")
    
    In this case, these are two employees of the same company who used the office phone number and address on their purchases. Since these should not be merged, click Cancel to get back to the list, and then click Ignore to mark that these have been reviewed and that they are ok.
    
    The record below is one that can be merged. This record has matched the phone number. Since we know this is the same person, we will go ahead and merge it.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/U6LQrWH-3ebKOFhbrEfNZ_ludus-manual-admin-2024-07-22t094936675.png?format=webp "Document image")
    
    I note that the arrow shows how the data will be merged. You can click on the record you wish to maintain, and the arrow will switch directions. If desired, you can also keep the email from the 2nd record as a secondary email address.
    
4.  Continue working through your list of possible matches until it is complete.
    
    You do not have to handle all merges in one session. You can return at any time, and the list will still be present.
    
    How often you check for duplicates is up to you, but doing so often can help keep your database healthy!
