# Secondary Phone Number

You can add a second phone number to patron profiles. You can manage patrons with multiple phone numbers and prevent phone number loss during patron merges.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/h0y3HnJ6GdPBhti3gw-gd_image.png?format=webp "Document image")

This can be incredibly helpful for patrons who perhaps have one patron profile but two numbers they can be reached at, allowing you to contact them in multiple ways if needed.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/h20Vhi5YZejSu9ivzWFFv_image-1.png?format=webp "Document image")
