# Merge patron profiles

Ludus automatically handles duplicate patrons by only allowing one email to be used in the system. We do this by identifying patrons via their email addresses. That being said, it's possible for a patron to have multiple email addresses and to use different ones over the years.

Thankfully, we've built an easy-to-use merge feature that lets you merge two patron profiles, update all existing data (ticket orders, donations, passes, etc.), and optionally set secondary email addresses on profiles.

Merging cannot be undone, so pay close attention to the steps as you merge.

## How to merge profiles

1.  First, find the patron you want to merge _into_ another profile.
    
    For example, if John has two profiles (profile A and profile B), you may want to merge profile B into profile A, so you'll want to look up profile B.
    
    To look up a profile, simply use the search bar/magnifying glass in your top navigation -> enter the name or email of the patron -> and select their profile in the search results under the **Patrons** tab.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_XKY6-YgaU3VRObD3H_0B_ludus-manual-admin-2024-07-12t121848619.png?format=webp "Document image")
    
    
    
2.  on the patron profile, click the **Merge** button located just below the patron's name.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Zmxn8MUswCB4uruxjJ3jR_screenshot-2026-06-26-at-35055-pm.png?format=webp "Document image")
    
3.  In the Merge popup, type in the name or email of the profile you'd like to merge into and select the patron in the results. Select which of the two records you would like to keep by clicking on it. The profile you are keeping will be colored as shown below, and the arrow will show which account is being merged into which.
    
    
    
4.  Verify all looks good before clicking Merge Profiles.
    
    If you'd like to keep their old or original email or phone number in the system as a "secondary" email/phone number, be sure to check the "Keep as a secondary email/phonenumber" checkbox.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4dpB1t-ZabqYYpcpwrYLS_screenshot-2026-06-26-at-35207-pm.png?format=webp "Document image")
    
5.  Click **Merge Profiles** to merge the profile.
    
6.  Once successfully merged, you'll be brought to the updated/valid profile with a success message.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/TDME8ddZ4I3N9vsHy_FZo_screenshot-2026-06-26-at-35340-pm.png?format=webp "Document image")
