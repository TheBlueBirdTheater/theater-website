# Patron Nicknames - Patron Tab (CRM)

Patron Profiles can include a patron's nickname. This information is for internal use and doesn't appear on tickets or other purchases.

Patron Nicknames can be searched via the search bar.

### Adding Nicknames on Patron Profiles:

1.  Look up the patron using the global search bar on the top Ludus navigation bar and click the patron record to open.
    
2.  Hover over the patron name on the right side of the screen and then click the Edit icon that appears.
    
3.  Click to enter a Nickname in the appropriate field.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/oEuEml5uAtxAs9NfXoBEZ_ludus-manual-admin-2024-07-12t102518704.png?format=webp "Document image")
    
4.  Save the changes after entering the nickname. The nickname will then appear with the patron name.
