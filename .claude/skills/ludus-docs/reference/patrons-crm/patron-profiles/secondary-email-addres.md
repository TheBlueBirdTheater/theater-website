# Secondary Email Addres

You can add a second email address on patron profiles. The primary purpose of this is to merge records when you find a patron has purchased tickets under a different email address and you want to keep that email as part of the record.

Having a secondary email address on an account allows the patron to log in using either address once merged and view all purchases. If this is a partner's email address it will allow both patrons to log in and view purchase history and print tickets.

The secondary email address does not:

-   Send a second marketing email to that address.

-   Send a second confirmation email.
