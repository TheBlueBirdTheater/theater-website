# Manually Update Patron Subscriptions

If a patron wishes to subscribe to a mailing list or remove their subscriptions, they can unsubscribe via their email OR you can manually update that on their account.

### Admin Panel Subscription Updates

If a patron wishes to be added or removed from a Mailing List or even a Tag, you can accomplish this via their patron profile.

1.  Search the patron's name using the Search Function (top right).
    
2.  Once there, you can select "Patrons" and then the Patron's Profile.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WjtMA9wqmnQyQPeTJsJk4_ludus-manual-admin-2024-06-09t175143432.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/olO6iDAFgh-v8MAjOA_I-_screenshot-2024-06-03-at-12841-pm.png?format=webp "Document image")
    
3.  With the patron profile open on the **Overview** tab, scroll down to **Mailing**.
    
4.  From here, you can choose to remove or add them to Mailing Lists, as well as Tags.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/SZZz_FMsZDkBu9mC9ZhPD_ludus-manual-admin-2024-07-12t121534459.png?format=webp "Document image")
    
5.  There is no need to save these items, as they are automatically saved when update for the patron.
    
    Once updated, the patron will be included or excluded from Mailing Lists and Tags as changed.
    

### Patron Ability to Unsubscribe

Patrons can choose to unsubscribe from Marketing Campaigns (NOT their purchase confirmation emails) when they receive those.
