# Update patron profiles with import

There may be a scenario where you'd like to update patron profiles in bulk. Let's say that you initially imported your patrons, but the file that you uploaded to the system did not include the phone numbers you have on file. You can easily re-upload a file using the same process as an initial upload to update records.

The Ludus import tool intelligently recognizes patrons by their email. If the patron email already exists in the system, their profile will be updated/overwritten with any new data from your most recent import. If the email is not in the system at the time of import, a new patron profile will be created.

To learn how to import patrons to Ludus, check out this article.
