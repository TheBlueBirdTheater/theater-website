# Contact Owner (CRM)

You can assign patron accounts to admins within your organization on the patron profile. This is useful if you have an admin who handles communication with VIP's or Donors. Once you set a contact owner, that admin's name will appear in the Patron Report when the Contact Owner field is added.

### Setting a Contact Owner

1.  Open the patron record by searching by patron name or from the link on a patron report.
    
2.  Select the Admin Name by using the drop-down located next to Contact Owner. The selection is automatically saved.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/oVj9K8QUSOk0QxPT85yjq_ludus-manual-admin-2024-07-12t104919479.png?format=webp "Document image")
    

Only Full Admins can set or change Contact Owners.

### F.A.Q's

**What happens if we disable an Admin?**

If an Admin is disabled, all patrons assigned to that Admin will be shown as Disabled.

**How do we remove or unassign a Contact Owner?**

To update or unassign a contact owner, use the drop-down on the patron record to assign it to another Admin or set it to None.
