# Add patron tags

Tags are an additional way to segment your patrons. You can add as many tags as you'd like to a patron. For example, you could add the tag "VIP" to important patrons or "Mega Donor" to patrons who have historically donated large amounts. These tags can be used in our [Marketing](https://support.ludus.com/marketing) feature to help sort your [Audiences](7Hl0rjmxRIgdirvYXOR5n)

To add a new tag, type in the text box provided and hit **Enter** to save. To remove a tag, click the X next to the existing tag in blue.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/DCFVnto3l91QG5Y_c2_IU_ludus-manual-admin-2024-07-12t120803163.png?format=webp "Document image")

Patron Tags are used to group patrons, such as VIPs, donors, or Volunteers. Paron Tags should not be used for single-use items such as phone numbers or Nicknames. Private Notes should be used for this instead.
