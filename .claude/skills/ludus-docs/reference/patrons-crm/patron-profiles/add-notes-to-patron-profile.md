# Add notes to patron profile

There are two types of notes on a patron profile. Standard patron notes and accessibility details.

Both types of notes will appear on the check-in lists for events that the particular patron is attending

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FXYgMaGLNnemGV6aGWtHY_screen-shot-2023-09-07-at-122112-am.png?format=webp "Document image")

## Add notes to a patron profile

### Standard Notes

This is a section for notes on the patron. As you type/edit the box, the text will automatically save. This can be found on the patron profile on the **Overview** page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FDCQJJix9GfbiSH6Ulkq4_screen-shot-2023-09-06-at-115623-pm.png?format=webp "Document image")

### Accessibility Details

If you are utilizing the Accessibility Details feature, any notes typed by the patron or the admin will appear in this field. Simply type new text, and the field will automatically save. This is located on the patron profile on the **Overview** page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RiZNKZCZGFgVRNtZqde_E_screen-shot-2023-09-06-at-115956-pm.png?format=webp "Document image")
