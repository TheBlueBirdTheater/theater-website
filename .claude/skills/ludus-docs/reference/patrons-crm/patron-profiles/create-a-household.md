# Create a Household

Households are a way to view a household's spending habits. For instance, a married couple might have separate patron profiles but be viewed as a household for spending statistics.

If desired, these can be imported when you [Import Patrons to Ludus](https://support.ludus.com/import-patrons-to-ludus) or set up at any time on your Ludus admin account.

## Set up a Household

To set up a Household in Ludus with existing customers:

1.  Navigate to the **search bar/magnifying glass** at the top right of your admin panel and **search** for the patron you wish to start the Household with.
    
2.  Select the Patron's profile under "**Patrons**".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/L8geMCA2ynYwFDAZQGeAq_ludus-manual-admin-2024-07-12t114222311.png?format=webp "Document image")
    
3.  Once selected, hover your mouse over the Household field and select the "**+**" icon to add a household. If no Household has been added before, it will say "**None**" as well.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ETlzgJKoalm8jjC08E51-_ludus-manual-admin-2024-07-12t114417285.png?format=webp "Document image")
    
4.  When you select the "**+**," you can choose a previously created Household OR create a new one by clicking **New Household**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/XOXvDxOprUqol1aPw6p43_ludus-manual-admin-2024-07-12t114657580.png?format=webp "Document image")
    
5.  At this point, you can create the name of the new Household and save that for the patron profile by selecting **Continue**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/jJMMHvTqrTbFG0mI1zVoN_ludus-manual-admin-2024-07-12t114805716.png?format=webp "Document image")
    
6.  Once created and added, this Household ID will be available under **Household** to be added to other patrons' profiles (as needed).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/bq48MszN6302Cmz-fnUFF_ludus-manual-admin-2024-07-12t114946756.png?format=webp "Document image")
    

### View Household Statistics

Once a Household has been set up, you may wish to view its statistics or spending habits.

To view that information:

1.  Navigate to the **search bar/magnifying glass** at the top right of your admin panel and **search** for the patron you wish to start the Household with.
    
2.  Select the Patron's profile under "**Patrons**".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-VrD9vFIzxcs47-R7Qi2f_screenshot-2024-04-26-at-103206-am.png?format=webp "Document image")
    
3.  From here, you can select the **Household Name** (under the patron details).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8EPBNS9D5q-feYWghHWCs_ludus-manual-admin-2024-07-12t114946756.png?format=webp "Document image")
    
4.  By selecting that Household, you can view statistics for that group. You can also:
    
    -   Add More Members
    
    -   Add Notes
    
    -   Remove Members
    
    -   View all Member Activity
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/kWgjqb-Xn3SCuEYRIWB40_ludus-manual-admin-2024-07-12t115449795.png?format=webp "Document image")
