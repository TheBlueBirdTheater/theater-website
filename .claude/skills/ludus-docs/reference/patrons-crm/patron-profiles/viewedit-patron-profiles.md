# View/Edit patron profiles

## View Patron Profiles

To look up a patron profile:

1.  Type the patron name or email into the search bar at the top of your admin panel.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nM_B38sX3G0wa-i-YgTRQ_ludus-manual-admin-2024-06-09t174956665.png?format=webp "Document image")
    
2.  Click the **Patrons** tab and choose the desired patron from the list.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/stpxUvSXVx-qrKrSBoz4M_screen-shot-2023-09-07-at-120901-am.png?format=webp "Document image")
    

You can view any and all information about a patron from this page. To review all the information that is available on a patron's profile, check out the main article.

_Suggested Article_: [Patron Profiles](https://support.ludus.com/patron-profiles)

## Edit patron Profiles

To edit a patron profile, locate the profile using the steps above to view a profile, then click **Pencil**. To edit the patron Name or nickname, hover over it and click the edit icon next to the name.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/n3uQU7qdIc4zTGRHVKwhf_screenshot-2026-06-26-at-34619-pm.png?format=webp "Document image")

To edit other patron information, hover next to the email field and click the edit icon.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/wvWExEEt92_t7zROxbJdB_screenshot-2026-06-26-at-34733-pm.png?format=webp "Document image")

Edit any necessary details from the pop-up menu. If you'd like to update this information for all past orders, ensure that you keep the "Update details on all orders" checkbox selected. Uncheck to keep previous details as they are.
