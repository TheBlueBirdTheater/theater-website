# Create Patron Relationships

The Relationship feature allows you to document Relationships on a patron's record. To create a Relationship, both patrons must have patron records.

Relationships are for internal informational use. They are not visible to patrons other than Student Relationships, and these do not allow patrons to view each other's orders on the patron side. As an Admin, you can click between the accounts.

### To create a relationship between Patrons

1.  Open the patron record of the first patron to create a relationship with by searching for the Patron Name in the global search and clicking to open the patron profile.
    
2.  On the **Overview** tab, scroll down to **Relationships.** Click on the **+**button in the upper right corner of Relationships.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YB9c71AJdNQX7hD_CM0af_ludus-manual-admin-2024-07-12t113458893.png?format=webp "Document image")
    
3.  A Modal window will open; search for the other patron to add as a connected relationship, then select the record.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/keyE3NRWuSd0VYLSvCNsv_ludus-manual-admin-82.png?format=webp "Document image")
    
4.  Once selected, a new modal will appear where you can select the relationship type from a drop-down. Make the proper selection and save.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mRZjKMW4-FMLo-i26aOhg_ludus-manual-admin-85.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8ywUS2mnL9-F8N2dvX8hM_ludus-manual-admin-84.png?format=webp "Document image")
    

Once saved, the relationship will appear on the patron profile.
