# Import Patrons to Ludus

## Overview

Keeping a database of your patrons is important. With Ludus, you are never starting from scratch. You can easily import your existing patron database to ensure you don't lose track of any patron.

Click the drop-downs below to learn more!

### What can be imported?

Here is a list of the contact information fields that can be uploaded to Ludus.

-   Email **(Required)**

-   Each email must be unique to that patron.

-   Secondary email

-   First Name

-   Last Name

-   Nickname

-   Primary Phone Number

-   Secondary Phone Number

-   Street Address

-   City

-   State

-   Zip Code

-   Company

-   Patron Notes (up to 3 at a time)

-   Accessibility Notes

-   Subscribed

-   True (1) = subscribed to emails

-   False (0) = not subscribed to emails

-   _If left blank, the default is true_

-   Household

-   If you want to group patrons into households, you'll want to create a column with their household names like "Smith", "Garcia", etc.

-   If two separate families share the same last name, you'll want to create unique names for those households, like "Smith-1" and "Smith-2".

-   Custom Tags

-   Example: Donor, VIP, Volunteer, Etc. **Tags should not be single-use or unique to a specific patron**

-   _One tag per cell can be placed in the columns labeled Tag 1, Tag 2, Tag 3, etc. (up to 15 unique tags per patron)_. These tags are per patron, not per column.

Patron Tags are used to group patrons such as VIPs, donors, or Volunteers. Paron Tags should not be used for single-use items such as phone numbers or Nicknames; Private Notes should be used for this instead.

### Instructions

Before you can upload, you will first want to organize your patron data into a CSV file or Excel sheet. Each bit of information that you'd like to import (such as email, first name, last name, etc.) will need to be in its own column. Each row will represent an individual patron.

**Once you have your list created and saved:**

1.  Navigate to **Patrons** --> **Database** from the top navigation bar.
    
2.  Click **Import**
    
3.  Drag your file to the grey area or click the space to choose a file from your computer. Click **Continue**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/N9TzomO_LYJSOl-somonQ_ludus-demo-admin-31.png?format=webp "Document image")
    
4.  Use the drop-down boxes to make sure the columns match up to the desired import area (i.e., email to email and phone number to phone number)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3btXslbcYxFKmI3mQ5jmj_screen-shot-2023-09-14-at-63958-pm.png?format=webp "Document image")
    
5.  Click **Import**.
    

Remove any unused columns from your spreadsheet to ensure it uploads.

### Troubleshooting

**Entire rows of data did not import**

If you see that an entire row of data, such as last name or zip code, did not import, it is likely because the column was not properly matched during import. Once you select the file, you'll see a screen where you can match the column in your spreadsheet to the data point in Ludus. Make sure the two points match.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3btXslbcYxFKmI3mQ5jmj_screen-shot-2023-09-14-at-63958-pm.png?format=webp "Document image")

**The secondary email did not upload.**

To upload a secondary email, ensure it does not exist as a primary or secondary email anywhere in your database. If it already exists, you will not be able to import it.

Larger files (thousands of records) may take a few moments to upload. If you experience a constant loading screen for more than a few minutes, please reach out to Ludus support, and we will be happy to assist with the upload.
