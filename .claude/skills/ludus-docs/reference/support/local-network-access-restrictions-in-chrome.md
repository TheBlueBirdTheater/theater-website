# Local Network Access Restrictions in Chrome

A recent update to Chrome (November 2025) may require you to update your Chrome settings. This will allow the Ludus Payment Terminal integration to continue to work as expected.

The following workflow will bring you through those steps:

1.  First, go to chrome://settings/
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/u-O0B4nGyDB7j3zatmmGt-20251103-161627.png?format=webp "Document image")
    
2.  Next, type "_**permission**_" in the top search bar and select Site Settings from the dropdown.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/NUohSFJ7AOvwPLf-aXBqo-20251103-161816.png?format=webp "Document image")
    
3.  Once selected, you will be brought to a screen showing your recent site visits, but you will want to select "_**view permissions and data stored across sites**_".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/TjxaJuWXucghXtRk5b1IU-20251103-162157.png?format=webp "Document image")
    
4.  You will be directed to a page displaying all sites, along with the option to view their permissions.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8BNE8AGRoNSLxS_BZDsRK-20251103-162440.png?format=webp "Document image")
    
5.  From this screen, use the search bar (located at the top right) and search for "_**Ludus**_". After the first few letters, it should pop up.
    
    Once selected, you will want to select the down arrow next to it, so you can get to your Ludus Account.
    
    ![Document image](https://app.archbee.com/api/optimize/hZcZIA5As4EsukOh0OMVE/3uydWeO5hsG2456iIzoDP-20251103-194857.png "Document image")
    
6.  Once you have located your account on this list, select the arrow next to it:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fFNmOpc6mC0gbwVTCe598-20251103-163044.png?format=webp "Document image")
    
7.  When that page opens, you will see a list of permissions and abilities:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-mZXFB1_O7adIN0rbLfb9-20251103-163231.png?format=webp "Document image")
    
8.  Finally, scroll all the way to the bottom of this list and select "_**Local Network Access" ->**_ **Allow** (in the dropdown).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dlufcyvfifx4VpBmjAK1W-20251103-163441.png?format=webp "Document image")
    
    Once selected, you will be able to proceed like normal with Ludus and exit this screen.
