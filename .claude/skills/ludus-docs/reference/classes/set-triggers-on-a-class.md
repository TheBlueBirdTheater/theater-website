# Set Triggers on a Class

Within Ludus, Triggers allow you to set a date on which public sales will automatically turn on. This allows you to set a start date for registrations and not have to worry about remembering to turn them on the day of. Check out the steps below to learn how to set a trigger for Classes.

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Options** --> **Triggers**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Ov06JEV7TNkaYofE8oeYj_screen-shot-2023-08-21-at-62305-pm.png?format=webp "Document image")
    
3.  Click the toggle so that it is green and the circle is on the right-hand side. Click the date and select from the calendar menu.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/A3izJxxdDwpQRqX2fWcOg_screen-shot-2023-08-21-at-62522-pm.png?format=webp "Document image")
    
4.  Ensure you are operating the the correct timezone. (Check out this article to change your account's default)
    
    _Suggested Article_: [Change your account Timezone](https://support.ludus.com/change-your-account-timezone)
    
5.  Click **Save Triggers**.
