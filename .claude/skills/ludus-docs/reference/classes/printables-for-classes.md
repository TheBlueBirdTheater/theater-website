# Printables for Classes

For classes, there are three printable items related to each class. These are found under the **Options** button for the full class or a specific class time.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/F-6PSwdXymshNacKonNY6_ludus-manual-admin-2024-07-26t145605901.png?format=webp "Document image")

### Attendee Information Sheet

This printable lists all attendees and their information for the class.

You can choose whether each attendee appears on a separate page or in a table view.

Using the per-page view, you can elect to have Additional Information and any Form Submissions added to the attendee page. Additional information is considered any custom fields you have added to the Student Registration.

_Suggested Article:_ [Add/Edit Student Registration Form)](https://support.ludus.com/addedit-student-registration-form "Add/Edit Student Registration Form)")

This can also be accessed by clicking **Class Roster** in the class, then choosing **Print.**

When **Per Page** is selected with Additional information and Form Submissions, your information will look something like the example below for each student.

### Attendee Fee Sheet

This option provides a chart showing the name of the class purchaser (not the student's name), the number of fees paid, and the total amount paid for the class. The order dates column shows when multiple transactions were made for the class.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-pAS0dx-L6gHIOkmeO-7Ux-20240730-173902.png?format=webp "Document image")

### Attendee Add-on Sheet.

The Attendee add-on sheet provides a printable list of all add-ons purchased by a patron. This list can be used to assemble the order ahead of time or as-picked-up, and it provides a column to mark who handled the order.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-UKbKOL5OKxtn-u_4_QwAp-20240730-181226.png?format=webp "Document image")
