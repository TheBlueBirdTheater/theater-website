# Class Categories

Whether you have two Classes or twenty-seven, you may wish to use class categories to help your patrons navigate through the listing of your various classes. This is particularly great if you have different types of classes. For instance, adult vs. student, or Camp vs. weekly classes vs. one on one classes.

### How it Appears to Patrons

When patrons are on your classes page, there will be different tabs for each event category with an active show. They can click each individual tab to pull a list of that specific category of events.
