# Share a Class

Whether for an email blast, a social media post, or marketing graphics, you may wish to include a direct link or code that takes patrons to your Class(es).

### Types of links

-   **Public Share Link** - An open link that directs people to the listing. This will only function when the event is made public.

-   **Private Share Link** - A hidden link that will give patrons access to an event that is otherwise turned off publicly. This is a great way to give early access aside from Access Codes.

-   **QR Code** - A Scannable image that will take patrons directly to the desired page in a web browser. Only for public links.

### Get a direct link/QR code to one specific Class

To share a direct link to a Class registration, navigate to **Collections** --> **Classes**. T

hen, next to the desired Class name, click **Options** --> **Share**.

It is important to share all Links as they are shown on your Share page. Adding the "www" prefix to a link in Ludus will prevent your link from working.

When you use the QR code for a class, it is specific to that class. Meaning, when scanned, your patrons will be taken to this class for purchase. If you prefer to use one QR code that is for your overall account (Splash Page, or Ludus Events page) an Account QR code is available to use. Instructions to get your account QR code can be found [here](https://support.ludus.com/qr-codes "here").
