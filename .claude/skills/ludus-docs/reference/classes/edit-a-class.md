# Edit a Class

To edit a created Class, navigate to **Collections** --> **Classes**. Then, next to the desired Class name, click **Options** --> **Settings**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/G7FqQ_YTcuHt4QHsn0b3p-20260519-155425.png?format=webp "Document image")

You will then be taken to the main setup page, where you can change settings as needed. To learn more about each section, check out this article.
