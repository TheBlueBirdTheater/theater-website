# Classes Reporting

For each Class (similar to standard Collections), you can access reporting for that specific class.

Simply go to **Collections** -> **Classes** -> and select **Reporting** next to the class you wish to view.

Reporting available includes:

1.  **Dashboard -** The dashboard displays a high-level overview of recent sales along with an area chart displaying sales.

2.  **Summary -** The Summary Report is best for viewing all collected money, payment type (cash, credit, comp), and the channel that money came through (events, passes, gift cards). It also shows a breakdown of "self-serve" online sales versus box office sales, and what each user did in box office sales. This is the "go-to report" and will be most helpful to give an overview of your account.

3.  **Revenue -** The Revenue Report shows what you actually sold each day, week, and month for the timeframe selected. (This is not a view of what was received from Ludus in direct deposits.

4.  **Itemized -** The Itemized report will break down each and every transaction, including new sales, donations, refunds, upgrades, etc.

5.  **Orders -** The Orders Report gives you an overview of all orders, as well as the ability to customize what you have visible in that report. For example, you can use this report to see whether they used a gift card or a discount on their order.

6.  **Submissions -** The Submissions report will include the purchaser's information such as name, email, phone number, and street address (if entered). Additionally, it will break down each fee that was purchased along with responses to any forms that were attached to the Class.

7.  **Add-Ons -** The Add-Ons Report will show you all add-ons sold. You can elect to mark those orders as fulfilled through this report as well.

Additionally, next to each class time, you can view and access the roster for that class.

_Suggested Article:_ [View a Class roster](https://support.ludus.com/view-a-class-roster)

Check out [Reports](https://support.ludus.com/reports) for more information on the various reports in Ludus and the information they can provide.
