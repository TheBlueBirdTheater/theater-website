# Sort Classes

If you have multiple Classes at once, you may wish to sort them in a custom order.

To do so, navigate to **Collections** --> **Classes**. Then, click the **Sort** button at the top.

Drag the Classes into the desired order and click **Save Sort**.

This will affect the order in which they appear for both the Admin Panel and the public patron view.
