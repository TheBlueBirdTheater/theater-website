# Choose Adult versus Under 18 Registration Fees

Unlike other Fees and ticket prices within Ludus, Classes can differentiate between Adult Fees and under-18 Fees. This allows you to customize the questions on Student profiles based on their status. To learn more about customizing each set of questions, check out this article.

_Suggested Article_: [Add/Edit Student Registration Form](https://support.ludus.com/addedit-student-registration-form)

When you are adding/editing Fees, you will see, an option for "Class Fee Type". To reach this screen, navigate to **Collections** --> **Classes** --> **Pricing** --> **Fees** --> **Edit**.

Then, simply choose whether you'd like to have your "Adult" set of questions or "Under 18" set of questions applied. Click **Save Changes** to finalize.
