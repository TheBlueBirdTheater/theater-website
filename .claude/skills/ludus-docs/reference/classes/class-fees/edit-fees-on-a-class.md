# Edit Fees on a Class

To edit an existing fee, navigate to **Collections** --> **Classes**. Next to the desired Class, click **Pricing** --> **Fees**. You can then click **Edit** next to the fee you'd like to alter.

To learn more about Class Fees settings, check out this article.

_Suggested Article_: [](https://support.ludus.com/settings-for-class-fees "https://support.ludus.com/settings-for-class-fees")[Settings for Class Fees](https://support.ludus.com/settings-for-class-fees)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1Sk80qPfhgmCG9qhYdVRu_edit-fees-on-a-class-archbee-document.png?format=webp "Document image")

Once a fee has been sold to at least one patron, you cannot alter its price. To change the price of a specific Fee after it has been sold, create a new fee and remove the existing one.
