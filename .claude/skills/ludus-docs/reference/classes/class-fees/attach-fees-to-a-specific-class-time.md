# Attach Fees to a specific Class Time

If you have a class with multiple times (e.g. a Monday class, a Wednesday class, and a Friday class) you may wish to charge different amounts for different times. You can attach different prices to specific dates so that registrants don't have to play guessing games or sort through a long list of options.

Check out the steps below to see how it's done.

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Pricing** --> **Fees**.
    
3.  Next to the Fee, click **Edit**.
    
4.  Go to the section titled "Assignment" and click the circle for "Specific class times". Then, choose the Class time(s) to which the Fee belongs.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/JJ2x7jVCbTj2AlpEsNLps_screen-shot-2023-08-18-at-124318-pm.png?format=webp "Document image")
    
5.  Click **Save Changes** at the bottom of the page.
    

Now, when patrons go to register, they will only see fees that are attached to that specific class time. If you leave any Fees as "All class times" they will appear across all times.
