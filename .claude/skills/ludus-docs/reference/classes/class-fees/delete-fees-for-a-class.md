# Delete Fees for a Class

To delete a Fee that has been created:

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Pricing** --> **Fees**.
    
3.  You can then click **Delete** next to the fee you'd like to remove.
