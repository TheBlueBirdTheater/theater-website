# Settings for Class Fees

This guide will cover all of the different settings and terminology related to Fees for Classes.

Check out each section below to learn more.

### Basic Info

-   **Name**: The name for the fee that the public will see.

-   **Price**: The price the patrons will pay.

-   **Allow Patron to enter custom price**: Checking this allows patrons to name their own price for the collection item. This also changes the Price field to be a Minimum price accepted.

-   **Description**: An optional bit of text that describes what the fee is.

-   **Assignment**: To which class time(s) does a specific fee apply?

-   _Suggested Article_: [Attach Fees to a specific Class Time](https://support.ludus.com/attach-fees-to-a-specific-class-time)

-   **Limit Per Patron**: Limit how many of this Fee a patron can purchase overall.

-   **Access**: Limit who has access to this specific Fee.

-   **Class Fee Type:** Select if this fee is for Adults or Students Under 18. Based on the Settings in Students, this setting determines which student registration items are asked for.

### Advanced Options

-   **Total Inventory**: The total number available before this specific Fee "sells out".

-   **Special Passcode**: Entering a code here will make this specific Fee need to be "unlocked" before it can be selected.

-   **Form**: Ask additional questions beyond name, email, phone number, and address if they select this specific Fee.

-   **Availability**: Choose when this particular fee becomes available/ends.
