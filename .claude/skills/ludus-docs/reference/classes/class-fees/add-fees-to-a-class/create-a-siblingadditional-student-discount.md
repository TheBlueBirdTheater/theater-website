# Create a Sibling/Additional Student Discount

There are a few options for creating a sibling/additional student discount. Below are a few examples.

### Use a bulk discount

You can create a bulk discount that applies automatically when two or more identical fee items are added to the cart. Bulk discounts can be a flat amount or a percentage off.

Bulk discounts automatically apply when the discount conditions are met.

With the bulk discount, you can set the amount to be per fee (attendee) or per order. By setting the fee to apply only to the remaining fees, the discount in this case would be $25 off each fee, starting with the 2nd fee. There is no maximum number of discounts that can be given with a bulk discount.

This discount will apply only to Adult registrations.

### Using a standard discount

A standard discount code can also be used for a sibling discount. This method would allow you to limit the number of discounts that can be applied by defining the Fees Limit column.

Additionally, you can set the Pricing Types to limit the discount to specific class pricing if needed.

The Minimum fees column would also be used to define how many fees must be in the order for the discount to apply.

Using codes would allow you to create a code for an additional discount when you want a different one when 3 fees are purchased.

### Using Buy X Get X

The Buy X Get X discount method could also work if you would like to make a matched sibling discount. The Buy X Get X would pair purchases within the same class and provide a discount on the 2nd fee.

### Global Discounts

Global discount codes allow you to create a code once and apply it to any or all classes you wish. Using Global Discounts lets you apply the same code across multiple events for a sibling discount.

With all the same functionality as a Standard discount, this option allows you to create the discount once and have it apply to multiple classes, with the ability to add it to additional classes at a later time by editing the discount term. This method also allows the discount to apply if you buy two different classes in the same order.

### Honor System

The honor system is just that. It involves creating pricing for classes with two or more registrants and trusting that your families will not abuse it. You can also make this Admin Only if desired, if you prefer to handle this in the box office.

### Utilizing One-Off Discounts

You can create an on-the-fly or one-off discount on the admin pages if selling a sibling discount. While this would mean you have to create the order, one benefit is that you can then invoice the purchaser with the discount applied. Allowing the payment to be made online or via mail-in check.
