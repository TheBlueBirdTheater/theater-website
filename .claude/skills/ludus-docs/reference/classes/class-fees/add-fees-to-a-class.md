# Add Fees to a Class

When you first [Add a Class](https://support.ludus.com/add-a-class), you will input the various names and settings and then be automatically taken to a screen where you can add Fees. The steps below will also walk you through how to add a Fee after the fact.

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Pricing** --> **Fees**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Kufj9zKFjlDDq15wI88Sq_ludus-manual-admin-2024-06-06t130126243.png?format=webp "Document image")
    
3.  Click the green **\+ Fee** button.
    
4.  Fill out the applicable information.
    
    To learn more about each setting and what is possible, check out this article.
    
    _Suggested Article_: [](https://support.ludus.com/settings-for-class-fees "https://support.ludus.com/settings-for-class-fees")[Settings for Class Fees](https://support.ludus.com/settings-for-class-fees)
    
5.  Click **Done**.
