# Sort fees for a Class

By default, Fees on a Class will be sorted by price (high to low). However, you may wish to sort them in a custom order.

1.  To do so, navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Pricing** --> **Fees**.
    
3.  Then, select **Sort Fees** from the top menu.
    
4.  Then, drag the fees into the desired order and click **Save Sort**.
