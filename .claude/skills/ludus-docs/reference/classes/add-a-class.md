# Add a Class

To create a new Class, navigate to **Collections** --> **Classes**. Then, click **+Add Class**. Fill out the Basic Info, Files, Form, and Additional Options fields as needed. For more information about each field, check out the descriptions below.

### Basic Info

-   **Class Name**: The public name for your Class. This will be visible to your patrons.

-   **Address**: Where the class will be located. To display this correctly on public listings, include street address, city, zip code, and state.

-   **Attendee Limit:** Limit the number of attendees before the class is "full."

-   **Cover Graphic**: A display image that will appear above your registration.

### Attachments

-   **Files**: A file that purchasers can download after successful payment.

-   **Form**: These are additional questions (in addition to the standard name, email, phone number, and address) for your purchasers. You can either choose an existing form or create a new form. To learn more about Forms, check out this article.

_Suggested Article_: [Forms](https://support.ludus.com/forms)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WzMQQkI0qi5dcJDYSYvvy-20251222-144022.png?format=webp "Document image")

Since the Classes feature utilizes questions on student profiles, we recommend placing any questions you'd like to live with the student year after year there and using the Forms feature mentioned above for questions that apply JUST to the class at hand. For example, a question about their accommodations would be under the student profile, but a question about which role they are most interested in would be best served on a Form.

### Payment Options

-   **Payout Method:** This applies only to Checks.

-   **Invoice Me:** Allow patrons to request an invoice to pay the class total at checkout.

-   Invoice Me due dates can also be set here.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1N0J_mkQwIgsyugV79Fro-20251222-144253.png?format=webp "Document image")

### Additional Options

-   **Waitlist**: Allow patrons to join a waitlist once this collection sells out.

-   **Waitlist Limit**: Limit the number of registrations that a party can request.

-   **Waitlist Expiration**: Choose how long a patron must claim their spot after an admin grants them their requested registrations.

-   **Waitlist Queue**: Public or Private. Allow patrons to see what position they are on the waitlist.

-   **Waitlist Form**: A custom form can be added to fill out when joining the waitlist.

-   **Waitlist Notice**: This is an optional message that the patron can see when they join the waitlist. It will override the global waitlist notice for this collection.

-   **Convenience Fee**: Choose whether to pass on convenience fees to patrons or absorb them.

-   **Exempt Order Custom Fees**: This option allows you to exempt this collection from any order-level custom fees that you may have set up.

-   **Class Categories:** Create a category for your class for easy sorting.

-   **View Only:** Disable sales to the public, but still allow patrons to view pricing and seating. (Does not affect admin panel sales.)

-   **Coming Soon**: Display a "Coming Soon" message that prevents patrons from purchasing now. This does not affect sales from the Admin Panel.

-   **Ludus Protect:** Let your patrons add Ludus Protect at checkout for peace of mind. Ludus will handle qualified refund requests, and they'll get up to $1,000 back — and you keep 100% of your sales. **86% of events keep Ludus Protect enabled.**
