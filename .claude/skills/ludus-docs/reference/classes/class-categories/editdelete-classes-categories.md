# Edit/Delete Classes Categories

After you have set up some categories for your classes, you might need to change how they are named, change which category a class is attached to, or delete a category entirely. To do so:

1.  Click Categories on your Classes Page.
    
    
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-rZ5B2ADVzeKBWq1vw2U2a-20240815-161543.png?format=webp "Document image")
    
2.  Next to each existing category, there will be delete and edit buttons.
    
    \-Click the pencil icon to edit and type in the new name. Click the check mark to finish.
    
    \-To delete, click the trash can icon and verify that you wish to delete.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-AZY9CTsouqObnzslT_AA1-20240815-161713.png?format=webp "Document image")
