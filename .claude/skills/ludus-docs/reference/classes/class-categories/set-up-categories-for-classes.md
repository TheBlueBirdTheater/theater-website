# Set Up Categories for Classes

When setting up or editing a Class, you can create a new Classes category or attach the event to a current category. To find this setting, go to your **Classes** tab, and next to the event's title, click **More** --> **Settings**. (For a new event, click **+Add Event**)

The Categories field will be located under **Additional Options**.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-8N4bZCKRkvyuz-i1GyjDC-20240815-160707.png?format=webp "Document image")

If you have existing categories, select which one(s) you'd like to attach this event to from the drop-down menu. To add a new category, click **Manage Categories**. Click **Save Settings** to complete.
