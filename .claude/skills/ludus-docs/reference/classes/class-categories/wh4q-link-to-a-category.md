# Link to a Category

You can use the Category Manager to link directly to a Category. This is useful if you want to sort your classes into categories such as Adult vs. Youth or perhaps Dance vs. Tap.

### Obtain the Share link for a Category

1.  Navigate to the Categories Manager by clicking the Categories button at the top of the Classes page.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-rZ5B2ADVzeKBWq1vw2U2a-20240815-161543.png?format=webp "Document image")
    
2.  Locate the category you want the link for and click the link Icon as shown.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-j94B9LGxLaONbmqy9-KaQ-20240815-163000.png?format=webp "Document image")
    
3.  Copy the Public Share Link from the pop-up that appears.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-cJOTqnMPQ6ahVCGsxSE_r-20240815-163102.png?format=webp "Document image")
    
4.  Paste the share link wherever you would like to share it.
    

Only Categories that have Classes assigned to them will appear on the public-facing pages.
