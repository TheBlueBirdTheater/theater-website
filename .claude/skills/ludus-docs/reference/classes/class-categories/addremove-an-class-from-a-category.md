# Add/Remove an Class From a Category

Once you have set up an event, you can attach it to an event category. Then, when patrons are searching under that specific category on your page, the event will appear. Events can belong to more than one category.

Select the **Categories** button on the main **Classes** tab to add or remove a class from an event category. Click **Add to Classes** next to the category you want to add the class to. Then click the checkbox next to the event and **Save** to add it to the category. To remove from a category, Click Add to Events, deselect the class, and **Save**.
