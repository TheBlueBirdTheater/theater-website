# Classes Category Manager

It is possible to create and edit Categories for your Classes by using the Category Manager. To access the Category manager click on **Categories** on the top of your **Classes** page.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-rTH6IFHi6BJkR5_h6RhjB-20240815-161143.png?format=webp "Document image")

The Categories Manager is used to:

-   Sort the categories into the order you would like them to appear.

-   Add new categories

-   Add classes to a category

-   Edit the category name

-   Get a direct link to a category

-   Delete a category
