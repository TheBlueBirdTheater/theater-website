# View a Class roster

Class rosters will show all of the registrants for a specific class time. To view a roster, navigate to **Collections** --> **Classes**. Then, next to the desired class time, click **View Roster**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ES-SlOk1q12GyvSqhdJg8_screen-shot-2023-08-22-at-85822-am.png?format=webp "Document image")

### What is found in a roster report?

-   **Order Code** - The number for and direct link to the order page for the registration.

-   **Student Contact Information** - Name, email, phone number

-   **Fee** - The type of registration that was selected

-   **Payment** - The amount paid.

-   Pay Later - Will show the status of the invoice if Pay Later was selected. This includes the following statuses:

-   **Paid**

-   **Past Due**

-   **Unpaid**

-   **Partially paid**

-   **Date** - The date and time of registration.

-   **Student Profile** - A handy link to view the [Student profiles](https://support.ludus.com/student-profiles)

-   **Answers to questions on student profile** - The responses to questions you ask on your student profiles.
