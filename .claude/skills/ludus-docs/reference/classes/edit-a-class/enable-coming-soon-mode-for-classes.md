# Enable "Coming Soon" mode for Classes

There might be a scenario in which you're ready to list a class publically but are not ready to have sales start just yet. "Coming Soon" mode is perfect for this. To enable coming soon mode:

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired class, click **Options**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Lx6jn6NOB7fDptNKCLN1n-20251222-144732.png?format=webp "Document image")
    
3.  Scroll down to the bottom of the settings page and next to "Coming Soon", click the circle for "On".
    
4.  Click **Save Changes**.
    

Now, when a patron views your class, they will see a greyed-out box labeled "Coming Soon".
