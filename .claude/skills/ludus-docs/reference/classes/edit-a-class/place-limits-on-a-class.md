# Place limits on a Class

Within a Class, you are able to place limits on the number of purchasers before a Collection becomes unavailable. Additionally, you can limit how many of each fee are purchased.

### Place overall limits on a Class time

1.  To set a limit, navigate to **Collections** --> **Classes**.
    
2.  Then, next to the desired Class name, click **Options** --> **Settings**.
    
3.  Scroll down to the section titled "Additional Options".
    
4.  For "Attendee Limit", insert the desired cap.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/P2-CRwZYOksZDLrUBQtcs_screen-shot-2023-08-22-at-100145-am.png?format=webp "Document image")
    
5.  Click **Save Changes**.
    

This will affect all class times under the specific Class. If you have a different number of slots available for each class time, check out this article.

_Suggested Article_: [Override total attendee slots for single Class Time](https://support.ludus.com/override-total-attendee-slots-for-single-class-time)

### Limit the number of Fees per patron

1.  To set a per-fee limit, navigate to **Collections** --> **Classes**.
    
2.  Then, next to the name of the desired Class, click **Pricing** --> **Fees**.
    
3.  Next to the desired fee, click **Edit**.
    
4.  Next to the section titled "Limit Per Patron," click the checkbox.
    
5.  Insert the desired cap and click **Save Changes**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aEr8h0KaHWDq6ovQ0dm75_screen-shot-2023-08-22-at-100551-am.png?format=webp "Document image")
    

### Limit the total inventory for Fees on a class time

Maybe you have 20 slots overall for a class. However, you might only have 10 slots for adults and 10 for youth. You will want to set a total inventory for fees on a fee.

1.  To set a total limit, navigate to **Collections** --> **Classes**.
    
2.  Then, next to the name of the desired Class, click **Pricing** --> **Fees**.
    
3.  Next to the desired fee, click **Edit**.
    
4.  At the bottom of the page, click **Advanced Options**
    
5.  Next to the section titled **Total Inventory** click the box that says **Set total inventory for this price** and insert the desired cap.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/XGOpSdvUdZ18oAFmu-M2i_screen-shot-2023-09-06-at-22224-pm.png?format=webp "Document image")
    
    You can choose whether this inventory limit is for the Class overall or for each class time. For instance. If you have three class times in a class and a limit of 10 adult spots per class time, you would want to click "Per Class time". If it doesn't matter which class time it is for and you just have 10 adult slots available across all three class times, select "For entire Class".
    
6.  Click **Save Changes**.
