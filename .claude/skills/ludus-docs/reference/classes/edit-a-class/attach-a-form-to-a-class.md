# Attach a Form to a Class

There are multiple ways to ask questions of your class registrants. While Student profiles are great for information that will live with the student year after year, Form submissions are great for questions that are only relevant to the Class at hand. _Suggested Article_: [Ask questions of Class registrants (Student profiles vs. Form submissions)](https://support.ludus.com/ask-questions-of-class-registrants-student-profiles-vs-form-submissions)

1.  Create the Form you want to use. To learn how to do this, check out this article. _Suggested Article_: [Create a Form](https://support.ludus.com/create-a-form)
    
2.  Navigate to **Collections** --> **Classes**.
    
3.  Next to the name of the desired Class, click **Options** --> **Settings**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Lx6jn6NOB7fDptNKCLN1n-20251222-144732.png?format=webp "Document image")
    
4.  Scroll to the "Form" section and choose the Form you created in Step 1 from the dropdown menu.
    
5.  Click **Save Changes** at the bottom of the page.
