# Print a Class roster

Although student profiles can be viewed at any time from your admin panel, there might be scenarios in which you'd like to print out the student profiles to have on hand.

To do so, navigate to **Collections** --> **Classes**. Then, next to the desired class time, click **View Roster**. In the upper right-hand corner, click **Print**.

### Choosing what to print

There are a few printing options for class rosters.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/IfBAASkn2amMJWbEk_ONd_screen-shot-2023-08-22-at-91623-am.png?format=webp "Document image")

**Checkboxes:**

-   **Additional Information**Check this box to include any additional questions you ask of your registrants on Student profiles.

-   **Form Submissions** - Have this box checked to include any questions you ask attached to a Form on the Class. _Suggested Article_: [Attach a Form to a Class](https://support.ludus.com/attach-a-form-to-a-class)

**Print Views:**

-   **Per Page** - Each student is printed separately on a page. Great if you are building a binder or something of the sort for each class.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ll8_M3VyVJ8o_-lvOzWuG_screen-shot-2023-08-22-at-92140-am.png?format=webp "Document image")

-   **Table View** - A listing of student registrations in spreadsheet format. Great for a quick overview and comparing all students simultaneously.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YcqYkpSHIKcbsX7oaI-yf_screen-shot-2023-08-22-at-92359-am.png?format=webp "Document image")
