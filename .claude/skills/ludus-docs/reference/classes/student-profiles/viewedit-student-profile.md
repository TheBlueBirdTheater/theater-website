# View/Edit Student Profile

Once a student has registered for a Class, a Student Profile will automatically be created.

To view or edit a student's profile:

1.  Use the search bar in the top navigation bar to look up the student.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/uBn5ct_Uow6f80cJcfY4e_screen-shot-2023-09-06-at-110121-pm.png?format=webp "Document image")
    
2.  Click the **Students** tab and choose the desired student from the list.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/V4SQAVkdl17U49j7ac9t7_view-edit-student-profile-archbee-document.png?format=webp "Document image")
    
3.  Scroll through the profile to view all the pertinent information. To make changes to the Student Details or Additional Parties, click **Edit**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/qdgtEXcMntuEj_bjyZxbF_screen-shot-2023-09-06-at-110443-pm.png?format=webp "Document image")
    
4.  Be sure to click **Update Student** to save any changes.
