# Class Fees

"Fees" is an overarching term for any registration payment or charge for a Class. Each selected fee will take up one slot in the overall availability of your class.

**Note** - You might charge different amounts for adult registrants versus youth in a class. Therefore, you would set up two other "Fees". The first could be titled "Adult" and cost $50; the second could be titled "Youth" and cost $40. This is what you'll be setting up with Fees.

Check out the blocks below to learn how to manage the fees on your Collection.
