# Limit Usage for Access Codes for Classes

You might want to limit the use of a specific Access Code. The drop-down menus below will walk you through setting different types of limits.

### Limit which class times they have access to

With Access Codes, you can choose whether they receive access to the entire class or just specific class times (e.g., the Wednesday class but not the Friday class).

1.  Navigate to **Collections** --> **Classes**.
    
2.  Then, next to the desired Class, click **Options** --> **Access Codes**.
    
3.  \-To set a limit on a new Access Code, click **\+ Access Code** in the top right corner.
    
    \-To set a limit on an existing code, click **Edit** next to the desired code.
    
4.  Next to "Unlocking", click the circle for "Unlock specific Class times"
    
5.  Check the box for each class time they may access.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/iEr_6iVtxA2iIWPl3WqCb_screen-shot-2023-08-22-at-82715-am.png?format=webp "Document image")
    
6.  Click **\+ Add Access Code** to save.
    

### Limit the number of registrations they can make with a code

1.  Navigate to **Collections** --> **Classes**.
    
2.  Then, next to the desired Class, click **Options** --> **Access Codes**.
    
3.  \-To set a limit on a new Access Code, click **\+ Access Code** in the top right corner.
    
    \-To set a limit on an existing code, click **Edit** next to the desired code.
    
4.  Next to "Type," click the circle for **Individual/Family**.
    
5.  For "Total Fees Inventory," insert the numbers of fees they can select before the Access Code stops working.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/x-nHjaXbXx3yCZkNrqac__screen-shot-2023-08-22-at-83505-am.png?format=webp "Document image")
    
6.  Click **\+ Add Access Code** to save.
