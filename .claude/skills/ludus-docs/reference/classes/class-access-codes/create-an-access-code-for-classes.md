# Create an Access Code for Classes

To create an Access code for a Class, check out the steps below:

1.  Navigate to **Collections**\--> **Classes**.
    
2.  Next to the desired Collection, click **Options** --> **Access Codes**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/A_5B68pRJX_g8p33H8_GV_ludus-manual-admin-2024-06-06t133840136.png?format=webp "Document image")
    
3.  Click the green **\+ Access Code** button.
    
4.  Choose whether this is a generic Access Code or one for an individual/family. "Individual/Family" is recommended when you wish to limit how many times this code can be used. _Suggested Article_: [Limit Usage for Access Codes for Classes](https://support.ludus.com/limit-usage-for-access-codes-for-classes)
    
    -   **Generic** — given to everyone with no usage limit; typically, one code is given to multiple people.
    
    -   **Individual/Family** — given to one specific individual/family with a set number of tickets they can purchase (e.g. allotted to purchase 4 tickets and no more).
    
5.  Type the actual code that will be used by the patron(s).
    
    Click **Generate random code** to have the system create one for you.
    
6.  _Optional_: Choose a reference text for future reference. This is useful when you have multiple Access Codes for different groups.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_5PJYKwoGkZwfmH_U-rI9_create-an-access-code-for-classes-archbee-document.png?format=webp "Document image")
    
7.  Click **\+ Add Access Code** to save.
    

Creating Access Codes does not automatically enable them. To turn on Access Codes and password-protect your Collection, make sure to enable the toggle at the top of the Access Codes page.
