# Edit an Access Code for Classes

To edit an existing Access Code, navigate to **Collections** --> **Classes**. Then, next to the title of Class, click **Options** --> **Access Codes.**

Next to the Access Code you'd like to edit, click **Edit**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WN4B0fygQKWIVT_2b0JVF_edit-an-access-code-for-classes-archbee-document.png?format=webp "Document image")

Make any changes desired and click **\+ Add Access Code** to save.

To learn more about the different settings available on a Collection, check out our article about creating an Access Code. _Suggested Article_: [Create an Access Code for Classes](https://support.ludus.com/create-an-access-code-for-classes)
