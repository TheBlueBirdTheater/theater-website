# Disable an Access Code for Classes

### Disable all Access Codes

When you are ready to remove all Access Codes, you can toggle the Access Code feature off for a Class.

To do so, navigate to **Collections** --> **Classes**.

Then, next to the title, click **Options** --> **Access Codes**. Ensure the toggle bar is not green and the circle is on the left side.

### Disable individual Access Codes

To remove one Access Code while keeping the other(s) in place, navigate to **Collections** --> **Classes**.

Then, next to the title, click **Options** --> **Access Codes**. Then, next to the code you'd like to disable, click **Disable**.

You can reinstate any Access Code by clicking **Enable** from the list of disabled codes.
