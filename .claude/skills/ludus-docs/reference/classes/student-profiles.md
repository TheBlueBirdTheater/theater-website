# Student profiles

One of the biggest perks of using the Classes feature is having the connected Student Profiles for each registrant. Student Profiles display all the information that you ask for on your registration form (_Suggested Article_: [Student Registration Form](https://support.ludus.com/student-registration-form)) current and past registrations, any parents/[Additional Parties](https://support.ludus.com/additional-parties), and form submissions for the student.

Essentially, it is a hub for all relevant information about a student.
