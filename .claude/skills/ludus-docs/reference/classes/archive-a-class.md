# Archive a Class

You can archive a class once you are finished with it or just wish to remove it from view.

To do so, navigate to **Collections** --> **Classes**. Next to the desired Class, click **Options** --> **Archive**.

### View Archived Classes/Recover

If you want to view an archived Class, navigate to **Collections** --> **Classes**. Then, scroll to the bottom of the page and click **View Archived Collections**.

If you need to recover an archived Class and bring it back to the main Admin panel, simply follow the instructions above, locate the desired Class, and click **Options** --> **Recover**.
