# Send an automated message to Classes

Automated messages use our drag-and-drop email design tool to craft custom emails to send to your purchasers, students, and other parties for a class. These messages are sent automatically based on the class start time. You can choose hours or days before or after a class. Check out the steps below to learn how to set these up.

1.  Navigate to **Collection** --> **Classes**.
    
2.  Next to the Class title, click **Options** --> **Messages**.
    
    If you have more than one class time and wish to send an email only to one specific class time, click **Options** --> **Messages** next to the desired class time.
    
3.  Click the green **\+ Message** button and then select **Automated**.
    
    To send an immediate, standard message, click **Standard**.
    
    _Suggested Article_: [Send a standard message for Classes](https://support.ludus.com/send-a-standard-message-for-classes)
    
4.  Insert the various settings for your automated message. To learn more, check out this article.
    
    _Suggested Article_: [Create an Email Automation](https://support.ludus.com/create-an-email-automation)
    
5.  Choose your starting design under the section titled "Template".
    
    _Suggested Article_: [Reuse a prior Automation as a template](https://support.ludus.com/reuse-a-prior-automation-as-a-template)
    
6.  Customize your design.
    
    _Suggested Article_: [Basics of the Marketing email design tool](https://support.ludus.com/basics-of-the-marketing-email-design-tool)
    
7.  Click **Save** to complete.
    

The email will now be sent at the time you specified under "Trigger".
