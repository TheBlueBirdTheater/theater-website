# Include/Exclude an Additional Party from Class messaging

Once an Additional Party is attached to a student, they will appear under every class that the student is registered for. From there, you can easily manage whether you want to include or exclude them from mailings.

To do so, navigate to **Collections** --> **Classes**.

Then, next to the class time, click **Options** --> **Additional Parties**.

Next to the individual you'd like to exclude, click **Exclude**. To reverse this action, click **Include**.
