# Create Additional Parties

To add additional parties to a class mailing, check out the steps below.

1.  Navigate to **Collections** --> **Classes**.
    
2.  Then, next to the desired Class or class time, click **Options** --> **Additional Parties**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YmI_RFA14R1zWBrJH-bWR_screen-shot-2023-08-24-at-71356-pm.png?format=webp "Document image")
    
3.  Click the green **\+ New Party** button.
    
4.  Type in the name and email for the contact.
    
    If you already have students registered for the class, you can attach the additional party to a student using the dropdown menu. This party will now appear for all classes for which this student is registered.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ghmrVCbqwrimpcHdbeW39_screen-shot-2023-08-24-at-71816-pm.png?format=webp "Document image")
    
5.  Click **Add Party** to save.
