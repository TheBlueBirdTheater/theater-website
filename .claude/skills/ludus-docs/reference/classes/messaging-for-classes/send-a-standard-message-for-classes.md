# Send a standard message for Classes

To send an email to your Class registrants:

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the Class title, click **Options** --> **Messages**.
    
    If you have more than one class time and wish to email only to one specific class time, click **Options** --> **Messages** next to the desired class time.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/uLtCPKTFBq3vFsYTJXubX_screen-shot-2023-08-25-at-94648-am.png?format=webp "Document image")
    
    
    
3.  Click the green **\+ Message** button and then select **Automated**.
    
    To send a scheduled, automated message, click Automated.
    
    _Suggested Article_: [Send an automated message to](https://support.ludus.com/send-an-automated-message-to-classes "Send an automated message to") [classes](https://support.ludus.com/send-an-automated-message-to-classes "classes").
    
4.  Type in the subject line and body of the email.
    
5.  You can also choose to send this message to students or additional parties. To do so, simply click on the icon for the corresponding group.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nXcjcHFU6D0B8UCmpWi9I_screen-shot-2023-08-25-at-101455-am.png?format=webp "Document image")
    
    To learn more about Additional Parties, check out this article.
    
    _Suggested Article_: [Additional Parties](https://support.ludus.com/additional-parties)
    
6.  Click **Send Message**.
