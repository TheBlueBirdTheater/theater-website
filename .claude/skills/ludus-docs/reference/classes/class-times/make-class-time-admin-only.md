# Make Class Time admin only

When adding class times, you may wish to make certain times available only to admins, not the general public. Check out the steps below to learn how to do this.

_Suggested Article_: [Add a Class Time](https://support.ludus.com/add-a-class-time))

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired class time, click **Options** --> **Edit Time**.
    
3.  Click the **Settings Wheel Icon** (⚙️)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gueXwi4sjH9AuLpotqfE7_screen-shot-2023-08-21-at-24632-pm.png?format=webp "Document image")
    
4.  Click the box next to "Admin Only".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pTeiIK-9poAn23YMiLPk__screen-shot-2023-08-21-at-24756-pm.png?format=webp "Document image")
    
5.  Click **Save**.
    

Now, when you are on your Admin Panel, you will see this time available but the general public will have it hidden.
