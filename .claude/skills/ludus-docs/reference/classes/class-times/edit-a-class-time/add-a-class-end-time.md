# Add a Class End Time

When setting up a Class, you can also enable an End Time for that Class if desired. This can be enabled for single and recurring classes.

To enable end times on your class:

1.  Go to **Options** (next to the Class time) -> and select **Edit Time**.
    
2.  On the Edit Time pop-up, you can add an (optional) end time.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-bGp9H0oQ_tL62GBeHvG96-20250121-151711.png?format=webp "Document image")
    
3.  Once added, be sure to select **Done** to save that time. This will save the End time for that Class time and you will see that on your Classes.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-g3_BPNbKYKhwYzdD4mndr-20241220-142849.png?format=webp "Document image")
    
4.  The end time will also show on the patron site.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-1me6cmCKN7EArf_ylrrkY-20241220-142849.png?format=webp "Document image")
