# Set up recurring Class Times

Not all classes occur on a single date. If your classes are recurring every week, you will want to set up recurring class times. Then, when users register, they will see that the class is recurring rather than a one-off.

To set up recurring class times:

1.  Navigate to **Collections --> Classes** and ensure you have set up your Class. If you still need to, check out our instructional guide here. _Suggested Article_: [Add a Class](https://support.ludus.com/add-a-class)
    
2.  Next to the desired Class, click **+Add Class Times**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/P-si8tIqL2SYn7rntMfOz_screen-shot-2023-09-06-at-104507-am.png?format=webp "Document image")
    
3.  Click the grey **Set Up Recurring Class Time**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YOWBHOjfExo8psntpV12f_screen-shot-2023-09-06-at-104646-am.png?format=webp "Document image")
    
4.  Input a start date and an end date for the Class.
    
    By default, registrations will stop at the start date you set for the class. If you'd like to allow patrons to register after the start date, check the box for **"Allow registrations until end date**."
    
5.  Click **Done**.
    

Now, your class time will appear as recurring based on the day that the class first occurs.
