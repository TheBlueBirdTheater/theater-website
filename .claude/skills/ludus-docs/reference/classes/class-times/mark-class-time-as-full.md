# Mark Class Time as full

At any point in time, you are able to change the total number of slots available for a class.

_Suggested Article_: [Override total attendee slots for single Class Time](https://support.ludus.com/override-total-attendee-slots-for-single-class-time)

_However_, there might be a time you wish to mark the class as full before it hits the total number of slots available. To do so, follow the steps below.

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired class time, click **Options** --> **Edit Time**.
    
3.  Click the **Settings Wheel Icon** (⚙️)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/v-Z97TJHj1Ngi0RNCY6Wt_screen-shot-2023-08-21-at-24632-pm.png?format=webp "Document image")
    
4.  Click the box next to "Manual Sold Out (Public)"
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/miFeUA95CIZh53r13uW4i_screen-shot-2023-08-21-at-24805-pm.png?format=webp "Document image")
    
5.  Click **Save**.
    

Now, you will still be able to make sales through your admin panel, but patrons will see the class as "Full" publicly.
