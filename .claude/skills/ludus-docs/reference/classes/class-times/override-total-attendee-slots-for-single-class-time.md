# Override total attendee slots for single Class Time

Class times don't always have the same capacity. Or maybe you need to increase or decrease the number of slots for a specific class time last minute. Check out the steps below to learn how to do this!

_Suggested Article_: [Add a Class Time](https://support.ludus.com/add-a-class-time)

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired class time, click **Options** --> **Edit Time**.
    
3.  Click the **Settings Wheel Icon** (⚙️)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/LO52UyI_mH81DYWuo4VeM_screen-shot-2023-08-21-at-24632-pm.png?format=webp "Document image")
    
4.  Under the section for "Total Attendees," insert the desired cap.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dtzdB9aQrwvD_7qGFHbyx_screen-shot-2023-08-21-at-50826-pm.png?format=webp "Document image")
    
5.  Click **Save**.
    

Your class times will now have a variety of total slots available.
