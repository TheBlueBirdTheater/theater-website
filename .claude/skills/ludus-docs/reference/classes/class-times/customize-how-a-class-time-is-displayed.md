# Customize how a Class Time is displayed

The Classes feature is extremely flexible and great for things like one-off workshops, summer camps, weekly skill-building courses, and more. Therefore, you might have the need to create a unique name for the class time. By default, the class time will show up as the dates you insert however, you can replace this with custom text.

1.  To start, navigate to **Collections** --> **Classes**.
    
2.  Next to the class time, click **Options** --> **Edit Time**.
    
3.  From the editing screen, click **Attach Subtitle**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dm9rE7VylXoCRSZFd4fXK_screen-shot-2023-08-21-at-11423-pm.png?format=webp "Document image")
    
4.  Type the custom text you'd like displayed, then click **Save**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/7F9OzxOosRnOsiDQiZaNm_screen-shot-2023-08-21-at-11626-pm.png?format=webp "Document image")
    
    When you replace the main time with a subtitle, you can also choose to hide the time completely. To do so, check the **Hide Class Time** box.

### What it looks like for patrons

Now, when patrons go to register, they will see the subtitle you used in lieu of the standard recurring or individual date. \*In this example, the custom subtitle that was typed in is "Every other Sunday starting on 12/6/23".
