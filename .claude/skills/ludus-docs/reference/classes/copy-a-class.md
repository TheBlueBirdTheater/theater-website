# Copy a Class

To copy a Class that has been created in the past, navigate to **Collections** --> **Classes**. Then, next to the name of the desired Class, click **Options** --> **Copy**.

Ludus will automatically make a copy and take you to a screen where you can alter details that make this Class distinct. Be sure to click **Continue** at the bottom of the page to save your new Class.

To learn more about Class settings, check out this article.
