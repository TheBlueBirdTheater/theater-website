# Waitlist FAQs

This resource contains the frequently asked questions about Waitlists and the best way to handle those items.

### How to add seats to an event and keep closed for the waitlist?

Once the waitlist is triggered by a sold-out event/collection, you can add more spots to the event or collection and this will not turn the waitlist off. Those spots could then be granted to patrons on your list.

### Does my event have to be on to use the waitlist?

It does not, but the patrons will not see the Waitlist if the event is turned off. If turned off, you can manually add to the Waitlist, via the admin panel. For more on this and other functions, check out [Waitlist Management](https://support.ludus.com/waitlist-management).

### Can I activate the waitlist before we sell out?

Yes! If you would like, you can use the "Manual Sold Out" feature under **Options** (next to the event time) -> **Edit Time** -> ⚙️ -> **Manual Sold Out.** This can be done in both Events and Classes.

### Am I notified when someone joins the Waitlist?

You will not receive an email when someone joins, but you will be able to monitor and grant tickets as those become available for the patrons on the list. It is recommended to use the [Waitlist Management](https://support.ludus.com/waitlist-management) resource to help with this process.
