# Set a Waitlist Expiration

Since you will most likely have multiple patrons signing up for the **Waitlist**, you may find the need to set an expiration for how long they have to claim their tickets once available. This can be done when initially setting up the Waitlist, or it can be done later as needed.

**To set an expiration time for how long a patron has to claim tickets:**

1.  Navigate to **More** (next to the event) -> **Settings**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/EFB_8AEqJJMc1myI8oedV_screen-shot-2024-01-18-at-112358-am.png?format=webp "Document image")
    
2.  From here, scroll down to **Additional Options** -> **Waitlist Expiration**.
    
3.  ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-lPMRGac2bHaIGdlwBFfEX-20250618-193238.png?format=webp "Document image")
    
    Once on the **Waitlist Expiration**, you can select how long a patron will have to claim their spot after an admin grants them their requested tickets.
    
    _For example_, if someone requested 2 tickets when signing up for the waitlist and you have an expiration of 10 minutes, they would have 10 minutes to claim (purchase) those tickets before their spot expired.
    
    **Waitlist Expirations** can be set to:
    
    -   Minutes
    
    -   Hours
    
    -   Days
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/B4wyQn64gkB59yqk1MRQt_screen-shot-2024-01-18-at-114312-am.png?format=webp "Document image")
    
4.  Once an expiration has been set (or you have opted not to use an expiration), be sure to **Save** your updated settings.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/0QzGx7vH2CsmzNHEDEjzV_screen-shot-2024-01-18-at-114422-am.png?format=webp "Document image")
