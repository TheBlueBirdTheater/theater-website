# Manage the Waitlist Queue

Once the event or event time has sold out, and the **Waitlist** has been enabled, patrons will start to add their names and ticket needs to that list. If and when you have patrons who release their purchased tickets, those tickets can then be opened up to patrons on your **Waitlist**.

To grant patrons on the **Waitlist** the opportunity to get those tickets, follow these directions:

1.  Navigate to the blue **Waitlist icon** next to the event time you wish to manage and select that icon.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9tadJYyJnnXF77p_C9dtQ_screen-shot-2024-01-22-at-102321-am.png?format=webp "Document image")
    
2.  Once to the **Waitlist** page, you will be able to view all patrons that are currently on your waitlist.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yJOZC2b1IapHqn8Cy-jWT_ludus-manual-admin-61.png?format=webp "Document image")
    
3.  From this spot, you can either grant the ability to get tickets, void a request, or just leave requests on the list.
    
    ### [](#grant-access)Grant Access
    
    To **Grant Access,** hover over the patron name (on the list) and select "Grant Access". Once selected, you will be able to **confirm** the request, and then see the time limit for the patron to claim and purchase their tickets.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4WQ1Hv6O1iX1J5nVH8TvW_ludus-manual-admin-90.png?format=webp "Document image")
    
    **Note**: It is possible to edit the number of tickets that a patron can purchase by changing the number of tickets before clicking continue when granting access.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fcN-tbGdF-Vy8vzUjj0gL_ludus-manual-admin-89.png?format=webp "Document image")
    
    ### [](#void-and-remove-from-the-waitlist)Void and Remove from the Waitlist
    
    To **void** a ticket request, go to the right of the patron's name on the waitlist and select **Void**.
    
    Once selected, you will need to confirm the void and whether the patron should receive an email letting them know they have been removed from the waitlist.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/E7apI5ICV1DYRM4Eowc5y_screen-shot-2024-01-22-at-113542-am.png?format=webp "Document image")
