# Enable the Waitlist

Enabling Waitlists is done the same way for all Events, Collections, and Classes. This can be done when creating the Event or later on, as you identify that you may need or want to use the feature.

When the waitlist is enabled and active, the public will be unable to purchase tickets for that event time. If you change limits or add tickets/fees, it will not turn the Waitlist off.

**Waitlists can be enabled with the following steps:**

1.  Navigate to **More** (next to the event) -> **Settings.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1n5QLZQlYqCI4jmbmxm7d_screen-shot-2024-01-18-at-112358-am.png?format=webp "Document image")
    
2.  Once there, scroll down to **Additional Options** \-> turn the **Waitlist** to "**ON**".
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-5siiTw8lpyJ028X5efSa5-20250618-193003.png?format=webp "Document image")
    
3.  Once enabled, the Waitlist will appear for all sold-out event times, allowing patrons to join as needed.
    
    **Admin Site view:**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Qt8Vk4ovmFIZBWcYegc96_screen-shot-2024-01-18-at-112756-am.png?format=webp "Document image")
    
    **Patron Site view:**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Yin6ekc4vSg9kBCYjNT1x_ludus-ludus-manual-5.png?format=webp "Document image")
    

Waitlists can be disabled the same way that they are enabled. If at any point you want to turn it off, simply go to **More** (next to the event) -> **Settings** -> **Additional Options** -> turn the **Waitlist** "**OFF**".
