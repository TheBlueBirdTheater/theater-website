# Set a Waitlist Limit

It is possible to limit the number of tickets a patron can request when signing up for the waitlist.

### Set a limit to the number of tickets that can be requested on the Waitlist

1.  Check the box **Waitlist Limit** and enter the maximum number of tickets that can be requested by a patron when signing up for the waitlist.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-YZfMmkaV7HkZMcodUROJV-20250618-193133.png?format=webp "Document image")
    
2.  Save the settings.
    

This can also be accessed and updated via the Settings tab within the waitlist itself.
