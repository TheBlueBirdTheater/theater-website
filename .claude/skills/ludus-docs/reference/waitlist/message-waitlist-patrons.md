# Message Waitlist Patrons

When a waitlist is active, patrons on the Waitlist can be messaged. This is done on the Waitlist dashboard.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-XV2nBHUaxfvYROUS1_XmB-20241025-195920.png?format=webp "Document image")

1.  When selected, you will be presented with a window to create the message and options as to what section (sections) of the list to send the message to. You can select to message the Pending List, the Sent List, or Patrons who have claimed tickets. Or a combination of the three.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-66WkH0RHaENBmgx1pl58_ludus-manual-admin-56.png?format=webp "Document image")
    
2.  Once you send your message, you will be shown the message sent as well as who it was sent to, along with the Status of the message.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_yCB-DQVjqHYZHDBU-TrE_ludus-manual-admin-59.png?format=webp "Document image")
    
3.  This message can be viewed again by clicking **Messages** in the **Options** menu next to the event time.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_DWynGb0crm8fwwPislW8_ludus-manual-admin-58.png?format=webp "Document image")
