# Add a Waitlist Notice

A Waitlist Notice can be added to display a message to the patron when they are joining the waitlist. This will override the global waitlist notice for this show.

### Set a Waitlist Notice

1.  On the Event Settings page, you will first set Waitlist to on for your event. This can be done while building your event, collection, or class. Or by navigating to **More**, or **Options**, next to the event and selecting **Settings**. The Waitlist feature is located under **Additional Options**.
    
2.  Scroll down to the Waitlist Notice Field and create a custom message that you wish to display to patrons as they sign up for the waitlist.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-k5MwPpINhTvqlN_saPUky-20250618-193459.png?format=webp "Document image")
    
3.  Save your event.
    

When Patrons go to sign up they will see your Notice.
