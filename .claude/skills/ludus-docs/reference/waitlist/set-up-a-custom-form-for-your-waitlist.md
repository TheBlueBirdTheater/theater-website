# Set up a custom Form for your Waitlist

If you wish to ask any questions specifically to people signing up for the Waitlist, you can create a form for those signing up for the waitlist.

### Set a form for Waitlist sign-up

Before starting, be sure to create your form ahead of time.

_Suggested Article:_ [Create a Form](https://support.ludus.com/create-a-form "Create a Form")

1.  On the Event Settings page, you will first set Waitlist to on for your event. This can be done while building your event, collection, or class. Or by navigating to **More** or **Options**, next to the event, and selecting **Settings**. The Waitlist feature is located under **Additional Options**.
    
2.  Scroll down to the Waitlist Form selector and select the correct form from the drop-down.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-t7hhjk88Twbw5f5rsxzfM-20250618-193353.png?format=webp "Document image")
    
3.  Save your event.
    

You patrons will see the form at the bottom of the Waitlist sign-up screen as shown below.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/g5aDlNlsf2NFSIohMf69C_ludus-ludus-manual-7.png?format=webp "Document image")
