# Add a discount to a purchase

If you have set up a discount on an event, collection, class, or pass, you can easily apply that at checkout.

To do so, add the items to your cart as you normally would on a sale. When you are at the checkout screen, you will see a box in the bottom right-hand corner for discounts. Click **Discount Code** to expand the box**.**

# To apply an existing discount

If you want to use a code that has already been set up, type in the code and click **Apply**.

Only one discount code can be used on an order at a time. If you'd like to alter the discount code you wish to use after you've already applied a different one, simply type in the new code into the same box and click **Apply** again.

## Create a one-off discount

If you don't have any discounts created for the event, or the ones you do have don't fit what you'd like to give, you can create a one-off discount on the fly.

### To do so:

1.  Click **+Create One-Off Discount** from the **Discount Code** box on the checkout page.
    
2.  Choose the type of discount (percentage or flat rate.
    
3.  Choose the amount per order or per ticket.
    
4.  Set any limits by checking the box that says **Limit number of tickets discount applies**.
    
5.  _Optional_: Input a reason for the discount.
    
6.  Click **+Add Discount**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/P84NC5fK2B05iBcZlGNWJ_screen-shot-2023-09-01-at-52105-pm.png?format=webp "Document image")
    

The ability to add a one-off discount is limited to Full Admin users.

One-off discounts are currently available for events, collections, and class purchases.
