# Sell a Pass

The process for selling a pass differs slightly depending on the type of pass. Check out the corresponding drop-down below to learn more.

### Sell a Flex Pass or Membership from your admin panel

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the pass that you'd like to sell, click **Sell**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/MIPdGZHKWaxrD_L_rnAA0_screen-shot-2023-09-01-at-121958-pm.png?format=webp "Document image")
    
3.  On the right side, choose the number of passes that you wish to sell.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gG-gmiYSpQw-O3bOFbCYm_screen-shot-2023-09-01-at-122141-pm.png?format=webp "Document image")
    
    Click **Add to Cart**.
    
4.  Click **Checkout** to accept payment. Choose **Change number of passes** to do just that.
    
5.  Under **Personal Information**, insert as much or as little information as your organization desires. We recommend at least name and email to make tracking this order easier later on.
    
    If they have been a patron with you before, you can click the green **Magnifying Glass** button (🔍) and look up their name/email. Then, click **Select** and all of the information that is on file will autofill and you can add/update as needed.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4YQPNzHBvunjMFq4l4tgx_screen-shot-2023-09-01-at-122702-pm.png?format=webp "Document image")
    
6.  Within **Personal Information**, choose whether or not you'd like to send a confirmation email for the purchase. The default is yes.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8PE42slzHgtx6wsbA_lVx_screen-shot-2023-09-01-at-122829-pm.png?format=webp "Document image")
    
7.  _Optional_: Add a donation or discount code to the order. (Check out the links at the bottom of this article)
    
8.  From the checkout screen, you have three main options **Credit**, **Cash**, **Comp**. Select the button for the type of sale you'd like to make. To learn more about each type, check out this article.
    
    _Suggested Article_: [Overview of payment options](https://support.ludus.com/overview-of-payment-options)
    
9.  Once you finalize the payment, you will be taken to the confirmation screen where you can view the code for the pass.
    

Pass codes will be randomly generated. If you'd like to set a custom code, you can do so by scrolling to the bottom of the **Personal Information** section and clicking **Custom Code**. No two passes can have the same code.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/udr1SGVqa8ip67iLTdfVz_screen-shot-2023-09-01-at-124704-pm.png?format=webp "Document image")

### Sell a Season Ticket from your admin panel

Season Tickets are a type of pass where the patron chooses their tickets for each event at the same time the pass is purchased. Check out the steps below to learn more.

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Next to the Season Ticket that you'd like to sell, click **Sell**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2914oa1UdjJoLW_PmDGfe_screen-shot-2023-09-01-at-10505-pm.png?format=webp "Document image")
    
3.  Choose the number of passes from the dropdown menu and click **Continue.**
    
4.  From the selection screen, use the list of events on the left-hand side to add tickets to the pass. Each Season Ticket has different settings so you will need to select events in accordance with the settings on the pass. Some require you to add a ticket from each event before you can complete the purchase. You can use the box on the right-hand side to view the number of tickets remaining and/or any missing requirements. See the image below for a guide.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/brBUXgF7_o2okVoVUQMc9_screen-shot-2023-09-01-at-12421-pm.png?format=webp "Document image")
    
5.  Once you have fulfilled all of the requirements on the Season Ticket, you will see a green **Checkout** button in the upper right-hand corner. Click it to continue.
    
6.  Under **Personal Information**, insert as much or as little information as your organization desires. We recommend at least name and email to make tracking this order easier later on.
    
    If they have been a patron with you before, you can click the green **Magnifying Glass** button (🔍) and look up their name/email. Then, click **Select** and all of the information that is on file will autofill and you can add/update as needed.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4YQPNzHBvunjMFq4l4tgx_screen-shot-2023-09-01-at-122702-pm.png?format=webp "Document image")
    
7.  Within **Personal Information**, choose whether or not you'd like to send a confirmation email for the purchase. The default is yes.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8PE42slzHgtx6wsbA_lVx_screen-shot-2023-09-01-at-122829-pm.png?format=webp "Document image")
    
8.  _Optional_: Add a donation or discount code to the order. (Check out the links at the bottom of this article)
    
9.  From the checkout screen, you have three main options **Credit**, **Cash**, **Comp**. Select the button for the type of sale you'd like to make. To learn more about each type, check out this article.
    
    _Suggested Article_: [Overview of payment options](https://support.ludus.com/overview-of-payment-options)
    
10.  Once you finalize the payment, you will be taken to the confirmation screen. From there, choose whether you'd like to print the tickets, send them digitally (email or text), or mark them for Will Call. This option will apply to all tickets within the Season Ticket.
     
     _Suggested Article_: [Overview of retrieval options](https://support.ludus.com/overview-of-retrieval-options)
