# Add patron details to an order

Patron Details are notes that Admins can add to a patron record. These details have the option to be added to tickets and can be added from both the checkout screen as well as the confirmation screen after purchase. On this screen, you will see a box to insert Patron Details.

Simply type your message in the box provided, and the notes will automatically save.

![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-VCg4eXg0uNzCS0ZhlW6pl-20240826-163257.png?format=webp "Document image")

If you'd like to display this note on the ticket itself, check the box that says **Display notes on ticket**.
