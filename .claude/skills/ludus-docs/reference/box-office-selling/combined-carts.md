# Combined carts

Whether you're selling tickets at the box office or patrons are buying tickets online themselves, multiple events and items can be added to an order before completing a sale.

As an admin or patron, click the **Add more to cart** button, and it'll bring you back to the list of events to add more. Or you can simply use the top navigation to go back to the main page to continue building your cart.

A cart can be combined with other items such as Add-Ons, Collections, Class registrations, and donations. Only Passes such as flex passes, season passes, and memberships must be purchased/sold separately.
