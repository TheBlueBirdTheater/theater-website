# Box Office View

Box Office View is an alternative method for day-of ticket sales. You can always use the **New Order** method as spelled out in the following article.

_Suggested Article_: [Sell tickets to an Event](https://support.ludus.com/sell-tickets-to-an-event)

However, some users find Box Office View more efficient for their needs. We recommend utilizing Box Office View when you are not planning on capturing any patron information, such as name and email. It is also useful for general admission events where you are just trying to plow through a long box office line.

## Where to find the Box Office View

There are two ways to get to the Box Office View**.**

1\. Click the computer screen icon next to the event time (this will only appear on the day of the event.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/l8RkSY-N4kLBUROM94eu8_screen-shot-2023-09-17-at-23152-pm.png?format=webp "Document image")

2\. Next to the event time, click **Options** --> **Box Office View**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/u8lTm-BVxT4hkHDUND2ip_screen-shot-2023-09-06-at-112809-pm.png?format=webp "Document image")

## Sell tickets with Box Office View

Once you have clicked the **Box Office View** icon (instructions above), you are ready to start selling tickets with this view.

While this view is useful for certain organizations and types of events, making sales from the **New Order** button is the number one recommended way to sell tickets in Ludus. To learn more, check out this article.

_Suggested Article_: [Sell tickets to an Event](https://support.ludus.com/sell-tickets-to-an-event)

1.  First, choose the number of each ticket type that you're going to sell.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Gj9d1tiRB8odRQaIsI9bX_screen-shot-2023-09-19-at-105145-am.png?format=webp "Document image")
    
2.  _**Reserved Seating Only**_**:** Then, choose the seats from the seating chart below. This must match the total number of tickets selected in the boxes above.
    
    \*Skip this step for general admission events.
    
3.  In the upper right-hand corner, click **Update**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/iOhkV0WYrMbzyyzMHOF5O_screen-shot-2023-09-19-at-105532-am.png?format=webp "Document image")
    
4.  Use the green boxes on the right side to pay with credit, cash, complimentary, or an "Other" payment method (if set up on your account).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ho0D2xmLAGBikZMTEZmjn_screen-shot-2023-09-19-at-105640-am.png?format=webp "Document image")
