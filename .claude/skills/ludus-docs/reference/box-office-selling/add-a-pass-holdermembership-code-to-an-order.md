# Add a pass holder/membership code to an order

Whether it be a flex pass holder wanting to redeem tickets on their pass or a member wanting to unlock their perks, you may have a need to apply a pass holder code to an order on your admin panel.

### When you are on the checkout screen:

1.  Click **Enter passholder code** from the bar at the top.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YFbod7JpBvS7_zhMTQXNl_add-a-pass-holder-membership-code-to-an-order-archbee-document.png?format=webp "Document image")
    
2.  If you or the patron knows the code, you can type it into the box provided. To look up the code, use the magnifying glass and search for the patron by name or email. Once you've located the pass you wish to use, click **Select**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KW2JR2nptC-BTCubY0iYt_screen-shot-2023-09-01-at-53057-pm.png?format=webp "Document image")
    
3.  Click **Apply**.
    
4.  If this is a membership, and attached perks will automatically be applied.
    
    If this is a flex pass, attached perks will be applied and you will be taken to a screen where you can choose which ticket(s) the patron would like to apply to the pass. Check each ticket they wish to apply and click **Done**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/olTWJKiWI4gIpPOWppL_X_add-a-pass-holder-membership-code-to-an-order-archbee-document-1.png?format=webp "Document image")
