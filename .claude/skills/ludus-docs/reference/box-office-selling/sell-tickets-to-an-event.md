# Sell tickets to an Event

## Video Overview:

### **To Tickets to an Event**

1.  Navigate to the desired event and, next to the appropriate event time, click **New Order**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2-8HH8nNrXItf3GeOmNqP_screen-shot-2023-09-01-at-112139-am.png?format=webp "Document image")
    
2.  **For a general admission event**, simply click the desired number of each ticket type you have available.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dD3eYg-AxsabO6jy-ww9d_screen-shot-2023-09-01-at-113055-am.png?format=webp "Document image")
    
    **For a reserved seating event**, click the desired seats from the chart and then scroll down and use the drop-down menu to change the ticket type/price that is applicable.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/NtTnKOFlNe_t7Kf5o3Iav_screen-shot-2023-09-01-at-113542-am.png?format=webp "Document image")
    
3.  Under **Payer Information**, insert as much or as little information as your organization desires. We recommend at least a name and email to make tracking this order easier later on.
    
    If they have been a patron with you before, you can click the green **Magnifying Glass** button (🔍) and look up their name/email. Then, click **Select,** and all of the information that is on file will autofill, and you can add/update as needed.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/HyP5l0-ds6KkcuxRcKAuf_screen-shot-2023-08-31-at-94601-pm.png?format=webp "Document image")
    
4.  Click **Add to Cart**.
    
5.  _Optional_: Add a donation, discount code, or pass holder code to the order. (Check out the links at the bottom of this article)
    
6.  From the checkout screen, you have three main options: **Credit**, **Cash**, and **Comp**. Select the button for the type of sale you'd like to make. To learn more about each type, check out this article.
    
    _Suggested Article_: [Overview of payment options](https://support.ludus.com/overview-of-payment-options)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6GMsGqR4f5xC1i2xkMkO7-20260529-170133.png?format=webp "Document image")
    
7.  Once you finalize the payment, you will be taken to the confirmation screen. If you inserted a patron's email during the order, they will automatically receive a confirmation email.
    
    From the confirmation screen, choose whether you'd like to print the tickets, send them digitally (email or text), or mark them for Will Call. _Suggested Article_: [Overview of retrieval options](https://support.ludus.com/overview-of-retrieval-options)
    
8.  _Optional_: Insert private notes for the order using the box in the bottom right-hand corner of the screen.
    

### Sell Tickets to a Pass Holder

If a patron is a pass holder (either a Flex Pass holder or a Membership holder), you can enter their information, and their pass will automatically be found and applied to the order.

1.  Navigate to the desired event and, next to the appropriate event time, click **New Order**.
    
2.  **For a general admission event**, simply click the desired number of each ticket type you have available.
    
    **For a reserved seating event**, click the desired seats in the chart, then scroll down and use the drop-down menu to change the applicable ticket type/price.
    
3.  At this point, you will enter the patron's information using the small magnifying glass. This will pull up the patron and their pass information when you proceed to checkout.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Rh_VFgzTmzt9Nl2lfx-U3-20260317-143343.png?format=webp "Document image")
    
4.  When you proceed to checkout, you will now see any associated passes at the top of the order screen:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/vYKSA0aod0mp_FY72snw5-20260317-143417.png?format=webp "Document image")
    
5.  Click **Select** next to the pass, then apply it to the applicable tickets in the cart.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/VNMPRC0hmgGrDmc5VZILj-20260317-143518.png?format=webp "Document image")
    
6.  Once you select **Done**, you will then see the pass applied to the selected ticket(s) in the cart and can proceed through checkout (**Submit Order**).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/cIy8K1NNr_AIOStL4NuXA-20260317-143617.png?format=webp "Document image")
