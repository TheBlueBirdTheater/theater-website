# Day of Event Check-List

If you need a checklist for your event and front-of-house staff/volunteers, the following is intended to serve as one.

[Download Ludus Mobile](https://support.ludus.com/download-ludus-mobile)

1.  ### [](#does-each-volunteer-have-their-own-admin-login)**✅ Does each volunteer have their own admin login?**
    
    Each person assisting (whether working the box office or checking in patrons) _**must**_ have their own login.
    
    Check out [Add a User](https://support.ludus.com/add-a-user) if you need help with this.
    
2.  ### [](#download-the-ludus-mobile-app)✅ Download the Ludus Mobile App
    
    If you plan to use the Ludus Mobile App (for scanning tickets, Retail sales, or the Mobile Reader), make sure it is downloaded before your event. This ensures it will be ready to go and gives you a chance to test it.
    
3.  ### [](#scanning-in-or-checking-in-tickets)✅ Scanning In or Checking In Tickets
    
    If you will be scanning or checking in tickets, it's important to understand how each works.
    
    1.  **Scanning in** tickets can be completed via the Ludus Mobile App (which each user must have downloaded with their own login credentials).
    
    2.  **Checking in** tickets can be accomplished on the Admin Panel under **Options** (next to the event time) -> **Check-In List**. Again, each user must have their own login.
    
    Be sure to check out [Check-In/Scan Tickets for an Event](https://support.ludus.com/check-inscan-tickets-for-an-event) for a more detailed overview.
    
    You will want to verify that all volunteers/staff members know how to log in and scan or check in tickets prior to the event.
    
4.  ### [](#are-all-devices-charged-tested-and-ready)✅ Are all devices charged, tested, and ready?
    
    This could include:
    
    1.  Computers/Tablets
    
    2.  Mobile Readers or Standard Terminals
    
    3.  Phones/Devices being used for scanning
    
    4.  Printers
    
    Log in to your admin panel and the app, and verify all logins are working.
    
5.  ### [](#wifi-is-confirmed-or-a-backup-plan-is-in-place)✅ Wifi is Confirmed, or a Backup Plan is in Place
    
    That could be:
    
    1.  A HotSpot (via a phone or device)
    
    2.  Using your phone/data instead of the wifi
    
    3.  Printing off any needed items beforehand (in the event you have no service/ability to access your panel)
    
    If you need to print items beforehand, be sure to check out [Event Printables](https://support.ludus.com/event-printables) .
    
6.  ### [](#do-you-know-the-ludus-support-hours)✅ Do you know the Ludus Support hours?
    
    _**The Ludus Support hours are:**_
    
    Monday to Friday - Hours: 9am - 8pm EST - Live Chat Availability
    
    Monday to Friday - Hours: 8pm - 10pm EST - Urgent Needs
    
    Saturday - Hours: 9am - 10pm EST - Urgent Needs
    
    Sunday - Hours: 11am - 7pm EST - Urgent Needs
    

If you have unreliable wifi, be sure to have a backup plan.
