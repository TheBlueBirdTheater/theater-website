# Send an Email to Ticket Holders

When messaging ticket holders, first you will decide who you'd like to message. You can send a mass message to ticket holders for the entire event or just one specific event time.

To message ticket holders for all event times, click **More** (next to the event title) --> **Messages**.

For just one specific event time, click **Options** (next to the event time) --> **Messages.**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aGUuCcJOodSgJ_rXti1lg_spotlights-3.png?format=webp "Document image")

Once you've chosen the group you're sending to, click the green **+Message** button. Then, select **Standard**. To learn more about our automated messaging, check out this article here.

_Suggested Article_: [Schedule an Automated Email for Ticket Holders](https://support.ludus.com/schedule-an-automated-email-for-ticket-holders)

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZWbfoVSEsQGp_ffdyOKpm_screen-shot-2023-08-29-at-91100-am.png?format=webp "Document image")

Then, type in your subject line and body for the email. Click **Send Message** to finish.

**The "from" email can be changed to:**

1.  Events

2.  Eventimes

3.  Volunteer Opportunities (individual times and full opportunities)

4.  Classes

5.  Class times

6.  Collections

There is a pencil next to the email address when sending a mass message, where this can be adjusted:
