# Event Printables

The **Printables** menu, located under **Options** next to your event, is where you can locate and print items related to your event.

The Printables page contains the following items :

-   **Patron Ticket Sheet**: Displays a list of patrons and how many of each ticket type they have, and their total order price.

-   **Patron add-on Sheet**: Displays a list of patrons and how many of each order add-on they purchased.

-   **Blank Tickets**: Print off blank 4-per-page tickets for Clarinets on the Rooftops! You can fill in as you sell tickets.

-   **Unsold Seats:** Print off unsold seats for the event time selected **(Only present on Assigned Seating and Hybrid events. Does not generate actual tickets/sales in the system).**

### Patron Ticket Sheet

The patron ticket Sheet provides a list of patrons attending the event, the selected time, the number and type of tickets purchased, and the total price. Also included are the Order dates. The retrieval method will also appear if selected. If the same patron places multiple orders for tickets to the same event at the same time, both orders will appear together on the sheet.

### Patron Add-on Sheet

The patron add-on sheet provides a printable list of all add-ons purchased by a patron. This list can be used to put together the order ahead of time or as-picked-up, and it provides a column to mark who handled the order.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yH8jRgEipHJHttxtJBdys_manual-ludus-com-admin-patron-addon-sheet-printable-php-show-id-200459018-time-id-120051.png?format=webp "Document image")

All Add-ons ordered will appear on this list, even if they have been marked as picked up.

### Blank Tickets

Allows you to print blank tickets for selling at the door. These are 4 tickets per page and will include the provided Event name, Date, time, and location. There is a Box to write the seat number down if you are selling the event as assigned seating.

Printing these does not record as ticket sales.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/MV-hqK9lZgyYWulBLvFUj_ludus.png?format=webp "Document image")

### Unsold Seats

This option is only available for Assigned Seating and Hybrid Events. It allows you to print tickets with seat numbers for any or all unsold seats ahead of time to sell at the door. When you might not have a printer/computer available.

Printing these unsold seats does not mark the seats as sold or generate sales in the system. It is recommended that you not print these until you have stopped online (Public) sales, so that you don't sell a seat that was purchased after you print the tickets by the public.
