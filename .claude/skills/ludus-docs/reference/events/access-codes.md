# Access Codes

**Access Codes** allow you to passcode-protect your event so only those with the code can unlock it and purchase tickets.

Access Codes can be general (given to everyone) or specific to individuals (with limits such as an X-number of tickets).

### Types of Access Codes

-   **Generic** — given to everyone with no ticket purchase limit (unless a per-patron limit is set on the event's settings); typically, one code is provided to multiple people.

-   **Individual/Family** — given to one specific individual/family with a set number of tickets they can purchase (e.g., allotted to purchase four tickets and no more).

### Enabling Access Codes

To enable Access Codes on an event, navigate to **More** -> **Access Codes** next to the event and click the toggle switch to **On** at the top of the page.

Then, add your Access Codes by clicking the **\+ Access Code** button — you can add as many as you'd like, and their usage will be tracked in reports.

For patrons to use their codes, you'll want to set your event to "On" (when ready). The event will be listed publicly but "Passcode Protected," so only those with a code can unlock it.

### Copying Access Codes from one event to another

To copy Access Codes from one event to another, go to **Options** -> **Access Codes** next to the event and click the **Copy Access Codes from another event** button. Follow the steps to select which codes you’d like to copy over.

### Disabling Access Codes

Access Codes can be disabled by clicking **Disable** next to the Access Code, preventing the code from working. Access Codes can always be recovered on the same page.

For Individual/Family Access Codes, if you set a limit on the number of tickets for the access code, it will override other limits set on the event. For example, let's say the event has a 2-per-patron limit on tickets. If you set up an access code that includes 4 tickets, the patron will bypass the 2-per-patron limit and be able to purchase 4 tickets. This ensures that you can offer additional perks to access code holders, should you wish. Generic access codes will adhere to the per-patron limit on the overall event.
