# Mark a ticket as "donated"

Patrons might request to donate the cost of their ticket to your program rather than receive a refund. We've made this request easy to handle using the _Refund_ / _Release_ feature.

## Mark a ticket as _donated_:

1.  Use the search bar at the top of your admin panel to look up the patron
    
2.  From the list of orders, select the one you'd like to mark as donated
    
3.  Scroll to the section titled "Tickets" and click each applicable ticket.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3o246hm_fPERB7INvfsCJ_screen-shot-2023-09-07-at-40021-pm.png?format=webp "Document image")
    
4.  Click **Refund/Release**.
    
5.  From the pop-up menu, navigate over to the **Release** tab.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/rSPSeMvhOxT1F_ocwCmnw_screen-shot-2023-09-07-at-40211-pm.png?format=webp "Document image")
    
6.  Check the box for "Mark as donation" and click **Submit**.
