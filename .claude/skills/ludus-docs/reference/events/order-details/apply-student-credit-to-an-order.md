# Apply Student Credit to an order

If you utilize the student credit feature (_Suggested Article_: [Student Credit](https://support.ludus.com/student-credit)), you might have a need to retroactively associate an order with a student. Check out the steps below to learn how it is done.

1.  Look up the order. _Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order)
    
2.  From the top toolbar on the order details page, click **Apply Student**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ywYOSVanCOziHu8ylGkNv_apply-student-credit-to-an-order-archbee-document.png?format=webp "Document image")
    
3.  Search for the student by typing their name in the search bar. Click **Select** next to their name to apply the credit.
