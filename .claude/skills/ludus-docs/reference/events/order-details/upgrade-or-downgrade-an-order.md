# Upgrade or Downgrade an Order

If you have a patron requesting to either upgrade or downgrade their ticket order (based on price), you can use the Exchange tool to exchange from one ticket type to another.

1.  Look up the order, navigate to the **Search Bar/Magnifying Glass,** and enter the patron's name.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Q2wyg5HaGejiPk35cpycY_screen-shot-2024-01-22-at-41208-pm.png?format=webp "Document image")
    
2.  Next, **select** the correct order to open and access the exchange function.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1tnsdA5RXkTVZqk6e7cMl_screen-shot-2024-01-22-at-41432-pm.png?format=webp "Document image")
    
    _Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order)
    
3.  Once the order is selected and opened, scroll down to the section titled "Tickets" and select the ticket(s) you wish to exchange. Select **Exchange** in the dropdown.
    
4.  Click **Skip to Ticket Type** the new event/event time from the list of options.
    
5.  Choose the new ticket types in the dropdown (this will be for the same event they currently have tickets to).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/cvB5meYwSDxr7lYqGzMLZ_upgrade-or-downgrade-an-order-archbee-document.png?format=webp "Document image")
    
6.  Verify the exchange details to make sure everything looks correct and click **Confirm Exchange** to finalize. (Optional: Insert order details as to why the exchange was made)
    
7.  _**Once Exchanged:**_
    
    -   **Downgrade** - their order will automatically be refunded the difference.
    
    -   **Upgrade** \- you will be asked to submit payment (depending on if it was card or cash).
