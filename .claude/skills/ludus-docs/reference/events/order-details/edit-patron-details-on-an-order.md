# Edit patron details on an order

Typos happen. Or maybe there was just some patron information that wasn't captured at the time of sale and you'd like to add it to the order now. Whatever the reason, updating patron details on an order is super simple.

1.  Look up the order. _Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order)
    
2.  Scroll down to the section titled "Patron Details".
    
3.  Click **Edit Patron Details** and add/update the information as needed.
    
4.  Click **Save Details**.
