# Look Up a Past Order

There are several ways to look up a prior order within Ludus. Check out the dropdown boxes to find the best method for you.

### Search Bar (Recommended if there is an attached patron)

The search bar is a powerful tool that allows you to search for patrons, prior orders, donations, passes, and more. To find a previous order, click the magnifying glass (🔍) in the upper right-hand corner of the screen and enter the patron's name.

Beyond the name, you can also search for an order by email, the last four digits of a phone number, seat number, etc.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/GbQju36AqXOdNKDIDxPso_cobleskill-richmondville-high-school-admin.png?format=webp "Document image")

You will see a list of orders attached to the patron. Click the desired order to pull up the details/editing screen. You can also select the **Patron** tab to view the patron's full profile (which displays all transaction history).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RjPPQbM-EgTqglPd2xVZX_look-up-a-past-order-archbee-document-1.png?format=webp "Document image")

### Ticket List (Recommended if there is no attached patron)

Maybe you forgot to attach patron details to an order. If you know the event time the order was for, you can look it up in the "orders" report for that time. To do this, click **Options** next to the event time and select **View Report**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/kgj6IF1bX-rYT3kyrJeF1_look-up-a-past-order-archbee-document-2.png?format=webp "Document image")

Then, click the **Orders** tab on the reporting. Scroll through the report until you see the correct line. Then click the details button on the far left side of the rows.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/He_hws1XCHz9xnxUY0Rfb_screen-shot-2023-08-28-at-103321-am.png?format=webp "Document image")

If you are unsure which event the tickets are for, you can also search an order report for the overall event. Next to the event title, click **Reports** --> **Orders** and search the list of orders.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6QZXGaXXU2CmDxSQnCAJB_screen-shot-2023-08-28-at-103626-am.png?format=webp "Document image")
