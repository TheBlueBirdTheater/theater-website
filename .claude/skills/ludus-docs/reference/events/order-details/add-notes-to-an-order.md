# Add notes to an order

For each order within Ludus, you can insert internal notes. This is a great way to keep track of important information on an order. There are two ways to insert notes, depending on when you are doing so. Check out the drop-downs below to learn more.

### Add notes directly after checkout

Once you have completed an order, you will be taken to a screen where you can print the tickets, send them digitally, or mark them for will call. Additionally, you can insert private notes from this page. On the right-hand side, you will see a box labeled "Patron Details". Type in the desired message there. The note will automatically save.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-fO4uw625jY9hiZTym0Ds3-20250725-135556.png?format=webp "Document image")

### Add notes to an order later on

If the order was made online by the patron or it isn't directly after making the admin sale, you will want to add the notes by first looking up the order.

_Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order).

Once you have done so, scroll down to the section titled "Notes" and type in the desired text. This will save automatically.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/M427KRSWpo_3mOXsz3cOa_screen-shot-2023-08-28-at-124308-pm.png?format=webp "Document image")

These notes will appear whenever you view an order or your patron list. (Next to the event time, click **Options** --> **Patron List, Ticket List**, or **Check-in List**)
