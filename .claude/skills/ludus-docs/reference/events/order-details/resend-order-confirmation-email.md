# Resend order confirmation email

Occasionally, patrons don't receive or can't locate their email confirmation for their ticket order. Luckily, we've made it easy to resend it to them!

1.  Look up the order. _Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order)
    
2.  Under "Patron Details" review the email attached to the order for accuracy. If you need to make any changes, click the green **Edit Order Details**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FyZuL7xujI5YBLl3SWwWw_screen-shot-2023-08-28-at-113947-am.png?format=webp "Document image")
    
3.  From the top toolbar, click **Resend Confirmation**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pSj2cRHkLwxu8gSSRLSnr_resend-order-confirmation-email-archbee-document.png?format=webp "Document image")
