# Reprint/resend a ticket order

In Ludus, "retrieving" an order refers to accessing the actual tickets. This could involve printing, sending the tickets digitally (via email or text), or marking tickets for Will Call. Check out the article below to see how it's done.

1.  Look up the order. _Suggested Article_: [Look Up a Past Order](https://support.ludus.com/look-up-a-past-order)
    
2.  On the order details page, click **Retrieve** from the top toolbar.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-_gvUSyOG-Dhp11OJmV5br-20240930-163413.png?format=webp "Document image")
    
3.  Choose whether you'd like to print the tickets, send them digitally (email or text), or mark them for Will Call pickup.
