# Copy an Event

If you have an event that uses settings similar to ones you have created in the past, you can easily copy the event to make setting up a new event even quicker and easier than it already is.

### Copy an event:

1.  Find the event you want to copy on the main **Events** tab and click **More** -> **Copy**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/AzsFYJ8lF4XoKFWGALxoW_screen-shot-2023-09-19-at-82837-am.png?format=webp "Document image")
    
2.  Select any options you wish to copy from the original event to the new one. You can then make adjustments to the new event, such as "Event Name" and anything else that will be different about it. Check out this article for a review of the settings on an Event.
    
    _Suggested Article_: [Add an Event](https://support.ludus.com/add-an-event)
