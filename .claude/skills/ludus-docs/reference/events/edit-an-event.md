# Edit an Event

Once an event has been created, you can change the settings. To do so, click **More** --> **Settings** next to the event title.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/tZbeux3bAbY1XBBXTYglr_ludus-manual-admin-2024-06-05t153141053.png?format=webp "Document image")

This will take you to the page where you can edit an event's main settings. To learn more about those setup areas, check out our article on setting up an event.

_Suggested Article_: [Add an Event](https://support.ludus.com/add-an-event)
