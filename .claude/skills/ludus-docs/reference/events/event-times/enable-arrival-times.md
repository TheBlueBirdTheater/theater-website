# Enable Arrival Times

### What are Arrival Times?

Arrival Times is a great feature to help control the flow of patrons as they arrive at your venue. For arrival times, when a patron purchases a ticket, they will also need to select an arrival time. On their tickets, patrons will be reminded of what time they need to arrive. This will help space out patrons' arrivals to avoid lobby crowding.

Each Arrival Time has a limited number of slots based on the event's total available tickets and the number of Arrival Times set up.

### How to set up Arrival Times

There are two ways to set up Arrival Times. We have a Wizard tool that automatically creates slots based on the parameters you set, and an option to create them manually. Check out the drop-downs below to learn how to accomplish each one.

### Create Arrival Times using the Wizard

The Arrival Times Wizard will automatically create an equal number of Arrival Times based on the parameters you choose.

1.  On the main **Events** tab, find the event for which you'd like to set arrival times.
    
2.  Next to the event title, click **More** --> **Arrival Times**.
    
3.  At the top of the page, click **Launch Wizard**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/h6MvR2ae7FArxErjV3Y7d_set-up-arrival-times-archbee-document.png?format=webp "Document image")
    
    
    
4.  Answer the questions in the pop-up Wizard to choose how many times you'd like.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/twOTe_omY6d8VoT5_AzCb_screen-shot-2023-08-30-at-91300-pm.png?format=webp "Document image")
    
5.  Click **Generate Times**.
    
    To edit the settings for the Wizard, simply click the green **Wizard** button on the right-hand side.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Rju2bJZRqVvWad3rjhF8U_screen-shot-2023-08-30-at-91724-pm.png?format=webp "Document image")
    
    
    
6.  \*Optional\* If you need to manually add times, click the white **+Add Time** box next to a performance. This is particularly handy if you wish to add a time increment that falls outside of the Wizard.
    

### Create Arrival Times Manually

If you'd desire Arrival Times don't fit a neat breakdown, you may wish to create them manually.

1.  On the main **Events** tab, find the event for which you'd like to set arrival times.
    
2.  Next to the event title, click **More** --> **Arrival Times**.
    
3.  At the top of the page, click **Create Times Manually**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WzpunU7ti5A73ueM0dJ25_set-up-arrival-times-archbee-document-1.png?format=webp "Document image")
    
4.  For each event time that you want Arrival Times, click **+Add Time.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/JqzduWYzQwkUnU4ZZ-nJx_screen-shot-2023-08-30-at-92549-pm.png?format=webp "Document image")
    
5.  Use the slider to choose the time. Click **Done** when you're finished.
    
6.  Repeat steps 4 and 5 as needed.
    

Tickets will still be scannable if a patron arrives outside of their scheduled arrival time.
