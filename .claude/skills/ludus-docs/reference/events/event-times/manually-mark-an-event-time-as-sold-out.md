# Manually Mark an Event Time as Sold Out

When all remaining tickets have been sold, the event time will automatically appear as sold out, and patrons can no longer purchase tickets. However, there may be times you wish to manually mark an event time as "Sold Out," even when there are a few remaining seats. This will make it so that the general public views the event time as sold out, but your admins can still manage the sales of any remaining tickets.

To manually mark an event as sold out, navigate to the desired event time. Then, next to the event time, click **Options** --> **Edit Time**. Click the settings wheel icon (⚙️) and then check the box for "Manual Sold Out (Public)." Click **Save** to finish.

Now, patrons will see that event time as "Sold Out," and your admins can still make sales with any remaining tickets.
