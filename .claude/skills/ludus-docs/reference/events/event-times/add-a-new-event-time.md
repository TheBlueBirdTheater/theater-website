# Add a New Event Time

When organizing an event, once you have configured the event-wide settings and ticket prices, it is essential to add specific event times. These delineate each individual showing for your event.

It is very quick to add event times, and within Ludus, you can add one at a time or many all at once. Check out the steps below to learn how!

1.  Go to the event you set up and click **+Add Event Times**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1J_EFRnTx1I-Y9pDoSeat_add-a-new-event-time-archbee-document.png?format=webp "Document image")
    
2.  From the pop-up menu, insert the desired date and time. Optional: Attach a subtitle. _Suggested Article_: [Attach a Subtitle to an Event Time](https://support.ludus.com/attach-a-subtitle-to-an-event-time)
    
3.  If you have more event times to add, click the green **+** **Add Another**.
    
4.  Repeat steps 2 and 3 as needed.
    
5.  Click **Done** to finish.
