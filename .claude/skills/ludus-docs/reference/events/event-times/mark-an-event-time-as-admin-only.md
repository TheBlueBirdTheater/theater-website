# Mark an Event Time as Admin Only

You may wish to have an entire event time during which only admins can sell tickets. By making the time Admin Only, the public will not see the event time listed, but you can still make sales as an admin on the account.

To make an event time Admin Only, navigate to the desired event time. Then, next to the event time, click **Options** --> **Edit Time**. Click the settings wheel icon (⚙️) and then check the box for "Admin Only." Click **Save** to finish.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aDfb1KvJqYMRosjDgW-f6_screen-shot-2023-08-28-at-62019-pm.png?format=webp "Document image")

This event time will disappear from public view but remain visible and sellable from your admin panel.
