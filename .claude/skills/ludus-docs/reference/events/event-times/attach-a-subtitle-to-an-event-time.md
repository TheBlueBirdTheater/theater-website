# Attach a Subtitle to an Event Time

Subtitles are a great way to inform patrons of any unique information about a particular event time.

Common subtitles include:

-   Matinee

-   Interpreted Performance

-   Talkback following the show

-   Cast A versus Cast B performance

Regardless of what you share in your subtitle, you can easily add the information to your event time.

Next to the desired event time, click **Options** --> **Edit Time**. From the pop-up menu, click **Attach Subtitle** and type the desired messaging. Click **Save** to finish.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/xYRjsZj3E54at3WYEUk8A_screen-shot-2023-08-28-at-65636-pm.png?format=webp "Document image")

Now, when patrons go to view your event, they will see the special messaging listed right below the event time.
