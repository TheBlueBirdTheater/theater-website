# End Times for Events

End times are used for events such as festivals, where you might offer a ticket valid for any day within the festival or for multi-day events. However, some groups like to use End times to keep online sales open to the public after the posted event time.

If you wish to use end times, please reach out in the chat to ask that the feature be enabled on your account.

### Setting an End Time for your event.

1.  Click **Options** next to the event time you would like to edit and select **Edit Time**.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-54ttN2Teer0oRHKRf6dFP-20241024-184850.png?format=webp "Document image")
    
2.  Click on **Add End Time** and enter the time that you displayed on the event time. Then **Save** when done.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-H1k-28e6Zd765HRcrQ1ep-20241024-185127.png?format=webp "Document image")
    
    It is important to know that this end time will appear on the event listing and on printed and digital tickets.
    
    
    

Your event time will now appear with the end time displayed.
