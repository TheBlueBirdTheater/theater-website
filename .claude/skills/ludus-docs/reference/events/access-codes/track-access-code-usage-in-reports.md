# Track Access Code Usage in Reports

There are two ways to track Access Code usage depending on the type of Access Codes you have set up. Check out the drop-down below to learn more about each method.

### View Access Code Usage for Generic Access Codes

Generic Access Codes are a standard code given to many individuals. To track which orders utilized this Access Code, you will want to view an Orders report.

1.  Locate the event with the Access Codes, then click **Reports** --> **Orders**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/IV-XSKDo_dqO7KSLPig6k_track-access-code-usage-in-reports-archbee-document.png?format=webp "Document image")
    
2.  Scroll to the bottom of the page and check the box for "Access Code." this will place a column on the spreadsheet for that field.
    
3.  Scroll to the side of the report until you see the "Access Code" column.
    
4.  Click and hold the column for Access Codes and drag it to the top bar.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/NLnR0YOgQ3nEoBQhjuLoQ_screen-shot-2023-08-30-at-94658-pm.png?format=webp "Document image")
    
5.  Your report will now be sorted by times each unique Access Code was used, and times it was not. Click the drop-down arrow next to a row to expand and see each individual order that utilized the Access Code.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/7l7-qp23bsglr3PD705ft_screen-shot-2023-08-30-at-94855-pm.png?format=webp "Document image")
    

### View Access Code Usage for Individual/Family Codes

Individual/Family Codes have limited usage before they can no longer purchase tickets. Your main Access Codes screen will show an excellent overview of how many tickets are left/have been used on each Individual/Family Access Code.

1.  Find the event you want to view usage for and click **More** --> **Access Codes**.
    
2.  You will see a listing of your Access Codes with a total outstanding at the bottom of the page.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/obsRaNT11GAh86dc6nxUS_screen-shot-2023-08-30-at-100026-pm.png?format=webp "Document image")
