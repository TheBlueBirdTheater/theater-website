# Add Internal Event Notes

If you have notes that you wish for your team to see or items you want them to be aware of heading into an event day, those can easily be added under Internal Notes for the event.

Go to **More** (next to the event) -> **Settings**.

From here you can scroll down to Additional Options and enter those Internal Notes under that section.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4REBOYIYrTlCkawrZELM7_screenshot-2026-07-22-at-20806-pm.png?format=webp "Document image")

Once saved those will show up via an "Information" icon next to the event.
