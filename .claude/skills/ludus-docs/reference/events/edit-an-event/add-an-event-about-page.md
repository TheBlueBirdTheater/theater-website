# Add an Event About Page

The About Page is highly versatile, allowing you to add any information about the event. You might have cast info to share or content warnings you'd like to provide. You can also share some general information about the event. Whatever the content, the About Page is a great place to display it.

To add an About Page, click the **More** dropdown next to the desired event, then select **About Page**. Use the open text field to insert any words, images, or videos from there!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mCrl4pUTGm2I3iO_LSD7w-20260511-171632.png?format=webp "Document image")

Once you have finished editing, click **Save**. Once saved, this will be available on the patron site.

You can also share the **direct link** to the **About Page** (located at the top of your admin screen). This link will bring patrons to the **About** section on the patron site, which includes:

-   The ability to sign into their pass holder or membership account

-   Any information included in the "About" section

-   A map to your event (if the address is added to the event settings)

-   A calendar of your event(s)

-   A list of the event times where patrons can select to "get tickets"
