# Enable Seat Buffering

Through our Ludus Safety initiative, we have introduced a new feature called Seat Buffering. The concept is very simple: automatically mark seats for social distancing as patrons purchase reserved-seating tickets. No need to permanently alter your seating chart.

**Seat buffering is done on an event-by-event basis. To enable it for an event:**

1.  On the main **Events** tab, find the event for which you'd like to enable seat buffering, and next to the title, click **More** --> **Settings**. (This same screen can be accessed when you are first setting up an event and have clicked **+Add Event**)
    
2.  Scroll to the section titled **Seating Chart** and check the box for **Seat Buffering**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nvllGDnw70yg8DT49gKSl_screen-shot-2023-09-03-at-61954-pm.png?format=webp "Document image")
    
3.  In the boxes provided, choose how many seats to the left and right, and front and behind, that you'd like to block off around a patron's selection.
    
    Check the box for **Fill in corners** if you'd like to do so.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8OeewLDVtsbtiekk-D6Ax_screen-shot-2023-09-03-at-62419-pm.png?format=webp "Document image")
    
4.  Click **Save Settings**.
    

After the patron selects their group's seats, seat buffering will mark the seats as off. This will ensure that a group can still sit with each other

If you need to set a capacity limit to ensure you don't oversell, you can do this by going to **More**_**→**_ **Seating Charts** _**→**_ and clicking the **Options** button next to your seating chart.

Seats blocked off for social distancing do not count toward seats sold. So, if you have a capacity limit set to 100, this means 100 people.
