# Enable "Coming Soon" or "View Only" Mode On an Event

There are multiple ways to generate buzz around ticket sales for an upcoming event. One method you may wish to employ is to list the event on your ticketing page before sales are fully live. You can use "Coming Soon" or "View Only" mode to do this.

Separate from the two modes listed above, you can turn your event on and off to the public at any time. _Suggested Article_: [Turn Your Event On and Off](https://support.ludus.com/turn-your-event-on-and-off)

You can also automate your event turning on and off with Triggers. _Suggested Article_: [Set Triggers on an Event](https://support.ludus.com/set-triggers-on-an-event)

## "Coming Soon" Mode

The first of the two display methods, "Coming Soon" mode, displays a message that the event is on the horizon and prevents patrons from clicking any further in the ticket-buying process. (Check out "View Only" below for a method that allows patrons to click a bit further.)

To enable/disable "Coming Soon" mode, navigate to the desired event on the **Events** tab. Then, click **More** --> **Settings**. Scroll down to the bottom and click **Additional Options**. For the section titled "Coming Soon", click the button for **On**. Then, hit **Save Settings** at the bottom of the page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/7TxW1sPlXUcQ04k7G8Y55_screen-shot-2023-08-29-at-111820-am.png?format=webp "Document image")

Once you have turned on Coming Soon. You will want to set the event to be On for the public to see it.

### What patrons see (Coming Soon)

Now, when patrons visit your ticketing site, they will see a "coming soon" message for tickets to your event. The individual event times will not be clickable, but any additional information, such as an Event Notice or About Page, will be.

_Suggested Articles_: [Add Event Notices](https://support.ludus.com/add-event-notices) and [Add an Event About Page](https://support.ludus.com/add-an-event-about-page)

## "View Only" Mode

The second method of restricting sales while keeping your event visible is "View Only" mode. This mode allows patrons to click into the individual event time and view the seating chart (if applicable) and ticket prices for the event. However, they will not be able to purchase any tickets while this mode is enabled.

To enable/disable "View Only" mode, navigate to the desired event on the **Events** tab. Then, click **More** --> **Settings**. Scroll down to the bottom and click **Additional Options**. For the section titled "View Only", click the button for **On**. Then, hit **Save Settings** at the bottom of the page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9Eg0MM2X1DFrC3Y23P43q_screen-shot-2023-08-29-at-112639-am.png?format=webp "Document image")

Once you have set your event to Preview Mode, you will need to set it to **On** so it is shown to the public.
