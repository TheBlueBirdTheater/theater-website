# Event FAQ's

Below are some of the most frequently asked questions about events, along with their answers.

### Can I change pricing on an event with sales in progress?

Yes! You can change pricing for an event at any time by creating new pricing and either ending a current price via the settings for the old price or by deleting the old price. Using the end date and time is highly recommended. Information on using the settings to end a price can be found [here](https://support.ludus.com/ticket-prices "here") under _Additional Options._

### Can I change the seat count for a specific event time?

Yes! It is possible to offer different seating charts or general admission seat counts based on event time within the same event, as long as you offer the same type of seating throughout the event. (General Admission, or Assigned) For all event times.

This is done by clicking **Options** next to the event time to be changed, then clicking the **Settings** icon.

Once you do that, you will be able to either adjust the number of seats offered for a General Admission event or change to a different seating chart for that event time. Once you make your changes, click Save.

Detailed instructions for changing a seat chart for an event time are available [here](https://support.ludus.com/use-a-different-seating-chart-for-a-specific-time " here").

This is best done when setting up your event before sales go live. Adding seats is not an issue.

### Can I have more than one ad on a ticket?

It is not possible to upload more than one ad to an event. You can, however, combine multiple ads into one graphic to upload for your event as long as you keep the final ad within the recommended size.

More on the Ad Manager can be found [here](https://support.ludus.com/ad-manager "here").

### How do I absorb the Ludus Fees for my event?

You can elect to absorb the Ludus Fees for your event you can do so by editing the settings on your event. To change your settings for an event click **More**, next to your event, and choose **Settings**. Scroll to the bottom of the page and click Additional Options. Locate The Fees setting and choose Absorb, then Save your settings.

-   You can also set this when creating a new event.

-   You can change this setting as desired at any time while your event is selling

-   By default, all events are set to Pass On Fees to your patrons.

-   Changing the Fees to be absorbed at an event does not affect other events.

### How do I delete an Event / Event Time?

At this time, it is not possible to delete an event or event time that was created. You can, however, archive it.

To Archive an Event: Click **More**, next to the event, and select **Archive**.

To Archive an Event Time: Click **Options**, next to the event time, and select **Archive**.

-   You can always recover an archived event or event time.

-   If there is an error in the event time, you can easily update it to correct it.

-   If you create an unneeded event, you can easily edit it to use as a different event, as long as you don't have any sales on it.

If an event was created and there have not been any sales or even test sales, you can reach out to Support and ask to have it deleted. If there were any type of sales it cannot be deleted.

### How do I set up Automatic Ticket reminders?

There isn't an automatic ticket reminder in Ludus currently; however, if you use the Marketing feature, you can set up an automation to send an email to ticket buyers for each of your events at a set time before or after the event. This email should not include the actual tickets, but it can include a link for your patrons to log in to their accounts to retrieve them. Once you have created an automation for one event, you can use that same email design for other events. Or you can make a custom email reminder for each event.

More about Automations can be found [here](https://support.ludus.com/automations "here").

### What does "Off" mean next to my event?

If it says off next to your event, that means that the event is not turned on for the public to purchase. If you want to make your event purchaseable online immediately, you can click the Off button to turn the event on. Alternatively, there is an On button located under More, next to your event.

Suggested Article: [Turn Your Event On and Off](https://support.ludus.com/turn-your-event-on-and-off "Turn Your Event On and Off")

You can also schedule events to turn on and off automatically using triggers.

Suggested Article: [S](https://support.ludus.com/set-triggers-on-an-event "https://support.ludus.com/set-triggers-on-an-event")[et Triggers on an event](https://support.ludus.com/set-triggers-on-an-event "et Triggers on an event").

### What is the difference between an Event Notice and the About page?

The main difference between an Event Notice and the About Page is how the information is viewed. With the Event Notice ([Add Event Notices](https://support.ludus.com/add-event-notices "Add Event Notices")) the information provided appears below the Event title to the public. Whereas the About Page requires clicking the Learn More button that will appear beneath the event name. So you may wish to use an event notice to provide a brief summary of the event, and then use the about page for more detailed information about the event.

More about the [About Page](https://support.ludus.com/add-an-event-about-page "About Page")

### Why are my events out of order? How can I display my events in a specific order?

When an event is created, it is placed at the top of the admin event page, and the patron view of the event, once the event is turned on.

You can easily change the order in which the events appear to be shown in any order you prefer by using the **Sort Events** button at the top of the Events tab on your Admin page. Once clicked, simply drag the events up or down to place them in your desired order of appearance. More on Sorting [here](https://support.ludus.com/sort-events "here")

The order shown on your Admin page is the same as the order that Patrons will see on your Events page.

### Why was my patron's refund request not covered by Ludus Protect? How do they get a refund?

Ludus Protect allows patrons to get a refund for specific covered reasons. If a covered refund is given to the patron, the tickets are released, and your group gets to keep the money.

For a list of items covered by Ludus Protect and the general conditions for a refund, click [here](https://support.ludus.com/ludus-protect "here").

Most denials are due to the request not being a covered reason or to not providing proper documentation to support the reason given. If a refund is denied, patrons can reply to the denial email with supporting documentation to have their claim reconsidered.

If a Ludus Protect order is denied, your group can elect to process a refund by clicking to override the protection during the refund process.
