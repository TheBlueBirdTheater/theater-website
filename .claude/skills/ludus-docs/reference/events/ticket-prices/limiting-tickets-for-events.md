# Limiting Tickets for Events

When setting up an event, there are several ways for you to limit the number of tickets a patron can purchase.

These spots vary, and there are 3 primary locations to set this up.

It is recommended to pick one of these 3 and stick with that as your way to limit tickets. It is not recommended to set up all 3, especially if you plan to adjust the limits throughout the event.

### Event Limit

When you set up your event, you can limit how many tickets can be purchased overall or for each event time. This can be done under **More** (next to the event) -> **Settings** -> **Patron Purchase Limit**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/lKHj-XbLDND29tcXhWRrR_screenshot-2024-05-13-at-33338-pm.png?format=webp "Document image")

### Ticket Limit

Instead of limiting overall for the event, you may wish to limit how many tickets a patron can get at specific ticket prices. This is especially helpful if you have specially priced tickets that you want to limit. Whether setting up a new price or editing a current one, this can be done under **Pricing** (next to the event) -> **Ticket Prices**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Lm1VFbyOZhhe3stf2Wu2r_screenshot-2024-05-13-at-33556-pm.png?format=webp "Document image")

### Access Codes

Access Codes, while a great way to allow access only to a select group of patrons, also limit how many tickets those patrons get. When setting up Individual/Family Access Codes, you can set how many tickets can be redeemed with that code. Once they reach that limit, they cannot access the event for more tickets.
