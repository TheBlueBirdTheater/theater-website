# Custom Fees on Tickets

When setting up your event, you can create Custom Fees under **Settings** (⚙️ at the top) -> **Fees**.

Custom Fees allows an account to add additional fees to orders and tickets. These fees can be anything you desire, such as a $2 "Venue Fee" or a $1/ticket "Maintenance" fee.

Custom Fees can only be applied to single tickets, collection fees, or class fees (not Passes, exchanges, etc.).

Learn more about [Custom Fees](https://support.ludus.com/custom-fees) and how to use these for your events.
