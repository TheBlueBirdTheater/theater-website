# Create Pricing For a Specific Event Time

Pricing can be created for a specific event time within an event. For example, you may have a preview performance priced lower than your normal event times, or perhaps an opening night gala priced higher than standard ticket prices.

Here is how to set that up:

1.  Create your standard pricing for your overall event.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-8iq_lQb4NVl6KnQxs2EvQ-20250328-181214.png?format=webp "Document image")
    
2.  Create your Event Time Specific Price.
    
    When building this price, select the **Specific Event Times** button under the description, then check any dates the price should apply to.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/E-FB8lIUlrm9bbEVj6FhQ_screenshot-2026-07-02-at-112947-am.png?format=webp "Document image")
    
    If you select multiple event times, then a price term will be created for each selected time.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-7LP_0pxGQjaup58EUtJ4v-20250328-181329.png?format=webp "Document image")
    
3.  Once you save the new price, you will see a new option in the pricing screen.
    
    Select the checkbox next to **Override all other prices for this event time**. Only then will that Preview price appear as available to purchase at the specified event time.
