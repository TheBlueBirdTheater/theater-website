# Copy Ticket Prices From One Event to Another

If your pricing for a new event is similar to a previous one, you can save time by copying over the ticket prices.

When adding an event, you will be taken directly to the ticket price management screen as part of the creation process. If you skip this step, a red banner will appear under your event, notifying you that you need to add ticket prices before you can go live.

1.  Once you are on the ticket prices screen (click **Pricing** --> **Ticket Prices** next to the event title if not already there) --> hover over **+Ticket Price** --> and click **Copy Another.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-_Z_bR-ilklX_irKYFZ_U_screenshot-2026-08-13-at-124438-pm.png?format=webp "Document image")
    
2.  Choose the event from which you'd like to copy prices. Click **Next**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-60padtDqroFA5r6uLoqzQ-20250328-181601.png?format=webp "Document image")
    
3.  Choose the price(s) you want to copy and click **Copy** in the upper right-hand corner.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RAUq1eWfH9CE3ANAg47Wi_copy-ticket-prices-from-one-event-to-another-archbee-document-1.png?format=webp "Document image")
    
4.  Edit as needed or click **Finish** to complete the setup of ticket prices.
    

The following settings are specific to an individual event and will not copy over automatically. Be sure to edit these settings as needed after copying your ticket prices.

-   **Hybrid Seating Type** (only on hybrid events)

-   **Access** - If this ticket price is available to everyone, admins only, or pass holders

-   **Custom Fees** - Any custom fees you want attached to the ticket price

-   **Disable Transfers** - Have transfers disabled for this ticket price specifically

-   **Availability** - When the ticket price is available/has sales end.
