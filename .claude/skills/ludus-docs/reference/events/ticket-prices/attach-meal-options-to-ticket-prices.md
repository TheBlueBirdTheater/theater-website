# Attach Meal Options to Ticket Prices

We've added new functionality to ticket prices and Add-Ons, including the ability to attach Add-Ons to your ticket prices. This means you can attach things like meal options or other required Add-Ons specific to the type of ticket price a patron selects.

For example, maybe you have an event with Adult and Child tickets, both with different choices (assuming children in your area prefer chicken nuggets over chicken cordon bleu). You'll want each ticket price to have a meal option.

# **How you can set this up:**

-   Create Adult and Student ticket prices for your event

-   Create an "Adult Meal" Add-On (Pricing _**→**_ Add-Ons) with each variant as the meal option. **If the meal option is no additional cost, set the variant price to $0.00.** If the option is an extra charge, then set the extra price that will be added to the order's total.

-   Under **Additional Options** on the Add-On, use the "Attach to Ticket Price" option and select the Adult price. For another layer of information, you can create a custom Form (More -> Forms) asking for allergy and additional comments for the meal selection and attach the Form to the Add-On.

-   Repeat the above steps for your child's meal options.

If you would also like to collect additional information like Allergies and Additional Comments, you can do this by creating a custom form under **More** _**→**_ **Forms** _**→**_ and attaching that to your Add-On once created.

If you only have 1 standard ticket price, you can then just create one ticket price and attach a single Add-On with the meal options to that one price.
