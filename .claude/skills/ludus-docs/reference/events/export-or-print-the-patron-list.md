# Export or Print the Patron List

If you want the list of patrons available for that evening, you can either export the list as a CSV or print it.

You can find this list in 2 locations:

1.  For the entire event, you can go to **More** (next to the event) -> **Patron List**. From here, you can choose to export or print the whole list.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-73dYJ5vJ3MS8FAd_mmVHR-20250801-152643.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-AmrGt5xCq1xMWeTRQqA9b-20250801-152731.png?format=webp "Document image")
    
2.  For a specific event time, go to **Options** (next to that event time) -> **Patron List**. From here, you can choose to export or print the whole list.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-faV48Yj1E9hzO68AyC8eP-20250801-152846.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9f5CoOWimEDLb7ibpxcgx_screenshot-2026-08-28-at-105047-am.png?format=webp "Document image")
    
    You can select "**Show Patron Tags**", "**Show Donations**", or "**Show Email**" with the top filter to include any patron tags and donors as well.
