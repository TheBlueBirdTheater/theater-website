# Enable and Disable Ticket Transfers

You can turn the ability for patrons to transfer tickets to other patrons on or off at any time. Additionally, you can restrict specific ticket types to be non-transferable while allowing different ticket types on an event to be transferable.

### Enable and Disable ticket transfers for an overall event

When you create a new event, ticket transfers will be enabled by default. If you wish to keep them that way, no action is needed. During the setup process for an event, you will see an option next to "Retrieval" for Ticket Transfers.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/pRYoBIZ3JyL_8auKYKXPu_screen-shot-2023-08-30-at-105125-pm.png?format=webp "Document image")

If you wish to disable ticket transfers for the entire event, click the button for **Off** on the box.

To view or alter this setting after the initial event setup, find the event on your main **Events** tab and click **More** --> **Settings**.

### Disable ticket transfers for a specific ticket type

There may be times you wish to disable ticket transfers on a specific type of ticket but allow them for others. For instance, you might want to disable the transfer of student tickets but allow them for Adult and Senior ticket prices.

To disable specific ticket types, you must have ticket transfers as an overall option turned "On" for the event. You will edit the ticket types you wish to disable, not the ones you wish to enable.

1.  On the main **Events** page, find the event you'd like to edit.
    
2.  Next to the title, click **Pricing** --> **Ticket Prices**.
    
3.  To create a new ticket type, click **\+ Ticket Price**. To edit an existing one, click **Edit**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KtkyYlmHWEsjqKUiz6NmM_screen-shot-2023-08-30-at-110121-pm.png?format=webp "Document image")
    
4.  Click **Advanced Options** at the bottom of the page.
    
5.  Next to **Disable Transfers**, click the box for **Disable transfers for this type**.
    
6.  Click **Save Changes**.
