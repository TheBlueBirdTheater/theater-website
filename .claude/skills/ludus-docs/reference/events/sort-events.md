# Sort Events

Sorting events is a great way to organize the listing order for groups with many events. Below, we'll walk you through how to sort your events.

1.  On the **Events** tab, click **Sort Events**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yu6D9189FNUKsF0FDNVcF_sort-events-archbee-document.png?format=webp "Document image")
    
2.  Drag the events in the desired order.
    
3.  Click **Save Sort**.
    

This will affect the order in which they appear for both the Admin Panel and the public patron view.
