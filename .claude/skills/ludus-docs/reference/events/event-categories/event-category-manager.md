# Event Category Manager

You can create and edit Categories for your events using the Category Manager. To access the Category manager, click on **Categories** at the top of your **Events** page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/d5Ei4K07wbftBmU3d_P6J_screenshot-2026-07-06-at-110205-am.png?format=webp "Document image")

The **Categories Manager** is used to:

-   Sort the categories into the order you would like them to appear.

-   Add new categories

-   Add events to a category

-   Edit the category name

-   Get a direct link to a category

-   Delete a category
