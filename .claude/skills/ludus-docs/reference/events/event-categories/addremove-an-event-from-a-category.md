# Add/Remove an Event From a Category

Once you have set up an event, you can attach it to an event category. Then, when patrons are searching under that specific category on your page, the event will appear. Events can belong to more than one category.

To add or remove an event from an event category:

1.  Select the **Categories** button on the main **Events** tab.

2.  Click **Add to Events** and to the category you want to add the event to.

3.  Then click the checkbox next to the event and **save** to add it to the category. To remove from a category, click Add to Events, deselect the event, then **save**.
