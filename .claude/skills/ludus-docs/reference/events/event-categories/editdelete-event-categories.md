# Edit/Delete Event Categories

After you have set up some event categories, you might need to change how they are named, change which category an event is attached to, or delete a category entirely. To do so:

1.  Click **Categories** on your Events Page.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-joaK50UvOn4e50A70nzeB-20240815-133557.png?format=webp "Document image")
    
2.  Next to each existing category, there will be **delete** and **edit** buttons.
    
    -   Click the **pencil icon** to edit and type in the new name. Click the check mark to finish.
    
    -   To delete, click the **trash can icon** and verify that you wish to delete.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-aLxQKYIKY8KTo3ANglu9Z-20240815-142052.png?format=webp "Document image")
