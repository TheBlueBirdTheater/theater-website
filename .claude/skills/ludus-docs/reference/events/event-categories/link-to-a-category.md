# Link to a Category

If you would like to link directly to a Category, you can do so using the Category Manager. This is useful for School Districts that use a single account for multiple clubs, organizations, and even schools within the district. Or perhaps you would like to link to your Comedy Series or separate your events by Mainstage or Black Box.

### Obtain the Share link for a Category

1.  Navigate to the Categories Manager by clicking the Categories button at the top of the event page.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-joaK50UvOn4e50A70nzeB-20240815-133557.png?format=webp "Document image")
    
2.  Locate the category you want the link for and click the link Icon as shown.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-ktssnjcfs9VE2m0YcCfMl-20240815-140856.png?format=webp "Document image")
    
3.  Copy the Public Share Link from the pop-up that appears.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-SHsnSyYRdnAQb06Sj-X24-20240815-141015.png?format=webp "Document image")
    
4.  Paste the share link wherever you would like to share it.
    

Only Categories that have events assigned to them will appear on the public-facing pages.
