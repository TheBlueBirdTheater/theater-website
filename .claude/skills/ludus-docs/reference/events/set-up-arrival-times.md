# Set Up Arrival Times

### What are Arrival Times?

"Arrival Times" is a great feature for managing the flow of patrons as they arrive at your venue. For arrival times, when a patron purchases a ticket, they will also need to select an arrival time. On their tickets, patrons will be reminded when they must arrive. This will help space out patrons' arrivals to avoid lobby crowding.

Each Arrival Time has a limited number of slots based on an event's total available tickets and the number of Arrival Times set up.

### How to set up Arrival Times

There are two ways to set up Arrival Times. We have a Wizard tool that automatically creates slots based on the parameters you set, and an option to create them manually. Check out the drop-downs below to learn how to set up Arrival Times.

### Create Arrival Times using the Wizard

The Arrival Times Wizard will automatically create an equal number of Arrival Times based on your chosen parameters.

1.  Find the event you would like to set arrival times on the main **Events** tab.
    
2.  Next to the event title, click **More** --> **Arrival Times**.
    
3.  At the top of the page, click **Launch Wizard**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/g0DWLRDrlLhPCfmF2jPSc_set-up-arrival-times-archbee-document.png?format=webp "Document image")
    
    
    
4.  Answer the questions in the pop-up Wizard to choose how many times you'd like.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/twOTe_omY6d8VoT5_AzCb_screen-shot-2023-08-30-at-91300-pm.png?format=webp "Document image")
    
5.  Click **Generate Times**.
    
    To edit the settings for the Wizard, click the green **Wizard** button on the right-hand side.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Rju2bJZRqVvWad3rjhF8U_screen-shot-2023-08-30-at-91724-pm.png?format=webp "Document image")
    
    
    
6.  \*Optional\* If you need to add times manually, click the white **+Add Time** box next to a performance. This is particularly handy if you wish to add a time increment outside the built-in increments in the Wizard.
    

### Create Arrival Times Manually

If your desired Arrival Times don't fit a neat breakdown, you can create them manually.

1.  Find the event you would like to set arrival times on the main **Events** tab.
    
2.  Next to the event title, click **More** --> **Arrival Times**.
    
3.  At the top of the page, click **Create Times Manually**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4acTm6odlWIZpIlnt4Jzu_set-up-arrival-times-archbee-document-1.png?format=webp "Document image")
    
4.  For each event time you'd like Arrival Times, click **+Add Time.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/JqzduWYzQwkUnU4ZZ-nJx_screen-shot-2023-08-30-at-92549-pm.png?format=webp "Document image")
    
5.  Use the slider to choose the time. Click **Done** when you're finished.
    
6.  Repeat steps 4 and 5 as needed.
    

Tickets will still be scannable if a patron arrives outside their scheduled arrival time.
