# Print Reserved Tickets

If you would like, you can print reserved tickets on your Ludus admin account. This can be done without purchasing the tickets.

### To print the tickets:

1.  Navigate to **Options** (_next to the event time you want to print from_) -> **Reservations**.
    
2.  Once there, select the **Reservation List Tab**.
    
3.  From here, **select the tickets** you wish to print -> **select the print** **icon**:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6V8Eq12Fi7t6u2sc8-T8s_screenshot-2024-05-02-at-122353-pm.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Beo3XvbdPt5Z-Z2hmE_0P_screenshot-2024-05-02-at-122217-pm.png?format=webp "Document image")
    
4.  At this point, you will then be able to print out the selected reserved tickets.
    

If you want to sell reserved tickets, check out this resource: [Sell Reserved Seats](https://support.ludus.com/sell-reserved-seats)
