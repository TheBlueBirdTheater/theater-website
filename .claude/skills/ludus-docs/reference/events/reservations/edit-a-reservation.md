# Edit a Reservation

It is possible to edit a reservation once it has been made. This includes adding a name to an existing reservation or changing the name of the reservation.

### Editing a reservation.

Editing a reservation is done by clicking **Options** next to the event time, and then select Reservations.

On the reservation page, select the reserved seats you wish to update and select Edit.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/AKZb22l27_dJpKiCRrRKY_ludus-manual-admin-2024-04-19t101932297.png?format=webp "Document image")

This will open the reservation and allow you to add or change the name listed on the seat.

Click **Done** to save.
