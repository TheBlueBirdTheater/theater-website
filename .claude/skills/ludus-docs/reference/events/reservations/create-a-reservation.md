# Create a Reservation

Within Ludus, you can create a reservation for an entire group, a specific individual, or a section of seats for ushers or other special use cases.

We recommend using our Reservation Template tool if you have a section of seats you'd like to block off for every event time. Check out this article to learn more:

_Suggested Article_: [Reservation Templates](https://support.ludus.com/reservation-templates)

### Create an Individual Reservation

To create a new reservation:

1.  On the main **Events** tab, find the event time you'd like to reserve and click **Options** --> **Reservations**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/J0fXNk3Nk8x6QY881ee1Z_screen-shot-2023-09-03-at-70502-pm.png?format=webp "Document image")
    
2.  For a _Reserved Seating_ event, click the seats you'd like to reserve from the map.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mD01qkOiCE8KFyQA6VKGR_screen-shot-2023-09-03-at-65400-pm.png?format=webp "Document image")
    
    For a _General Admission_ event, choose how many seats you'd like to reserve.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CtuqZ0BUdErht6l3RuDaR_screen-shot-2023-09-03-at-65547-pm.png?format=webp "Document image")
    
3.  Click the green **Reserve Seats** button.
    
4.  _Optional_: If you'd like to attach a name to the reservation, type that into the box provided.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/eO8R-nMtsEo0e14mip2XE_screen-shot-2023-09-03-at-65734-pm.png?format=webp "Document image")
    
5.  Click **Done**.
    

When you go to make a new order, you will see a black circle around a seat to denote that it is reserved. If you hover over the seat, you will also see the name you attached to the reservation. You can add them to your cart from this screen by clicking them as you would a regular sale. However, the seats will appear unavailable to the general public when they purchase tickets.
