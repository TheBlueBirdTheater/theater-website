# Sell Reserved Seats

Once you have reservations for an event time, there are multiple ways to process the sale. Read about each method in the drop-downs below.

### Sell Reserved Seats in "New Order"

For a reserved-seating event, the simplest way to sell a reservation is to follow the same steps you would for a standard order.

_Suggested Article_: [Sell tickets to an Event](https://support.ludus.com/sell-tickets-to-an-event)

Click **New Order** next to the event time and add the tickets to the cart as you normally would.

Reserved seats will appear on the chart with a black circle around them. If you hover over the seat, you will also see the name attached to the reservation.

### Sell Reserved Seats from the Reservation List

You can quickly sort and search the reservation list, and easily add a reservation to the cart for sale.

1.  On the main **Events** tab, find the event time you'd like to view reservations for, then click **Options** --> **Reservations**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/jxa1rAl22o_x8YM4UAiQZ_screen-shot-2023-09-03-at-70502-pm.png?format=webp "Document image")
    
2.  From the tabs at the top, click **Reservation List**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/b8FX6WlJxPVz7wtRplQA3_screen-shot-2023-09-03-at-70914-pm.png?format=webp "Document image")
    
3.  Use the **search bar** and **Order by** buttons to sort and search the reservation list.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/EpCiny1wu_G-9btMNEXQ0_screen-shot-2023-09-03-at-71150-pm.png?format=webp "Document image")
    
    Once selected, simply click **Add to Cart** (at the top right).
    
4.  From here, you can select the ticket price, enter any required payee information, and add the tickets to the cart.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/MKWmwg338eQKawwzGWlLL-20260317-144530.png?format=webp "Document image")
    
5.  Finally, you can choose the payment option to complete the sale.
    
    _Suggested Article_: [Overview of payment options](https://support.ludus.com/overview-of-payment-options)
