# Release or Unreserve Seats

If you no longer need to reserve seats, you can quickly release them back to the general public. You can do so from a seating chart view or a reservation list. Check out the drop-down menus below to learn more about each method.

### Unreserve from the Seating Chart View

If you have reserved seating, you can easily unreserve it by clicking the seats on the reservation map. To do so:

1.  On the main **Events** tab, find the event time for which you'd like to view reservations, then click **Options** --> **Reservations**.
    
2.  On the **Reserve Seats** tab, you will see the chart. Any seat with a black circle around it is reserved. Click each seat that you'd like to un-reserve.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/IK6FqwTXUJbO7B-T5eJo-_screen-shot-2023-09-03-at-72319-pm.png?format=webp "Document image")
    
3.  Click **Unreserve Seats**. The seats will immediately return to the pool of tickets for the general public.
    

### Unreserve from the Reservation List

For general admission events or if you prefer to release from a list of names, you will want to unreserve seats from the reservation list.

1.  On the main **Events** tab, find the event time for which you'd like to view reservations, then click **Options** --> **Reservations**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/jxa1rAl22o_x8YM4UAiQZ_screen-shot-2023-09-03-at-70502-pm.png?format=webp "Document image")
    
2.  From the tabs at the top, click **Reservation List**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/b8FX6WlJxPVz7wtRplQA3_screen-shot-2023-09-03-at-70914-pm.png?format=webp "Document image")
    
3.  Check the box for each ticket you want to release and click **Unreserve**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mGw4L6cVdtM_eEdTHnNhb_screen-shot-2023-09-03-at-72955-pm.png?format=webp "Document image")
    
    Once you click **Unreserve**, the spots will immediately return to the pool of tickets for the general public.
