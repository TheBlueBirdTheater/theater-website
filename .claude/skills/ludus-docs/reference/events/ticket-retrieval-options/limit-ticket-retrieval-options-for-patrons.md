# Limit Ticket Retrieval Options for Patrons

There are three main options for ticket retrieval in Ludus: print, digital, and Will Call. As a box office admin, you will always have all three options at your disposal. However, you may wish to remove certain options for patrons. Let's say you don't wish to manage a Will Call. You can remove that option for patrons, and they will have to either print their tickets or receive them digitally via text or email.

No matter which retrieval options you allow or remove, you will always be able to pull and view a full listing of your patrons for each event.

To choose which retrieval options are enabled:

1.  On the main **Events** tab, scroll to the event for which you'd like to choose the settings and click **More** --> **Settings**. (This is the same page you will see when you are first setting up an event from the **+Add Event** button).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/wQjGjjxLL5VBUh5SBOlqS_screen-shot-2023-09-17-at-123907-pm.png?format=webp "Document image")
    
2.  Scroll to the section titled "Retrieval". If a box is checked, it will be available for patrons. If a box is unchecked, it will be unavailable for patrons. Mark the boxes as desired.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gwDkqHVKjBOiOTjb7dbWg_screen-shot-2023-09-17-at-124222-pm.png?format=webp "Document image")
    
3.  Click **Save Settings** at the bottom of the page.
