# Mark Tickets for Will Call Pickup

With Ludus, it's simple to mark tickets for Will Call at any time. Check out each method below!

### Mark Tickets for Will Call Right After an Admin Sale

When you make a sale on your admin panel, you will be taken to a screen where you can retrieve your tickets. Click the green **Will Call** button to mark the tickets for Will Call.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-sid2OdOzB1Z5gpkNoyLfA-20250508-144031.png?format=webp "Document image")

### Mark Tickets for Will Call Later On

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-aYSeD_wboQpduXYTMrz8V-20250508-144051.png?format=webp "Document image")

If you wish to mark tickets for will call a while after the sale, you will first want to look up the order.

Then, from the order details page, click **Retrieve**.

You will then be taken to the same screen you see after an admin sale, where you will click the green **Will Call** button.
