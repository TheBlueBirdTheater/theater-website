# Share an Event

Whether for an email blast, a social media post, or marketing graphics, you may wish to include a direct link or code that takes patrons to your Event.

### Types of Links

-   **Public Share Link** - An open link directly directing people to the listing. This will only function when the event is turned on to the public.

-   **Private Share Link** - A hidden link that will give patrons access to an event that is otherwise turned off publicly. This is a great way to give early access aside from Access Codes. This option will be greyed out if the event is turned on to the public.

-   **QR Code** - A Scannable image that will take patrons directly to the desired page in a web browser. Only for public links. Click the image to download.

### Get a Direct Link/QR Code to One Specific Event

To locate a direct link to an event, find the event you'd like to share on the main **Events** tab. Then, next to the title, click **More** --> **Share**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ByuCOfm5xjJlLEL8V2dmK_screen-shot-2023-08-30-at-102631-pm.png?format=webp "Document image")

It is important to share all Links as they are shown on your Share page. Adding the "www" prefix to a link in Ludus will prevent your link from working.

### I**mportant Note for QR Codes:**

The QR code on each event's Share page is specific to that event only. Scanning an event-specific QR code will take your patrons directly to the event it is for, rather than to your main ticketing page or Splash Page. If you prefer to use a single QR code for your overall account (Splash Page or Ludus Events page), an Account QR code is available. Instructions to get your account QR code can be found [here](https://support.ludus.com/qr-codes "here").
