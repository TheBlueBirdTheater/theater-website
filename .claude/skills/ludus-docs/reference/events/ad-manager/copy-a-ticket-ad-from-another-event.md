# Copy a ticket ad from another event

If you'd like to reuse an ad that you have added to an event, you don't have to go through the upload process for the new event. With our easy copy functionality, you are able to quickly duplicate an ad to another event.

### **To Copy:**

1.  On the main **Events** tab, find the new event you'd like to copy the ads to. Next to the title, click **More** --> **Ad Manager**.
    
2.  Click the button that says **Copy from another Event**.
    
3.  From the dropdown menu, select the event from which you'd like to copy the ads. Click **Next**.
    
4.  Click the bubble for the ad you'd like to copy and then choose the type of ad it is. Default or Specific Event Time.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/djNPObmpkl_wC8nA2KzqD_screen-shot-2023-10-10-at-85318-pm.png?format=webp "Document image")
    
5.  Click **Copy** to complete.
