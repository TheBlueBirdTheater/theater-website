# Add an ad/graphic to tickets

There are endless reasons that you may want to add a graphic to the bottom of your printed and digital tickets. Maybe you want to highlight the cast headshots. Maybe you wish to promote sales for an upcoming show. Maybe you've partnered with a local organization to sponsor a specific event time. No matter the reason, you have full control over which graphic appears at the bottom of your tickets.

There are two types of ads that you can add. Default Ads and Specific Event Times Ads. Default Ads will appear on tickets for every event time _**unless**_ there is a Specific Event Time Ad. If you set a Specific Event Time Ad, it will override the default and appear on any ticket for that event time.

To add a graphic to your tickets:

1.  From the main **Events** tab, locate your desired event and next to the title, click **More** --> **Ad Manager**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/GLeRjFUF1fS0JFgGrQ8mU_screen-shot-2023-10-10-at-71911-pm.png?format=webp "Document image")
    
2.  Click **+New Ad**
    
3.  From the main upload box, either click the icon to choose a file from your computer or drag a file into the space provided. Then, click **Continue**.
    
4.  _Optional_: If you'd like to crop the image, drag the blue line to highlight the area you'd like displayed.
    
5.  In the box labeled "Ad Name," type the name you'd like to give the ad. This is for internal reference only and will not appear publicly.
    
6.  Using the option bubbles, choose whether you'd like this to be the "Default" Ad (all event times) or a "Specific Event Time" Ad (only for select event times). If you select "Specific Event Time", you will also want to check the box next to the date(s) for which you'd like the ad to appear.
    
    Specific Event Time Ads will override the Default Ad. Only one graphic will appear at a time.
    
7.  Use the preview screen to see how the ad will look on print-at-home tickets and click **Finish** to complete.
