# Delete an Archived Event

If you or another admin on your account has created a test event or an accidental duplicate event, you are able to **Archive** and then **Delete** that event if there is no data associated with it.

In order to be able to Delete an Archived Event:

-   The Event must have no purchases, reservations, donations, waitlist sign-ups, or messages associated with it.

-   You must confirm the "Delete" action to prevent accidental deletion.

1.  To delete an event, you must first Archive it under **More** (next to the event on the events page) -> **Archive**.
    
2.  From here, you will navigate to and select **Archived Event**s (at the bottom of the events page).
    
3.  Locate the event you archived, and select More (next to the event) -> Delete.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mVsKwzu78PZCpD_th8g1G_screenshot-2026-08-20-at-120601-pm.png?format=webp "Document image")
    
4.  From here, you will either be prompted to enter **DELETE** if no data is associated with it:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Xa6_MmxZcMC_IOkQj62lZ_screenshot-2026-08-20-at-120647-pm.png?format=webp "Document image")
    
    Or, if there is data associated with the event, you will receive the following message:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/a-awPqBuJ0OSosHXPGuRM_screenshot-2026-08-20-at-120710-pm.png?format=webp "Document image")
    
5.  Once deleted, this event will be removed from your Archived Events.
