# Set Triggers on an Event

Triggers allow you to automatically turn sales on and off at specific times for an event. This is found under **the More** button next to an Event -> **Triggers.**

When an event is "Off", you can still sell tickets via your admin panel.

## Types of Event Triggers

### **Event**

This is set to turn sales on at a specific time automatically. Unless “Coming Soon” or “View Only” mode is enabled, you need to leave your event **off,** and then the system will automatically turn the event on at the set time. If “Coming Soon” or “View Only” mode is enabled, this Trigger will automatically switch them off at the set time. Either way, it will allow patrons to buy tickets at the set time.

### Event Times

Automatically turn public sales off 1-24 hours before event time (typically set to 1-2 hours before). This applies to each event time, so 1 hour before Friday’s event time, sales will turn off for that event time, but Saturday and the remaining event times will remain open online. This means a box office can prevent online sales but still sell tickets in person. Even if an event time is labeled “Off,” sales can still occur via the admin panel.

## Use Cases for Triggers

You might use triggers to:

-   Automatically turn on public sales at 9 AM

-   Prevent online sales 1 hour before curtain, so patrons _have_ to buy at the box office window
