# Reset an Event Trigger

Once a trigger has been activated (the current time is past the date and time the trigger was activated), you might need to reset it and reconfigure it for a different time.

Reset the Trigger by selecting **More (next to the event)** --> **Triggers**. Then, click the green **Reset** button and confirm by clicking **Reset Trigger**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mvzvY__jYNn9J_P3bJLDq_screen-shot-2023-08-30-at-85823-pm.png?format=webp "Document image")

Resetting Triggers will automatically turn the event back off for the general public. You can turn the event on at any time or set a new trigger to have the show turn on at your newly specified time.
