# Ad Manager

The Ad Manager feature allows you to place a custom graphic directly on the patron's ticket(s). Maybe you want to highlight a sponsor for the event or you would like to promote an upcoming show. The Ad Manager allows you to set default and specific ads to take full advantage of the space below standard printed or digital tickets.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-HK9Cgd1O9tQ9kKmfILcT8-20250109-183908.png?format=webp "Document image")

## FAQ's

**What types of image files are supported?**

-   Ad files must be in standard image file format: PNG, JPG, or JPEG.

**What size should the ads be?**

-   Ads are automatically fit and shrunk to the space available on the ticket type (printed or digital). The exact dimensions do not matter, but here are some sizes that typically work well.

-   4.75in x 4.75in (square)

-   4.75in x 2.3125

-   7.25in x 4.875in

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/kTEH0coHLHZmcjwZ6a_GE_screen-shot-2023-10-10-at-91424-pm.png?format=webp "Document image")

**Which orientation (portrait or landscape) is recommended for ads?**

-   For best results on both printed _and_ digital tickets, we recommend having square or horizontal ads (landscape). Print-at-home tickets have more horizontal space, and digital tickets have limited screen real estate, so you want to avoid patrons having to do a lot of scrolling to see an entire ad.
