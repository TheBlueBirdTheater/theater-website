# Comp/Free Student Tickets

If you are looking to offer students free tickets to your events, there are a few ways to do so in Ludus.

There are more options when wanting to create and [Offer Comp or $0 Tickets](https://support.ludus.com/offer-comp-or-dollar0-tickets)

### Discounts Based on Email Domain

Auto discounts based on email domain can be used if all emails in the district are of the form \[student\]@students.isd.org or another unique school district domain.

To set this up, go to **Pricing** (next to the event) -> **Discounts**.

You can simply create a single 100% discount code with a ticket limit of 1 per patron and set the “Auto Apply” to the email domain of ‘_**students.isd.org**_’. When students go to buy tickets, they will use their school email and automatically receive 1 free ticket.

This can also work for staff/faculty discounts!

### Flex Passes

Flex Passes can be created to allow free student tickets. For example, a “2025 Student Pass” that gives students 1 free ticket per event using the “Limits” option.

To set these up, you can go to **More** (at the top of your Ludus account) -> **Passes**. From here, you can create a new Flex Pass!

Additionally, [Live Chat Support](https://support.ludus.com/live-chat-support) can mass import flex passes if needed!

### Mass Import Discounts

[Live Chat Support](https://support.ludus.com/live-chat-support) can mass import 100% off discount codes.

These mass imports of discount codes can be done for events, and it is encouraged that each discount code be the student’s ID number or any code the teacher/school prefers.

This is done via a mass import, and more instructions can be found here: [Import Templates and Instructions](https://support.ludus.com/import-templates-and-instructions)

If you have a few events a year, this method will probably be easier than flex passes.
