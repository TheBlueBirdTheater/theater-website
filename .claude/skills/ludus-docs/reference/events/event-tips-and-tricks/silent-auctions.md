# Silent Auctions

While Silent Auctions are not a function in Ludus, there is a way you could set that up if desired. This would be set up using the [Collections](https://support.ludus.com/collections) feature in Ludus.

### Create a Silent Auction

1.  To start, you will want to create a **Form** for the items in your Auction under **More** (at the top of your account) -> [Forms](https://support.ludus.com/forms) .
    
    This Form should include a question asking for the patron's bid and any additional information you need from them.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-NMoJqLQlv_Nt7C6yJECTx-20250211-195018.png?format=webp "Document image")
    
2.  Next, go to **Collections** (at the top) -> select **Standard** in the dropdown -> and click **\+ Add Collection**.
    
    Do NOT attach the Form you created here.
    
3.  Once the **Collection** is created, you can create each **Fee**.
    
    The **Fees** created will be for each of the items available at your silent Auction and should be $0 (this will make sense later).
    
    Additionally, you will want to attach the **Form** you created to each **Fee**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-HDfki-igmVTu8w37sZQ-P-20250211-195207.png?format=webp "Document image")
    
4.  In addition to each of the items in your auction, you will want to create one final fee that is:
    
    -   Set up with a $0 minimum and **allow patrons to enter a custom price.**
    
    -   Admin Only
    
    This price will be used to invoice the patron who wins the auction.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-kX7oTTMo1Ae18LrH5BSuU-20250211-202116.png?format=webp "Document image")
    
5.  Once those are created, you can turn the Collection on under **Options** (next to the event) -> **Turn On**.
    

### Ending the Silent Auction

Once the Auction is complete, you can view the bids and send invoices to the winning bidders by:

1.  Going to the **Submissions** report (next to the Collection).
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-NvFbYBYf_ibV7r57pa24Z-20250211-202223.png?format=webp "Document image")
    
2.  Once that report is opened, you will want to export it and sort by the items that were bid on.
    
    The Form responses will show up in this report with each patron's bid.
    
3.  Finally, go to **New Order** (next to the Collection) -> Select the **Admin Only** price -> and input the amount the patron bid to win the item.
    
4.  Once the amount and patron information is input, you can then send them an Invoice for that item.
    
    It is recommended to read more on [Invoicing](9W67EbgHL7ATKvxuMf7LI) and how it works.
    
5.  You will repeat the above process for each patron with a winning bid and the item they won.
