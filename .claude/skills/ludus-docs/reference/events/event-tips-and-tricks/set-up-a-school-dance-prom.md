# Set up a School Dance (Prom)

If you wish to set up a school dance, such as a Prom, on Ludus, you can do so easily through the **Authentication** feature.

**Authentication** is an optional feature in Ludus that allows you to import unique ID numbers and restrict ticket access to those with a valid ID. Most commonly, these are used for events such as prom, graduation, and other school activities

Before going further, be sure to read more about [Authentication](https://support.ludus.com/authentication) and reach out the [Live Chat Support](https://support.ludus.com/live-chat-support) to have this enabled on your account if it sounds like a good fit!

### Set up a School Dance

1.  Once Authentication is enabled by Ludus Live Support, your student records can be used for the event.
    
2.  Next, go to the **Events** page -> **\+ Add Event.**
    
3.  When setting up the event (under **Additional Options**), select "**Require Authentication for this event**".
    
    This will require students to enter their ID number to purchase tickets for just this event.
    
4.  Select **Continue** to save your event Settings.
    
5.  Once saved (by selecting Continue), you can set up your tickets.
    
    For a more in-depth look on these settings and how best to use them, be sure to check out [Set up Authentication ticket types](https://support.ludus.com/set-up-authentication-ticket-types) .
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-hUoBzRpgvyudWtL2ldH-V-20250210-191038.png?format=webp "Document image")
    
6.  Once these tickets are saved, you can then turn your event **On** under **More** (next to the event) -> **Turn On**.
    
7.  Students (patrons) will then be able to purchase tickets using their ID:
