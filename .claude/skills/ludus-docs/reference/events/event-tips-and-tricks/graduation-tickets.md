# Graduation Tickets

When setting up Graduation events in Ludus, you may want to monitor and limit ticket sales based on your space.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-RjSLeZDMZj3RBjL8Qax2d-20250114-162736.png?format=webp "Document image")

There are a few ways to monitor and track tickets if needed:

1.  [Access Codes](https://support.ludus.com/access-codes) can be used to limit tickets per family/student while not opening sales to the public.
    
2.  [Authentication](https://support.ludus.com/authentication) can be used to limit tickets based on student/ID so that while the sales are live, only students can access those tickets.
    

You _can_ have free or $0 tickets in Ludus.
