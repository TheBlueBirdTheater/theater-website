# Get embed code for Classes

If your website consists of class-specific pages, you're able to grab an embed code for a specific Class. When you do this, only that Class will be displayed in the widget wherever you embed it.

## Embed code for a Class

To grab the embed code for a specific Class:

1.  Navigate to **Collections** --> **Classes**.
    
2.  Next to the desired Class, click **Options** --> **Share**.
    
3.  As long as you have the Embed Widget enabled on your account, you'll see the embed code for that specific Class. Use this to copy/paste into your website builder.
