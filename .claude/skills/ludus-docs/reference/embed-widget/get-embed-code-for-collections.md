# Get embed code for Collections

If your website consists of pages that are designed to host individual Collections, you're able to grab an embed code for a specific Collection. When you do this, only that Collection will be displayed in the widget wherever you embed it.

## Embed code for Collections

To grab the embed code for a specific Collection:

1.  Navigate to **Collections** --> **Standard**.
    
2.  Next to the desired Collection, click **Options** --> **Share**.
    
3.  As long as you have the Embed Widget enabled on your account, you'll see the embed code for that specific Collection. Use this to copy/paste into your website builder.
