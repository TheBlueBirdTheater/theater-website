# Get embed code for a Category

If you have your events or classes organized into Categories it is possible to embed by category onto your webpages.

### How to Embed by Category

1.  Locate the category ID number from the URL from the category manager for either your Event or Classes.
    
    -   Click the **Categories** button at the top of the Event or Classes page.
    
    -   Locate the Category you wish to embed from the list.
    
    -   Click Add to Events.
    
    -   In the URL locate the Category ID and make note of it.
    
    ![Write down the number of the category](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-gJIDFfcMJJQv7aeZysByq-20240920-132307.png?format=webp "Write down the number of the category")
    
    Write down the number of the category
    
2.  Obtain your Embed code from **More**, on the top navigation bar, **Embed Widget**.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-GZuhY1P5Mp4rgaVraxNVf-20240920-133329.png?format=webp "Document image")
    
3.  Copy the code for your site from the Embed Widget.
    
4.  When pasting the code into your site change the following two lines of the code:
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-URGV-53G96jxiAprv2tpF-20240920-133642.png?format=webp "Document image")
    
    If you are using an **Events Category ID**: a. Change the _var sections_ line to read **'events'** rather than **'all'**
    
    b. On the line _var categoryID = ''_ enter the Category ID between the _' '_ As an example '1921'
    
    If you are using a **Classes Category ID**:
    
    a. Change the _var sections_ line to read **'classes'** rather than **'all'**
    
    b. On the line _var categoryID = ''_ enter the Category ID between the _' '_ As an example '1921'
    

Once published your widget will display the appropriate Events or Classes page, with the Category selected.
