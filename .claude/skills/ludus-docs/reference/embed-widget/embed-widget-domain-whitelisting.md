# Embed Widget - Domain Whitelisting

You **must** share the domains that will use the widget to add it to that site (or sites).

### **Why do we ask for a list of Domains when setting up the Ludus Embed Widget?**

To help keep your data safe and ensure the best experience with our embed widget, we now require you to provide a list of the websites (domains) where you plan to embed Ludus. This is part of a broader security update. As web browsers continue to increase their privacy and security standards, especially around cookies and cross-site content, this step helps us stay ahead of the curve.

**By knowing which domains are authorized to use the Ludus embed widget, we can:**

1.  Support stronger browser security (like advanced content security policies)

2.  Ensure cross-site cookies work reliably where needed

3.  Prevent unauthorized use of your embedded content

4.  Deliver a smoother, more consistent experience for your audience

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4vnERSHpm0Ug9wYwHWEUN-20251230-143353.png?format=webp "Document image")

This helps us future-proof your embed experience and keep things working securely across all modern browsers. If you’re unsure which domains to list or how to update them, we’re happy to help—reach out to the [Live Chat Support](https://support.ludus.com/live-chat-support) !

Even if you are embedding only part of the site (e.g., the donate page, a single event, or passes), you need to use this whitelist for it to function as expected.

There will be a request on the Embed Page requesting those domains:
