# Get embed code for Passes

If your website has a dedicated page for passes or season ticketing, you may wish to embed your list of passes directly on that page in Ludus. Then patrons will never leave your website to purchase a pass.

## Embed code for Passes

To grab the embed code for your listing of passes:

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Click **Share**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/lwjwgMRXNS4IIBgGpSnXu_get-embed-code-for-passes-archbee-document.png?format=webp "Document image")
    
3.  As long as you have the Embed Widget enabled on your account, you'll see the embed code, which you can copy/paste into your website builder.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-NXi-p4P2BoOlg8ejn45q_screen-shot-2023-08-31-at-90457-pm.png?format=webp "Document image")
    

You can embed a single pass by going to **Options** (next to the Pass) -> **Share**.
