# Get embed code for individual Events

If your website consists of event-specific pages, you're able to grab an embed code for a specific event. When you do this, only that event will be displayed in the widget wherever you embed it.

## Embed code for a specific event

To grab the embed code for a specific event:

1.  Navigate to your **Events** tab in your admin panel -> click the **More** button _next to the event you'd like the code for_ \-> and click **Share** in the dropdown.
    
2.  As long as you have the Embed Widget enabled on your account, you'll see the embed code for that specific event which you can copy/paste into your website builder.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/orz_Wsw2yzcm40y4qJgup_image.png?format=webp "Document image")
    

As mentioned above in the script, you can use the variable 'collections' or 'events' to only show those specific items on your page. The variable 'classes' also works only to show classes when that code is embedded on a class page, if desired.
