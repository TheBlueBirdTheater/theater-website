# Get embed code for Gift Cards

If you are using the Gift Cards feature, you may want to consider adding a widget to your website where patrons can purchase them directly.

If you do not have the Gift Card feature enabled but would like to, please reach out to our live customer support found in the bottom right-hand corner of your admin panel.

## Embed code for Gift Cards

To grab the embed code for Gift Cards:

1.  From the top navigation bar, click **More** --> **Gift Cards**.
    
2.  At the top of the page, click **Settings**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/oIo07KwFBt1gFMBMmSH-w_get-embed-code-for-gift-cards-archbee-document.png?format=webp "Document image")
    
3.  As long as you have the Embed Widget enabled on your account, you'll see the embed code for that specific event which you can copy/paste into your website builder.
