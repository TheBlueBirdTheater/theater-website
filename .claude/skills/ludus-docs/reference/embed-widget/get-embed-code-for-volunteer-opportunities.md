# Get embed code for Volunteer Opportunities

If you are utilizing the Volunteers feature, you may wish to plug a widget on your website where patrons can purchase them directly.

## Embed Code for Volunteers

### To grab the embed code for the Volunteers page:

1.  From the top navigation bar, click **More** --> **Volunteers** \-> **Opportunities.**
    
2.  Select **Share** at the top of Opportunities. From here, you can copy that code.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZS1CWNOG6jYTcLwsxuJ9g-20251209-145255.png?format=webp "Document image")
    

### To grab the embed code for an individual Opportunity:

1.  From the top navigation bar, click **More** \-> **Volunteers.**
    
2.  Once there, go to **More** (next to the Opportunity) --> **Share**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/K2L6IUT5h6hCalxfhuelz_ludus-manual-admin-2024-06-13t093517936.png?format=webp "Document image")
    
3.  From here, you will be able to copy the embed code for that opportunity.
