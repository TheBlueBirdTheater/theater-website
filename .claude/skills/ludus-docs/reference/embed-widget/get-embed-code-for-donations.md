# Get embed code for Donations

If your website has a page dedicated to donations, you may wish to embed your Ludus fundraising page directly into your website. Then, wherever you plug in the widget, the various donation options will be displayed.

## Embed code for the donation page

To grab the embed code for the donation page:

1.  Navigate to **Fundraising** --> **Donations**, and select **Share**.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-C0bfF6vWdScVuvg676AlE-20241002-154914.png?format=webp "Document image")
    
2.  At the bottom of the page, you will see the embed code for your donation page. Use this to copy/paste into your website builder.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-xpQBGE16mmGrumTNPaR2k-20241002-154723.png?format=webp "Document image")
