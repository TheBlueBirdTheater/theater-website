# Can I hide the top menu bar?

Yes - if you want to hide the top menu bar from the embedding on your group's site (similar to below), you can do that!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/UQR6UXeDQA97Xfs8Aaxtc_screenshot-2024-03-20-at-15651-pm.png?format=webp "Document image")

To do so, follow these instructions for the Widget when going to embed:

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FcKhhurzwQNdaIBt0i6C__image.png?format=webp "Document image")

If you use _'false';//'false'_ = top navigation will be shown on the widget load; _'true'_ = navigation will be hidden.
