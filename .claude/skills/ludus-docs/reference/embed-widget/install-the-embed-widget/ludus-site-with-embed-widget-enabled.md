# Ludus Site with Embed Widget Enabled

While the Embed Widget provides you with the ability to embed Ludus directly on your site, you can continue to use your Ludus site as well. It will look and function the same as it would without the Widget enabled.

This can be incredibly helpful if you still share the Ludus site, or if patrons happen to find it as well.
