# Summary Report

The Summary Report provides a general overview of sales for an event, collection, class, or account. This report breaks the data down into different categories. You can view sales by payment type (cash, credit, comp, etc.), by event or event time, by ticket prices, channel (online/self-serve or in-person/box office), and more. These categories are dependent on whether you are pulling an account-wide or event-specific report. See the drop-down menus below for more information.

Use the bar along the top of the report to filter by a specific type (tickets, donations, add-ons, etc.) or payment type (credit, cash, comp, etc.). Additionally, use the "Just to section..." menu to easily navigate to a specific area of the report.

Check out the drop-downs below to learn how to view each type of Summary report and an explanation of the information found in each report.

## Global Summary Report

To view an account-wide Summary report, click **Reports** (at the top of your admin panel) -> **Summary**. You can set a desired date range from here and view, export, or print as needed.

### Categories included in a Global Summary Report

-   **Payment type** - All sales are sorted by method of payment. Credit versus cash, versus comp, flex pass redemption, and any other payment options you've set.

-   **Invoices** - Shows invoices paid and by what payment method. Includes partial payments in the totals.

-   **Events** - Each event's sales are broken down by payment type.

-   **Collections** - Each collection's sales are broken down by payment type.

-   **Classes -** Each class's sales are broken down by payment type.

-   **Passes -** Each pass's sales are broken down by payment type.

-   **Donations** - All donations are grouped by category (fundraisers, general, categories) and divided by payment type.

-   **Gift Cards** - Gift cards sold are broken down by payment type

-   **Channels** - "Self-Serve" (purchases made by patrons online) versus "Box Office" (sales made from your admin panel)

-   **Sellers** - Sales grouped by each user and broken down by payment type.

The Summary Report displays in collapsed view by default. This means that if a particular item doesn't have sales for the time frame of the report, it will not appear on the report.

You can easily switch to an expanded view by clicking the expand button on the far right of the report toolbar.

## Event Summary Report

To view an event-specific Summary report, click **Reports** (next to the event listing on the **Events** tab) -> **Summary**. From here, you can set a desired date range and view, export, or print as needed.

### Categories included in an Event Summary Report

-   **Payment type** - All sales are sorted by method of payment. Credit versus cash, versus comp, flex pass redemption, and any other payment options you've set.

-   **Times** - Each event's sales are broken down by payment type.

-   **Prices** - Each ticket price's sales are broken down by payment type. This includes Add-ons.

-   **Channels** - "Self-Serve" (purchases made by patrons online) versus "Box Office" (sales made from your admin panel)

-   **Sellers** - Sales grouped by each user and broken down by payment type.

## Collection Summary Report

To view a collection-specific Summary report, click **Collections** --> **Standard** from the top navigation bar. Then, next to the desired Collection, click **Reports** --> **Summary**. From here, you can set a desired date range and view, export, or print as needed.

### Categories included in a Collection Summary Report

-   **Payment type** - All sales are sorted by method of payment. Credit versus cash, versus comp, flex pass redemption, and any other payment options you've set.

-   **Prices** - Each fee price's sales are broken down by payment type. This includes Add-ons.

-   **Channels** - "Self-Serve" (purchases made by patrons online) versus "Box Office" (sales made from your admin panel)

-   **Sellers** - Sales grouped by each user and broken down by payment type.

## Class Summary Report

To view a class-specific Summary report, click **Collections** --> **Classes** from the top navigation bar. Then, next to the desired Class, click **Reports** --> **Summary**. From here, you can set a desired date range and view, export, or print as needed.

### Categories included in a Class Summary Report

-   **Payment type** - All sales are sorted by method of payment. Credit versus cash, versus comp, flex pass redemption, and any other payment options you've set.

-   **Times** - Each class's sales are broken down by payment type.

-   **Prices** - Each class's sales are broken down by payment type. This includes Add-ons.

-   **Channels** - "Self-Serve" (purchases made by patrons online) versus "Box Office" (sales made from your admin panel)

-   **Sellers** - Sales grouped by each user and broken down by payment type.
