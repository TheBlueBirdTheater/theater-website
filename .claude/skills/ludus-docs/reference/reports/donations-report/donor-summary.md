# Donor Summary

The **Donor Summary** report provides the cumulative donation totals for each of your patrons for the period requested.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-PZZ9IYDHjWOyQgFieDfyp-20250217-200515.png?format=webp "Document image")

The Total Amount, Last Donated, or Last Amount columns can sort the report.

Clicking **View Report** will open an Individual Donation Report which shows all donations by a patron for the time frame and this can also be exported to CSV.
