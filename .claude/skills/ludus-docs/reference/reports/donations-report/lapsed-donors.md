# Lapsed Donors

The Lapsed Donors report provides two different reports on donors year over year. Here you can run a LYBUNT or SYBUNT report on your donors. Each report allows you to view a donor report on each donor and each of these reports can be exported to a CSV.

### LYBUNT Report (Last Year But Unfortunately Not This Year)

The LYBUNT reports donors in the prior calendar year that have not donated to date in the current year. The start date for the report can be defined and the resulting report will cover one year period from that date.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-WIALAVRPgAOOrS4eNAQQ4-20250217-200802.png?format=webp "Document image")

### SYBUNT Report (Some Year But Unfortunately Not This Year)

The SYBUNT reports all donors that have ever donated to your program but have not in this calendar year. The start date for the report can be defined and the resulting report will cover one year period from that date.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-h0-e5DYf5VORQM-u0bMvH-20250217-200833.png?format=webp "Document image")

You can also click to view a report on a specific donor. LYBUNT reports are exportable to CSV.
