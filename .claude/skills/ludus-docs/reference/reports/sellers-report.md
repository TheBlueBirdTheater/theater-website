# Sellers Report

This report is for the end of the day (or a selected date range) for reconciling sales by admin on an account. It will show a summary and itemized list of those sales.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-v4AaCRd6GPrfMm0dJSJgB-20241106-152340.png?format=webp "Document image")

## Generate the Sellers Report

When generating the **Sellers Report**, there are a few criteria that can be set to generate the desired information:

-   **Start and End Date**

-   **Type** (of purchase - IE single tickets)

-   **Payment Methods**

-   **All Sellers** or **Specific Sellers**

Once those are set, you can generate the report to be exported or printed.
