# Discounts

## What can this feature help with?

This feature allows you to create discount codes that patrons enter at checkout and bulk discounts that automatically apply based on specific parameters. Discounts can be attached to events, collections, classes, and passes.

## Why use this feature?

Discounts come with several settings, allowing you to create a discount that works exactly as you need.

_Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)

## What makes this feature so special?

Discounts can be created for a singular event, collection, or class. You can also utilize our Global Discount feature to have a single code that works across multiple events.

There are two main types of discounts within Ludus:

-   **Code -** A patron has a code they can enter at checkout. Coded discounts can be for a singular event or multiple (Global)

-   **Bulk -** A discount that automatically applies when parameters are met. Typically, when a certain number of tickets have been added to the cart.

## So how does this feature work?

Discount codes can be set up in various locations in Ludus. Once you decide where you wish to have the code (events, collections, etc), you can then share that code with patrons.

Patrons will be able to use that discount code during the checkout process on your patron site. Be sure to communicate to them the ticket type or any limitations if you have set specifications for what the code can be used for.

## How do I create a Discount?

Discount codes can be created in various locations in Ludus (depending on what you require.

Check out [Create a discount](https://support.ludus.com/create-a-discount) to find your exact need and location.
