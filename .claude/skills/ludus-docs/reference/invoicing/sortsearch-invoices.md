# Sort/Search Invoices

The main Invoicing page allows you to sort and search through your invoices easily.

To do so, navigate to **More** --> **Invoicing** from the top navigation bar. Invoices can be sorted by date range, status, and event name, and can be searched via the search bar. You can use these tools separately or in conjunction to locate the invoice(s) you want to view. The financial stats at the bottom of the table will automatically update based on selections.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-KYF4rVw_jjdP_SZAKq9oT-20250826-154542.png?format=webp "Document image")

The following status types are available:

-   **All Statuses** - This is the default and will show all invoices.

-   **Pay Later** - will display invoices that patrons have requested to have issued.

-   **Pending** - The Admin issued invoices that are currently pending.

-   **Paid in Full** - All fully paid invoices, regardless of how they were issued.

-   **Past Due** - Invoices that are currently past due.

-   **Void** - Invoices that have been voided.
