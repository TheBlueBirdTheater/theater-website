# Create/Send an Invoice

# Create an Invoice for an Order

You can also create an order invoice under **More** -> **Invoicing** -> **New Order**.

1.  Start an order for any event, collection, or class from your admin panel. Add any items you'd like on the invoice to the cart.
    
    _Suggested Articles_:
    
    [Sell tickets to an Event](https://support.ludus.com/sell-tickets-to-an-event)
    
    [Sell a Collection](https://support.ludus.com/sell-a-collection)
    
    [Sell a Class Registration](https://support.ludus.com/sell-a-class-registration)
    
2.  Once you have added all the items to the cart, click the purple **Create Invoice** button.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-riw95lws47ksodN4TEL71-20250826-155628.png?format=webp "Document image")
    
    The invoice will automatically be created with any defaults you set on your Invoice Designer.
    
3.  If you input patron information on the selection screen, that information will automatically be carried over to your invoice. Otherwise, add any patron information or additional recipients to your invoice.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-DQX3CB2T1DJevfkOpZ2Pt-20250826-155518.png?format=webp "Document image")
    
4.  Make alterations to the due date, memo, and footer as desired.
    
5.  Preview the invoice, payment page, and email on the right-hand side. When satisfied, click **Send Invoice** to send.
