# Void an Invoice

If you send an invoice and discover that it is unnecessary or perhaps you need to send a different one, you can easily void it before the patron pays it.

### To Void an Invoice:

1.  Go to **More** (at the top of your account) -> **Invoices**.
    
2.  Once there, select **View** (next to the Invoice you need to Void).
    
3.  When you select it (as long as it's Pending and not paid), you will see **Void** at the top right corner.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/BuDjFOA6CjVuC2mB5u3Le-20251001-190533.png?format=webp "Document image")
    
4.  Once selected, you will be prompted to verify if you wish to go through with the Void. If so, simply select **Void** (instead of Cancel).
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-uczmOwKEPjqE0osa9Gsqe-20250829-142508.png?format=webp "Document image")
    
5.  When successful, you will see the Void page next, and the Invoice will show as Voided on the Invoices page too.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-E7p0BU0ZrSTB1F-jo-fgK-20250829-142549.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/u_66B7RNRN9QuCg3eNk0g-20251001-190751.png?format=webp "Document image")
    

You can also void an invoice with a partial payment. You will simply choose to Void (like above), and then you will be prompted to refund the patron and void the invoice.
