# View Activity on an Invoice

When an invoice is created, sent, paid, or otherwise updated, a history log is maintained on the invoice's details page.

To view the history log for an invoice:

1.  From the top navigation bar, click **More** --> **Invoicing**.
    
2.  On the main Invoicing page, locate the invoice for which you'd like to collect payment and click **View**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-05OGglZv6k65lVbbHv3cb-20250829-135819.png?format=webp "Document image")
    
    You can sort invoices by status from the top bar or use the search bar to search by name, email, or invoice number.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-170mAOYMV9Ei5J1L4ZDGt-20250829-135909.png?format=webp "Document image")
    
3.  Scroll to the section titled **Activity**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-E7BUu9mYcsdjhDHowcq2m-20250829-143842.png?format=webp "Document image")
