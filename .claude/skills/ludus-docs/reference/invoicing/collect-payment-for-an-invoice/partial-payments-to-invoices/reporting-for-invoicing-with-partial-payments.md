# Reporting for Invoicing with Partial Payments

When using Partial Payments, your Reports will include additional information about the invoices and payments that have been processed, as reflected below. Below are reports where you will see changes in reporting due to partial payments.

### Summary Report

The Summary Report will include any Partial payments received for the dates requested. Amounts will be shown for invoices paid as well as amounts owed in each category of the report.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/0E4I8IvDM7o7cxqjfO9KK-20251021-182158.png?format=webp "Document image")

### Revenue Report

The revenue report includes an Invoice Paid filter that displays the dates and amounts of received invoice payments.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yZFzR9Tt92lVwMTJ9hjlO-20251021-182345.png?format=webp "Document image")

### Itemized Report

The itemized report will reflect any partial payments made via invoice, including the method of payment that was used.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YCe0mMW0NRnEVDKiL7xSb-20251021-182536.png?format=webp "Document image")

### Orders Report

The Orders Report will reflect any completed invoices after the payment is made in full. Invoiced items that have not been fully paid will not be reflected on this report. You can see whether an order was invoiced or paid using another payment type.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZBhvnOtFlEM_Npt3qa72Z-20251021-182735.png?format=webp "Document image")
