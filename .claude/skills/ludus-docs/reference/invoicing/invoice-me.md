# Invoice Me

When selling **Collections** or **Classes**, you can allow patrons to request an invoice for the total due with the **Invoice Me** feature.

All account Super Admins will receive an email when a patron opts for the Pay Later option.

Invoice Me is an optional feature that can be enabled on a collection or class basis. Within the same collection or class, it is also possible to have specific fees that allow invoicing and others that do not.

When **Invoice Me** is active on a class or collection fee, patrons can select to pay later on the checkout screen, which will automatically issue an invoice. If a fee is not eligible for Invoice Me, a message will be displayed to indicate this.

Partial payment of the invoice generated by Invoice Me can be done via the admin panel in Invoicing and is subject to the same fee as an admin-issued invoice.

Invoice Me does not affect an Admin's ability to send an invoice. It only allows patrons to request an invoice without contacting the box office or account administrator.

### Turn on Invoice Me for your Collection or Class

Enabling Invoice Me can be done when creating a New Collection or Class, or by navigating to **Options ->** **Settings.**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/yFLjU7B-ROVTCjoctA_rm-20251027-194358.png?format=webp "Document image")

Once enabled, you can also choose per fee whether you would like Invoice Me available. That way, if there is a fee you do not want available for, that can be turned off!

Once you select **Invoice Me,** a second setting will appear, allowing you to set the due date for invoices created by the patron.

You have the following options:

-   **Custom Date** - This can be set to a specific date before the class or collection opens or after the class or collection's end date.

-   **Days after Invoice is sent** \- By default, it is set to 14 days, but it can be changed.

-   **Days Before** **Collection Deadline -** The number of days before the class begins. This setting determines the due date for invoices requested by patrons, which is

These settings **do not** affect the due dates of invoices sent by an admin via the admin panel.

### What Invoice Me looks like for Patrons

On the cart screen, before finishing checkout, the patron will see the option to add **Additional Payment Options** to their order.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/I9BtD5o6DyC7r4B7It-Zy-20260603-123401.png?format=webp "Document image")

When this is selected, the patron will be able to select Request Invoice for the amount due on the Class or Collection.

If it is a Class and you have [Payment Plans](https://support.ludus.com/payment-plans) available this will also appear as an option.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8PkWjluYn-obyHB_mIIqM-20260603-123420.png?format=webp "Document image")

Once selected, they will see a confirmation note that the **Request Invoice** was applied and that the invoice will be sent to the patron's email used for the order.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/D5DjCuNkwgwn8WnoFpsz_-20260603-123457.png?format=webp "Document image")

The other item patrons will notice occurs when they create an order that combines items that cannot utilize the Invoice Me option with ones that can, or when items have different payment due dates. In these situations, a message will be displayed explaining why paying later is not possible, along with the relevant details.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-SaY4ZMZnNfGuvZIVXLQ3Y-20250829-145628.png?format=webp "Document image")

Patrons can easily remove conflicting items if they choose to use an **Additional Payment Option**, or simply pay at checkout.
