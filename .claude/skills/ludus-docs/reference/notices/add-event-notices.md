# Add Event Notices

In addition to Global Notices, you can add event-specific notices. These will apply on an event-by-event basis and can be incredibly helpful in sharing event-specific information with your patrons.

## To add an Event Notice:

1.  Go to **More** (next to the event) --> **Event Notices**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/HS2yybkdjUWB0N1TcZGgt_add-event-notices-archbee-document.png?format=webp "Document image")
    
2.  From here, you can select any of the Notices listed to edit or add information to any of the desired **Notice** options.
    

## Types of Event Notices

### Event Listing

This is a Notice that will show up along with the event listing on your patron site. If you have specific information that pertains to that event, you can share that information via this Notice!

**Admin Panel View**

**Patron Site View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/L5ZtV5xbile1OOF7FuolL_screen-shot-2023-08-17-at-110530-am.png?format=webp "Document image")

### Ticket Selection Page

This is a notice that will appear when patrons go to select tickets for an event. This is great if you need to inform them about anything related to the ticket selection process. When using this notice, you can let patrons know about tiered seating or even just the checkout process.

**Admin Panel View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/5-35qVv8bElPdKeKKafrE_screen-shot-2023-08-17-at-110736-am.png?format=webp "Document image")

**Patron Site View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/16T61mx1akspxXDgQMa0Z_screen-shot-2023-08-17-at-110747-am.png?format=webp "Document image")

### Confirmation Email

This is a notice that can be attached to the confirmation email. This would be good for any additional information like where to park or what time to arrive to an event.

### Tickets

This is a notice that will be printed on the tickets themselves. This is great if you need to let a patron know to enter through a specific door, or perhaps a reminder for the event itself.
