# Add Class Notices

In addition to Global Notices, you can add class-specific notices as well. These will apply on a class-by-class basis and can be incredibly helpful in sharing information that is only relevant to the specific class.

## Add a Class Notice

1.  Go to **Options** (next to the Class) -> **Notices**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nUtTpcvilCDO9HoikQa3I_add-class-notices-archbee-document.png?format=webp "Document image")
    
2.  From here, you can select any of the Notices listed to edit or add information to any of the desired **Notice** options.
    

## Types of Class Notices

### Class Listing

This is a Notice that will show up along with the Class listing on your patron site. If you have specific information that pertains to that Class, you can share that information via this Notice!

### Fees Selection Page

This is a notice that will appear when patrons go to select Fees on a Class. This is great if you need to inform them anything about the Fee selection process.

### Confirmation Email

This is a notice that can be attached to the confirmation email. This would be good for any additional information like where to park or what time to arrive at an event.
