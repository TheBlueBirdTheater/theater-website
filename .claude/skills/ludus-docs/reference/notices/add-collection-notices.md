# Add Collection Notices

In addition to Global Notices, you can add collection-specific notices as well. These will apply on a collection-by-collection basis and can be incredibly helpful in sharing information that is only relevant to the collection at hand.

## Add a Collection Notice

1.  Go to **Options** (next to the Collection) -> **Notices**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/p4MuKYsbdNUZ9dnqgefHz_add-collection-notices-archbee-document.png?format=webp "Document image")
    
2.  From here, you can select any of the Notices listed to edit or add information to any of the desired **Notice** options.
    

## Types of Collection Notices

### Collection Listing

This is a Notice that will show up along with the Collection listing on your patron site. If you have specific information that pertains to that Collection, you can share that information via this Notice!

### Fees Selection Page

This is a notice that will appear when patrons go to select Fees on a Collection. This is great if you need to inform them anything about the Fee selection process.

**Patron Site View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gNsmxOIHJjU2vyRsGn562_screen-shot-2023-08-17-at-112358-am.png?format=webp "Document image")

### Confirmation Email

This is a notice that can be attached to the confirmation email. This would be good for any additional information like where to park or what time to arrive at an event.

**Admin Panel View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_y693aFKDXPyRjnXvSlmI_screen-shot-2023-08-17-at-112515-am.png?format=webp "Document image")

**Patron Confirmation View**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/RBwdAMxTXxk8Pz-y0Wu2J_screen-shot-2023-08-17-at-112639-am.png?format=webp "Document image")

By default, the background color of page Notices is a light yellow — to change this, go to **Settings** (⚙️ in your top navigation) -> **Design Tool** -> **Notices**.
