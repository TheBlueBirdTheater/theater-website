# Add Global Notices

# Add a Global Notice

Global Notices are custom messages that you can directly place throughout the patron experience. You can use these to communicate anything you need with your patrons.

# To add a Global Notice:

1.  Go to **More** (at the top of your admin panel) → **Global Notices**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-aAeSkUtpL9Jkn3VQxKOCE-20250620-192315.png?format=webp "Document image")
    
2.  From here, you can select any of the Notices listed to edit or add information to any of the desired **Notice** options.
    

Global Notices are account-wide and apply to every item (events, tickets, etc.)

# Types of Global Notices

This is a Notice that will show up along with the event listing on your patron site. The Event's Notice is perfect for those situations where you would like to share more information about your events or the season of events ahead.
