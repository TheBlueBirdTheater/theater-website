# Edit/Disable a discount

Once a discount has been added to an entity with your Ludus account, you might need to make adjustments or disable the code entirely. To do so, check out the steps below for the corresponding entity.

### Edit/Disable a discount for an Event

1.  On the main **Events** tab, find the event that you'd like to add a discount for.
    
2.  Next to the event title, click **Pricing** --> **Discounts**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/r03G0kfs9pLKD_w9siSTd_create-a-discount-archbee-document.png?format=webp "Document image")
    
3.  Click the green **+Discount** button.
    
4.  \-To edit, click **Edit**. Be sure to save at the bottom once you've updated the settings. (Note: The amount off may not be changed once the discount has been used.)
    
    \-To disable, click **Disable** and verify in the pop-up box.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_1PcwuLMhjVZij-CeQ1e5_screen-shot-2023-09-01-at-92350-pm.png?format=webp "Document image")
    

### Edit/Disable discount to a Collection/Class

1.  Navigate to **Collections** --> **All Collections** from the top navigation bar.
    
2.  Find the collection/class for which you'd like to add a discount.
    
3.  Next to the title, click **Pricing** --> **Discounts**.
    
4.  \-To edit, click **Edit**. Be sure to save at the bottom once you've updated the settings. (Note: The amount off may not be changed once the discount has been used.)
    
    \-To disable, click **Disable** and verify in the pop-up box.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZIuENfnVKBKzVhgSsG3wg_screen-shot-2023-09-01-at-92619-pm.png?format=webp "Document image")
    

### Edit/Disable a discount on a Pass

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Find the Pass for which you'd like to add a discount and click **Options** --> **Discounts**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/n3eJA3conaQSqQOMG-yBK_screen-shot-2023-09-01-at-91302-pm.png?format=webp "Document image")
    
3.  \-To edit, click **Edit**. Be sure to save at the bottom once you've updated the settings. (Note: The amount off may not be changed once the discount has been used.)
    
    \-To disable, click **Disable** and verify in the pop-up box.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/bExiJWiJ04Vl5i468Fj2I_screen-shot-2023-09-01-at-92928-pm.png?format=webp "Document image")
