# Create a discount for free ($0) tickets

There may be times when you'd like to/are required to, offer free tickets to specific patrons.

With the discounts feature, you can do so while still preventing the general public from accessing the free prices! This article will walk you through the specific settings you need to create such a discount.

## Creating a Discount Code for Free Tickets

You will create a 100% discount code that you can hand out to any patron(s) you'd like. You can add a ticket limit to the discount in case they only get X number of free tickets. Ludus will track each patron so they can't continue to use the same code over and over again.

In this example, let's pretend we want to offer _**2 free tickets**_ to patrons.

### To do so:

1.  Next to the desired event, click **Pricing** \--> **Discounts.**
    
2.  Click the **\+ Add Discount** button.
    
3.  For "Code", enter the code you want to hand out (e.g., 'STAFF2024').
    
4.  For "Amount", type in **100**. This will reduce any ticket price to zero.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/PXgHlG5hc7uV8BQ2FYN1t_screen-shot-2023-10-09-at-113615-am.png?format=webp "Document image")
    
    If you set a flat amount off, it will be a fixed reduction instead of flexible, based on the starting ticket price. This comes into play if you have multiple ticket types/prices.
    
5.  To limit how many tickets they get free, check the box for "Limit number of tickets the code applies to in an order". Type the desired quantity into the box that appears and leave it set to **Per Patron**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/c5h_CZzHrmcD8cxdDU00f_screen-shot-2023-10-09-at-113713-am.png?format=webp "Document image")
    
6.  Click **+Add Discount** at the bottom of the page.
    

There are many other settings and options you can add to your discount to make it specific to your needs. For more information about the settings available for discounts, check out this article.

_Suggested Article_: [Create a discount](https://support.ludus.com/create-a-discount)

_Worried about patrons sharing codes?_ Don't fret! With the Ludus reporting, you can easily sort your reports to see which patrons are using the discount code on their orders. Additionally, you can limit the number of times a specific code can be used before it is invalid. If you set this to "1", once it is used, it will not work again. You can set up multiple one-off discounts to provide extra security.
