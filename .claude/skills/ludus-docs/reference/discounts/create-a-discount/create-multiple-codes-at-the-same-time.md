# Create Multiple Codes at the Same Time

If you have multiple discounts and each will be for the same percentage off, you can easily set up all of those codes at once. These can be set up under Global Discounts or Event-specific discounts (whichever is needed).

### Create Multiple Discounts at Once

1.  To start, you will want to go to the event or Global Discounts.
    
    -   Global Discounts: Go to **More** (at the top of your account) -> **Global Discounts** -> **+Global Discount**.
    
    -   Event Specific Discounts: Go to **Pricing** (next to the event) -> **Discounts** -> **+Discount**.
    
2.  Once there, you will see (under **Code** and NOT **Bulk**) the ability to add multiple codes at the same time, they only need to be comma-separated.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-JGgrXlcecr08M-Mc2Uhss-20250429-141042.png?format=webp "Document image")
    
3.  At this point, you can add the discount codes needed (they will all be the same percentage off. After that, be sure to fill in the remaining information to [Create a discount](https://support.ludus.com/create-a-discount) .
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-zQji0dwtha2YdWpuwAOdb-20250429-141247.png?format=webp "Document image")
    
4.  Once finished, select Submit at the bottom of the discount. At this point, you will see all the codes created!
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-JxvrfDCnCL9lxgFIHLGql-20250429-141347.png?format=webp "Document image")
