# Create a discount

Discounts can be attached to any Event, Collection, Class, or Pass. To create a discount, first navigate to the entity it will be attached to. Check out the fields below for more specifics.

Discount codes are not case-sensitive.

### Create a discount for an Event

1.  On the main **Events** tab, find the event for which you'd like to add a discount.
    
2.  Next to the event title, click **Pricing** --> **Discounts**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8IWBmELszA6KHE4v3VRBN_create-a-discount-archbee-document.png?format=webp "Document image")
    
3.  Click the green **+Discount** button.
    
4.  Choose whether to set up a Code discount or a Bulk discount using the tabs at the top of the page.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Xi5BFVSxPPvc2Vf56IneR_screenshot-2026-07-16-at-115409-am.png?format=webp "Document image")
    
5.  Fill out the applicable discount settings. _Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)
    
6.  Click **+Add discount** to finish.
    

### Create a discount for a Collection/Class

1.  Navigate to **Collections** --> **All Collections** from the top navigation bar.
    
2.  Find the collection/class you'd like to add a discount to.
    
3.  Next to the title, click **Pricing** --> **Discounts**.
    
4.  Click the green **+Discount** button.
    
5.  Choose whether to set up a Code discount or a Bulk discount using the tabs at the top of the page.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Xi5BFVSxPPvc2Vf56IneR_screenshot-2026-07-16-at-115409-am.png?format=webp "Document image")
    
6.  Fill out the applicable settings for the discount. To learn more about the settings and terms for each type of discount, check out this article.
    
    _Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)
    
7.  Click **+Add Discount** to finish.
    

### Create a discount for a Pass

1.  From the top navigation bar, click **More** --> **Passes**.
    
2.  Find the Pass for which you'd like to add a discount and click **Options** --> **Discounts**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/n3eJA3conaQSqQOMG-yBK_screen-shot-2023-09-01-at-91302-pm.png?format=webp "Document image")
    
3.  Click the green **+Discount** button.
    
4.  Fill out the applicable settings for the discount.
    
    _Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)
    
    Bulk discounts are not available for pass purchases.
    
5.  Click **+Add discount** to finish.
    

### Create multiple discount codes with the same settings for Events, or Collections/Classes

If you need to make many discount codes with the same settings, you can do so easily by entering all the codes into the Code field under Discounts, either comma-separated or by pasting each code on one line.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/PNisO_C4gpAz6F2RJh0-v_ludus-manual-admin-2024-06-03t103834105.png?format=webp "Document image")

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/rGu4rRorpN0bUcICyjZdj_ludus-manual-admin-2024-06-03t103704718.png?format=webp "Document image")

Once you create the settings and click Submit, each code will be generated with the same settings.
