# When to use a Pass instead of a Discount or Comp Code

There are times where it may be beneficial to use a Pass to create Comp tickets rather than using a Discount Code.

This would include times when:

-   You have a lot of comp codes for your event and don't want to create codes. (30 or more)

-   You want to have a unique code issued to each person rather than do a shared code.

-   You wish to offer comps or discounts to specific patrons and ensure they don't share the code. These comps can be for more than one event, or event time, up to the total number allowed on the pass.

-   As an example - they get a total of 4 comp tickets but can use them for any or all of 3 events.

-   You want to offer a discount for ordering tickets for more than one event at the same time.

-   Packaging two events together for a flat cost or percentage off normal prices on one of more of the events.
