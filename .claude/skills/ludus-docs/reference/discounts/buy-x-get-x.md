# Buy X, Get X

Buy X, Get X allows you to have a discount that applies to subsequent tickets after the first requirement has been met. For instance, Buy One, Get One 50% off.

To set up Buy X, Get X,

1.  Create a Code discount as you usually would.
    
    _Suggested Article_: [Create a discount](https://support.ludus.com/create-a-discount)
    
2.  For the **Amount**, insert the percentage or flat amount that will be deducted. For instance, if you want to buy one and get one 30% off, enter 30 for the amount.
    
3.  Scroll to the section titled "Buy X, Get X", and check the box.
    
4.  Enter the number they will have to buy to get off. This number will be both the Buy and the Get. (e.g., Buy One, Get One)
    
5.  Click **+Add discount** to save.
    

Buy X, Get X discounts can be applied to events, collections, and classes.
