# Global Discounts

Global discounts are a great way to set up a discount that works across multiple events. For example, you may wish to have the same discount code for ushers or VIP members that they can use across multiple events. This saves everyone the struggle of remembering multiple codes throughout the year.

Global discounts work across Events, Collections, and Classes.
