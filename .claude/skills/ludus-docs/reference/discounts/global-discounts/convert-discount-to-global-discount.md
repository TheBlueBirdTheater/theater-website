# Convert Discount to Global Discount

If you have added a discount to an Event, Collection, or Class, you have the ability to turn that discount into a Global Discount. In short, Global Discounts are discounts that apply across multiple events. By converting a standard discount into a global one, you can have patrons use the same code that they are already familiar with.

This is optional based on your organization's preferences. If you prefer to have different discount codes for each Event, Collection, or Class, you can still do so.

**To convert an existing discount into a global one:**

1.  Navigate to the existing discount by clicking **Pricing** --> **Discounts** next to the existing event, collection, or class.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nnMNG8uhjoyK1A9Yasr_K_screen-shot-2023-11-01-at-121324-pm.png?format=webp "Document image")
    
2.  Next to the discount, click **Edit**.
    
3.  Scroll to the bottom of the page and click **Convert to Global Discount**. Verify that you want to perform this action in the pop-up menu.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aswPXcwT8JUvPwmz67ibt_screen-shot-2023-11-01-at-123706-pm.png?format=webp "Document image")
    
    Converting a single discount into a global one is an irreversible action. If you have questions or concerns before doing so, we recommend reaching out to our live chat support found in the bottom right-hand corner of your screen!
    
4.  You will be taken to a page where you can edit the settings for your Global discount.
    
    Your Global Discount will not be converted and saved until you make your selections on this screen and click **Save as Global**.
    
    From this screen, you will choose the items, times, and types to which the discount will apply. You can select as many or as few as you'd like. For more information about these options, check out the following article.
    
    _Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)
    
    The two main options are all items or a select few. If you only want them to apply to certain items, click the circle for "Apply to specific items/times/price types"
    
5.  Adjust the "Usage Limits" and "Additional Options" as needed.
    
6.  Click **Save as Global**.
