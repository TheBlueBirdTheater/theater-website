# Create a Global Discount

[Global Discounts](https://support.ludus.com/global-discounts) are any discounts that apply to more than one event, class, or collection within Ludus. Global Discounts are very similar to single-code discounts. The main difference when setting up a Global Discount is that you will select which events, classes, times, and prices the code applies to from a series of checkboxes. These checkboxes can be edited at any time and give you complete control over where the discount works.

To create a Global Discount:

1.  From the top navigation bar, click **More** --> **Global Discounts**
    
2.  Click the green **+Global Discount** button.
    
3.  Select the code and amount (percentage or flat amount off) for the discount.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fzycj4PGYUB224QRT_J6c_screenshot-2026-07-16-at-120051-pm.png?format=webp "Document image")
    
4.  For "Eligibility," choose whether you'd like the Global Discount to apply to all items or a select few. If you select "Applies to Everything", skip to step 7.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2UjB9NyCzOTPPFOwlvB_F-20251007-151739.png?format=webp "Document image")
    
    If you select "Applies to Everything", this discount code will work across all events, classes, and collections, for every event and class time, and any ticket price. If you'd like to restrict any of the above, select "Applies to specific items."
    
5.  If you choose "Applies to Specific....", use the checkboxes to check all items to which the discount will apply. Be sure to check the boxes for your events, collections, and classes.
    
6.  Repeat steps 4 and 5 for the times and prices you'd like the discount to be attached to.
    
7.  Adjust the "Usage Limits" and "Additional Options" as needed. For more information about these settings, check out the following article about settings for code discounts. _Suggested Article_: [Settings for Code and Bulk Discounts](https://support.ludus.com/settings-for-code-and-bulk-discounts)
    
8.  In the "Additional Options," select whether this discount should apply to Add-Ons. This is disabled by default.
    
9.  Click **Save as Global**.
