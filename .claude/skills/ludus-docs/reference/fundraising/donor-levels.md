# Donor Levels

Donor Levels are a great way to encourage donations of a specific amount.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/eklloWWoNEu0s9LGLeCv7-20251020-155443.png?format=webp "Document image")

Within a level, you can customize confirmation emails, notify admins when certain levels are reached, and more.
