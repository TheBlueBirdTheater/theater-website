# Cancel Recurring Donations

To cancel a recurring donation from the Admin Panel, follow the steps below.

1.  Look up the donation you'd like to edit. There are multiple ways to do so. If you want to learn about these options, check out this article.
    
    _Suggested Article_: [Look up a donation](https://support.ludus.com/look-up-a-donation)
    
2.  In the section titled "Recurring Info", click **Cancel**. Click **OK** to confirm.
    

If a patron would like to cancel or edit the payment method for a recurring donation on their own, they can use the link in the donation confirmation email. If they are unable to find the confirmation email, you can either resend it or send them a direct link to manage the donation.

To do this, click **Copy to Clipboard** next to "Manage Link" on the donation details page.
