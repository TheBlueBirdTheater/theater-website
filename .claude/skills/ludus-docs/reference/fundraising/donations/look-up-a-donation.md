# Look up a donation

There are several ways to look up a prior donation within Ludus. Check out the dropdown boxes to find the best method for you.

### Donation Page (Recommended for recent donations)

If a donation was made recently, you can easily look it up by navigating to **Fundraising** --> **Donations**. This will show a log of the most recent donations made. Simply scroll until you find the donation you are looking for. Click the three vertical dots to view the details page.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/mCyOoVVJAgO5XupWzhCW2-20251218-212621.png?format=webp "Document image")

### Search Bar (Recommended if the donation is attached to a patron name)

The search bar is a powerful tool that allows you to search for patrons, prior orders, donations, passes, and more. To find a previous donation, click the 🔍 in the upper right-hand corner of the screen and enter the patron name.

From here, click the **Donations** tab and select the donation you'd like to view. You can also select the **Patron** tab to view the patron's full profile (which displays all transaction history).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/D1sINWmMK7SJROrMPlLq5_look-up-a-donation-archbee-document-1.png?format=webp "Document image")

### Donation Report (Recommended if you only know the date a donation was made)

If you are unable to look up the donation by patron name, you can search by date using our Donations Report.

1.  Navigate to **Reports** --> **Donations**.
    
2.  Use the date range filter to narrow your search.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/HcCjHv-8bG_Jqc3_C9kJq_screen-shot-2023-07-19-at-125938-pm.png?format=webp "Document image")
    
3.  Find the donation from the list and click the details shortcut on the left-hand side.
