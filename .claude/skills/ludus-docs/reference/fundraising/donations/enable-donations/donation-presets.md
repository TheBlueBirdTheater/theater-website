# Donation Presets

While there are default donation amounts that appear as possible for donors (IE - $5, $10, $25, $50, $100), you are also able to change those to custom amounts.

To change those amounts to custom presets, go to **Fundraising** (at the top of your account) -> **Settings** -> Scroll down to the **Donation Presets** section.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/snAHT-un83WyBZMZNL0uh-20251103-203650.png?format=webp "Document image")

From here, you can update 3 locations for those donation amounts:

1.  **Patron Cart** - Preset donation amounts suggested to patrons when buying tickets. We suggest keeping these smaller to encourage in-cart donations.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-HfFO9WL2MzzaCPX4es1Tv-20250625-134214.png?format=webp "Document image")

2.  **Donation Tab (Individual)** - When patrons visit your direct “donate” tab, they will be presented with these options as an individual donor.

3.  **Donation Tab (Corporate)** - When patrons visit your direct “donate” tab, they will be presented with these options as a corporate donor.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-tpvZ7qzLnGrIq6xAQPMII-20250625-134248.png?format=webp "Document image")

Once that is updated and saved, the changes will show on the patron site in the designated sections!
