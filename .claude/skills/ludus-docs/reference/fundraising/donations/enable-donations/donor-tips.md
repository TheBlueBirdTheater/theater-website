# Donor Tips

This will only be available on the public-facing side. Donor Tips allows you to pay 0% in donation processing fees for any donations made through public [Fundraiser](https://support.ludus.com/fundraisers "Fundraiser") pages.

### How does the Donor Tips feature work?

When your patrons donate through a public-facing fundraiser page, they’ll see an option to include a small tip. This will only be available on the public-facing side.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-DAWIqkR5DrUQwqjoyJgJQ-20250513-181925.png?format=webp "Document image")

For example, if a donor gives $100 and selects a 10% tip, your organization still receives the full $100, and the additional $10 supports Ludus in continuing this free model. However, if the donor opts for a $0 tip, your organization still benefits fully—the fee remains 0%.

The 0% rate will apply only to true donations. No donations were added to an order.

### How to activate:

This new model is _**opt-in**_, giving you complete control.

To set this up on your account:

1.  Log in to your Ludus admin panel

2.  Navigate to **Fundraising** (in your top navigation) **→ Settings**

3.  Enable **0% processing fees on Fundraisers supported by Donor Tips 💚**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/iRs81euWBzESXidafjB_M-20251103-203544.png?format=webp "Document image")

If you choose not to activate this model, standard processing fees (3.5% + $0.50 per donation) will continue to apply. Additionally, this is not eligible as a donation because it covers processing fees and is not tax-deductible.

_**Once enabled, your patrons will see this on their checkout screen:**_
