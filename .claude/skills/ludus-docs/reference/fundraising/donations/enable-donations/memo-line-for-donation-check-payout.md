# Memo Line for Donation Check Payout

If you have set your proceeds to **Checks** (not Direct Deposits), you can adjust the memo line on the donation checks you receive.

By default, these will read "_**Donation Proceeds**_," but the account admin can edit them.

Simply go to **Fundraising** (at the top of your account) -> **Settings** -> scroll down to **Check Memo**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/8KXXTFenqLUjiIl4ouwZH_image.png?format=webp "Document image")

From here, you can update the memo for all donation checks if you wish. This will apply to all checks that are cut and sent for donation proceeds.

This Memo is for donations only and cannot be edited elsewhere.
