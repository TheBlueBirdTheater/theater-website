# Resend donation confirmation

Resending a confirmation email for a prior donation is extremely easy within Ludus.

1.  Look up the donation for which you'd like to resend the confirmation email. There are multiple ways to do so. If you would like to learn about these options, check out this article.
    
    _Suggested Article_: [Look up a donation](https://support.ludus.com/look-up-a-donation)
    
2.  Click **Resend Confirmation**.
