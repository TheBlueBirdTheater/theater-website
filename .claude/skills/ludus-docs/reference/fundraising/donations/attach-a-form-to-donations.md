# Attach a Form to donations

Just like many other areas in Ludus, you can attach a custom Form to donations. By adding a form to donations, you will have that set of questions asked anytime someone makes a donation to your organization.

First, ensure that you have created the form you'd like to attach to donations.

_Suggested Article_: [Create a Form](https://support.ludus.com/create-a-form).

Once created, navigate to **Fundraising** --> **Settings**. Scroll down to the section titled "Custom Form". Then, use the drop-down menu to select which form you'd like to attach.
