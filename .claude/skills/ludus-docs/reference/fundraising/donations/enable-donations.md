# Enable donations

If you would like to accept donations from patrons on your Ludus page, you will need to turn on the donation feature. To do so, navigate to **Fundraising** --> **Settings**. Then, under "Allow Donations," click **Yes**. Be sure to scroll to the bottom and save your changes.
