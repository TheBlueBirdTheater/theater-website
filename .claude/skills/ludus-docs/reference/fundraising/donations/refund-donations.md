# Refund donations

To refund a donation:

1.  Look up the donation you'd like to refund. There are multiple ways to do so. If you would like to learn about these options, check out this article.
    
    _Suggested Article_: [Look up a donation](https://support.ludus.com/look-up-a-donation)
    
2.  Select **Donations** from the list of tabs, then click the donation you want to edit.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/GbG445iO8RimF1Z_LKi8r_refund-donations-archbee-document.png?format=webp "Document image")
    
3.  Click **Refund** next to the section you'd like to alter.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Z-Mf3Zh69CqOmkVmt3xgO_refund-donations-archbee-document-1.png?format=webp "Document image")
    
4.  Choose the reason for the refund, any details you'd like to enter, and click **Refund**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/MSX-_T0bWqyWTbhEhK_Oy_screen-shot-2023-07-19-at-120956-pm.png?format=webp "Document image")
