# Edit a donation

There may be times you need to go back and edit the details on a donation. Maybe there was a typo or you would like to route the donation to one of your other [Donation Categories](https://support.ludus.com/donation-categories).

Follow these steps to edit a previous donation.

1.  Look up the donation you'd like to edit. There are multiple ways to do so. If you would like to learn about these options, check out this article.
    
    _Suggested Article_: [Look up a donation](https://support.ludus.com/look-up-a-donation)
    
2.  Click **Edit** next to the section you'd like to alter.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/-fPNmjkFVd63GhX0kVRO5-20260209-144515.png?format=webp "Document image")
    
3.  Update the necessary details and click **Save Details**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/dwA55o5gXXe40rkbtcGVk-20260209-144556.png?format=webp "Document image")
    
    If you need to update the donation date, you can do so here.
    

To learn more about each section on the donation details page, see this article.

_Suggested Article_: [Overview of Donation details page](https://support.ludus.com/overview-of-donation-details-page)
