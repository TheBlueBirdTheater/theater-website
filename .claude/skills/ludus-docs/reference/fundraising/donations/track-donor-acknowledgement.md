# Track Donor Acknowledgement

Within Ludus, it's easy to track and monitor whether a donor (donation) has been acknowledged or not.

### Track Donor Acknowledgment - Reports

1.  Go to **Fundraising** (at the top) -> **Donations**.
    
2.  From here, select "**Generate Report**".
    
3.  Once there, you can set the date range for the report and select if you wish to see whether acknowledgment was sent to the donor.
    

### Edit Donor Acknowledgement

To edit whether a donor has been acknowledged or not, go to:

1.  **Fundraising** (at the top of the screen) -> **Donations**.
    
2.  Once there, you can select the donor you wish to edit from your donation list. Select the **View (next to the donation)** and click **Details**.
    
3.  Once there, select **Edit Donation Details**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/sqjRxiV8ggi6G4ooFTEfK_screenshot-2024-03-20-at-115729-am.png?format=webp "Document image")
    
4.  At this point, you can update the **Acknowledged** section to either checked or unchecked. Be sure to select **Save Details** to save acknowledgment.
