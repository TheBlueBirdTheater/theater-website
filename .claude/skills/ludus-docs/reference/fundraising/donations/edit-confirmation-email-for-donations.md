# Edit confirmation email for donations

When a donation is made, the patron will automatically receive a receipt of the donation via the email entered at the time of checkout. You may wish to insert some additional text into these emails. To set up this messaging, navigate to **Fundraising** --> **Settings**. Scroll to the section titled "Confirmation Email".

Then, use the open field to insert any text, links, or photos you'd like. When you are done, make sure to click **Save Changes**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9ogCU2vdzneO9Sz_zKNkX-20251103-203856.png?format=webp "Document image")

If you are using Donor Levels, you can customize the confirmation email based on the donation level.
