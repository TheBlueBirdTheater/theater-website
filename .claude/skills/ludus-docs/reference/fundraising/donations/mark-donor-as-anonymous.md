# Mark donor as anonymous

For donation [Fundraisers](https://support.ludus.com/fundraisers), you might want to mark a patron as anonymous. Here's how to accomplish that.

1.  Look up the donation for which you'd like to edit. There are multiple ways to do so. If you would like to learn about these options, check out this article. _Suggested Article_: [Look up a donation](https://support.ludus.com/look-up-a-donation)
    
2.  In the "Donation Details" section, click **Edit Donation Details**.
    
3.  Check the box next to **Anonymous**.
    
4.  Click **Save Details**.
