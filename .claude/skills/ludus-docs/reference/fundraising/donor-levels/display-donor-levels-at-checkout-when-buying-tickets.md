# Display Donor Levels at checkout when buying tickets

When utilizing the [Donor Levels](https://support.ludus.com/donor-levels) feature, you might want to display these levels during checkout. To do so, navigate to **Fundraising** --> **Settings**.

From there, under the **Levels at Checkout** section, select **On** and click **Save Changes**. Subsequently, the set donation levels will appear at checkout as seen below.
