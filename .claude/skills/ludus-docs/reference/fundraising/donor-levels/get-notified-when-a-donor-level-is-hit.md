# Get notified when a Donor Level is hit

Within Ludus, any number of users can receive an email notification when someone donates to a specific level. This will help you stay on top of incoming donations.

To select who receives these notifications, navigate to **Fundraising** --> **Levels** --> **Edit** (next to the desired level). Then, under the section labeled "Admin Notifications," check the box that says "Send notification email to admin(s)". From there, click the name of each admin you'd like to receive a notification.

If you'd like to add additional people to this list, you will need to set them up as admins within the system.

To do so, check out this article here: [Add a User](OM_qzdd_l0mcTwNrEyPdz)
