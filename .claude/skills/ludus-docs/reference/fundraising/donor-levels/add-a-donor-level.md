# Add a Donor Level

To create a new Donor Level, navigate to **Fundraising** --> **Levels** --> **Add Donation Level**. Check out each section below for more information about each field.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-KcP3VxPsTjZj-g63iJ7eA-20250822-155134.png?format=webp "Document image")

### Basic Info

-   **Level Name** - Name of your Donation Level

-   **Starting Amount** - The base dollar amount for a patron to qualify for the tier.

-   **Description** - Description of this level and any benefits or perks that are attached (Optional)

### Confirmation Email

-   **Send Confirmation Email** - Customize the message sent to a patron who donates at this level.

-   _Suggested Article:_ [Edit confirmation email for Donor Level](https://support.ludus.com/edit-confirmation-email-for-donor-level)

### Admin Notifications

-   **Send Admin Notification** - Enable sending notifications when a patron donates to a specific level.

-   **Admins** - Select which admins you want to be notified.

### Other Options

-   **Donor Type** - Choose whether this Donor Level is for Individual or Corporate donors. This section will only appear if you have enabled Corporate donations.

-   _Suggested Article_: [Enable corporate donations](https://support.ludus.com/enable-corporate-donations)

-   **Form** - Select a custom form you'd like donors to fill out if they fall in this Donor Level.

-   _Suggested Article:_ [Attach a Form to a Donor Level](https://support.ludus.com/attach-a-form-to-a-donor-level)

-   **Display to Public** - Choose whether this Donor Level is posted publicly for patrons or hidden for admin-only access.

-   _Suggested Article_: [Hide Donor Level from the public](https://support.ludus.com/hide-donor-level-from-the-public)

-   **Color** - The color used when displaying this Donor Level.
