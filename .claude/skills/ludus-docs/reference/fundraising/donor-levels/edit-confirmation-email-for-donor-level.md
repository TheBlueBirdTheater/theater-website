# Edit confirmation email for Donor Level

You can set the default acknowledgment text for confirmation emails on donations made to your site. However, you may wish to use custom text based on the level at which a patron donates. Here is how to achieve that.

Navigate to **Fundraising** --> **Levels** --> **Edit** (next to the desired level). Scroll to the section titled "Confirmation Email". Check the box that says "Send confirmation email to patron". This will enable a box in which you can insert any custom text, links, or photos you desire.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aB1dklIARk84OqJjO9-ec_screen-shot-2023-07-18-at-125624-pm.png?format=webp "Document image")

This messaging will appear above the receipt for donations made at this level.

The Email Confirmation Setting within Donor Levels is not a separate confirmation email from donation Confirmation emails. Instead, this is additional text that goes within the Donation confirmation email
