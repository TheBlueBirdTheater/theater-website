# Fundraising FAQ's

Below are some of the most commonly asked questions about Fundraising / Donations.

### Can we get an email for every donation?

Donations are not explicitly set up to email the admin for every donation received. You can create a [Donor Level](https://support.ludus.com/get-notified-when-a-donor-level-is-hit "Donor Level") that will generate an email to an admin. For example, you can set a $5.00 donation level, and every donation of $5.00 or more will be emailed to the admin you select. This works for both a standard donation and a donation added as part of another purchase, as well as for both online and admin-processed transactions.

### How do fees for donations work?

The transaction fees for donations are 3.5% + $0.50 per donation, except for donations of $3 or less, which have a $0.50 fee. The fees are always absorbed; however, when a patron donates via the fundraising path, they may elect to cover the fee. This is not possible when donating as an add-on to a purchase. More info on processing fees is available [here](https://support.ludus.com/ludus-pricing-table "here").

### How do I send a confirmation email for donations?

When a patron donates, either from the donation path or as part of a purchase, they automatically receive an email confirmation of the donation. The default email contains the basics of the donation, as shown below. However, you can add information to that email in **Fundraising -> Settings** to include an acknowledgment.

### How can I find who donated and thank them?

You can obtain a donor report from **Reports -> Donations**, which is located on the top navigation bar. At the time of the donation, an email confirming the donation is sent to all donors, and it will include any message you have added in **Fundraising->Settings**. By default, the report shows the last 30 days of donations; however, you can easily adjust the date range to any period you like. You can read more about the Donations report [here](https://support.ludus.com/donations-report "here").

### What does "Acknowledged" mean?

Acknowledged appears on both the Donations report and the transaction record for a donation. The acknowledgment field is for your organization to track any additional acknowledgments, such as a handwritten letter or a name added to the program. Whether or not "Acknowledgment" has been sent. By default, a confirmation email will be sent.

### Can we request information such as "In Memory of" or "Family Name for Program"?

Yes! You can create a form that asks any questions you would like donors to answer, then attach it to your donation form in **Fundraising -> Settings**. The form would be created in **More**, on the top Navigation bar, **Forms**.
