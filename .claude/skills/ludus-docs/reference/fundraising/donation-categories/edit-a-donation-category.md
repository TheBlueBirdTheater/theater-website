# Edit a Donation Category

There are a few settings you can change within a Donation Category. To edit a category:

1.  Navigate to the category by clicking **Fundraising** --> **Categories** from the top navigation bar.
    
2.  Next to the desired category, click **Edit**.
    

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/iGuR3d3YyBpzSfS7LF9Se_screen-shot-2023-09-18-at-23951-pm.png?format=webp "Document image")

From here, you will be able to edit the name of the category, the payout method (if receiving paper checks) and custom text for the confirmation email when patrons donate to this category.
