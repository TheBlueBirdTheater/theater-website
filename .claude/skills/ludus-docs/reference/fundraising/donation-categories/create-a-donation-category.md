# Create a Donation Category

You can easily create multiple donation categories in one step.

Once you have navigated to Donation Categories (**Fundraising** --> **Categories**), simply click the green **Add Categories** button.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4j08iEMmA1bpDbbpFj9XF-20260209-145134.png?format=webp "Document image")

When selected, you will be able to add:

-   Category Name

-   A Confirmation Email Notice (for this Category)

-   Make Public or Admin Only

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/hKPwyggWyntTnrrGuJCTO-20260209-145015.png?format=webp "Document image")
