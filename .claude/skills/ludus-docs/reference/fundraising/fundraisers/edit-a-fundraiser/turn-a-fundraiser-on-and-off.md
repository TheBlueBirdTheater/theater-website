# Turn a Fundraiser On and Off

If you wish to turn a fundraiser on or off, you can do so easily.

1.  Go to **Fundraising** (at the top of your account).
    
2.  From here, go to **Fundraisers**.
    
3.  Select **More** (next to the **Fundraiser**) -> Select Turn **On** (or **Off**) in the dropdown.
    
    If a fundraiser is turned off, you will see a red pop-up that says "Off". You can also select this to turn it back on.
