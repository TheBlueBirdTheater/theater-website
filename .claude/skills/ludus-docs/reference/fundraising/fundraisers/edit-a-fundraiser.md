# Edit a Fundraiser

Once the Fundraiser has been set up, there might be a need to make some alterations. To edit a Fundraiser, navigate to **Fundraising** --> **Fundraisers** --> **More -**\-> **Edit** (next to the desired Fundraiser).

_Suggested Article_: [Create a Fundraiser](https://support.ludus.com/create-a-fundraiser)
