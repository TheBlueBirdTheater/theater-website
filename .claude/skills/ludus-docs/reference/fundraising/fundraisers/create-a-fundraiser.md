# Create a Fundraiser

To create a new Fundraiser, navigate to **Fundraising** --> **Fundraisers**. Click **New Fundraiser**.

This will take you to a screen where you set up all of the details for the Fundraiser. See below for more details about each section.

### Basic Info

-   **Fundraiser Name** - The name of your Fundraiser. This is how it will appear on all public and internal pages.

-   **Cover Graphic** - This is the image that will appear on your Fundraiser's main donation page. The recommended size is 600 x 250 pixels

-   **Description** - Add text, graphics, videos, and more to share what your Fundraiser is about.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/eEIHMLdLHR3UV9dRLy3Le-20251007-154819.png?format=webp "Document image")

### Goal

-   **Public Goal Display -** Display the dollar amount donated, the number of donations, or hide the progress bar completely.

-   **Goal Amount** - The dollar amount of your fundraising goal.

-   **Deadline** - When you'd like this Fundraiser to end.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CqFlptaD1dMEI2ERYlp1V-20251007-154916.png?format=webp "Document image")

### Additional Options

-   **Ticket Buying** - Allow patrons to route their donation to this fundraiser at checkout.

-   _Suggested Article_: [Display Fundraiser at checkout](https://support.ludus.com/display-fundraiser-at-checkout)

-   **Donation Levels** - Display Donor Levels on the Fundraiser instead of a single "Donate" button.

-   _Suggested Article_: [Display Levels on a Fundraiser](https://support.ludus.com/display-levels-on-a-fundraiser)

-   **Public Donor Wall** \- Encourages donation matching and displays top donors on the fundraising page. Allows turning off the public Donor Wall.

-   If enabled, you can also opt to include full donor names on your donor wall.

-   **Require Comments** - Requires comments when contributing to a Fundraiser.

-   _Suggested Article_: [Require comments on Fundraiser donations](https://support.ludus.com/require-comments-on-fundraiser-donations)

-   **Student Credit:** Allow donors to associate their donations with a student**.**

-   **Payout Method**: Select a Payout Method.

-   _Suggested Article:_ [Add paper check payout option](https://support.ludus.com/add-paper-check-payout-option)
