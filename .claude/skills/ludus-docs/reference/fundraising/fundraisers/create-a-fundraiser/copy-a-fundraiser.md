# Copy a Fundraiser

If you wish to copy an already created Fundraiser, you will want to go through the following steps:

1.  Go to **Fundraising** (at the top of your account) -> **Fundraisers**.
    
2.  From here, go to the Fundraiser you wish to copy and select the **More** dropdown.
    
    In this dropdown, you will select **Copy Fundraiser**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/vohwsK4FMsjZVmSvAaNl3-20260330-145456.png?format=webp "Document image")
    
3.  Once opened, you will be able to update any needed information for the Fundraiser and then save.
