# Fundraisers

Fundraisers are a way to build and promote a targeted fundraising campaign within Ludus. If you have a larger, specific goal for which you need to raise funds, Fundraisers are the perfect solution.

Within Fundraisers, you can set goals and deadlines, post videos and text about why you're raising money, display photo/video updates about progress, and encourage donation matching with a donor wall.
