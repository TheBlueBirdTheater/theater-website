# Patron Facing Volunteer List and Anonymous Sign Ups

If you wish to allow your patrons to see who else is signed up for a shift, this can easily be accomplished under the Volunteer Management Settings.

### Enable the Public Volunteer List

Go to **More** (at the top of your dashboard) -> and select **Volunteers** in the dropdown.

Once there, select **Settings** (at the top of the screen).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Tt78i3NkhE79-uOoyv9WV-20251022-125854.png?format=webp "Document image")

This will open up the Settings, and from here you will be able to select to allow the **Public Volunteer List.**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CZlEaD3zutpGJWV2-7j8V-20251022-125927.png?format=webp "Document image")

Once that is enabled, the patrons will be able to view those sign-ups under the Opportunities when registering to volunteer.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6uph73OibVahiXdN8NntB-20251022-130254.png?format=webp "Document image")

### Anonymous Sign Ups

If a patron does not wish to have their name show, this can easily be accomplished on the admin or the patron site. There are a few options for how to do this:

1.  The patron can elect to be anonymous during the registration process:
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/lGhMFPUOKpkMDFnF8YXAN-20251022-130352.png?format=webp "Document image")
    
2.  The patron can elect to be anonymous after registering by going to their shifts (**Volunteer** on the patron site -> **sign in** -> select "_shifts_"):
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fSNjPy9DEO8OLYwCXwsgn-20251022-130451.png?format=webp "Document image")
    
3.  The account admin can also do this by going to **More** (at the top of your account) -> select **Volunteers** in the dropdown -> and selecting the **Volunteers** next to that **Opportunity**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ZrRRZC5juEOtB3lSAgqjd-20251022-130759.png?format=webp "Document image")
    
    From here, the account admin can select to change the patron's status to anonymous on the public-facing list.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KERq1EGdr3pmWii5QCznR-20251022-130847.png?format=webp "Document image")
