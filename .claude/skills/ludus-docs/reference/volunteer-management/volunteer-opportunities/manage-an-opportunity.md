# Manage an Opportunity

In addition to setting up your volunteer opportunities, you can manage them from the **Opportunities** tab.

Each Opportunity has its own dashboard, which provides the following information:

-   Number of Volunteer Slots Filled for all shifts of this opportunity

-   Number of upcoming shifts

-   Required Roles, and the ability to edit the roles

-   Ability to add a shift.

-   Report on the opportunity

-   The ability to sign up new volunteers for the opportunity, as well as remove volunteers from a shift.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CiTWxSRdymU1nVNkSxSa0_ludus-manual-admin-2024-06-11t082440291.png?format=webp "Document image")

_**Under the More Dropdown (next to the Opportunity and on the dashboard), you can access:**_

-   Turn On/Off (enable and disable the opportunity)

-   Messages (send a message to the volunteers)

-   Requests (review sign-up requests for the opportunity)

-   Roster (view all volunteers)

-   Share (link and QR code to sign up)

-   Notices (additional information for the opportunity)

-   Edit (adjust the settings)

-   Archive (remove from the Opportunities live page)

Each of these items can also be accessed through the **Options** dropdown next to each available Volunteer time and the overall volunteer event under **More**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/A1snU-ygEuwjuYfczECuE_ludus-manual-admin-2024-06-11t082543434.png?format=webp "Document image")

### Turn the Opportunity On/Off

This simple button lets you turn the Opportunity **On and Off** at any time.

**Messages** include the ability to message all volunteers.

### Messages and Automated Reminders

**Messages** include the ability to message all volunteers.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/2MIexJflaGLAuBX_QA4I5_screenshot-2024-03-05-at-30909-pm.png?format=webp "Document image")

**Automated Reminders** can be set up under the Opportunity Settings.

This can be found under **More** (next to the Opportunity) -> **Edit** -> **Additional Options.** This can also be accessed when setting up the Opportunity initially.

You can add multiple reminders (for example, 10 days, 5 days, and 1 day before the event). Additionally, you can include a custom message that will go out with that!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/VLYrUY7djgl1de4RJuDs5-20251205-144129.png?format=webp "Document image")

When you open the **Edit** tab, you can adjust the settings for the opportunity.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1NtlAmwVufaVL3BLjlCwQ-20251106-165927.png?format=webp "Document image")

### Archive

When choosing to **Archive** an Opportunity, this will remove it from the "live" opportunities page. You can still access the information, but it will not be live for sign-ups.
