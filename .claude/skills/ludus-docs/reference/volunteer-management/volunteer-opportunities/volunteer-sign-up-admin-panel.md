# Volunteer Sign Up - Admin Panel

At any time, you can add a new signup for any of your opportunities. Similar to the New Order button on the Events page, New Signup allows the admin to sign up a volunteer at any time. Additionally, you can sign up multiple volunteers under one primary volunteer (instead of signing each volunteer up individually).

To do this, go to **More** (at the top of your account) -> **Volunteers** -> **Opportunities**.

From here, you can select **Sign Up** next to the opportunity you wish to set up a patron/volunteer for.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Na7iGG-msSrchoC3NbdXg-20251120-150018.png?format=webp "Document image")

At this point, you will select the role for the Volunteer.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WE2a4Hfh6DsO6vQK5TK9A-20251120-150101.png?format=webp "Document image")

Once selected, you will be prompted to enter the volunteer information. You can either search for an existing patron/volunteer or enter their information.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/arAjc9sULw9MTWNmtJ318-20251120-150227.png?format=webp "Document image")

Once this is completed, you will be able to proceed with assigning roles to the volunteer and their associated volunteers.

If they have signed up an additional person before on the patron site, or you have signed someone up for them, these volunteers will show as possibilities under that initial Volunteer.

Be sure to assign the correct volunteer to the correct role (or add a New Volunteer), and then you can proceed to complete the sign-up process.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/xJZ0eMtiOTdypZCbvGzei-20251120-150515.png?format=webp "Document image")
