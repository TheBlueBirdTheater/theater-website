# Import Volunteers

You can import volunteers from the Volunteers page in Volunteer Management.

### Import a list of Volunteers to your account.

1.  From the top navigation bar, select More, then Volunteers.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-YeZMEKCpvQn6rR2V_041z-20250618-192319.png?format=webp "Document image")
    
2.  Select the Volunteers Tab from the lower navigation. Then click Import Volunteers.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/eNVQafTKmp92-pf_BVLtm-20251120-154458.png?format=webp "Document image")
    
3.  On the import page itself, there is a sample of how the CSV must be laid out that you can download to use, as well as a list of the proper headers to use on the CSV file. Use either the CSV file or the list of headers to format your CSV file for upload. Any columns that don't contain any data should be removed from the CSV before upload.
    
    While the email field is the only field required for an import, if a record is imported with only the email, the volunteer that was imported will look blank. The volunteer will exist as an approved volunteer, but will not show a name (only email). When that volunteer signs in to their account, they will be forced to add contact information, and at that time, the system will automatically create or connect their patron profiles.
    
    Roles do not have to be defined prior to import. You can simply type the name of the role into the Role fields.
    
    [volunteers\_example.csv](#)
    
4.  Once you have a CSV file ready to import drag it into the import field and click Continue to scan the document.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YHAGMdD3lHdzpvoBnJFGR_ludus-manual-admin-2024-05-20t152442232.png?format=webp "Document image")
    
5.  After clicking **Continue**, the file will be scanned, and some data pulled into the importer. Review all the columns to verify that the ones you are using are paired with the matching columns in your CSV file.
    
6.  Select whether you want to update patron records or not update patron records upon import. (updates names/addresses/phone, etc. if selected to update)
    
7.  Once all columns are matched up and you have selected to update or not update records. Click **Import**.
    

When importing, the hours the volunteer has worked will be included in reporting as well.
