# Manually Log Volunteer Hours

Volunteer hours can be logged to a volunteer profile without being tied to an opportunity.

### Recording hours to a volunteer profile:

1.  Search for the volunteer from the **All Volunteers** page. Optionally you could also search using the search box on the top navigation bar, or by looking them up in **Patrons-> Database.**
    
2.  If using the Volunteers Page, simply click on the volunteer's name to open the profile.
    
    If using the search bar: Click to select the patron's Volunteer Profile.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-18u-bbzi3kpN4GqFPc2H6-20240808-160301.png?format=webp "Document image")
    
3.  Click the Log Hours button.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/FAtLdveGaNHdAEH-B86oP-20251120-154638.png?format=webp "Document image")
    
4.  Fill out the form that appears and save it to record the hours.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-ByYbvPSAt2pivYLWe5Oej-20240808-160719.png?format=webp "Document image")
    
5.  After Saving the hours will be added to the activity screen for the volunteer.
    
    ![Document image](https://images.archbee.com/y_yS_sVZWor_q35Q4f09J-e6AM4zg_dRSRh4co0b9Bg-20240808-160858.png?format=webp "Document image")
