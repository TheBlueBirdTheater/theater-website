# Manage Volunteers

Managing your volunteers is easy in Ludus and can be handled simply through the **Volunteers** tab.

To navigate to management, go to **More**, on the top navigation --> **Volunteers**, then select the **Volunteers** page.

_The_ _**Volunteers**_ _page provides the following:_

-   A list of all of your volunteers.

-   The ability to edit the roles they can select from.

-   The ability to archive a Volunteer who is no longer active.

-   The ability to send messages to one or more volunteers.

-   The ability to send a request to serve a specific shift/opportunity to one or more volunteers

-   The Ability to Add a New Volunteer.

-   Sort the list by the roles they are authorized for.

-   The ability to edit a volunteer's information

-   The ability to Archive and View Archived/Denied Volunteers.

-   The ability to import volunteers.

A banner will appear when you have volunteers to review and approve or deny.

### Send a Request to Serve

Requests to serve sends your selected volunteers a message asking them to cover a shift that you have selected.

A request to serve can be sent by all Admin levels.

To send a Request to Serve

1.  **Select** the volunteer or volunteers to send the request to by selecting the checkboxes next to each person you wish to send the request to.
    
2.  Click the **Request to Serve** button.
    
3.  Select the opportunity from the pop-up, as well as which shift, or all shifts if there is more than one.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gfOeff_tyPBaVRbjNL9yK_ludus-manual-admin-2024-06-14t090339783.png?format=webp "Document image")
    
4.  Click Continue.
    
5.  You will be taken to the opportunity that you set the request for. Here you can select other volunteers to contact if desired, then click **Next** at the bottom of the page.
    
6.  A new pop-up will appear in which you can write a message to send to the selected volunteers.
    
7.  Click to send your message.
    

### Send a Message

You can message any or all volunteers by selecting the checkboxes next to the people you want to contact, then clicking Send Message. This will open a pop-up where you can compose a quick message to send.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/e2KRxG5CSkJwso87OiufT-20251120-151937.png?format=webp "Document image")

Messages can be sent by all User levels.

### Edit a Volunteer's information

You can edit a volunteer's information by clicking Edit next to the volunteer's name on the Volunteer roster.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/IOAMuNQVxd-X-VIeMFBwK-20251120-152109.png?format=webp "Document image")

A pop-up will then appear for you to edit the volunteer's information.
