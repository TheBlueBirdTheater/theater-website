# Volunteer Requests

The Volunteer Requests area is where you can manage your volunteers. The Requests screen is where you can approve **Shifts**, **New Volunteers**, **Hours,** and **Roles**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/1T5S8Tzm-6X8ENrG68n6v-20251120-150838.png?format=webp "Document image")

Anytime a patron is added as a volunteer (by the admin or when they sign up) they will receive an email notification. The same is true if they are imported into the system as well.

## Functions of the Requests Screen

### New Volunteers

Here you can review new volunteer applications and then approve or deny applicants. There is also a selector to filter the view on this page between New Requests, Denied or Approved.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fyxY7zT9-3KFZ9OBu4at1-20251120-151011.png?format=webp "Document image")

When you review the Application, you will be able to edit the roles that were applied for and approve or deny the request.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/seOp8L83yO_oQH5YUmwMv_ludus-manual-admin-2024-06-14t083608103.png?format=webp "Document image")

If you undo an Approval for a New Volunteer, you will need to assign roles after approving the volunteer. To do this, click on the Volunteers Tab and then click Edit next to the volunteer, edit the roles drop-down, and save.

### Shifts

The Shifts page is where you will approve or deny shifts that volunteers have signed up for, if you do not have Auto Approvals of shifts turned on.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Q5s65i9iySjJ70N-QxJ5N-20251120-151405.png?format=webp "Document image")

When you review the Application, you will be able to edit the roles that were applied for and approve or deny the request.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/seOp8L83yO_oQH5YUmwMv_ludus-manual-admin-2024-06-14t083608103.png?format=webp "Document image")

If a volunteer has been denied for their shift, go to the dropdown that says "New Request" and instead select **Denied**. From here, if a message was sent to the volunteer for the denial, you will be able to hover over the "i" and view this information.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6EwjZzPaMn8SFDk04_r5I_screenshot-2026-08-20-at-122533-pm.png?format=webp "Document image")

### Roles

The Roles tab shows any volunteers requesting approval for that role (unless auto-approval is turned on).

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/0m38bun_Ce1OwvIq3XHbu-20251120-151506.png?format=webp "Document image")

### Hours

If Auto Approval of Hours is not enabled, the Hours page lets you approve or deny Hours worked after a shift.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/ktOPX7bhz82nb-UUp2d4S-20251120-151603.png?format=webp "Document image")
