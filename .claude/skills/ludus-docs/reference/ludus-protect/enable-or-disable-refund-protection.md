# Enable or Disable Refund Protection

Ludus Protect is an option that you can enable or disable on an event-by-event basis. By default, Ludus Protect will be turned on for a new event.

### To enable/disable this feature:

1.  On the main **Events** tab, find the event you'd like to edit and click **More** --> **Settings**. \*This same page can be reached when setting up a new event by clicking **+Add Event**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/kpGJafTfvbUo2YZAQDEbp_screen-shot-2024-01-23-at-112853-am.png?format=webp "Document image")
    
2.  Scroll down to the section titled "Refund Protection." To have this option enabled for patrons, click **Yes**. To disable it, click **No**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/9L3qfspVQ1hLg8tHUxlfJ-20251020-134950.png?format=webp "Document image")
    
3.  Click **Save Settings**.
