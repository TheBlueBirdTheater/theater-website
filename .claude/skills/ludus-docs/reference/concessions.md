# Concessions

Concessions will allow you to sell concessions and merchandise in person using a mobile device or tablet.

## What can this feature help with?

The Concessions feature in Ludus was created to make selling extra items (like concessions or other merchandise) convenient and easy for you, especially during intermission breaks or at the start of your events.

## Why use this feature?

This feature has been a massive boost for many groups, as you cannot only handle concession purchases but also accept donations during that process.

## What makes this feature so special?

Ludus was built for the performing arts by people who care about them, and we want to make your life easier. The Concessions feature in Ludus has so many amazing extras, including:

-   It gives you the ability to sell, manage, and update products

-   It streamlines the payment process for "other" items

-   Manage inventory and the different items you sell

-   Collect tips, generate reports, & more — all in one place

-   Send receipts by print or digitally

-   Connect Concessions sales to patron profiles for a full sales picture

-   Track different groups selling within the same organization (like theatre, music, dance).

## So how does this feature work?

The Concessions Feature is not a premium feature in Ludus, so it is available to everyone without the premium fee upgrade. Simply navigate to the feature (either on the app or your admin panel), and you will be able to start selling those extra items!

## How do I start using Concessions?

Want to start selling? There are 2 ways to accomplish this:

1.  Via the **Admin Pane**l, under **Concessions** -> **Sell an Item** (at the top of the screen).
    
2.  Additionally, you can sell items via the app. To find out more about how this process works, be sure to check out [Concessions and the Ludus Mobile App](https://support.ludus.com/concessions-and-the-ludus-mobile-app)
