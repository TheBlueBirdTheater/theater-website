# Redeem Gift Cards

Using a gift card as full or partial payment is done by entering the gift card code into the Gift Card redemption field on checkout and clicking apply.

### Apply a Gift Card on the Patron Site

Patrons can redeem a gift card by adding the code to the Gift Card Field on the checkout screen before adding any other payment method.

1.  Enter the code in the **Gift Card** field and click **Apply**.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-5EZ39Fi7WWWCYZcsrkMLM-20250428-194246.png?format=webp "Document image")
    
2.  Select the items you wish to apply the gift card towards. Note that you can only apply one gift card per item. Gift Cards are applied on an item level, not an order level. A second gift card can be applied if there are more items that it can be applied to. Click **Apply** once you select the items you wish to redeem the Gift Card. It does not have to be all the tickets/items in the order.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-i81LrJT_Up16QjW8WHLQc-20250428-194316.png?format=webp "Document image")
    
3.  After applying the gift card, the checkout can be completed. Any outstanding amount or donations will be collected on the checkout screen.
    

### Apply a Gift Card on the Admin pages

1.  Gift Cards can be applied on the checkout screen for admin orders. Expand the Gift Card option, enter the code, and click Apply to do this.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-c1lrgA32wSaX5HoIFUmss-20250428-194358.png?format=webp "Document image")
    
2.  Select the items to apply the Gift Card to by checking the boxes. As you apply the gift card, the available balance shown will decrease in amount.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-cuqc83kle_DiawnvKy2BG-20250428-194416.png?format=webp "Document image")
    
3.  Click Done to apply the amount from the card. If there is any additional amount due, that amount will be prompted for payment in the cart.
