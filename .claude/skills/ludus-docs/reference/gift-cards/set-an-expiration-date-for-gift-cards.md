# Expiration dates for Gift Cards

When getting ready to sell your gift cards, you might wish to set an expiration date for them. This can easily be accomplished via the Gift Card Settings tab, which allows you to select the time frame for which the purchased/issued gift cards are good.

## Setting an expiration date

To set an expiration date, you will want to:

1.  Go to **More** (at the top of your admin panel) -> **Gift Cards**.

2.  Once there, you will want to select **Settings** (next to **+New Gift Card**).

3.  Once in Settings, you can see the option to set the **Expiration** in the dropdown from Never up to 60 months.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-0FXBA_Ux8ehi4_6-dq8EE-20250428-191531.png?format=webp "Document image")

Be sure to **Save** once selected, and that expiration date will apply to each purchased gift card.
