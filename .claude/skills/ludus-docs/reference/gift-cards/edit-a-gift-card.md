# Edit a Gift Card

Updating or correcting certain information on a gift card once it is sold is possible.

The following items can be updated on a gift card:

-   **Code**: The code auto-generated by Ludus can be changed to be customized prior to use. Once used partially the code cannot be changed.

-   **Customer Details**: Information on the Sender and receiver can be updated.

### Steps to edit information on a gift card

1.  Locate the gift card from the **Gift Cards** page under **More** on the top navigation page.
    
2.  Click the code next to the gift card you would like to update.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-uPA-lCvFPlIKE8PFovsn_-20250428-191826.png?format=webp "Document image")
    
3.  The gift card order will open. From here, you can click the edit icon (pencil) next to the code to change it. You can also click the Edit Customer Details link to update the sender or receiver information.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-G1ARg7a7SWf5cFUfcK21s-20250428-191728.png?format=webp "Document image")
    

The ability to edit these fields is dependent on your User level and accessibility settings.

Once a gift card is partially used, it is not possible to edit the code.
