# Disable a Gift Card

The Gift Card function makes it easy to disable a gift card (make it no longer accessible) at any time.

To accomplish this, you will want to:

1.  Navigate to gift cards by clicking **More → Gift Cards.**

2.  Once there, **select (click on) the code** for the Gift Card you wish to disable.

3.  When that code is selected, you will be brought to that particular card's gift card purchase page. From here, you can select the Disable button at the top. This will disable that gift card only and make it unusable in the future.
