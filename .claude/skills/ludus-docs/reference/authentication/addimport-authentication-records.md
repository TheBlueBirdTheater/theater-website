# Add/Import Authentication records

When adding Authentication records, you can do so individually or import an entire spreadsheet. Read through the corresponding drop-down menu below for specific instructions.

### Add a single record (Manual)

To add a single record:

1.  From the top navigation bar, click **More** --> **Authentication**.
    
2.  Click **+Add Record**.
    
3.  Fill in each field for the new record. All fields are required except for "Grade".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/koXgdRwXaSG4G1U5kwLEk_screenshot-2023-11-21-at-44457-pm.png?format=webp "Document image")
    
4.  Click **+Add Record** to finish.
    

### Import records in bulk (CSV spreadsheet)

Before you can upload, you will first want to organize your records into a CSV file or Excel sheet. Each bit of information (ID, email, first name, last name, grade) will need to be in its own column. Each row will represent an individual record. For more information about what information is needed for an Authentication record, check out this article.

_Suggested Article_: [What information is needed for an Authentication record?](https://support.ludus.com/what-information-is-needed-for-an-authentication-record)

**Example Spreadsheet Columns:**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/amAOjsAvd1IqDXqZR7lft_screenshot-2023-11-20-at-43634-pm.png?format=webp "Document image")

**Once you have your list created and saved:**

1.  Navigate to **More** --> **Authentication** from the top navigation bar.
    
2.  Click **Import**.
    
3.  Drag your file to the grey area or click the space to choose a file from your computer. Click **Continue**.
    
4.  Use the drop-down boxes to make sure the columns match up to the desired import area (i.e., email to email and Auth ID to Auth ID)
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/AwG5msE9S8OP3Wf_l9dzn_screenshot-2023-11-21-at-44239-pm.png?format=webp "Document image")
    
5.  Click **Import**.
