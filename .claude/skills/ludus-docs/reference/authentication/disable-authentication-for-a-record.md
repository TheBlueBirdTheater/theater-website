# Disable Authentication for a record

You may have a situation where you need to block Authentication access to a specific record. Maybe they are on academic probation and unable to attend the event. Whatever the reason, it is very simple to disable and re-enable access for a specific record.

**To disable access:**

1.  From the top navigation bar, click **More** --> **Authentication**.
    
2.  On the main hub, use the scroll or the search bar to locate the record for which you'd like to remove access**.**
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/nB6UBZ59rCgiHG8eQcZ9u_screenshot-2023-11-20-at-52659-pm.png?format=webp "Document image")
    
3.  Click **Disable** for the record that should have access removed.
    
    You can re-enable access at any time by clicking **Enable** next to a currently disabled record.
