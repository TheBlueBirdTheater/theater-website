# Set up Authentication ticket types

With events that have Authentication enabled, there are three different types of tickets.

-   **Student Ticket** - The authenticated record purchasing a ticket for themself.

-   **Student Guest Ticket** \- The guest of the main student, who must also be an authenticated record in your system.

-   **Outside Guest Ticket** - The guest of the main student who is not an Authenticated record in your system.

To complete the purchase, an Authentication ID must be entered for any of the ticket types mentioned above. Outside Guest Ticket types cannot make a purchase independently and must have an Authenticated record to enter their number before purchasing.

You can collect additional information for any of the ticket types, like name, school, and grade of an outside guest. To do so, attach a form to the ticket price. _Suggested Article_: [Attach a Form to a Ticket Price](https://support.ludus.com/attach-a-form-to-a-ticket-price)

You can control which types you make available for purchase. If you don't allow outside guests, you do not have to set up that ticket type.

To set up Authentication ticket types:

1.  Next to the event title, click **Pricing** -> **Ticket Prices.**
    
2.  Click the **\+ Ticket Price** button and choose the name and price for your ticket
    
3.  Under "Authentication," choose the type of ticket that you'd like.
    
    (If you don't see the Authentication Ticket Type options like in the screenshot below, ensure that you [Enable Authentication on an Event](https://support.ludus.com/enable-authentication-on-an-event)).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/HX42OhZH-83cF4LmTkMmO_screenshot-2023-11-21-at-43201-pm.png?format=webp "Document image")
    
4.  Continue choosing the setting for your ticket. _Suggested Article_: [Ticket Prices](https://support.ludus.com/ticket-prices)
    
    You will likely want to limit the number of tickets that a particular Authentication record can purchase. To do so, be sure to set a "Limit Per Patron" on each ticket type you set up.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/hBUoxmYp1iTpM7NcaJ_-f_screenshot-2023-11-21-at-43759-pm.png?format=webp "Document image")
    
5.  Once you've set up your ticket prices, you can verify everything looks good by going back to your **Events** tab and clicking the **New Order** button next to your event. Here you should see something similar to the below, where it asks for an ID.
