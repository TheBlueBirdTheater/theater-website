# Enable Authentication on an Event

Authentication is an optional feature within Ludus that allows you to restrict ticket access to those with a valid Authentication ID. Common events that utilize Authentication include prom, graduation, and other school-hosted functions.

Please reach out to Customer Support to have Authentication enabled on your account.

This will restrict access to only individuals with records that you have previously uploaded to your account and will be valid for the entire duration of ticket sales. If you are looking to use codes to give early access to ticket purchases, please check out the Access Codes feature.

_Suggested Article_: [Access Codes](https://support.ludus.com/access-codes)

Once you have uploaded your Authentication records, you will want to set up an event with Authentication enabled. To do so:

1.  Begin adding your event as you would normally. _Suggested Article_: [Add an Event](https://support.ludus.com/add-an-event)
    
2.  From the Event settings page, click **Additional Options** at the bottom of the page.
    
3.  For "Authentication," check the box for "Require Authentication for this event".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/cmujuRcwJtaIMSAdy85N1_screenshot-2023-11-20-at-54117-pm.png?format=webp "Document image")
    
4.  _Optional_: Restrict which grades have access to this event by checking the box for "Limit Authentication to specific grades" and entering the grade number(s) that have access.
    
    Grade numbers must be added as a comma-separated list without any spaces.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/zTYrWJd_qTwQNM00L03RW_screenshot-2023-11-20-at-54336-pm.png?format=webp "Document image")
    
5.  Click **Continue** to continue with the event setup.
    

After choosing your event settings, you will set up Authentication ticket types. For more information about the options for Authentication Ticket Types, check out this article.

_Suggested Article_: [Set up Authentication ticket types](https://support.ludus.com/set-up-authentication-ticket-types)
