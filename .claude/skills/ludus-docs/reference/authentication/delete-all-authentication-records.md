# Delete all Authentication records

Whether you are in a new school year or simply want to start from scratch, you can mass-delete your current list of Authentication records from your admin panel. This will work for all records in your database. To disable access for a specific record, check out the following article.

_Suggested Article_: [Disable Authentication for a record](https://support.ludus.com/disable-authentication-for-a-record)

Please note that this action is permanent and may not be reversed.

To delete all Authentication records on your account:

1.  From the top navigation bar, click **More** --> **Authentication**.
    
2.  Click **Settings** at the top of the page.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WPq2g79liKHKMkcOxy9KR_screenshot-2023-11-20-at-51703-pm.png?format=webp "Document image")
    
3.  For "Delete Authentication Records", click **Delete All Records**.
    
4.  Type "DELETE" in the text box provided to confirm, and click **Continue** to confirm.
    
    This action is irreversible and permanent. All current Authentication records for your site will be deleted.
