# What information is needed for an Authentication record?

If you are utilizing the Authentication feature, four different pieces of information are required before you can upload a record.

-   **Authentication ID (Required)** - The identification number that is connected to the record. This is the number they will enter to unlock access. Each record must have a unique ID. E.g., "12345678"

-   **First Name (Required)** - The first name of the record. E.g., "Miles"

-   **Last Name (Required)** - The last name of the record. E.g., "Bright"

-   **Email (Required)** - The email associated with the record. E.g., "m.bright@school.com"

-   **Grade (Optional)** - The grade of the record in number. E.g., "11" If you attempt to import a record without an Authentication ID, first name, last name, or email, the record will fail to import.

If you attempt to import a record without an Authentication ID, first name, last name, or email, the record will fail to import.
