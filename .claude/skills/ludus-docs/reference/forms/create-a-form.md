# Create a Form

Ludus offers a fantastic way to track additional information from your patrons and that is through Forms. Forms can be created in Ludus and attached to multiple items, like ticket prices or an event. The first step to collecting this additional information is creating the Form.

## Set up your Form

1.  Log in to your Ludus admin panel and navigate to **More** → **Forms** in your top navigation.
    
2.  Select the **Create New Form** button → name your form → and click **Create Form**.
    
3.  Under _Add New Field,_ click the field type you want to include. The various field types are:
    
    -   Text: short answer text field
    
    -   Checkboxes: multiple answer checklist
    
    -   Dropdown: single answer dropdown
    
    -   Paragraph: long answer text field
    
    -   Multiple Choice: single answer selection
    
    -   File Upload (including):
    
    -   jpeg
    
    -   png
    
    -   gif
    
    -   pdf
    
    -   csv
    
    -   xls / xlsx
    
    If using the "File Upload" Form Field, the maximum size that can be uploaded is 10 MB.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/_Ik2AGPYTPCvO0IDzZl1K_screen-shot-2024-02-21-at-95015-am.png?format=webp "Document image")
    
4.  Under _Label_, change the title of the field → add a description → and adjust your options.
    
    Fields can be marked as required.
    
    Labels are required and must have a unique name.
    
5.  Duplicate your fields and delete fields using the + / - buttons.
    
6.  Click **Save Form** when you are done, as this will save the Form and make it available to attach to various items on your admin panel.
