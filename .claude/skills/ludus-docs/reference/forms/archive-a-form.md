# Archive a Form

In addition to copying forms, you can choose to archive a form if needed. Archiving a Form can be helpful to clean up your Forms page, but it is also great if there is a Form that you no longer need but wish to have access to in the future.

### To Archive a Form, you will want to:

1.  Start by going to **More** (at the top of your admin panel) -> **Forms**.

2.  Select the three dots (next to the Form) -> **Archive.**

3.  Once selected, you will get an "**Okay**" pop-up; you will want to select Okay to process the Archive.

4.  When you have finished archiving, you can always view those forms under **View Archived Forms** (at the bottom of the Forms page).
