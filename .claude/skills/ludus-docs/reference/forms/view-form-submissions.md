# View Form Submissions

# View Form submissions

While collecting information is essential, being able to view that information is crucial. Through Ludus, you can easily view and export your Form submissions and data via the Forms tab.

## Locating your form using filters

If you have many different forms, you may find filtering helpful for quickly locating the exact form you want.

### You can locate it either by:

1.  Searching for the form name in the **Search Box**

2.  Select the form by using the **Used By** drop-down to select the Event, Collection, or Class using that form by name.

## View and Print Submissions

To view and print or export your Form Submissions, you will want to:

1.  Go to **More** (at the top of your admin panel) -> **Forms**.
    
2.  Next to the Form, select the **Submissions** button.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/TdkkE94Ss47NlbNAKapVp_screenshot-2026-06-22-at-21056-pm.png?format=webp "Document image")
    
3.  Once there, you will be able to select the event that the form was used for (as well as applicable times) and click **Apply.** You can now use the dropdown to choose which event times you want to view.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/WuSYwBY5Lg9OglaAXzvF9-20260608-154123.png?format=webp "Document image")
    
4.  Once the time is selected, you will see all available information populate, along with the ability to **export it as a CSV** or **print** it.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/raJZtl585yP6wGFU0Y_Zx-20260608-154318.png?format=webp "Document image")
    
5.  If you choose to print, you will be prompted to print the submissions as either a **Per Page** or a **Table View** (depending on which is needed).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/Cz1Lrqf9L_RrE8qpDhukR_screenshot-2026-06-22-at-21328-pm.png?format=webp "Document image")
