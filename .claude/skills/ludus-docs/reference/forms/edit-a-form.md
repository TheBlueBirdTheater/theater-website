# Edit a Form

If at any point you need to edit your Form, whether it's adding a new dropdown to something like "How did you hear about us?" or removing a field, this can easily be accomplished!

### To edit the Form, you will want to:

1.  Go to **More** (at the top of the admin panel) -> **Forms**.

2.  From here, you will select the three dots (next to the Form) -> **Edit**.

3.  Once in the Form, click (select) the block you wish to edit. When you do this, you will see that section's information pop up on the left.

4.  From here, you will edit, and all changes are automatically saved and applied to the Form.

If you want to duplicate a field or remove it, when you select that block, you can duplicate it with the "**+**" or remove it with the "**\-**".
