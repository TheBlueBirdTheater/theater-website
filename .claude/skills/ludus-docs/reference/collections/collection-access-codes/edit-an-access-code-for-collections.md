# Edit an Access Code for Collections

To edit an existing Access Code, navigate to **Collections** --> **Standard**. Then, next to the Collection title, click **Options** --> **Access Codes.**

Next to the Access Code you'd like to edit, click **Edit**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/gOCxEnVAoTh0b2IXVhkX-_edit-an-access-code-for-collections-archbee-document.png?format=webp "Document image")

Make any desired changes, then click **\+ Add Access Code** to save.

To learn more about the different settings available on a Collection, check out our article about creating an Access Code.
