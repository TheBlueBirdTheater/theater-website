# Copy Access Codes from another Collection

If you'd like to reuse Access Codes from a previous Collection, Event, or Class, you can easily copy them over. Check out the instructions below to see how it's done!

1.  Navigate to **Collections** --> **Standard**.
    
2.  Next to the title of the Collection, click **Options** --> **Access Codes**.
    
3.  Click the bar that says **Copy Access Codes from another Collection**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/IR8F3zaRCkejgADnZtUkX_copy-access-codes-from-another-collection-archbee-document.png?format=webp "Document image")
    
4.  Choose with Collection/Event/Class from which you'd like to copy the Access Codes.
    
5.  Choose which code(s) you'd like copied over and click the **Copy** button. _Tip_: Click **Select all** to easily highlight all codes.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/tuF58Q-W7hBLiDyWOkYCX_copy-access-codes-from-another-collection-archbee-document-1.png?format=webp "Document image")
