# Limit usage on Access Codes for Collections

You might have a scenario where you'd like to limit the use of a specific Access Code. Check out the steps and tips below to learn how to achieve this!

1.  Navigate to **Collections** --> **Standard**.
    
2.  Then, next to the desired Collection, click **Options** --> **Access Codes**.
    
3.  To set a limit on a new Access Code, click **\+ Access Code** in the top right corner. To set a limit on an existing code, click **Edit** next to the desired code.
    
4.  Next to "Type," click the circle for **Individual/Family**. Now the code will only be able to be used once and can not be shared or passed around.
    
5.  If you'd like to further limit the code and restrict how many Fees they can select with this Access Code, check the box for "Allot number of fees to this code" and enter the desired cap.
