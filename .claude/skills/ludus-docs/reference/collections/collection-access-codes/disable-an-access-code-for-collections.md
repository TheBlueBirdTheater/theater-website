# Disable an Access Code for Collections

### Disable all Access Codes

When you are ready to remove all Access Codes, you can toggle off the Access Code feature on a Collection. To do so, navigate to **Collections** --> **Standard**. Then, next to the title, click **Options** --> **Access Codes**. Ensure that the toggle bar is not green and the circle is on the left side.

### Disable individual Access Codes

To remove one Access Code while keeping the other in place, navigate to **Collections** --> **Standard**. Then, next to the title, click **Options** --> **Access Codes**. Then, next to the code you'd like to disable, click **Disable**.

You can reinstate any Access Code by clicking **Enable** from the list of disabled codes.
