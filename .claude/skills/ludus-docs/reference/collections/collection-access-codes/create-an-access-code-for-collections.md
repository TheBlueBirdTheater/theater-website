# Create an Access Code for Collections

To create an Access code for a Collection, check out the steps below!

1.  Navigate to **Collections**\--> **Standard**.
    
2.  Next to the desired Collection, click **Options** --> **Access Codes**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/K5q8PNS_9L7QrggVKdzov_ludus-manual-admin-2024-06-06t112412934.png?format=webp "Document image")
    
3.  Click the green **\+ Access Code** button.
    
4.  Choose whether this is a "generic" Access Code or an "individual/family". "Individual/Family" is recommended when you limit the number of times this code can be used.
    
    _Suggested Article_: [Limit usage on Access Codes for Collections](https://support.ludus.com/limit-usage-on-access-codes-for-collections)
    
    -   **Generic** — given to everyone with no limit to the number of fees/tickets purchased; typically, one code is given to multiple people.
    
    -   **Individual/Family** — This is given to a specific individual/family with a set number of tickets they can purchase (e.g., they are allotted 4 tickets and no more).
    
5.  Type the actual code that will be used by the patron(s). Click **Generate random code** to have the system create one for you.
    
6.  _Optional_: Choose a reference text for future reference. This is useful when you have multiple Access Codes for different groups.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/fWJnJ-p7DfUBQvTfj-vpG_screen-shot-2023-08-17-at-115228-am.png?format=webp "Document image")
    
7.  Click **\+ Add Access Code** to save.
    

Creating Access Codes does not automatically enable them as a whole. To turn on Access Codes and passcode protect your Collection, make sure to enable the toggle at the top of the Access Codes page.
