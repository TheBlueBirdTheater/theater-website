# Sort Fees for a Collection

By default, Fees on a Collection will be sorted by price (high to low) however, you may wish to sort them in a custom order. To do so, navigate to **Collections** --> **Standard**. Next to the desired Collection, click **Pricing** --> **Fees**. Then, select **Sort Fees** from the top menu.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-hHEmeHTwn5v-2qEEHEYHZ-20250328-183240.png?format=webp "Document image")

Then, drag the fees into the desired order and click **Save Sort**.
