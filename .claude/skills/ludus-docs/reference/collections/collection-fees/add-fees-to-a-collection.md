# Add Fees to a Collection

When you first [Add a Collection](https://support.ludus.com/add-a-collection), you will input the various names and settings and then be automatically taken to a screen where you can add Fees. The steps below will also walk you through how to add a Fee after the fact.

1.  Navigate to **Collections** --> **Standard**.
    
2.  Next to the desired Collection, click **Pricing** --> **Fees**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/4xk5i5QKOYRHs4zPIC94Y_ludus-manual-admin-2024-06-06t111634883.png?format=webp "Document image")
    
3.  Click the green **\+ Fee** button.
    
4.  Fill out the applicable information.
    
    To learn more about each setting and what is possible, check out this article. _Suggested Article_: [](https://support.ludus.com/settings-for-collection-fees "https://support.ludus.com/settings-for-collection-fees")[Settings for Collection Fees](https://support.ludus.com/settings-for-collection-fees)
    
5.  Click **Done**.
