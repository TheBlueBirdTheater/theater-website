# Delete Fees on a Collection

To delete a Fee that has been created, navigate to **Collections** --> **Standard**. Next to the desired Collection, click **Pricing** --> **Fees**. You can then click **Delete** next to the fee you'd like to remove.

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-gJ__kEeJhRHagEf0hfhvW-20250328-183338.png?format=webp "Document image")

Deleting a Fee is a permanent action. However, this will not affect any prior sales of a particular Fee.
