# Edit Fees on a Collection

To edit an existing fee, navigate to **Collections** --> **Standard**. Next to the desired Collection, click **Pricing** --> **Fees**. You can then click **Edit** next to the fee you'd like to alter.

To learn more about Collection Fees settings, check out this article.

_Suggested Article_: [](https://support.ludus.com/settings-for-collection-fees "https://support.ludus.com/settings-for-collection-fees")[Settings for Collection Fees](https://support.ludus.com/settings-for-collection-fees)

![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-iODmqA-UqwxU9gCVdN659-20250328-183201.png?format=webp "Document image")

Once a fee has been sold to at least one patron, you will be unable to alter the price. To change the price of a specific item after it has been sold, create a new fee and remove the existing one.
