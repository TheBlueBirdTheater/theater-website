# Settings for Collection Fees

This guide covers all settings and terminology related to Fees on Collections. Check out each section below to learn more.

### Basic Info

-   **Name**: The name for the fee that the public will see.

-   **Price**: The price the patrons will pay.

-   **Allow Patrons to enter a custom price**

-   : Checking this allows patrons to set their own price for the collection item. This also changes the Price field to be a Minimum price accepted.

-   **Description**: An optional bit of text that describes what the fee is.

-   **Limit Per Patron**: Limit how much of this fee a patron can purchase overall.

-   **Access**: Limit who has access to this specific fee.

-   **Custom Fee**: Add a custom fee to this price.

### Advanced Options

-   **Total Inventory**: The total number available before this specific fee "sells out".

-   **Special Passcode**: Entering a code here will make this specific fee "unlocked" before it can be selected.

-   **Form**: If they select this specific fee, ask additional questions beyond name, email, phone number, and address.

-   **Availability**: Choose when this particular fee becomes available/ends.
