# Archive a Collection

You can archive a Collection once it is finished or if you wish to remove it from view.

To do so, navigate to **Collections** --> **Standard**. Next to the desired Collection, click **Options** --> **Archive**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/USq7DVrSyOp1epa_5RHJK_archive-a-collection-archbee-document.png?format=webp "Document image")

### View Archived Collections/Recover

If you'd like to view an archived Collection, navigate to **Collections** --> **Standard**. Then, scroll to the bottom of the page and click **View Archived Collections**.

If you need to recover an archived Collection and bring it back to the main Admin panel, simply follow the instructions above, locate the desired Collection, and click **Options** --> **Recover**.
