# Sort Collections

If you have multiple Collections at one time, you may wish to sort them into a custom order. To do so, navigate to **Collections** --> **Standard**. Then, click the **Sort** button from the top.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/YjFEuAnN8Ak6-i8z69Kp-_ludus-manual-admin-2024-06-06t111414072.png?format=webp "Document image")

Drag the Collections into the desired order and click **Save Sort**.

This will affect the order in which they appear for both the Admin Panel and the public patron view.
