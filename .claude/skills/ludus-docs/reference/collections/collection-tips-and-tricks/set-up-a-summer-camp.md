# Set up a Summer Camp

If you are looking to set up a Summer Camp in Ludus, there are a few different ways to do this.

The [Invoicing](9W67EbgHL7ATKvxuMf7LI) feature in Ludus is a great tool/resource to check out when setting up Collections/Classes as a Camp!

### Set up a Camp with Standard Collections

To set up a Camp in [Collections](https://support.ludus.com/collections) :

1.  Go to **Collections** (top of your page) -> **Standard** \-> **+ Add Collection.**
    
    Be sure to set your Payment Deadline to the Camp date, OR when the fee needs to be paid by.
    
2.  Once created and **Continue** is selected, you will be prompted to set up the **Fees** for the camp.
    
    This is a great spot to create an "_**Admin Only**_" fee, if you have Scholarship or Comp fees you want to create!
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-1XmgzXwLGgFY0FAVgI4Ga-20250211-161055.png?format=webp "Document image")
    
    
    
3.  Once your Fees are saved, be sure to go to **Options** (next to the Collection) -> **Turn On**!
    

### Set up a Camp in Classes

To set up a Camp in [Classes](https://support.ludus.com/classes) :

**Note** - Classes is a _Premium Feature_ in Ludus. Check out [How much does Ludus cost?](https://support.ludus.com/how-much-does-ludus-cost) to see the pricing table and how this will affect your fees on Ludus.

1.  Go to **Collections** (top of your page) -> **Classes** \-> **+ Add Collection.**
    
2.  Fill in all the setup information, then select "**Continue**" at the bottom of the page.
    
    Once this is selected, you will be prompted to set up **Fees**.
    
    This is a great spot to set an "_**Admin Only**_" fee if you have Scholarship or Comp fees to create!
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-1XmgzXwLGgFY0FAVgI4Ga-20250211-161055.png?format=webp "Document image")
    
3.  Once your Fees are saved, you will be brought back to the main Classes tab. From here, you can select to **Add Class Times**.
    
    When adding these times, you will want to set them up as a **Single Time** (not recurring).
    
    It is recommended that this time be set up for the last date of the class, BUT you can use Subtitles to show the entire run of the Camp (see below):
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-6lvrqk_I7HcQGoQG51qoY-20250211-162107.png?format=webp "Document image")
    
4.  Once all Camp times are added, you are able to select **Options** (next to the event) -> **Turn On**, and your Camp will be live!
