# Raffles

While there isn't a "Raffle" section in Ludus or a way to generate raffle tickets, you can charge for those tickets and track those sales via the Collections portion of your Ludus account.

### Selling Raffle Tickets on Ludus

1.  Go to **Collections** (at the top of your account) -> Select **Standard**.
    
2.  Once there, select **\+ Add Collection**.
    
3.  When creating the Collection, you can fill in all the details needed for your Raffle. Be sure to save by clicking "**Continue**" once finished.
    
4.  Once the Collection is set up, you can create **Fees** (cost of the tickets) under **Pricing** (next to the Collection) -> **\+ Fee.**
    
    When adding Fees, you can choose what works best for you. For example:
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-wMP_MN-CrNFFrBRa0cVXV-20250114-154202.png?format=webp "Document image")
    
5.  Once prices are saved, you can start selling tickets using New Order next to the Collection.
    
    While Ludus _**will not generate ticket numbers**_, you can leave the Raffle turned off and use it to sell tickets (cash or credit).
