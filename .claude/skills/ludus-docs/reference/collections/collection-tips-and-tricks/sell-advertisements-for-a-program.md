# Sell Advertisements for a Program

You might be looking for the ability to set up sales for advertising space in your program, which can be easily done in **Collections**.

Be sure to read through [Collections](https://support.ludus.com/collections) if you have not yet.

### Set up Advertisement Sales

1.  Under **Collections** -> **Standard**, you can select **\+ Add Collection**.
    
2.  Once set up, be sure to select **Continue**. When selected, this will bring you to the **Fees** portion of the setup process.
    
3.  The **Fees** section is where you can show the various Ad sizes and their availability.
    
    For example, if you have _Full Page Ads_ available, you can set those up at your specified price and quantity.
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-E2r_UBVgzMMrWcxOVRIxl-20250210-184822.png?format=webp "Document image")
    
    ![Document image](https://images.archbee.com/-Wjcg2-gpBfUKvBZQaMyV-OIoaOwhXCALxi4pU3QXfv-20250210-184836.png?format=webp "Document image")
    
4.  Once you have all of your ad sizes and prices saved, be sure to set your Collection to On (under **Options** next to the **Collection** -> **Turn On**).
    
    Your fees might look something like this, once they are all entered (under **Fees** next to your event):
