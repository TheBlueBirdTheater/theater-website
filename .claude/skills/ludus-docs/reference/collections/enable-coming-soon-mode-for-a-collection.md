# Enable Coming Soon mode for a Collection

You may wish to display that a Collection is coming up soon without opening up sales quite yet. Coming Soon mode is a great solution to achieve that.

To enable Coming Soon mode, navigate to **Collections** --> **Standard**. Then, next to the desired Collection, click **Options** --> **Settings**.

Scroll down to the section titled "Additional Options." Where it says "Coming Soon," click the circle next to **On**. Click **Save Changes**.

### How it will appear for patrons

Once Coming Soon mode is enabled, patrons will now see the below display message. Please note that this will not affect your ability to make a sale from the Admin Panel.
