# Edit a Collection

To edit a newly created collection, navigate to **Collections** --> **Standard**. Then, next to the desired Collection's name, click **Options** --> **Settings**.

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/qtWyUpKMdEs25YMhTbkYX-20260519-155215.png?format=webp "Document image")

You will then be taken to the main setup page, where you can change settings as needed. To learn more about each section, check out this article.
