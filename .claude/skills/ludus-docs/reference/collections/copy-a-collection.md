# Copy a Collection

To copy a created Collection, navigate to **Collections** --> **Standard**. Then, next to the name of the desired Collection, click **Options** --> **Copy**.

Ludus will automatically make a copy and take you to a screen where you can alter details that make this Collection distinct. Be sure to click **Continue** at the bottom of the page to save your new Collection.
