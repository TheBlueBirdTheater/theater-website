# Add a Collection

To create a new Collection:

1.  From the top navigation bar, click **Collections** --> **Standard.**
    
2.  Click **\+ Add Collection**.
    
3.  Enter the Basic Info, Files, Form, and Additional Options fields as needed. The descriptions below provide more information about each field.
    
4.  Click **Continue** to save and begin the steps of adding fees to your Collection. _Suggested Article_: [Add Fees to a Collection](https://support.ludus.com/add-fees-to-a-collection)
    

### Basic Info

-   **Collection Name**: The public name for your Collection. This will be visible to your patrons.

-   **Cover Graphic**: The graphic that will appear above your Collection listing on the patron-facing side. Recommended size 600x250 pixels

-   **Payment Deadline**: The date and time by which patrons need to pay.

Patrons will not be able to pay online after the deadline has passed. However, admins will still be able to process payments internally.

### Files

-   **Files**: A file that purchasers will be able to download after successful payment. (Optional) This file has a 2MB size limit.

### Form

-   **Form**: These are additional questions (outside of the standard name, email, phone number, and address) for your purchasers. You can either choose an existing form or create a new form. To learn more about Forms, check out this article.

_Suggested Article_: [Forms](https://support.ludus.com/forms)

### Additional Options

-   **Waitlist:** Allow patrons to join the waitlist once this collection sells out.

-   **Waitlist Limit**: Limit the number of registrations that can be requested by a party.

-   **Waitlist Expiration**: Choose how long a patron will have to claim their spot after an admin grants them their requested registrations.

-   **Waitlist Queue**: Public or Private. Allows patrons to see what position they are in on the waitlist.

-   **Waitlist Form**: A custom form can be added to fill out when joining the waitlist.

-   **Waitlist Notice**: This is an optional message that the patron can see when they join the waitlist. It will override the global waitlist notice for this collection.

-   **Registration Limit**: A cap on the number of registrations before the Collection will be "sold out". _Suggested Article_: [Place limits on a Class](https://support.ludus.com/place-limits-on-a-class)

-   **Payout Method**: Allows selecting a custom payout name & address if payment should go to a different club/group. It will be set as your Primary payout address by default. (Only present when using Checks as your payout method)

-   **Convenience Fee**: Choose whether you'd like to pass on convenience fees to patrons or absorb them.

-   **Exempt Order Custom Fees**: This option allows you to exempt this collection from any order-level custom fees that you may have set up.

-   **Coming Soon**: Display a "Coming Soon" message that prevents patrons from purchasing now. This does not affect sales from the Admin Panel.

-   **Invoice Me as Payment Option**: Allows patrons to request an invoice.

Suggested Article: [Invoice Me](https://support.ludus.com/invoice-me "Invoice Me")
