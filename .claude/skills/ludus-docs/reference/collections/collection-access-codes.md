# Collection Access Codes

Access Codes allow you to passcode protect your Collection so only those with a valid Access Code can unlock it and select Fees. You can create a generic Access Code or individual Access Codes for different patrons and groups.

Check out the articles below to learn more about managing Access Codes.

[Create an Access Code for Collections](https://support.ludus.com/create-an-access-code-for-collections)

[Edit an Access Code for Collections](https://support.ludus.com/edit-an-access-code-for-collections)

[Disable an Access Code for Classes](https://support.ludus.com/disable-an-access-code-for-classes)

[Limit usage on Access Codes for Collections](https://support.ludus.com/limit-usage-on-access-codes-for-collections)
