# Message all purchasers for a Collection

You may wish to send an email to all purchasers of a specific Collection. Check out the steps below to send such messaging!

1.  Navigate to **Collections** --> **Standard**.
    
2.  Next to the desired Collection, click **Options** --> **Messages**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/GCGtHDRa6vU_-PjtFnk6w_message-all-purchasers-for-a-collection-archbee-document.png?format=webp "Document image")
    
3.  Click the green **\+ Message** button in the upper right-hand corner.
    
4.  Choose whether you'd like to send a standard or automated message.
    
    Standard messages are best for quick text-based emails you wish to hit send on immediately.
    
    Automated messages are best for more intricate, scheduled emails sent based on the Event Time/Class Time.
    
    The rest of these instructions will be for a standard message. To see how to set up an automated message, check out this article.
    
    _Suggested Article_: [Create an Email Automation](https://support.ludus.com/create-an-email-automation)
    
5.  After clicking **Standard**, type in the subject of the email, place any content in the body, and click **Send Message**.
