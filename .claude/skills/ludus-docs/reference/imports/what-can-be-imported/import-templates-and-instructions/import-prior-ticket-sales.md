# Import Prior Ticket Sales

Ludus can import your ticket sales history from your prior ticketing system. This is generally done during onboarding. However, it can be done at any time. This type of import is completed by the customer support team for you.

Once imported, your sales will be reportable under the **Imported Events** button on the Events page.

The following information is needed to complete the import:

-   **Event Name** - (Required).

-   **Time** - (Required) The date and time of the event are formatted as such: 2024-08-01 19:00:00

-   **Ticket Price** - (Required) The face value of the ticket. Do not include the $ in the field.

-   **Ticket Name**\- (Required). Adult, Student, Senior, etc.

-   **Seat** - (Optional) Full seat number. Include the section if you use those as well.

-   **Patron Email\*** \- (Optional)

-   **Actually Paid** \- (Optional) The amount paid for the ticket

-   **Purchased Date** - (Optional) The date of purchase for the ticket.

\*The Patron Email field ties the ticket sale to the patron profile. It is an optional field unless you want to attribute sales to specific patrons; then you would need this information.

All columns must be labeled as listed. Additionally, please be sure that:

1.  The format must be a CSV.

2.  The CSV needs to be per event (only one event per CSV).

3.  This should be finalized data (no refunds, exchanges, etc.)

Once events are imported, you will be able to view and report on them from the Imported Events area.
