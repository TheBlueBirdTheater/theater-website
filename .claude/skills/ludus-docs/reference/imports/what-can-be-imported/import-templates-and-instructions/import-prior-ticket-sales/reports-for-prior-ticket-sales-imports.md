# Reports for Prior Ticket Sales Imports

Once your prior ticket sales have been imported, you can easily view that information whenever needed.

_**This can be located by:**_

1.  Going to **Events** (on your Ludus admin panel).
    
2.  Scroll to the bottom of your Events page and select **Imported Events** (next to Archived Events).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/s_G9bYhMFW2K_4QXL1yZh-20251007-143010.png?format=webp "Document image")
    
3.  Once selected, you will be brought to a page containing all imports. Each event time report can be viewed under **View Report** (next to that time).
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/TVrOyUiTmJHs0KWT_Xx_n-20251007-143322.png?format=webp "Document image")
    
4.  From here, you can view a variety of Reports associated with those imports.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/XKkA098GrNo0ikIUbjWJx-20251007-143425.png?format=webp "Document image")
    
    See [Events Report](https://support.ludus.com/events-report) for more information on each of these reports.
