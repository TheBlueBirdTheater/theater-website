# Import Prior Gift Card Sales

If you will be utilizing the Gift Card feature in Ludus, outstanding balances can be imported from your prior system as part of your data imports when switching over to Ludus.

This type of import is completed by the client services team on your behalf.

More information on Gift Cards can be found here: [Gift Cards](https://support.ludus.com/gift-cards "Gift Cards")

The following items can be imported for gift cards:

-   **Code**: (Required) The code to be used to redeem the gift card. This can be the same code used by your old system or a new code. Codes must be unique.

-   **First Name**: The recipient's first name

-   **Last Name**: The recipient's last name

-   **Email**: The recipient's email address.

-   **Amount**: (Required) The original amount of the Gift Card

-   **Balance**: (Required) The amount remaining of the Gift Card.

### FAQ's for Gift Card Imports

-   **How can I add expiration dates?** Expiration dates for gift cards are set in the Gift Card settings. Gift cards are imported as being issued on the date of import. So any expiration date you select for gift cards would apply from the import date.

-   **Are patrons notified when Gift Cards are imported?** No, currently when imports of gift cards are performed your patrons are not automatically emailed. It is possible to email your patrons if and when you wish to do so by opening the Gift Cards screen and then clicking on the gift card and then selecting to resent the confirmation email. If you were to use the same codes from your prior system, you could notify your patrons that the old codes have been added to Ludus and that they can redeem them as desired.
