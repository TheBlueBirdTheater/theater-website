# What can be imported?

Several items can be imported into your Ludus account. Some items can be imported by you directly, and others will require assistance from the customer service team.

## Admin Importable Items

The following can be imported directly without needing assistance:

-   **Patrons:** This is done in **Patrons,** under **Database.**

-   _Recommended Article:_ [Importing Patrons to Ludus](https://support.ludus.com/import-patrons-to-ludus "Importing Patrons to Ludus")

-   **Students:** This is done in the Student settings.

-   _Recommended Article:_ [Import Bulk List of Students](https://support.ludus.com/import-bulk-list-of-students " Import Bulk List of Students")

-   **Patron Tags:** This is done as part of a Patron import. You can import up to 15 tags at a time to a patron record. Additional tags can be imported via a secondary import using the same patron information with new tag information.

-   _Recommended Article:_ [Patron Tag Manager](https://support.ludus.com/patron-tag-manager-crm "Patron Tag Manager ") 

-   **Bulk patron updates:** If you import patron information using the same email that is currently present on the patron record, data such as Address, Phone number, etc. will be updated on the existing record.

-   **Patron Properties:** Additional properties that are created can be imported via the Patron Import.

-   _Recommended Article:_ [Import Properties](https://support.ludus.com/import-properties "Import Properties")

-   **Authentication Codes:** Used for dances/proms, etc

-   _Recommended Article:_ [Add/Import Authentication records](https://support.ludus.com/addimport-authentication-records "Add/Import Authentication records").

-   **Volunteers:** Volunteer profiles can be imported from a prior system, including roles, with a CSV/.

-   _Recommended Article:_ [Import Volunteers](https://support.ludus.com/import-volunteers "Import Volunteers ") 

-   **Mailing List Signups:** You can add patrons to a Mailing list in Bulk via the Audience import in Marketing.

### **Specifics about Access Codes**

Imports for Access Code currently have the following options available when importing:

-   **Access Code**

-   **Reference Text** (internal note)

-   **Total tickets**

Access Code imports currently do not allow setting specific event times. If the Total Tickets column is used in the import, the access code will be set as Individual/Family. If that column is empty, then the access code will be set as Generic.

### **Specifics for Flat Rate and % off Discounts**

Imports of this type have the following settings available when performing the import:

-   **Code**

-   **Flat Amount or % off amount**

-   **Flat Type -** only used on flat amount discounts.

-   **Total Available -** This is the total inventory of tickets for this code**.** Leave as 0 if there is no limit to the total number of tickets this code can be used on.

-   **Ticket Limit -** This is the total number of tickets (Per Patron or All) that the code can be used on. (**You must use Ticket Limit Type if you use this**)

-   **Ticket Limit Type -** Use '**all**' if the discount code should expire after being used on that many tickets in total across all orders. Use '**patron**' if it's a shared discount code amongst multiple patrons (per patron).

-   **Global -** used to create a global discount across events**.** Set it to 1 if this is a global discount.

-   **Global Shows** \- Used to assign which events the discount works on when it is a global discount.

If you plan to use global discounts and global shows, please reach out to support for additional information on these items.
