# Overview of Thermal Printing

Having quality, professional tickets that you can give to patrons when they purchase tickets at your box office is always a nice option. Fortunately, Ludus makes thermal printing easy and fast!

If you're unable to buy a thermal printer, no worries! By default, you can print tickets to normal 8.5 x 11 sheets of paper. _Remember_, besides a computer with an internet connection and a web browser, there is no required equipment to use Ludus!

When Thermal Printing is enabled in your account for printing via devices like Boca and STIMARE, there are multiple options for you to choose from:

-   **Basic Printing - Thermal (5.5 x 2)** — This uses your browser's built-in print dialog to print tickets directly to your thermal ticket printer, ideal for standard 5.5x2-inch ticket stock. [Learn more about Basic Printing - Thermal (5.5 x 2)](https://support.ludus.com/basic-printing-thermal-55-x-2 "Learn more about Basic Printing - Thermal (5.5 x 2)")

-   **Basic Printing - DYMO** — this uses your browser's built-in print dialog to print tickets directly to a DYMO 450 printer.

-   **Direct Thermal Printing** — for thermal printing using FGL, you'll install a program called QZ Tray that allows Ludus to communicate directly with your thermal printer to send the FGL commands.

## FAQ's

### Which Thermal Printers are supported?

Ludus offers thermal printing integrations with:

-   **Boca**

-   Website: [https://www.bocasystems.com/](https://www.bocasystems.com/ "https://www.bocasystems.com/")

-   Recommended Printer: Lemur-S

-   As a Ludus user, you are eligible for a discount with Boca

-   **STIMARE**

-   Website: [https://stimare.net/products/desktop-ticket-printers/](https://stimare.net/products/desktop-ticket-printers/ "https://stimare.net/products/desktop-ticket-printers/")

-   Recommended Printer: STIMA CLS

-   As a Ludus user, you are eligible for a discount with STIMARE

-   **DYMO 450**

-   Note: DYMO has discontinued DYMO 450 and blocked support for 3rd party ticket stock/labels in their new models.

-   The DYMO 450 printer is supported but not recommended if you're looking to purchase a new thermal printer.

If you have a different thermal ticket printer, let us know, and we'll be happy to see if it'll work with Ludus. Most of the time, if the printer supports FGL for printing, it'll work.

Thermal ticket stock can be purchased under **More -> Supplies** Shop in your Ludus account.

### How do I enable thermal printing on my account?

If you'd like to enable thermal printing, navigate to **Settings** (⚙️ in your top navigation) _**→**_ **Advanced** _**→**_ "Thermal Printing". By default, this will enable the "Basic Printing - Thermal (5.5x2)" option to print using your browser's print dialog.

If you'd like to enable FGL thermal printing for your Boca via a direct connection using QZ Tray, contact Ludus support with the operating system you'll be printing from (Windows or Mac), and we'll send you instructions.

If you'd like to enable thermal printing for your DYMO, navigate to **Settings** (⚙️ in your top navigation) _**→**_ **Advanced** _**→**_ enable "Thermal Printing -> enable "DYMO Printing".
