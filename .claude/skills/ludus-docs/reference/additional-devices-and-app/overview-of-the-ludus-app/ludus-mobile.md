# Ludus Mobile

"**Ludus Mobile**" is an all-in-one app that combines ticket scanning and Mobile Reader payment capabilities.

Users with **Full Admin** access can easily view sales reports directly on the app. This way, you can conveniently track ticket sales from your phone or tablet.

Additionally, First-time users are guided through selecting a showtime to get started quickly!

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/G7xqmndH3JIi7hqtySFEP_img-0787.jpg?format=webp "Document image")

**Minimum iOS Version Needed** - 17.5

**Minimum Android Version Needed** - 8.0

When logging into the app, if someone is also logged in with those same credentials, you will receive the a message letting you know. This will show as the following pop-up:
