# Add payment device

If you have purchased one of the compatible [Mobile Readers](https://support.ludus.com/mobile-readers) or [Standard Terminal BBPOS WisePOS](https://support.ludus.com/standard-terminal-bbpos-wisepos), you will want to be sure to add the device to your Ludus account.

To add a payment device:

1.  Click the **Settings wheel icon** (⚙️) in the upper right-hand corner of your admin panel.
    
2.  Navigate to the **Payments** tab.
    
3.  Click **+Add Payment Device**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/3_XytEw3H2Z1yn7N6Ed5g_screen-shot-2023-09-06-at-92526-pm.png?format=webp "Document image")
    
4.  Insert the name and location of your organization.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/aWKLmR5aGET73vxOtDptY_screenshot-2023-09-19-at-32956-pm.png?format=webp "Document image")
    
5.  Click **Continue**.
    
6.  Choose the type of device that you are setting up.
    
7.  Follow the on-screen instructions for the given device.
