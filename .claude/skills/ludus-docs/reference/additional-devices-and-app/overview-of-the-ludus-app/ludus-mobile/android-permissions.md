# Android - Permissions

On Android, the app is going to ask for permission to make and manage phone calls. The app **will not** need to make calls, it is just the permission we need to determine their cellular service strength so we can display a banner when you have a poor connection.

This is an update that comes from Android so we cannot adjust the pop-up.
