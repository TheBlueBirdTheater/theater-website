# Basic Printing: Tickets printing backwards.

We have heard from some Windows users using basic printing that when printing the tickets appear to be printing backward, with the stub printing on the wrong side of the ticket.

### To fix this in Windows:

1.  Chose the navigation path for your computer's operating system:
    
    -   **Windows 11** - from the Desktop, select the **Start menu** > **Settings** > **Bluetooth & devices**. Then, select **Devices and Printers**.
    
    -   **Windows 10:** From the Desktop, select the **Start** menu > **Devices** > and scroll down to **Devices and Printers**.
    
2.  Click on your Boca printer that is setup for basic printing, and then select **Printer Properties.**
    
3.  Click on **Preferences**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/KZ-ApPWLMDQdxi4Sqzo1b_rundll32-hyrvoj27td.png?format=webp "Document image")
    
4.  On the printing preferences window click **Advanced**.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/DSvG9Gy8M6uje1PVVFVLx_rundll32-j4l18n9cg7.png?format=webp "Document image")
    
5.  On the advanced options locate **Pages per Sheet Layout** and change to Right then Down.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/X0UUvo0TJn33E4uQTYp5V_rundll32-icshfvz59i.png?format=webp "Document image")
    
6.  Click **Ok**. To save the setting. The ticket should now be printed with the stub information on the correct end of the ticket stock.
