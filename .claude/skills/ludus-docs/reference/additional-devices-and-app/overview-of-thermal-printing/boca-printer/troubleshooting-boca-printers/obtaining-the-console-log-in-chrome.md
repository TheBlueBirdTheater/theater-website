# Obtaining the Console Log in Chrome

If you are contacting support for assistance with a potential issue, you may be asked to provide information from the Console Log within Chrome as part of troubleshooting.

These logs will often provide key data as to the problem and be helpful in resolving the issue.

As an example, if you are having difficulty with a Standard Terminal, the console logs will normally show the error it is having connecting, as well as give links to resources for fixing the issue.

### Open the Console Log:

When you encounter an error message in Ludus, you can obtain the console log by one of the following methods:

-   **Windows**: Press **F12** on your keyboard or **Press Ctrl + Shift + J**

-   **Mac**: Press **Cmd+Opt+J**

This should be done on the screen where something is not working in Ludus or where you are getting an error message. **This will open a window like this:**

![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/CUjPsFW1Rc1W5HCJI6_8m_guthqqwupb.png?format=webp "Document image")

Errors that the Console catches will be in Red. You can copy and paste those errors into your chat/email with support if asked for them.
