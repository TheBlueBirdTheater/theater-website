# Boca Setup for Windows

This is for setting up _**Boca printing on Windows**_!

Looking for setup on a Mac? [Click here](https://support.ludus.com/boca-setup-for-mac "Click here")

When thermal printing is enabled on your account, you'll have access to the "Basic Printing - Thermal Printing (8.5 x 11)" option, which uses your browser's print dialog.

If you'd like to have a direct connection with FGL commands, you'll need to set up the Boca as a raw printer and download the QZ Tray application — this allows Ludus (a web-based system) to communicate directly with your printer through your web browser, giving fast and seamless printing.

1.  Plug your Boca in. If the driver isn't automatically installed, ensure you download the Boca driver from their website: [https://bocasystems.com/repairs.html](https://bocasystems.com/repairs.html "https://bocasystems.com/repairs.html") (under Printer Drivers)
    
2.  Set up your Boca as a raw printer. Here are the instructions for Windows: [https://qz.io/wiki/setting-up-a-raw-printer-in-windows](https://qz.io/wiki/setting-up-a-raw-printer-in-windows "https://qz.io/wiki/setting-up-a-raw-printer-in-windows")
    
3.  Lastly, download the QZ Tray software here (v2.2.0 or higher): [https://qz.io/download](https://qz.io/download "https://qz.io/download")
    
4.  **Let the Ludus team know you have your Boca set up as a raw printer and are ready to have direct thermal printing enabled on your account.**
