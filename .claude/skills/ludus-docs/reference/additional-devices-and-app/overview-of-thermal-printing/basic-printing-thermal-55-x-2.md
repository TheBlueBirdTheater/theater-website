# Basic Printing - Thermal (5.5 x 2)

When you have [Thermal Printing](https://support.ludus.com/overview-of-thermal-printing "Thermal Printing") enabled on your account under **Settings (⚙️) -> Advanced**, you'll gain access to the default print option called "Basic Printing - Thermal (5.5 x 2)" which uses your browser's print dialog to print tickets.

## **What you'll need on your end**

-   Ensure the driver for your printer is installed. Most newer printers will automatically install their drivers once you connect to the printer, while older ones may not. Ludus cannot provide you technical support for how to install printers on your computer. Here are some popular ones:

-   Boca: [https://www.bocasystems.com/repairs.html](https://www.bocasystems.com/repairs.html "https://www.bocasystems.com/repairs.html") (under "Printer Drivers")

-   STIMARE: [https://stimare.net/drivers](https://stimare.net/drivers/ "https://stimare.net/drivers")

-   Contact your printer company if you are unsure on how to install your printer.

-   When you go to print, you'll want to ensure the correct **5.5 x 2** paper size is selected.

-   This may also be listed as a "Concert Ticket" in your system.

-   **Recommended browser:** Google Chrome

-   Google Chrome offers the most flexibility when it comes to print and respects the dimensions Ludus sends when you print. We cannot guarantee this will work in Firefox, Safari, or Edge.

-   **Print Orientation**: ensure your printing preference for the printer is set to _Landscape_.

-   On Windows, navigate to "Devices & Printers" -> right-click on your Boca -> and select "Printing preferences" and here apply "Landscape".

-   On Mac, you'll set the orientation in the print dialog.

-   **Backward printing**: depending on where you're printing from, sometimes we'll see a Boca print these tickets backward. To fix this, look up the instructions for your printer and how to set the device's orientation.

-   On a Boca: press and hold the MENU + CHOICES button on the side of the printer which will bring up the "Factory Settings" menu -> use the MENU button to scroll down the list until you get to "Orientation" -> press the CHOICES button -> press the CHOICES button again to scroll down and select REVERSE -> press TEST button to save. If the printer is still printing backward, try the other option for orientation.

## How to print

Once you [sell tickets via your admin panel](https://support.ludus.com/sell-tickets-to-an-event "sell tickets via your admin panel"), you can print directly on the confirmation screen where you'll see a **Print** button.

If you'd like to print existing tickets, you can do this via any ticket list whether that is under **Options** -> **Ticket List** next to an event time or by [looking up an existing order](https://support.ludus.com/look-up-a-past-order "looking up an existing order").

To show you what it looks like to print tickets, let's assume you are printing from a ticket list and thermal printing is enabled in your account:

1.  Select the tickets from the list you'd like to print.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/6mlpIVANRqeXgnbM8QqcI_basic-printing-thermal-5-5-x-2-archbee-document.png?format=webp "Document image")
    
2.  Above the list of tickets, click the dropdown and select **Print selected tickets** which will display another dropdown -> in this dropdown, select "Thermal (5.5 x 2)". Click the **Submit** button when ready to print.
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/raFtzcHSX9c2rLU73LwpI_screen-shot-2024-04-11-at-12717-pm.png?format=webp "Document image")
    
3.  A new screen will appear which will open your browser's print dialog (like below). Here you'll want to ensure a few things:
    
    1.  Have your thermal printer selected. In this example, we have the Boca selected that is installed on the computer.
    
    2.  Set the Paper Size to **5.5 x 2 in** (may also appear as a "Concert Ticket"). If this is not available, it's possible your printer was not installed fully OR you'll need to create a custom paper size for your printer — we recommend ChatGPT'ing (or Googling) how to create a custom paper size on your specific computer.
    
    3.  Ensure the Margins and Scale are both set to "Default".
    
    ![Document image](https://images.archbee.com/hZcZIA5As4EsukOh0OMVE/UC7Xqp9EStdAB2WaO7fDe_screen-shot-2024-04-11-at-12814-pm.png?format=webp "Document image")
    
4.  Click **Print** in your browser's print dialog.
