# Contributing

Thanks for helping out with the Blue Bird Theatre / Orangeburg Part-Time Players site. This is a
small, volunteer-run project — this file is short on purpose.

## Setup

See [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) for running the site locally, and
[docs/CONTENT_EDITING.md](docs/CONTENT_EDITING.md) if you're here to change copy or content rather
than code.

## Submitting a change

Open a pull request against `main`. The PR template will walk you through what's expected —
content-only changes (via Decap CMS or hand-edited `src/content/*`) are a much lighter checklist
than code changes.

The one rule that applies everywhere: never invent real show titles, dates, addresses, or contact
details — see [AGENTS.md](AGENTS.md) and
[.claude/skills/branding](.claude/skills/branding/SKILL.md) for the placeholder convention and
what's currently confirmed real.

## Reporting a bug or requesting content

Use the issue templates — [open a new issue](../../issues/new/choose) and pick "Bug report" or
"Content update or feature request."
